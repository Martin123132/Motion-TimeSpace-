# Replaying the private EROS source and coupling test

Use the saved checkout and a Python with NumPy, pandas, SciPy and PyMuPDF. The tested runtime is Python 3.13. From this folder, run `python -B replay.py`. One calculating process runs at a time, with one numerical-library thread. The launcher refuses network operations in its calculation children. It does not request remote catalogs, install a dependency or write into either predecessor. Existing products must reproduce byte-for-byte; a changed product fails rather than overwriting the record. Because exact CSV bytes include floating-point results, a different numerical library may require comparison at numerical precision in a separate copy rather than changing this seal.

Order: recover the field records from the thesis and existing image metadata; repeat the position-only matches; compare observed groups; calculate lens responses at integration orders 8 and 14; examine the rare foreground IDs; calculate the covariance-robust designs; enclose the survey-wide positional and exposure uncertainty; verify progenitor files, the cache origins/counts, native optical selection, per-source zero points, convergence, geometry and optimization. The two imaging tables for foreground candidates use cached records. Acquisition scripts are retained for provenance, not run by replay. No wheel contents are executed.

The mask distinction and astronomical assumptions are in `PROTOCOL.md` and `PARALLAX-TO-GRAVITY.md`. `verification.json` lists quantitative cross-checks and `seal.json` lists SHA-256 hashes by filename, excluding itself. Keep the two predecessor directories at their existing relative paths and their retained upstream gravity and survey dependencies accessible. The raw archive queries, bounding boxes, row counts and payload hashes are recorded per strip: `{surot,virac,gaia,gaia_ipd}-{0,1,2,3}.csv.gz.json`. See also `eros-positions.json`, `thesis-source.json`, `gaia-foreground-source.json` and `ir_acquire.py` for upstream identifiers. Do not interpret the finite geometric bounds or the withheld event outcomes as a new fit.

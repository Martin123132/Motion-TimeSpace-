# Private replay

Run in this stage with the retained Windows Python 3.13 and its installed NumPy/SciPy using -B. One numerical thread per worker; at most two workers. No network, fits to the reported comparison curves, UI, Git change or server required. All generated tables and packets are write-once or compare-only on replay. The earlier sealed source and initial stationary packets must be adjacent in their original stage directories.

1. Reproduce all population shapes and both normalizations: stellar.py, mass_convention.py. Inspect normalization-replay.csv. The source is the upstream SHA-256-pinned FITS file. No download of a new catalogue is needed.
2. Run field.py with base-catalogue, high-catalogue, finer-catalogue, high-column, finer-column and base-plummer as arguments; ring_check.py; then resolved_bank.py, and again with --graded. Run force_gate.py. Only accepted-rings.npz goes to the response. ring-controls.csv retains the initial lower-order miss at 2 kpc, outside the curve readouts. All multipole-versus-ring force results (also those exceeding 20 ppm) remain available.
3. Run resolved_response.py freeze first, then resolved_response.py CASE MODE for each of catalogue, column, mass-shape and modes calibrated, fixed, tangent; also run resolved_response.py CASE calibrated above high. Replay uses the same older parent states and the same outer calibration for both competing models. The scalar mass in the packet norm keys is dimensionless; tabular wave masses are solar masses. Predictions are fractions along the specified potential change, not cosmic times. The nonlinear scalar field includes its own change of gravity; the NFW comparator is a prescribed spherical shape, not a live collisionless model.
4. Run angular_force.py. After freezing the independently specified three radii in SPATIAL-NULL-PROTOCOL.md, run spatial_null.py freeze and then spatial_null.py test. The stellar template weights use only ring integrations, not a wave, a halo fit or the exposed circular speeds.
5. Run endpoint_refine.py LABEL COUNT ORDER for labels main and above and (256,24), (320,28), (384,32). These embed the previous converged state in a larger radial/angular basis with the same physical box for each label, then solve both the stationary equation and the original outer constraint. All use the finer stellar field. Run resolution_report.py to recompute the angular observable directly from the potential and compare the final independent endpoints and successive refinements. These tests estimate numerical differences; no theorem about infinite-volume or observational errors is implied.
6. Run gas_leakage.py with the fixed gas-source-input.csv. This is an independent direct-force calculation on the three saved points, not a new coupled solution. Each gas mass has a direct radial integral and the analytic Bessel check; two independent order/cutoff pairs check the weighted force.
7. Run verify_resolved.py replay for the saved outputs, constrained stationarity, Newton controls, nulls, exposed-data alignment, differential versus finite solves and content hashes. Initial sealing alone uses seal. Source and numerical diagnostics are not independent observations. No task-owned worker needs to remain running after replay.

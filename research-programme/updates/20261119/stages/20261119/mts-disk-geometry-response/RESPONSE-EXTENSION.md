# Extension fixed before calculating general source responses

The first disk-size families already show that one cannot transfer an infrared scale directly to the model disk. Rather than fit another foreground number, derive the linear response to *any* specified axisymmetric change of the external potential. At the unaltered a=3 packet, publish the angle/radius integration weights for the shear, vertical force and annular mass, plus the required direct ordinary accelerations and calibration term. Test a constant potential (gauge), disk size, and zero-net-mass transfers between spherical shells (12→9, 40→25, 60→40 kpc; notation from outer shell to inner shell). For 40→25 kpc do a nonlinear symmetric small-amplitude derivative check. A signed redistribution is a susceptibility experiment, not an assertion of negative density or an observed Galactic environment. A prescribed smooth halo is not a live control; it feels only the changed ordinary force and its own amplitude recalibration in this protocol.

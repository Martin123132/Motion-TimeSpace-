# Offline replay and conventions

Everything belongs in this private stage beside the sealed calibrated precursor. Use the retained Python, NumPy and SciPy with -B. No Astropy, Git, UI or server required. Existing outputs are compare-only on replay. External source fetch is not part of normal replay.

1. `python -B common_shape.py` (original and corrected shape mappings); `python -B geometry_state.py center fine-minus fine-plus half-minus half-plus short long ir-low ir ir-high stars-low stars stars-high retained-bt center-above erratum-stars-low erratum-stars-high`. A suffix "above" uses the independently continued alternate mesh and physical units. Runs from either side check sensitivity but do not prove global uniqueness.
2. `python -B threshold.py`; `python -B source_kernel.py`; `python -B shell_operator.py main above finite`. The thresholds on both comparison curves are local zeros, never fit targets. Raw, corrected, fixed-occupation and recalibrated shell responses remain separately named.
3. `python -B population_gate.py` rechecks the local authoritative FITS blob (read only). Only if acquiring it anew in a separate replay: `python -B freeze_source.py fetch`. Limits response bytes, verifies pinned Git blob plus recorded SHA-256, and never downloads or runs author code. Data source and DOI in imig-source-receipt.json. The receipt concerns acquisition; the subsequent population_gate.py separately checks the two mass conventions.
4. `python -B check_geometry.py replay` rechecks the upstream seal and files, compares regenerated summaries, verifies the package manifest. Use `seal` only during initial freeze. Files contain symmetric full solves, solved state and norm/shape tangent, complete curve predictions, direct, rearrangement and calibration terms, source/radius checks and statistical conventions. Many thousands of rows are calculations, not independent sky data.
5. To use arbitrary-source-weights.npz: for each named output sum its 2D weights times the perturbing physical potential in (km/s)² on the supplied radius × positive-hemisphere cosine points, then add the sum of its direct_mts weights times the Cartesian physical ordinary acceleration perturbation at the included positions (km/s)²/kpc. Weights include quadrature, symmetry, velocity conversion and outer-constraint subtraction. For the fixed-shape halo only its direct_nfw weights enter. Slope in km/s/kpc, Kz signed up, annulus_billion in 10⁹ solar masses. Valid only for a weak perturbation of the central disk-loaded state within the finite domain, sufficiently resolved; use integrated operators at discontinuities and a full solve for finite changes. No automatic completion of a missing formation boundary.

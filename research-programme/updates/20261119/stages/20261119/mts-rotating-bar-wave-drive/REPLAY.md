# Private reproduction and controls

Keep the predecessor stages in place. The existing Python 3.13 environment uses NumPy, SciPy, mpmath and the earlier project dependencies (including pandas). Run sequentially here with python -B, numerical threads set to one by bar_io.py. No network, new measured data, fit, or GPU is required. All generated outputs use write-once or byte-compare semantics. To inspect rather than recompute use python -B stage_seal.py. Reproduction on another BLAS/library build may give different bytes; compare numerical values in a separate copy, never replace a sealed packet.

1. Run bar_field.py with each of base, fine and extra separately, then direct_check.py. These three potential banks resolve different maximum spherical degrees and angular meshes. direct_check.py independently integrates in Cartesian directions as seen from the observation point; it does not use the source multipoles as its reference.
2. Run drive.py with each of base, fine, extra, then drive.py fine additional. Source data, the 512×40 wave states, the external calibration, gravitating masses, northern/southern comparison bands and the NFW control are read from the retained chain. The two negative endpoints supplement, rather than overwrite, the matched reference/positive cases.
3. outgoing.py arguments are LEVEL CASE PATTERN_SPEED live|test [M=2] [BANK=fine] [balance]. Each force/check receipt stem fixes the exact combination. Run the fine-bank m=2 reference refinement (pilot, radial, angular, exterior, high, far at 33.29), high test at 33.29, and reference far at 31.48 and 44. Run high live for reference, added-free2-plus, transfer-free2-plus at 31.48,33.29,35.1,38,41,44; for added-free2-minus and transfer-free2-minus at 31.48,33.29,41,44.
4. With the extra bank at 33.29 run high and far for reference and added-free2-plus over m=2,4,…,32, and more_angles for these two cases at m=2,4,6,8. Run far for transfer-free2-plus at m=2,4. Use the optional balance flag on extra-bank far m=2,4 for the three reference/positive cases and on fine-bank high reference m=2 test. This additionally projects the second-order source onto the original ground quadrature; the existing first-order results must replay unchanged.
5. Run free_check.py, then bar_decision.py and stage_seal.py. The isolated free open/closed Green check uses the same Numerov implementation with independent ordinary/modified spherical Bessel integrals; it does not load the physical galaxy solver. The paired-refinements table includes early discretizations, including failures; the absolute-value thresholds and the physical data intervals are different things. All forces in the sky/force decision tables are in 10⁻¹⁰ m/s². The far J/(N t_unit) column is a calculated outgoing rate, not observed halo loss. See DERIVATION.md for the difference between torque and mass current.
6. For the separate radial-cancellation check add the final argument green to extra-bank m=28 high and far for reference/added-free2-plus, and to far m=2 reference. At m=28 on added-free2-plus run green300 and green360 with the same green argument. Run radial_check.py. Keep the original spline comparisons; the new gravitational derivative uses independent interior/exterior Poisson integrals.
7. The seal is created once, after results and restart notes, with stage_seal.py seal. It excludes itself and the external resume pointer, verifies the complete immediate predecessor and rejects missing or additional files on later checks. It does not certify external catalogue systematics or numerical convergence of everything in the historical corpus. Original package versions: NumPy 2.4.6, SciPy 1.17.1, mpmath 1.3.0, pandas 3.0.3.

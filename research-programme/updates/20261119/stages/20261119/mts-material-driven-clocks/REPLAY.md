# Private replay

All commands are stage-relative and use the retained Python 3.13, NumPy and SciPy. Start from a fresh sibling copy of the scripts and protocols, retaining the named predecessor stages at the same relative locations. Do not rerun producers in a sealed directory. The common run module selects one numerical thread and checks the inherited owner holds. Do not use optimized Python (-O); run with -B to avoid bytecode caches.

1. Run `python -B clock_run.py freeze inputs`. For each mesh 128, 256 and charge 0, .8, run `python -B clock_run.py prediction MESH ETA empty load occupied`. Then run `python -B clock_run.py freeze forecast`.
2. For each of the same mesh/charge combinations run `python -B clock_run.py target MESH ETA empty occupied`. The original dense finite-event preparation is retained: its positive 256-cell launch exceeded its independent mass-cross-check threshold before any propagation. For the validated arithmetic repair run `python -B finite_repair.py freeze`, then `python -B finite_repair.py plus minus quiet`. These targets retain the two old/new launch discrepancies and both freeze hashes. See FINITE-REPAIR.md; do not disable the original assertion.
3. For the independently normalized dilute test run `python -B dilute.py freeze setup`. Run `python -B dilute.py prediction MESH plus minus quiet` on each of 128 and 256. Freeze with `python -B dilute.py freeze prediction` before any dilute target. Run `python -B monopole.py` for the exterior approximation. Run `python -B dilute.py target MESH plus minus quiet` on both meshes. The dense finite and dilute finite target solvers pair the occupied and the empty geometry at fixed e, not positive and negative material events. Subtract the paired quiet readout subsequently. The controlled source normalization is unchanged.
4. Run `python -B score.py create`, `python -B dilute_score.py create`, `python -B conditioning.py create`, `python -B mixed_launch.py create` and `python -B actuator.py create` exactly once. Their `check` argument instead recomputes the tables without writing. The prediction, independent target, finite events and frozen-source controls are separate numerical products; validation never converts a failed row into a passing one.
5. Put the results and derivation with the outputs, then `python -B verify.py` twice, the second time from a fresh interpreter. Existing seal verification is read-only. A different platform or arithmetic library may not reproduce bytes; investigate a mismatch, do not replace the reference seal.

Primary budgets compare the differential clock response of the occupied/empty/equal-material preparations under two independent equation implementations. The material split is a diagnostic within the predictor; the matching condition is on its sum. Dilute budgets compare a derivative **in occupation** at finite material source against fully nonlinear finite occupied-minus-empty solutions. These are deliberately different comparisons. The parent bank, fixed profiles, prior central-response history and research repositories are never rewritten by these commands.

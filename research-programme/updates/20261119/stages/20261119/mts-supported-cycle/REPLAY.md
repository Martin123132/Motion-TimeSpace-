# Replaying the private stage

From this directory run `python -B verify_cycle.py`. The verifier reads saved numerical packets and the predecessor; recomputes the histories' observables, exact static clocks, state-exclusion integrals, stationary alternatives and cross-checks; and compares to the seal. It does not re-run all eight time histories. The two target tube replays, which did re-run the finite evolutions, checked timestamps' mass and flux bit-for-bit before adding their corrected area-weighted diagnostics. No browser, downloads, other agent, service or GitHub is needed.

For a new end-to-end run, copy **only the Python and Markdown files** to a fresh sibling directory, keep the older sibling research directories in place, and use the retained Python 3.13 with SciPy and NumPy. Never overwrite the authoritative packets.
1. `python -B cycle.py init`; for each PHASE (turn, kinetic): run `python -B cycle.py prediction PHASE 128 256`, then `python -B cycle.py freeze PHASE`, then `python -B cycle.py target PHASE 128 256`. Predictor and target use different matter and mass evolution. Only these clock/motion predictions were prospectively frozen.
2. Run `python -B tube_replay.py PHASE` for each phase. Use at most two one-thread numerical jobs, one per phase. STOP-REQUESTED is honored at saved integration boundaries.
3. Run `python -B SCRIPT create` in this order: evaluate.py, observables.py, occupation_test.py, bound_state.py, source_scale.py, coarse_bridge.py, static_clock.py, mean_packet.py. The clock arrays are frequency out/echo then delays out/echo, in the earlier four-corner convention (empty, matter difference, scalar difference, mixed). Times are in Compton units; the raw target's stored diagnostic index 5 is a momentum-force conversion checked **only at launch**, not the general proper acceleration after launch. Use the velocity history for measured-cycle changes.
4. `python -B verify_cycle.py seal`; then `python -B verify_cycle.py`. The manifest includes both the first flux readout with its miss and its sampling correction. Historical normalized mode results use the saved November 7 ground state from mts-wave-state-20261107/result.json; the previous raw mismatch is not hidden.
5. The bound-state NPZs store local/SciPy piecewise-polynomial coefficients, grid, scale and energy. Read with PPoly(coeff,x,extrapolate=False). The saved quantities are u,du/dx,v,dv/dx in scaled x=r/S. The density, projected standing-field amplitude and approximate mean-to-real corrections are in bound-to-real-launch.csv. Those corrections use the Newtonian/weak-field lapse and eigenfrequency; they are not yet a fully backreacting relativistic oscillating equilibrium.

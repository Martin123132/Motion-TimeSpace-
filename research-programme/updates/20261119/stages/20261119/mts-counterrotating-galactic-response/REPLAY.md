# Replay and conventions
Use the existing local Python 3.13, NumPy and SciPy. From this folder, `python -B audit.py replay` rechecks the scientific comparisons, source chain and all stage-file digests; it does not run the long calculations. All numerical scripts request a single numerical thread. No package installation, download, release update or new fit needed.

Construction order:
- `pair.py freeze MESH COUNT CHANNELS`: (medium,64,7), (fine,100,10), (fine,168,14), (fine,256,16), (fine,384,16), (medium,256,12). MESH fixes the original ground grid; COUNT/CHANNELS specify the excited radial/equatorial basis. The largest angular degree in the excited state is 2×CHANNELS−1. Immutable prepared forecasts and norms precede all corresponding finite probes. Each uses the parent source archives, corrected stars, ground state, matched spherical control and original pointwise force signs.
- `pair.py test medium 64 7` and `pair.py test fine 168 14`. Three positive fractions for each ensemble. The smaller frozen eigensystems use direct Hermitian diagonalization. At large size eigenvectors use a preconditioned iterative solver, with independently evaluated Hamiltonian residuals and both lowest Ritz values checked. One inner eigensolver emitted a postprocessing target warning at roughly 2.1e-12 against its requested 2e-12; tested residual, self-consistency and observable tolerances passed. A repeated eigenpair calculation on the final fully occupied mode checks its ordering separately from the continuation.
- `continue_pair.py MESH COUNT CHANNELS BRANCH FIRST LAST` for (fine,384,16) and (medium,256,12), BRANCH fixed and matched, FIRST=1, LAST=8. The index divided by eight is the *total* excited fraction. Each completed knot is persisted; save points can start a later range. Uses the projected two-state Hessian and fixed norms, not the alternating eigensolves of the small-fraction test. Full-transfer endpoint has exactly zero ground population.
- `boundary.py` projects the fine states in **physical** radius into the second retained background/grid, then actually re-solves at 50% and 100%, fixed and matched. Radial units and truncation radius differ. This is not a readout-only comparison on the same wave.
- `control.py`, `stress.py fine 384 16`, `preparation.py fine 384 16`, `preparation.py medium 256 12`. The latter two record normalized transition moments, not occupation forecasts. `audit.py summarize` recreates or checks the comparison tables; `audit.py seal` constructs the immutable manifest only after the documentation exists. Files are create-exclusive or checked for identical content. For independent regeneration in a different software environment, use a clean sibling working copy with preserved parent access; do not overwrite sealed outputs to accommodate last-bit numerical differences.
- `compared-forecasts.csv`: total forces (north signed polar and radial; the reflection rule is applied in the two-hemisphere coverage), both rotation RMS values, quasar drift and solar slope. Spherical NFW is the same amplitude-matched control at all wave fractions: it has no wave population parameter. Conditional mass calibration is not formation. `readout-resolution.csv` uses |a−b|/max(1,|b|) and is not a collection of relative errors where b≈0. The figures are exposed checks, not an independent galaxy likelihood.

# Private replay

Use the retained Python 3.13 environment, NumPy, SciPy, mpmath and the prior height module's installed dependencies. Run in this stage's directory with -B; report generation and replay work offline. io_stage.py caps numerical threads and refuses an owner stop marker. No live service or third-party code downloaded for execution.

1. io_stage.py acquires only the two OGLE-IV **input** tables plus Nataf table 4 and its README. sources.json records exact URLs, sizes and digests. Angular count selection, source hypotheses and crossed-force probe were fixed separately in PROTOCOL.md and CROSS-PROBE.md.
2. kernel.py base and kernel.py fine construct the separate CCD-level predictions. controls.py independently integrates the bar mass and source kernel and constructs the same-depth example; optics.py tests the Maxwell split and integrates the two perturbed point-lens rays. distance_bounds.py gives continuous moment certificates and inner attainable ranges for each of 291 sightlines. bound_checks.py tests these independently with finer slabs and modulus intervals and propagates the published moment-error rectangles. Source-rectangle row indices are one-based data rows excluding headings.
3. dual_probe.py medium and dual_probe.py fine compute the response of the original stationary solutions. The medium run also solves each signed finite perturbation independently. refine_induced.py 384 32 medium compares the source mesh on the same fine wave; refine_induced.py 512 32 fine, 512 40 fine, and 640 40 fine isolate radial/angular basis differences. These supplemental checks cost substantially more than a replay. Do not launch them simultaneously. Each preserves the physical box, population source and outer anchor and re-solves the stationary reference on its own basis.
4. audit.py check derives the matched angular/source and cross-observable summaries and validates the protected input chain. audit.py seal creates the complete manifest; audit.py replay checks it byte-for-byte and rechecks the principal comparisons. Historical failed component refinements are explicitly retained; they are not passing numbers hidden by a tolerance change. All stage outputs are write-once or checked for equality.

# Private replay and receipts

Use the retained Python 3.13 with NumPy and SciPy. All solvers run with one numerical thread. No services, web requests, fixups to older checkpoints or background jobs are necessary. Verify the existing directory with `python -B verify_cloud.py`. The verifier checks the previous seal, every predecessor artifact, inherited code/data dependencies recorded there, immutable forecasts, the packed fields, control identities and numerical result tables. It also checks the one explicitly expected failure of the weak-field *approximation* at the old high mass. The small-scale clock integrations are not counted as independent observations.

For independent reproduction, use a **new empty sibling** of this stage directory and copy only the Python files and the five Markdown notes there; leave all existing results and old directories alone. Keep their original filenames. The scripts read their predecessor by explicit sibling name. In the fresh directory:
1. `python -B cloud.py init`; `python -B cloud.py physical 128 256`; `python -B cloud.py freeze`. These signatures must exist before producing the finite targets.
2. `python -B cloud.py target 128 256`; `python -B cloud.py flat 128 256`; `python -B cloud.py static 128 256`. One or two processes at a time only; do not launch the same mode and mesh twice.
3. Run `python -B SCRIPT create` for reduce_cloud.py, cloud_receiver.py, binding.py, shell_acceleration.py, support.py, phase_support.py. These are write-once. Calling with `check` instead regenerates and compares the tables without overwriting.
4. `python -B verify_cloud.py seal`; then `python -B verify_cloud.py` in a fresh process. The SHA-256 manifests check content and file membership. The pre-target receipts protect only the physical primary forecast; the virial, launch-binding, phase and mechanism budgets are additional diagnostics, not new blind clock predictions.

Each clock NPZ stores all four arithmetic components. Index 0 is empty, 1 matter-minus-empty, 2 scalar-minus-empty and 3 the mixed response. The occupied endpoint is their sum. The arrays retain the small components directly. Each tube packet stores evolved mass, independent metric mass, pressure work rate and flux rate before time integration. An owner STOP-REQUESTED file is honored at the short integration boundaries. There is no reason to kill an unrelated process.

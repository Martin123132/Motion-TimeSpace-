# Reproducibility, units and inputs

Run with the retained Python 3.13, NumPy and SciPy (`python -B`), inside this private directory. The default verification needs no network. No re-integration of the original five-billion-year orbit is needed. Keep the complete immediate parent and its ancestors at their existing relative paths. The steady-state solves are new calculations, not restarts of the original orbit. Every output function checks an existing result instead of overwriting it. No servers, detached workers or Git operations.

**Inputs and exposure.** `acquisition.json` records the raw file SHA-256, Git blob, exact commit and prior protocol hash. `geometry.py` (optional network replay) fetches only the [published binary table](https://github.com/thomasdonlon/Empirical_Model_MSP_Spindown_Accels/blob/6cb4e31f6b2e732f5973b024634507c2e4f59988/v3/binary_only.csv), checks its blob/size and units, retains only NAME, GL, GB, DIST, DIST_ERR, and writes no raw outcome-bearing file. Its cited README identifies v3 as the published sample and explains why curated distances need not equal inverse parallax. `geometry.csv` is the offline calculation input. Selection/exclusions upstream belong to the authors. Only the observational geometry is used here, no assertion of historical non-exposure. The [Erkal orbit](https://zenodo.org/records/2661108), its mass and solar axes are imported through the parent; the published orbital model and Cepheid amplitude reference are exposed. The [MWPotential2014 convention](https://docs.galpy.org/en/v1.3.0/reference/potential.html) is a fixed literature foreground/reference, not a baryon measurement derived in this experiment. The comparison bin and the rest of its published table are exposed, not a future independent test.

**Finite forecast.** Run `sightline_forecast.py angular24-cap angular28-diff angular16-cap angular16-diff outer16-cap outer16-diff` after `python -B`. In the same way run `newton_check.py angular24-cap angular28-diff`, `projection_check.py`, and `sightline_forecast.py exact angular24-cap angular28-diff`. A full mode sum at nominal and perturbed distances is the final readout. Files without the exact prefix retain the earlier cubic radial interpolation; they underlie the numerical comparisons and printed rounded summaries. Primary vectors use full density angular orders 48 / 56. Distances are kpc; nominal output and distance sensitivity tables give mm/s per Julian year. All foregrounds are projected at exactly the same endpoints. The explicit total for the frozen runs is a conditional superposition, not the result of evolving a disk-loaded state.

**Stationary solutions.** `disk_state.py TAG STATE COUNT ORDER EDGE LOAD START`; STATE cap or diff; START original or other; even axisymmetric angular orders, radial count per order, radius in branch code units. Only disk0 uses load 0, all other tags load 1. For both labels disk0 uses (64,4,30); disk8 (64,8,30); disk12 (96,12,30); disk16 (128,16,30). For disk20 use (160,20,30) cap / (192,20,30) diff with other start; disk20-twin uses the same grid and original start. For diskbox use (192,20,36) cap / (232,20,36) diff. The other cases start from original. Packet names end in the label, e.g. `disk_state.py disk20-diff diff 192 20 30 1 other`. `disk_readout.py disk20-cap diskbox-cap disk20-diff diskbox-diff` integrates midplane/sightline forces and independently checks them. `disk_tangent.py disk20-cap disk20-diff` solves the constrained response, saves the residual-polished state, and checks both derivatives using nearby fully nonlinear residual solves. These controls perturb inputs only for differentiation. Periodic changes in baryonic structure and environmental state selection are not in this model.

**Audit.** `summarize.py` recreates the aggregate tables. `validate.py` checks the parent file manifest, new packet contents and stored seal, geometry and units, numerical results and honest coarser misses. Initial sealing uses the explicit one-time `seal` argument. `PROTOCOL.md`, `FRAME-CONTROL.md`, `DISK-PROTOCOL.md` and `RESPONSE-PROTOCOL.md` distinguish tests frozen before each calculation from the later physical interpretation. The orbit/source cache, galaxy lab, prior formalization work and publicly released files remain unchanged.

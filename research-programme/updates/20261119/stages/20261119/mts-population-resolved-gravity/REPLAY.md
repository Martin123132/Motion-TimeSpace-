# Reproduce locally

Python 3.13, numpy and scipy; scripts use -B and import numerical libraries with one math thread. Run from this folder. Two numerical workers maximum. No publishing or scheduler. All original inputs are immutable, earlier stages verified by seal; a source download is needed only when its pinned local file is absent.

1. inputs.py checks the three official current Git blobs against their content IDs. population.py verifies the older FITS blob before using the coordinate column only. Vertical conversion, local/global normalizations, mass units, Abel split, bin ranges and the component/aggregate inconsistency are documented. The map files do not contain velocities.
2. For gravity.py pass triplets normal:geometry:level with normal mass/local, geometry flat/spherical, level fine/medium. It recomputes star potentials and separate direct forces on inherited sites plus the quasar point. Existing raw and generated files are create-exclusive or compare-only.
3. For solve.py pass main 384 32 and the four fine triplets, main 256 24 and four medium triplets, and above 384 32 with mass:spherical:fine. Only the parent's positive standing state and original NFW scale are used; compare six fixed/matched forecasts in each of the nine main sensitivity packs. The solver uses fixed parent masses as controls and a common matched outer velocity. An analytic cached anchor force is checked against the original force integrator; source codes/outputs in other stages are not modified.
4. Run angular_source.py, shape_bounds.py, validation.py. The shape cone checks one common physical stellar input across sites rather than choosing separately optimal radii. Its polar-force maximizers are diagnostic endpoints selected by an ordinary-source extremum, not proposed Milky Way measurements. Run gravity.py and solve.py main 384 32 for upper1:spherical:fine and upper2:spherical:fine. These two solves check actual nonlinear MTS at specific extreme inputs, not the supremum of MTS over all allowed inputs.
5. Run susceptibility.py main 256 24 medium and susceptibility.py main 384 32 fine; these reuse the corresponding primary mass/spherical packets without changing their calibration. Run verify.py replay to validate the compact scientific results, both protected predecessors and this stage's full manifest. See RESULTS.md and NEXT.md for interpretation. Do not publish the raw authors' data as part of any unreviewed export.

# Private replay instructions

Run from this folder with the retained Python 3.13 numerical environment (NumPy, SciPy and pandas) and the original sibling stages in place. No catalogs need to be downloaded. Use one calculating process at a time; all scripts inherit the one-thread numerical setting from shared.py. Existing outputs are compared, never silently overwritten; source stages remain read-only. Exact-byte comparisons depend on the original library build. Inspect owner holds before starting a new run.

1. python -B budget.py and python -B global_shape.py (sequentially). Source provenance: Lian et al.'s [corrected published Table 2](https://doi.org/10.3847/2041-8213/ae6e40), [corrected radial table at pinned release](https://github.com/lianjianhui/Source-data-for-MW-mass-paper/blob/78ba3c4e8e92a2d3b6e03842e437d6e95df6e9fd/surfm-remnants-260820.txt). The table is physically interpreted in the retained mass calibration; the uncertainty on that calibration is not a new measurement from these galaxy forces.
2. python -B finite.py medium, then fine, then 512-40 (each a separate invocation with the same script and a single argument). The first two reuse 256×24 and 384×32 stationary states; the third rebuilds the baseline on a 512×40 basis from the saved state and enforces the same outer force. Run python -B assess.py medium fine and python -B assess.py medium fine 512-40. Earlier failed comparisons remain in the record. The high-resolution reference and twelve finite wave states, each with its conserved number, are retained as NPZ packets for new readouts. No need to solve again to inspect those states.
3. python -B optics.py 8, then python -B optics.py 14. Follow with python -B assess.py light, python -B verify.py 512-40, python -B angular_bounds.py and python -B packet_check.py. Reconstruct the stored wave density with python -B wave_modes.py coarse, python -B wave_modes.py fine, then python -B wave_report.py. Finally run python -B verify.py seal. These steps test both source-zone geometries, finite dynamics, data-file identity, same-source signed optical extrema and the angular source on separate meshes. The final manifest excludes itself. The supplementary polar calculation is separately labeled in ANGULAR-EXTENSION.md.
4. The prior microlensing stage supplies 3,760 accepted-pilot IDs and simultaneous parallax intervals, not a measured optical depth. The force comparison uses the original [SEGUE population table](https://arxiv.org/abs/1309.0809) and the [independent Gaia acceleration study](https://arxiv.org/html/2305.13358v3) already present in the retained parent. They were already exposed, not newly held out. The two refinements and spherical comparator use identical sites and common matter. Results are local; no data were published.

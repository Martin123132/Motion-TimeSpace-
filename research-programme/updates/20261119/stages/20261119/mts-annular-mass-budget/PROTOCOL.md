# Finite, independently limited changes to the same compact source

Freeze the experiment before recomputing forces. The existing SEGUE residuals are known; this is not a blind test. No halo shape, coupling, force target, error width or EROS source list is fitted. Reuse the saved pooled-height, mass-normalized stellar profile. Let the 4–7 kpc cylindrical living disk change by fractional amount a. (A) Add/remove only that mass; total living mass can change and this family is excluded except at a=0 if the published total is held exact. (T) Transfer it from/to the contiguous 7–8 kpc ring with the same retained local vertical law; scale the donor by 1−a M_i/M_o. This conserves total living mass exactly, leaves the calibrated solar cylinder untouched and changes neither bulge nor remnants. The donor is an explicit test family, not a derived history. Bound nonnegative columns.

Use the corrected radial table's *point-at-center convention* already adopted by the parent (not a fabricated radial covariance). At measured centers 4.5, 5.5, 6.5 and 7.5 kpc enforce the living column, and include all other measured centers for a common calibration nuisance. Quote one and two printed marginal-error widths as deterministic sensitivities, not a joint statistical confidence region. At fixed multiplicative source calibration the allowed changes obey |a f_i| ≤ width σ_i/Σ_i. Allowing one common comparison calibration t>0 instead gives t max(0,1−width σ_i/Σ_i) ≤ 1+a f_i ≤ t(1+width σ_i/Σ_i). Here f_i is 1 in the inner ring, 0 outside in family A, or −M_i/M_o in the T donor. Outside both rings f_i=0 for both. Compare the two constraints before force readout; t is a nuisance in comparing the source table, not another physical source scaling in the solver. Do not claim an arbitrary change of stellar population is bounded by this construction.

Run both signs of the fixed-calibration one-width range and the outside envelope (free calibration/two widths) against the retained pooled ground state and spherical NFW control. Normalize both at the same outer speed, with the same direct ordinary Newtonian field. Compare finite, not derivative-only, responses at the same 14 inner SEGUE entries; verify by refinement and anchor/residual tests, preserving the earlier tolerance. Report predictions at tested points separately from rigorous continuous bounds. For ideal microlensing use all 3,760 drawn optical IDs and saved simultaneous signed-parallax intervals, no observed event depths. Treat both signs of the compensated line-of-sight density, not just its positive annular part. Do not import a mass gap or infer local occupancy. Keep everything private.

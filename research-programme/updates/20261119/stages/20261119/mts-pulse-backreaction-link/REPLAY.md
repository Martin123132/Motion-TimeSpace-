# Reproduction and scope

Use Python 3.13 with NumPy and SciPy and the preceding retained local research folders. No new downloads. Run `python -B verify_stage.py` to recheck the completed folder, including the sealed input, both freezes and the table budgets. Only run producers in a fresh sibling copy of the scripts and protocol notes. No overwrite is intended. Use at most two one-thread numerical workers and respect owner stop files.

1. Run `response.py forecast .8 N:64:tangent M:64:tangent N:128:tangent M:128:tangent` with `python -B`; repeat with charge 1. Run `response.py freeze` **before** the corresponding `response.py full` calls (identical argument lists).
2. For the charge .8 finite controls run `response.py full .8 N:128:plus N:128:minus N:128:halfplus N:128:halfminus` and repeat with M in place of N. Then `score_link.py leading` and `exterior.py`.
3. For the fixed ADM, charge .8 next stress coefficient, run `stress_series.py aux 128 .125 -.125 .25 -.25` and repeat with 256. Run `stress_series.py freeze` before `stress_series.py target 256` and `stress_series.py target 128`; then `score_link.py second`. Do not send a production job to the new middle clock pair before this freeze.
4. Run `constraint_check.py 128` and `constraint_check.py 256` for the weak Gauss, geometric mass and shell Hamiltonian comparisons, including the separate empty-background scalar control at 128. These are constraints, not comparisons to measured clock noise.
5. `quiet_clock.py` produces an independently evolved zero-amplitude massive control; `mass_order.py` compares the derived quadratic mass and compensated preparation against the signed real banks, and the prefront Reissner–Nordström clock response against finite event minus this quiet solution. These are follow-up physical diagnostics, not new blinded tests.
6. Run `verify_stage.py` twice after the reports are present. Upstream seals are byte-specific; do not revise a reference seal to accept a reproduction on a different numerical stack. Physical units, launch hierarchy, first/second order distinction, forecasts and resulting scientific restrictions are in DERIVATION.md, SECOND-ORDER.md and RESULTS.md.

`out`, `echo` denote fractions of the emitted frequency; delays are proper-time differences in code time. Waveforms are first variations with respect to the specified scalar seed unless explicitly identified as finite differences. Each tolerance test compares a whole waveform with its own peak, not only values at the maximum. For the early null the absolute signal is more informative than a percentage.

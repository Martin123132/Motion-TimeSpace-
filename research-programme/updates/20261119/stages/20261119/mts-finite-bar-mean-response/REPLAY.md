# Offline replay and restart

Use the same retained Python 3.13 numerical environment as the sealed rotating-bar predecessor (NumPy 2.4.6, SciPy 1.17.1, mpmath 1.3.0). Use python -B and one process at a time, working in this folder. All inputs come from the predecessor and its existing dependencies. Check owner holds before starting. Use verify_pulse.py sealed for a read-only verification, not a rerun. Generated artifacts are written once and compared on replay; last-bit differences across builds require a separate copy, not modifying a seal.

1. finite_bar_pulse.py takes LEVEL CASE STEPS_PER_TURN M [zero]. Each stem ending in -state.npz gives its exact parameters (n denotes steps; the no-drive stem uses zero). Cases are reference and added-free2-plus; positive m is either 2 or 4. This generates a history, forces, numerical checks and resumption packets at switch-off and one turn later. A fresh run always starts from the sealed stationary state, not from an arbitrary positive-energy level. The mean evolves to second order; the no-drive option is an actual evolution of zero perturbations. The quarter-turn rows, including switch-off and the one-turn-later rows, are retained.
2. Run occupation.py LEVEL CASE STEPS M for each stem ending -bound-projections.csv, and phase_control.py fine reference 128 2. The selected one-body states are enumerated in increasing energy; the predeclared localization screen is applied without dropping failed states from the table. Run pulse_bound.py and forecast.py for the frozen-Hamiltonian envelope bounds and low-orbital forecast.
3. Run collective.py LEVEL CASE STEPS 2 for each stem ending -collective-time-test.csv. Run collective.py fine reference 256 2 1024 for the separate two-pattern-turn challenge only after its existing predictions match (the 256 labels the saved reference fixture; 1024 is the independent direct-evolution step count). Run collective_bound.py fine and radcheck separately; repeat for relative_coercivity.py. Both compute all 16 retained even harmonics at two baryonic endpoints. Factoring the scaled Schur complement tests all discrete directions; a nonpositive pivot is not an acceptable norm bound.
4. Run collective.py fine reference 256 2 kernel and collective.py upper added-free2-plus 256 2 kernel, then tidal_control.py. In these packets the weights include radial and angular quadrature, the eigenvector convention and velocity conversion. Use a complex Fourier coefficient of specific potential in (km/s)², not twice its real part. The index-order convention is radius then positive μ; the saved mode has even reflection symmetry about the disk. For a source not symmetric in z, use its even projection here; other symmetry sectors require their own modes. The packed weights are intended for arbitrary spatial shape, not only a uniform tide. The synthetic source has a 5-kpc Plummer smoothing length, fixed central trace-free tidal difference, and no fitted mass or orbit.
5. Run readout.py, compare.py and verify_pulse.py. Only if creating the original private seal run verify_pulse.py seal; verify again with sealed. Sideband intensities and bound one-body projections are particle-number norms, while collective action × mass unit is a conventional scale, not in general a particle mass. All sky accelerations are in units of 10⁻¹⁰ m/s². Source and signed ground-force changes should be compared on the same mesh against zero drive, rather than as independent absolute calibrations of the Galaxy.
6. Further work starts in a sibling folder using NEXT.md, not by editing these packets or sending them to GitHub. Neither the handoff route nor another chat's work was touched.

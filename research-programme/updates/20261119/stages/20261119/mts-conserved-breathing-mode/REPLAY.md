# Reproducing this local result

Use the retained Python 3.13 with NumPy and SciPy, -B, from this folder. Do not regenerate create-only products over the saved files. No downloaded data are needed to replay. The source profiles, observation inputs and solver ancestry are in the predecessor seals; the two local forecasts record exact input hashes.

- python -B verify_mode.py reconstructs the three-domain eigenproblems, checks mode and forecast packets, re-evaluates all finite-wave diagnostics, the live energy exchange, anchored outer comparison and excitation forecasts, and checks the final seal.
- python -B replay_wave.py space512 space1024 time8192 re-executes the full nonlinear histories without overwriting this stage. One numerical worker at a time. For each resolution, the output is compared array-for-array and byte-for-byte in a task-owned temporary directory, then removed. All three were actually replayed.
- Creation order for a fresh independent copy: breathing.py BRANCH create for each of isolated, rigid, live; mode_forecast.py freeze; nonlinear.py GRID for each named grid; cap_test.py freeze then cap_test.py test; accuracy.py create; excitation.py create. The observation-transfer formula was recorded before its comparison, not before the raw evolution; the astronomical inputs were already exposed. The original wave forecast predates the finite evolutions. verify_mode.py seal is create-only.
- Each nonlinear run contains an unexcited control and four matched finite perturbations with a fixed, common initial integrated number. Every 1/128 of a period we saved velocity/density projection diagnostics, and every quarter period the cumulative positive density in *each* arm. A derivative is the paired, centered difference. The signed finite single-arm results are retained separately.
- This stage uses the original numerical tolerance; density and current residuals are scaled by the corresponding full peak profile norms, a vanishing response at an intermediate phase is not used as its own denominator. The fixed-mass anchor uses its mass as an absolute-relative control. Two zero crossings give one modal half-period; this does not establish arbitrarily long phase coherence.

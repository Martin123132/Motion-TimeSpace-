# Reproduce or inspect this local calculation

Use the same retained Python 3.13 with NumPy, SciPy and SymPy. The scripts set one numerical thread, honor the inherited owner holds and run with -B. No network, catalogue, accelerator or new dependencies. For an existing sealed folder, run only `python -B close_stage.py` to verify it. The producer commands are for a **fresh sibling copy of the scripts and protocols only**, with the unchanged earlier stage one directory above at its original name. Archives do not overwrite prior results.

1. Prepare the launch data: `python -B contact_model.py tangent step plus minus halfplus halfminus`; `python -B action_checks.py`. Preparation is not the evolution used for the finite tests.
2. `python -B evolve_contact.py tangent:80 tangent:160`, then `python -B clock_channels.py freeze`. This saves all signed time-dependent derivative predictions, including the small common-metric channels, before testing real couplings. In the original run the two resolutions were separate jobs; one job is sufficient for replay.
3. `python -B evolve_contact.py tangent:320 step:80 plus:160 minus:160 halfplus:160 halfminus:160` and `python -B clock_channels.py tangent:320 step:80 plus:160 minus:160 halfplus:160 halfminus:160`. Finite waveforms solve the Einstein/matter system and the two moving-clock Hamiltonians. A repeated archive is intentionally rejected.
4. `python -B comparison.py weak:160 weak:320 final`; `python -B cross_checks.py`; `python -B tidal_channels.py 160`; `python -B observable_basis.py`. `python -B paired_delay.py` reintegrates the real saved event-minus-quiet rays. For the additional predeclared wider increments: `python -B wide_check.py` then `python -B paired_delay.py wide`.
5. `python -B wave_cone.py` checks the independent scalar Hessian and the local scalar/photon cone difference; `python -B relative_arrival.py` tests the relative travel times. `python -B dilute_front.py` independently solves with the previous 0.1 GeV/cm³ example density, not a rescaling of the dense readout.
6. Run `python -B cold_dust_symbol.py`, `python -B core_regularity.py tensor`, `python -B core_regularity.py trace`, and `python -B core_regularity.py` without an argument. These track both signs against the ordinary zero-contact matter control and independently evaluate the full local principal matrix. The four +4 domain failures are diagnosed, not scored as finished waveforms. Do not form a Richardson result using a missing sign.
7. Inspect the numerical ledgers and results, then use `python -B close_stage.py` twice to create and cold-verify a manifest in a fresh complete result folder (include the two human-readable reports). It hashes both the new artifacts and the retained predecessor files; validating a seal is not a claim of agreement with observations.

**Reading the data.** All couplings, times, radii and fields are in the predecessor's dimensionless code units unless an explicit physical conversion is given. Positive outward coordinate momentum is positive j; “out”/“echo” without “delay” means fractional frequency. “Base” is the same source at zero contact, “metric” the change in common gravity, “probe” the extra clock and light response, “total” their sum. Waveforms are event minus quiet, except where explicitly marked ordinary. Most peaks occur at different emission times, so do not add signed peaks from different rows. The weak balances use three compact radial test functions; a zero physical reference is not a meaningful relative-error denominator. Weak and tidal checks share the simulated fields, unlike the analytic ordinary exterior solution. Positive/negative numerical excursions of order unity are derivative controls; they are not proposed physical couplings.

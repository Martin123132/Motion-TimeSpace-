# Private replay

Use the installed Python 3.13 with NumPy and SciPy, with bytecode disabled (-B). No network, code installation, other chat, Git operation, external service, or new raw catalogue is required. Maximum two one-thread numerical processes. Stop between solver cases if necessary; a completed case has its own readout plus nominal state. Existing artifacts are compare-only or create-exclusive. Do not clear folders or retry a failed check blindly.

1. Run python -B -c "from census_common import freeze; freeze()" here. This verifies the gas and stellar source seals, reruns the three stellar sightlines, and fixes the scale factors before computing the finite solutions. The adjacent gas stage supplies the observed Fig. 9 values, source amplitudes and previous states. The complete width, population-convention and height distinctions are in PROTOCOL.md and the prior census files.
2. Run census_solve.py via python -B, with groups of four arguments case label count order. Cases are catalogue and column; grids are main 256 24, main 384 32, above 384 32. Each run saves its frozen tangent and spherical feasibility test before the finite changes, its state, force comparisons, velocities, and stationarity. The modest grid adds independent positive/negative steps to test the frozen tangent. The high-resolution main grid is the reporting convention, not a branch selected from outcomes.
3. Run spherical_density.py, compare_census.py and solar_dipole.py. The first adds a radial monotonicity test independent of the SP solver. Only the diagnostic feasibility calculation adjusts an unobserved continuous mass profile to the exposed bands. This is not a fitted parent prediction. The quasar measurement was not used in the stellar or outer calibrations. The programme-wide data exposure is not audited here.
4. For the metric stress run hilbert_stress.py with case:label:count:order:quality arguments. Use both cases, main:384:32 at both coarse and fine quadrature and above:384:32 at fine quadrature. It uses both fixed and matched nominal solutions in each packet. Mass, kinetic and wall terms are in physical model units; relative force checks are ledgered separately from projected stationarity. Run verify_census.py replay when a seal is present. A seal attests the files and specified checks, not a theory or population fit.
5. The analytic shell check is emitted by spherical_density.py. Run bulge_budget.py on that check to bound the strongest spherical-bulge bookkeeping repair before sealing. Exact defect attribution in the stress replays is separate from the predeclared plane check: it does not adjust the field, force, or acceptance threshold.

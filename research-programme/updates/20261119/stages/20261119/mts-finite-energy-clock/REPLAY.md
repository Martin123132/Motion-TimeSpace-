# Local replay guide

The verified parent is the sibling directory mts-pulse-backreaction-link-20261119; keep the older sealed physics inputs in place. All commands below use the retained Python 3.13, NumPy and SciPy, invoked with `python -B`. Each numerical worker uses one thread; permit at most two independent workers. Producers are for a fresh sibling copy of this stage's scripts and protocols only; they do not overwrite completed banks.

1. On meshes 128 and 256, run `experiment.py node MESH PREP -3 -2 -1 0 1 2 3` for PREP=N and M, and `experiment.py basis MESH N hu hv uu uv vv`. Nodes are trial source amplitudes, not observations or values fitted to clock results. The predictor uses the independent ordinary-plus-scalar rate implementation and differentiates its full backreaction along the preparation family.
2. Run `make_forecast.py` to freeze dense prepared energies, both signs, clocks, meshes and amplitude quadratures before producing any new targets. `compare.py saved` reuses the exposed parent real events for an additional check and reports the independently derived initial stress components.
3. For each MESH run `experiment.py test MESH N 0 1 -1` and `experiment.py test MESH M 1 -1`. Run `compare.py raw`. The independent real event and quiet runs are retained, including failures when nearly equal arrivals are subtracted. `paired_clock.py algebra` validates the cancellation-safe real evolution against the parent's full right-hand side at both endpoints. Run `paired_clock.py MESH PREP 1 -1` for each mesh/preparation and `compare.py paired`. No precision threshold is loosened.
4. `source_ceiling.py` calculates the leading equal-mass ellipse, tests selected directions against the nonlinear constraint and evaluates the energy budget. `energy_exclusion.py` evaluates the separate exact nonlinear exclusion inequality at the original requested energy and the retained 0.1 GeV/cm³ density example. Both use only the saved units and material/field shapes.
5. `dilute_test.py freeze` fixes predictions for the smaller energy before the independent dilute runs. Run `dilute_test.py MESH PREP 1 -1` on both meshes and both preparations, then `dilute_test.py score`. The five leading shapes are reused with the exact new quiet normalization and separately solved finite compensation; a dense clock waveform is not simply divided by the density ratio.
6. `nonlinear_ceiling.py` bounds all equal-mass energies in the stated interval, not only the sampled roots. `analytic_controls.py` tests the paired method with a time-dependent analytic clock metric and a 60-digit reference. `clock_interpretation.py` reports sign dependence, SI proper delays and an independent mass-only reference. `matter_drive.py` tests a derived quartic source coefficient against the earlier archived material-only runs.
   For the independently driven response, run `driven_wave.py 160`, `driven_wave.py 320`, then `driven_wave.py score`. Run `driven_energy_check.py freeze` **before** `driven_energy_check.py 320` and `driven_energy_check.py 160`. These full coupled targets use the same matter perturbation and no initial scalar pulse.
7. For the remaining far-link parity checks use `experiment.py node 384 M -3 -2 -1 0 1 2 3`, `fine_even.py 384`, `fine_even.py 256`, then `fine_even.py freeze`. Only after this freeze run `fine_even.py target dense`, `fine_even.py target dilute`, and `fine_even.py score`. The earlier budgets are not overwritten or relabelled.
8. Run `verify_stage.py` after writing the reports, then run it again for cold verification. The verifier on an existing sealed result is read-only. Distinct floating-point or SciPy versions may not reproduce archive bytes; do not replace a reference manifest to make a comparison pass.

The plus/minus channels report finite events against quiet. “Odd” and “even” are the half-difference and half-sum at equal excitation energy unless an existing amplitude pair is explicitly identified. A frequency is fractional and a delay is in code proper time; both are signed. Different channels and different signs can peak at different emission times. Real clock noise, a particular sky link or an inferred galactic scalar occupation is not part of these calculations.

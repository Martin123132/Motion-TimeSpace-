# Private replay

Retain mts-material-driven-clocks-20261119 and its predecessor siblings. Use a fresh sibling copy of these scripts and protocols, local Python 3.13 with NumPy, SciPy and mpmath. Run every command with python -B, not -O; each solver uses a single numerical thread. Do not run more than two numerical jobs together. Producers refuse an existing packet. On a sealed copy use only verify.py.

1. controls.py, then transport.py freeze inputs. On each mesh 128 and 256 run transport.py forecast MESH plus minus and transport.py masscoefficient MESH plus. Freeze finite using transport.py freeze finite and the lighter-source predictions using transport.py freeze light.
2. transport.py target MESH plus minus on both meshes. ordinary_control.py plus minus reconstructs the material-only axis with independently implemented paired real equations and a separate exterior geodesic null. For each mesh run transport.py light3 MESH plus and transport.py light6 MESH plus.
3. neutral.py freeze; for each mesh run dust_clock.py MESH and neutral.py MESH. These keep the exact geodesic material solution at zero occupation separate from the reduced neutral Einstein–scalar calculation.
4. mass_curvature.py freeze setup. On each mesh run mass_curvature.py MESH 64 128. mass_forecast.py freeze constructs all linear-plus-Hessian predictions (including f=0.01) and signs the held sources. Only now run mass_curvature.py MESH 0 at each mesh to calculate the two independent real finite f=0.01 packets.
5. Run each postprocessor with the argument create once: measure.py, neutral_compare.py, mass_forecast.py, clock_identity.py, source_scale.py, preparation_energy.py, calendar_transfer.py. The argument check instead recomputes and compares. Galaxy Lab's existing samples.js is read-only and only its NGC3198 ROTMOD record is used. EPTA dates are read from the earlier sealed cache; no download, residual analysis or public change is needed.
6. Save RESULTS.md; verify.py, twice in different interpreters, to verify and seal. Inspection or verification does not launch simulations. The inherited spherical scalar pole and source units are conditional physical inputs, not parameter estimates from either data set.

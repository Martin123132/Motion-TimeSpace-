# Saved inputs, verifications and replay

This is a local research stage, not a new release law. From this directory, `python -B audit.py replay` verifies the two direct predecessors, exact input digests, row-level calculations, cross-resolution readouts, and all sealed local files. It does not download anything or rerun the wave solver. The manifest covers the scripts and documentation as well as the numerical results. A manifest check does not itself establish a continuum limit or independent observational validation.

Construction order for a separate working copy with the same relative parent paths:

1. Wu et al. v1 arXiv source includes thindiskhz_first.pdf. acquire.py extracts exactly this member; source.json records both hashes. digitize.py uses PyMuPDF to read vector coordinates. The 245 recovered markers are not a substitute for a raw star catalogue. Bovy & Rix v3 source includes surf.txt, retained as Bovy-Rix-surf.txt. segue.py can obtain that small member if absent; the saved replay is offline. Neither source archive is redistributed by this checkpoint.
2. For each of `medium` and `fine`, run height.py LEVEL, then solve_height.py LEVEL, wedge.py LEVEL and odd_source.py LEVEL. Keep the unmodified population-resolved stellar, gas and compact-source files and the saved counter-rotation endpoints. Ground backgrounds: original main 256/24 and 384/32; the odd-sector radial count and number of angular channels are separate. The prior outer speed and sites, force signs, normalizations and numerical threshold 2e-5 come from the parent. The direct-force source grids are separate from the wave Galerkin basis.
3. Run moments.py once. Run collective.py LEVEL COUNT CHANNELS for medium 96 8, fine 168 12, fine 320 16 and fine 384 16. Compute energy_gate.py medium 96 8 full and energy_gate.py fine 384 16 iterative. Run coercivity.py medium 96 8 and coercivity.py fine 384 16 for the independent shifted-matrix lower-floor test. Only the medium energy_gate.py run decomposes the entire normal-mode spectrum; the fine coercivity test validates the static quadratic bound without claiming a full fine spectrum.
4. Run turning_drive.py for the analytic and integrated rotating-template controls. Run segue.py medium, segue.py fine, then spherical_test.py. Saved force predictions use independent dark-field readouts at the SEGUE sites. The published offsets, vertical forces and positive printed errors are read from the original rows. The old-height and fixed-number controls are retained. No empirical amplitudes are learned.
5. audit.py check recomputes the acceptance diagnostics. seal and replay modes additionally write or compare the resolution ledger and compare local SHA-256s; replay expects a pre-existing manifest. Do not replace original sealed results to erase last-bit differences on a different machine. Coarse-to-fine differences in the tiny sudden-switch energy are reported separately from the force-resolution checks.

Run serially in the retained Python 3.13 environment with NumPy, SciPy and PyMuPDF. All commands use -B. For full regeneration keep numerical thread counts to one, including OPENBLAS_NUM_THREADS, MKL_NUM_THREADS, OMP_NUM_THREADS and NUMEXPR_NUM_THREADS. No online job, Git operation or other chat is required.

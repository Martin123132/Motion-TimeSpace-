# Inspect or reproduce the longitudinal response

**Safest inspection:** from this folder, `python -B seal_stage.py` checks the hashes, parses the tables, loads the numerical archives without pickle, and reconstructs the held-pulse budgets from the four real evolutions per resolution. It does not rerun or overwrite any physics. Keep the original predecessor directories and the 4878/4943 records available at the same relative paths.

**To recompute:** use a new sibling directory with copies of the Python files and Markdown inputs, not the sealed output folder. Use the retained Python 3.13 environment with NumPy, SciPy and SymPy. Use one numerical thread per worker and at most two workers. For each script name below invoke `python -B` followed by the indicated script and arguments. Inherited owner holds apply. The order of the prediction freezes matters.

1. `centre_jet.py` freezes the constrained launch matrix. Run `independent.py ordinary`, `independent.py massive`, `axis_flux.py`, `conditioned_slice.py`. `regime.py` and `mixed_bound.py` evaluate the first-order physical coefficient corridor, distinct from the numerical stress tests.
2. `propagate.py tensor`, `propagate.py trace`, then `propagate.py score` produce the full massive launch evolution checks. Keep failed and null rows; these calculations cannot all be compared by relative error.
3. `balance_forecast.py`, then `balanced_sphere.py tensor` and `balanced_sphere.py trace` for the charged force-balance control. `shell_transport.py` freezes the general ordinary central proper-time prediction. Run `ordinary_evolution.py tensor 160`, `ordinary_evolution.py trace 160`, and the same pair with 320. `zero_mode.py` handles the small k=0 response separately; `credible_band.py` computes the conditional finite-time, all-wavenumber envelope.
4. `scalar_readout.py .8` and `scalar_readout.py 1` compare four scalar approximations on the k=4 and 24 controls. `held_packet.py freeze` makes **all** predictions before any `held_packet.py .8` or `held_packet.py 1` evaluation. The two tests use signed real simulations and separately refined target/prediction grids. `early_check.py` extracts the independent early quartic coefficient from those saved real histories without rerunning a solver.
5. Inspect the reports and receipts, then seal a fresh completed directory with `seal_stage.py`. The shipped verifier is intentionally pinned to the recorded forecast and input bytes. A different library build can change binary artifacts: retain and compare that separate reproduction, do not overwrite the reference or change thresholds to get matching hashes.

The original bank and protocols remain unchanged. Time, wavenumber, fields and charge per mass in the ledgers use the parent's dimensionless normalization. Relative waveform errors use max absolute difference divided by the full signal peak, not pointwise division at a zero. The source-to-SI conversion and conditional caps are in SCALES.md. The number readout is the induced variation of log proper material density. No observation or astronomical source population was used.

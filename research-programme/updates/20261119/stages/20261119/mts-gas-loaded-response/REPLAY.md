# Private calculation and replay

Use the retained Python 3.13 with NumPy, SciPy and PyMuPDF. All scripts use -B; worker math libraries are set to a single thread. Existing tables and numerical packets are write-once / compare-only. Two workers maximum and no services or scheduler. Units and signs are in DERIVATION.md.

1. Confirm the adjacent resolved-stellar-source seal and the scope in PROTOCOL.md. Run gas_field.py base high fine, then gas_rings.py. Inputs are only the earlier gas-source-input.csv and model profiles. No new rotation data enters the reconstruction. The outer R=40 ring refinement and multipole/force component misses are retained; vetted ring forces go to readouts.
2. For cases catalogue and column and (label,count,order) = (main,256,24), (main,384,32), (above,384,32), run loaded.py freeze CASE LABEL COUNT ORDER, before loaded.py full CASE LABEL COUNT ORDER. Also run loaded.py small CASE main 256 24. Fields and occupations start from the corresponding sealed stellar endpoints. The extrapolated combined derivative uses small fractions ±1/64 and ±1/128; these are strictly local numerical probes. Run diagnostics.py for full changes, energy and finite response, scores and resolution.
3. Run cross_stress.py main 256 24 coarse; repeat with fine. Run cross_stress.py main 384 32 fine. Residual Poisson energy, reciprocal volume integration and the upper-half-space stress verify the coupling in different ways. The packet includes the unit-convention correction; never apply it to a speed or change the original state label.
4. GAIA-COMPARISON-PROTOCOL.md describes the freeze before reading the new force outcomes. Run gaia_projection.py; published_figure.py uses the local pinned PDF if present, otherwise fetches only arXiv:2305.13358v3 and enforces a byte limit. Figure_compare.py (filename on disk: figure_compare.py) reads the three central/filled paths for each hemisphere and component, checks actual axes, plot boundaries and rendered colors; force_deficit.py converts the paired components. The PDF itself was inspected visually. The table is a figure extraction, not raw catalogue access. The R=12 row in the forecast is outside coverage and never enters the comparison. Physical predictions, extracted values and the census-based response to this result are distinct artifacts. Do not publish or redistribute the local PDF as part of a checkpoint dump.
5. Run column_gate.py, census_height.py and census_contrast.py. These are secondary local-density diagnostics, not additional predictions from a coupled wave that has not been solved in those deformations. Census source, units, height domain and limitations are described in the derivation and results.
6. Run verify.py replay to check the saved results, sources, controls, decisions and manifest. Use seal only for the first save. No tests require modification of older checkpoints or communication with another agent.

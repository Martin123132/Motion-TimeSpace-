# Replay in private working directories

Use Python 3.13, NumPy, SciPy, bytecode disabled, one numerical thread per worker. In place, use `python -B verify_quarter.py`. Stage and predecessor folders stay beside each other. No downloads, live telescope data or additional agents are required. The frozen inputs use the parent's checked field profiles and the previous quarter-forecast table. No catalogue is used to tune the finite calculation.

For an independent generation use a fresh sibling copy of just the programs and Markdown (this stage's frozen manifests include the directory name). Run quarter_evolve.py inputs; then quarter_evolve.py forecast PREP 128 256 for PREP=radial_rest and periodic_velocity; then quarter_evolve.py frozen. Only now run quarter_evolve.py finite PREP 128 256 for both preps. The main script checks the local stop marker at output intervals; at most two workers. Do not overwrite existing packets or run them automatically on an observation timeout.

Run read_quarter.py create first. For the precision diagnostic run paired.py pair-inputs, paired.py forecast 128 256, paired.py pair-freeze, paired.py finite 128 256, gauge_replay.py receiver, gauge_replay.py halfstep. Run clock_identity.py create, gauge_checks.py create, preparation.py create, shell_gas.py create, ordinary_budget.py create. Use verify_quarter.py seal and again without arguments. For a reproduction in a different absolute directory, compare content/normalized paths and numerical arrays rather than expecting all archive hashes to agree across SciPy versions. Use a fresh output location, not the live sealed stage.

Primary packet diag axes: time, quantity, four-corner axis, shell. Quantities in order: mass, excess pressure, Eulerian displacement label, coordinate speed, logarithmic lapse excess, scalar and matter energy flux times r², radial force diagnostic, particle count excess, specific J/r² excess, Hamiltonian constraint residual, radial derivatives of displacement/speed/excess pressure, full orbit lapse rate N/γ and its radial derivative. First 11 static baseline components are exactly zero for the perturbed readout. Paired archives use a different basis described in DERIVATION.md; component 3 there is the difference between particle preparations *with the same ordinary source*. Refined replays include the finite contrast in scalar H and W for possible later second-order work. Externally reported numerical inputs and limitations are in ORDINARY-MATTER.md. The two initial high-frequency phases and the independent Φ=π/4 launch threshold come from the predecessor, not this replay.

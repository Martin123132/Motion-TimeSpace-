# Reading or replaying the finite-duration local experiment
Read RESULTS first, then the action/field reductions in CENTRE-EQUATIONS, WHY-NEWTON-APPEARS, POYNTING-AND-RULER and MAGNETIC-NULL-SOURCE. There are no observations in these packets. Radius and time are in the parent geometrical units; directional volumes are dimensionless log-volume differences per squared infinitesimal spin. Fractions of small differences have their own denominators; failure to reach 2e-5 is not rounded to a pass.

**Read-only validation.** Run `python -B verify_centre.py` in the closed stage directory. It checks actual arrays, calibration and exact controls, re-derives the mass ledger from the trajectories, relinks the verified parent inputs and compares the full report and every file digest to the recorded closeout. It distinguishes structural checks from numerical accuracy and preserves missed comparisons. A sealed verifier is not a new field-theory postulate.

**Recalculation only in a new, empty sibling, never on top of these packets.** Copy the stage's Python files and notes into that sibling alongside the intact upstream stage directories. Python 3.13, NumPy, SciPy and mpmath; single numerical thread. Execute these in order:
1. For the archived failed raw prototype and resolution controls: `python -B regular.py .05 1 0`; repeat with `--damping 1`, and with `--damping .5 --reduced`. The raw .025 run with damping 1 previously became nonfinite and produced no valid packet; it is **not** needed to replay the physical readout.
2. `python -B regular.py .025 1 0 --damping .5 --reduced`, then `python -B retained_runs.py` (does not repeat the preceding calibration case). The eight source/state combinations have original numerical seeds, two radial grids, fixed R₀ and final clock.
3. `python -B linear_spectrum.py`, `python -B analytic_controls.py`, `python -B metric_controls.py`, `python -B flux_bound.py`. The last is the first quadrature; the root-resolved replacement is run in the next step.
4. `python -B budget_runs.py`; `python -B state_and_limits.py`; `python -B null_current.py`. These respectively build the smooth-source ledger and simultaneous numerical-variation control; exact dust, flux sign partitions and independent homogeneous state differences; and the prescribed coherent-current electromagnetic prediction.
5. `python -B mass_runs.py`, `python -B mass_score.py`, `python -B score.py`, `python -B scalar_signature.py`. The mass runs replace only the spherical gravitational evolution with the derived independent mass, work and pressure equations. The last command directly differences the full scalar/ordinary accelerations before integration.
6. In the replica only, create a new receipt with `python -B verify_centre.py --seal` and read it back in a separate process. Numerical fields and comparisons are the physical replay targets; archival metadata, compression, and the optional extra diagnostic members added to later packets are not guaranteed byte identical across environments.

No worker, preview or web server is required to inspect saved results. Any interrupted output must be checked before continuing, and only missing cases should be launched. Do not overwrite a completed packet or alter a tolerance to turn a miss into a pass.

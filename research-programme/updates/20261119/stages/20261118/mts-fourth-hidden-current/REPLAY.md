# Evidence and replay

Use local Python 3.13 with NumPy, SciPy and SymPy and the -B option. Run verify_hidden.py in this directory for the read-only cold check. It recomputes the response/energy polynomials, real intersections, channel projections, score tables and independent numerical controls from packets; it does not rerun the lengthy field equations. Do not edit earlier stages or remove receipts to bypass a hold.

For a fresh replay use a new sibling folder with these scripts and the three protocol documents PROTOCOL.md, WITHHELD-PROTOCOL.md, WEAK-LIMIT.md. The retained MTS branches, including their original input archives, stay in their original relative locations. At most two single-thread numerical workers:
1. hidden_run.py 0 prepare and hidden_run.py 1 prepare obtain the fourth magnetic columns, freeze compensated profiles from early fields alone, and evolve the hidden and centre-plus-hidden currents at .0125 and .025. The fine weights stay fixed on the coarse grid. Only finite, complete, verified packets should be reused; check every owner hold before a restart. The passive second field checks the fourth magnetic-only run’s spherical propagation.
2. hidden_detector.py coarse freezes a coarse-only observable. hidden_detector.py joint builds the separate two-grid observable. weak_limit.py freeze derives the ordinary-limit coefficients, then hidden_family.py freezes all candidate source weights. No direct imitation, joint or intermediate matched-scalar run may precede its corresponding forecast.
3. hidden_run.py 0 test and hidden_run.py 1 test run all frozen full-amplitude candidates on both original grids. weak_limit.py .125 and weak_limit.py .5 independently test the three-clock, smaller-amplitude scalar response on the original fine grid, reusing archived fixed/opposing and second magnetic traces. They first obtain the missing third magnetic column, freeze the finite early-field calibration, then propagate the scalar ruler. Do not exceed the two-worker limit when interleaving these commands.
4. launch_measurement.py, assess_hidden.py, hidden_detector.py score, witness_checks.py, focusing_witness.py and weak_limit.py score produce the scored tables. The local stress readout also checks direct trials not used to design their source weights; see LOCAL-FOCUSING-NULL.md. verify_hidden.py seal creates a receipt in a new completed replay; verify_hidden.py alone checks an existing receipt. Output writers normally reject overwriting. Keep all numerical misses visible.
5. For the physics start with RESULTS.md and DERIVATION.md. Root counts and exact orthogonality refer to the represented numbers on the saved grids, not rigorous continuum error bounds. Values at clock 6.4 are in retained solver units per spin (magnetic) or spin squared (ruler and kinetic cost). The scalar amplitude A is a separate initial-data parameter.
6. Run free_fall.py, vacuum_stress_control.py, then range_precision.py before sealing. They apply the clock test with unknown mass/charge, free constant vacuum stress, and explicit radius/velocity errors (FREE-FALL-TEST.md) to the already saved spherical backgrounds. This consumes no new field evolutions and does not give four independent monopole histories from four current shapes.
7. Run clock_source.py before sealing for the separate pressure/energy-transport explanation of the clock residual. It integrates only the reduced radius/mass equations with saved stresses; see CLOCK-SOURCE-BALANCE.md.

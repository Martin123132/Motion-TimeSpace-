# Replay and boundaries
Use the retained Python 3.13 and the existing local native scalar solver, NumPy, SciPy and psutil. Run verify.py with -B for a non-writing check. All new outputs stay here, except for the short pointer in CURRENT_LOCAL_RESUME.md. No observed absorption fluxes were used. The private observer build has two repurposed transfer output columns; it is NOT a replacement for the ordinary solver. observer.diff gives the exact change; observer.json records the compiler and object inputs. The original native library was not overwritten.

A recalculation should be in a fresh sibling of this folder under the same parent, with only the stage source files and protocol Markdown copied, not sealed outputs. Keep the PREVIOUS stage and its mode archive at their original paths. Order, with the retained interpreter and -B throughout:
1. prepare.py; envelope.py; check_fields.py reference; check_fields.py score. This freezes before its two held-out pressure tests.
2. make_observer.py; trace_input.py stock; trace_input.py observer; trace_map.py; trace_test.py. The frozen new a=0.0002600 forecast precedes acquiring direct pressures there. The earlier centers are now controls, not new holdouts. Independent results are numerical, on the same physical equations, not new astronomical observations.
3. late.py for 225pred, 250pred, 225direct, 250direct, 225tight, cold, lcdm, lcdm-mapped. The first two use no measured late-state seeds. All use stock perturbation code.
4. Run forest_switch.py with each (heavy,on/off/leading), (cold,on/off), (lcdm,on/off) in its own process. In the parent environment before creating each process set MTS_FOREST_INDEX=1, MTS_FOREST_SCALE=0.01 and MTS_FOREST_FACTOR=1 for on or 0 for off/leading. This is necessary for the statically linked Fortran runtime. One unsuccessful startup without inherited environment variables produced no states; no successful output was overwritten. read_results.py calculates ratios and pressure decompositions and checks bit-identical initial states. No estimated RAM or process cleanup by name.
5. verify.py --seal only in an unsealed stage after reading both forecast receipts; verify.py re-verifies on subsequent runs. File fingerprints document the actual run (not a promise that compressed files regenerate byte-for-byte on other library versions). Times, grids, conventions and input ownership are in the scripts and the two frozen protocols.

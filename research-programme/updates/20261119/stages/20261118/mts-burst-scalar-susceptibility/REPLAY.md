# Local replay and evidence map

Read RESULTS.md first. All comparisons use the inherited bank, charge .8, original time and spatial discretizations, and a relative target of 2e−5. A tick is .02 proper-time units. No sky data, new priors, fits or external jobs are involved. The weak amplitude is 1/160, not its square.

The supported read-only audit is: use the retained Python 3.13 with NumPy, SciPy and mpmath; from this directory run python -B verify_stage.py. This recomputes comparisons from saved packets, tests algebra independently at high precision, checks the ordinary source hashes, independently integrates the ruler forcing, checks stored tables against recomputation and verifies the closed manifest. The verify command does not rerun long evolutions or overwrite receipts. Original inputs are siblings mts-coherent-current-ruler-20261118 and mts-regular-centre-burst-20261118, using their existing protected ancestors. Predicted arrays use columns documented in susceptibility.py and their parent tangent packets. In the saved prediction the 12 columns are ruler, determinant, polar B, transverse E, transverse B, areal radius, shear, twist, direct scalar, polar electric, dipole, material. Physical observer radius at release is 6.

To replay from scratch, use a **fresh sibling** with the stage Python sources and protocol documents, leaving the sealed stage alone. Never start a duplicate packet or remove an owner hold. Run at most two single-thread numerical workers.
1. Run susceptibility.py with each spacing .025 and .0125 and tag minus, then forecast.py to freeze the leading coefficients. The historical full-amplitude result was already known. No new finite-arm data were read to derive that forecast.
2. Run finite.py for (.0125,.00625), (.0125,.5), (.0125,.125) and (.025,.00625). Each computes the specified fixed and then independently matched current. For the pure passive-wave control call finite.evolve(.025,0.,"fixed") once. Baseline, matched full-arm, and all full-arm basis traces are reused from their archived solutions.
3. Run paired_evolution.py at .025 .00625 fixed then matched. The weak direct fixed packet supplies one actual early field column. The paired solution works at finite amplitude, not the A=0 tangent. The two short paired smoke packets document a numerical logarithm issue and its repair. Only the final implementation is the replay target; do not expect it to recreate the old failing .04 determinant. The .04 tangent smoke is optional. 
4. Run susceptibility.py at .025 with first and second, then mixed_coefficient.py derive. This calculates the mixed part of the A⁴ term from ordinary-equation derivatives only. Run mixed_coefficient.py compare, nonlinear_remainder.py, arithmetic_controls.py, clock_features.py and assess.py. Writers refuse to overwrite existing evidence. verify_stage.py seal is for a completed new stage; verify_stage.py alone rechecks it.
5. Read amplitude-tests.csv and per-clock-tests.csv separately. The main history norm is maximum absolute residual divided by maximum absolute predicted scalar response (or measured response where explicitly labeled); a particular clock instead uses its own value. Percent accuracy on the much larger total metric signal is not evidence of accuracy on the scalar correction. The two grid runs change spatial spacing and associated internal RK subdivisions together; they are not an isolated temporal convergence test. The integrated ledger uses all 321 clocks; the independent Simpson check uses the five reporting clocks.

# Short-time response to an independently specified radiation stress

The matched operator jump is a special case, not the reason for the power law. In this linear CDM-comoving, common-metric branch, perturb just the massless radiation shear with all densities, fluxes, field perturbations and gravitational constraint data initially matched. Write π for the **difference** in the induced radiation quadrupole. Let I_j f=(1/(j−1)!)∫₀ᵗ(t−s)^{j−1}f(s)ds. To leading nonzero order the flux equation gives ΔF=−2 I₁π/3; radiation continuity gives Δ(D−4C/3)=2 I₂π/3. The Einstein trace then gives ΔC_x=2(f_r/g*²) I₃π. A scalar minimally coupled to the same metric obeys LΔu=(φ′/k)ΔC_x, hence its scaled pressure is

    ΔP = 2 (φ′*)² (f_r/g*²) I₄π + higher-order terms.

Specifically for π=A tⁿ+O(tⁿ⁺¹), the leading pressure coefficient is

    (2 A n!/(n+4)!) (φ′*)² (f_r/g*²) tⁿ⁺⁴.

Here x=kτ, t=x−x*, so powers and units are tied to this dimensionless clock. Each integration arises from a separate physical equation, not from fitting powers to simulations. A pure initial shear offset (n=0) is allowed by the scalar energy/momentum constraints: they constrain density and flux, not this quadrupole. For n>0, supply an explicit shear-derivative source n A tⁿ⁻¹; this is a normalized response experiment, not a claimed cosmological production mechanism. The coefficient is universal only within the stated linear system and matching conditions; an initial density/velocity change or a direct scalar coupling need not have this delay.

Test n=0,1,2,3 at unit amplitude on both saved backgrounds, each with the full hierarchy and with the fluid closure. Use the same tolerances, unchanged moment definitions and independently evolved trace and Hamiltonian metrics. This separates a property of the retained matter–metric coupling from the particular numerical switch that first exposed it. Keep the fixed original cosmological predictions separate from these unit-source responses.

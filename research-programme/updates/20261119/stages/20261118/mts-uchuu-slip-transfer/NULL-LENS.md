# Replace a theoretical k cut by a constructible combination of lensing maps

For three thin source planes measured in the same region, combine convergence maps as a₁κ₁+a₂κ₂+a₃κ₃. Take a₃=1; solve Σa=0 and Σa/χ_s=0 using the *retained heavy branch's distance ratios*, without using lens power. Freeze those weights for every comparison, even ΛCDM. This is an application of the geometry null of Bernardeau, Nishimichi & Taruya, https://arxiv.org/abs/1312.0430, not a new mathematical invention. New here are the native MTS fields and the test of whether their distinctive signal remains on controlled scales.

The effective kernel is g(χ)=Σa_i max(0,1−χ/χ_i). With correct distances it vanishes for χ<χ₁, so the foreground is removed at the map level before using Limber. Within Limber the surviving wavenumbers satisfy (L+1/2)/χ₃ ≤ k ≤ (L+1/2)/χ₁. A different geometry leaves the calculable leakage −χ Σa/χ_i for χ<χ₁. Report the equal independent bin noise multiplier Σa², not a survey error bar. The sharp k support is not exact beyond Limber.

For the ideal auto-map only, report the full-sky Gaussian/no-shape-noise sensitivity ceiling on the heavy-vs-same-background-cold contrast over integer L=30..floor(0.1χ₁−0.5). This fixes the conservative k ceiling before computing the null. It is not the sensitivity of all lensing statistics, and not an observed detection.

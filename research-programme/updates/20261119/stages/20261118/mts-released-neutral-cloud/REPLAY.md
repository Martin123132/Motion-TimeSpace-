# Verification and replay
From this directory, the retained Windows Python 3.13 runtime with NumPy, SciPy, SymPy and mpmath can run `python -B verify.py` for an independent cold read. It checks upstream seals and numerical outputs without launching an evolution or changing the files. `closeout.json` hashes this stage's files (excluding itself), the direct inputs it consumes and the named verification outcomes. There is no dependency on a notebook, remote server or observational download.

**Full regeneration:** use a clean sibling of this folder in the same research parent, copy the scripts and Markdown there, and leave the original untouched. Some producers use exclusive output creation specifically to prevent silent overwrites. One process and one numerical thread suffice. In order, with `python -B`:
1. `strip.py` replays the original higher-accuracy parents; final tangents and sampled detector quantities must match exactly. `trajectory.py` follows each centre in proper time; `cloud.py` evolves curvature and separation independently.
2. `paired.py` computes baseline–scalar and emitting–matched-mass differences. `area_map.py`, `early.py`, `exact_cloud.py` provide the alternative geometry, initial-data/neutral-Newton and full exact spinning controls.
3. `synchronise.py` retains the first clock-matching attempt. `wave_difference.py` reproduces the baseline electromagnetic bank bit for bit and propagates the microscopic source difference. `synchronise.py --repaired` reuses that difference. Its `repaired.npz` is the input to `paired_arms.py`.
4. `killing.py`, `diagonal_arms.py`, `paired_arms.py`, `ancestor_ruler.py` evaluate the signed local rate, finite-length readout and comparison to the earlier free probes. `verify.py --seal` is restricted to first creation; verify again without the flag. Library/interpreter differences may change file bytes; compare scientific arrays on their declared scales, not ZIP metadata across new regenerations.

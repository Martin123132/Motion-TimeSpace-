# Replay
Read RESULTS.md for the scientific result. Run verify.py with the retained Python 3.13 and -B to perform non-writing verification here. A full rerun writes into a *fresh* sibling under the same parent, with the same input directories and only the stage scripts and Markdown copied in. Do not overwrite the sealed run. The compiler, CAMB, NumPy, SciPy and psutil are already local. Single numerical thread; one process per environment-changing native intervention.
1. observer.py builds readout diagnostics in a private copy; sources.py for heavy, cold and lcdm produces source-only packets and separate check packets. Only the driver's photon gauge conversion consumes the CDM velocity column from its own check packet; there is no use of a pressure-off output for forcing.
2. physics.py preserves the first Newtonian and synchronous-source comparisons. photon_frame.py carries the photon dipole in a common frame and saves new comparisons. independent_epochs.py freeze locks forecasts at redshifts not among the original seven readouts. Run independent_epochs.py with arguments heavy wave, heavy off, cold cold, lcdm cold in separate processes: MTS_FOREST_INDEX=1 and MTS_FOREST_SCALE=0.01 must be set before creating the process, and MTS_FOREST_FACTOR=0 for off or 1 for others.
3. campaign.py modes then campaign.py main: small-amplitude planar checks, repeated amplitude/time/resolution checks and the controlled 3D gas boxes. nonlinear_checks.py: independent nonlinear and free-field analytic controls. sightlines.py: thermal/redshift-space operator, analytic checks, transverse effects and sensitivities. The box stores velocities in km/s in the sightline fields; spectra are comoving until explicitly converted with aH. The native gas and the extra assigned heat are distinct.
4. primordial.py campaign then primordial.py scores: sparse-box modes with invariant P_R/V variance, phase-paired tests and warm linear prediction. radial_and_scales.py: physically mapped plane-only examples and acoustic scale integration. energy.py then work_quadrature.py: three matched energy budgets, including event-split controls on the same trajectories.
5. band_prediction.py generates the authoritative mapped continuous-band tables and midpoint forecasts. The three rejected unmapped historical diagnostics need not be regenerated. verify.py --seal in an unsealed stage, then verify.py. File checksums identify exact outputs, not a cross-platform byte-for-byte compression guarantee. Previous verified folders remain intact. No new downloads of observational data, no subagents or background services required.

# Replay and resource limits

Run verify.py with the retained Python 3.13 and -B for a non-writing integrity and numerical check. For a computational replay use an EMPTY sibling of this folder with only the scripts, PhaseMesh.f90 and protocol/notes. Keep all older research at its current path. Stage files are exclusive-create; do not reuse a completed output directory to retry a failure. Compiler scratch is removed after linking. The original CAMB library, previous banks, earlier checkpoints and all observations remain untouched.

1. build.py creates the private solver from the original source/object library and existing pressure switch and diagnostic-output diffs. PhaseMesh.f90 and native.diff define the new inverse-clock treatment; build.json pins the compiler, modules, objects, original sources and runtime hash. Use a fresh process for each native invocation. Unless running switch.py, do NOT export MTS_FOREST_INDEX / FACTOR / SCALE. The optional clock mesh is installed before creating a CAMB background; it cannot change during a run.
2. microscopic.py fine then microscopic.py coarse. impulse.py fine/coarse checks all interior samples as well as endpoints. bridge.py fine/coarse. For each mesh run late.py LABEL heavy 1200 and 1500, plus late.py stock cold 225 and late.py fine cold 225. This reuses, not rewrites, the sealed, independently validated gas operator. The cold background is the retained rolling all-cold branch. Labels stock/fine keep the disabled and enabled private treatment distinct.
3. In separate processes run switch.py fine CASE TAG ARM. Set MTS_FOREST_INDEX=1, MTS_FOREST_SCALE=0.01, MTS_FOREST_FACTOR=1 for on, 0 for off **in the parent environment before launch**. Run both arms for heavy at 1200 and 1500, cold at 225. Each new output directory receives the actual full initial vectors before the intervention. Leave the switch environment before continuing. controls.py and gravity_sources.py score them.
4. work_source.py then balance_map.py reconstruct the metric work and conserved projected propagation with independent initial constants; do not use the later D/Q as input. Repeat microscopic.py finer, impulse.py finer, work_source.py finer and balance_map.py finer for the quartered versus initial phase-mesh control. Run convergence.py fine coarse and convergence.py finer fine. The extra clock refinement changes only integration coordinates and resolution, not temperatures, field parameters, initial populations or tolerances.
5. After the original four sentinel endpoint tests, WIDER-PROTOCOL.md fixes the remaining nodes, including a single repeat anchor. For each of wide and wideCoarse: wide.py seeds LABEL, wide.py bridge LABEL, wide.py late LABEL heavy 1200 and 1500. Also wide.py late wide cold 225. band.py joins the two acquisition groups by physical k and omits the repeated 37 anchor only after comparing it. tail_budget.py uses full-grid-bands.csv; it does not substitute the last interval for the unknown tail.
6. With the human-readable results present, verify.py --seal once and verify.py again. The private native background sometimes reports a Romberg roundoff warning around 13481.84 with estimated absolute error of order 10⁻¹¹ versus a requested ~3×10⁻¹⁴. Independent phase meshes, fixed-mode repeats, true output scales, full-state interventions and source checks, rather than the requested accuracy string alone, are used to assess the result. No long-running service, subagent, publication or data download is needed.

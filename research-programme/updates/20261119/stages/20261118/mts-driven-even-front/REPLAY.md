# Reproduce in a private sibling folder
Use the retained Python 3.13 (NumPy, SciPy and the existing MTS dependencies) with -B, one worker per command. All relative upstream paths assume this directory is a sibling of the sealed MTS source folders. Do not run the writers in the archived results directory: numerical packets open exclusively. To recreate, copy the Python and Markdown files to a fresh sibling, retaining parent folders and file hashes. No remote data, changing fit, GPU, worker scheduler or foreground app is needed. Time is the launch clock in the parent's geometrical units. The shell option changes the scalar initial preparation, not the evolution laws.

1. Run falling_test.py with spacings .05 and .025, η .8 amplitude 0 (no --direct). These are retained failed comparisons on the leading flank of the pulse, not production predictions. Both adjacent first derivatives approximate a second derivative but have a different short-scale dispersion.
2. For each spacing .05, .025, .0125 run falling_test.py DX ETA AMP --direct for (1,0), (.8,0), (.8,1/160), (.8,1), (0,0), adding a separate --shell run for the two nonzero amplitudes. Here 1/160 is entered as .00625, not a Python expression. The direct wave stencil discretizes (A_x/a)_x by the product rule with a direct eighth-order spatial second derivative, the same order as the independent polar-sliced radiation bank. For nonzero signals compare the complete window normalized by its peak, rather than dividing by an arbitrarily small pre-front wave.
3. refinement.py adds the two-source and moved-domain runs, independently reconstructed momentum constraints, the next detector resolution and a time refinement. late_refinement.py adds the independent neutral master comparison and the two wide, finest source runs. smooth_vacuum.py separately checks division into a smooth analytic exterior and tabulated interior initial seed in the neutral vacuum control only. The material solver did not inherit or use Zerilli data. preparation_difference.py computes the difference-state evolution independently.
4. summarise.py and magnetic_comparison.py construct human-readable comparison CSVs. The tables retain failures, including where comparing two small differences is less accurate than comparing the absolute results. verify_front.py --seal once in the fresh directory, and verify_front.py without arguments for a cold replay of the direct source links, comparisons and local hashes. A failed refinement in the accuracy ledger remains failed. The file-integrity checks do not imply all physics checks passed. For the preserved original, run only the latter read-only command.

The domain with x≤1.65 or x≥10.35 is a numerical holding zone in the standard grids, not a physical boundary condition for the complete emitter. The wide grids move both holding zones outwards by 0.5. Do not extend the fixed-radius 6 trajectory as though the centre were regularized by this boundary. Extend the material domain through a regular centre to follow the longer burst.

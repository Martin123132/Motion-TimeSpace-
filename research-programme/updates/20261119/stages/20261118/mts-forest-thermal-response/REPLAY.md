# Private replay, sources and scope

Quick read-only verification: use the retained Python 3.13 installation, run verify.py with -B in this directory. For a computational replay create an empty sibling containing ONLY these scripts and Markdown notes. All numerical outputs and receipts use exclusive creation; do not rerun a completed producer into the sealed folder. No network, data release, fitting, Git operations or long-running service is needed. Scripts set one numerical thread, pin the worker to one allowed CPU and use below-normal priority; keep at most two independent workers. The source-acquisition commands require fresh processes to initialize each native clock exactly once. The inherited and local STOP-REQUESTED gates should be honored.

Dependencies: the saved NumPy/SciPy/psutil environment and previously sealed native CAMB library and scalar source banks on this laptop. Actual external module paths and hashes are checked by verify.py; the source tables are not duplicated into this stage. The project's older code uses the labels fine and wide for *different wavenumber groups on the fine clock*; 1200 and 1500 are matching surfaces, not temperatures, and cold always uses its own 225 source. Duplicated 37 Mpc⁻¹ is compared and counted once. All-cold is not flat ΛCDM.

1. Run tangent.py 1200 and tangent.py 1500. Run spectrum.py to save the mathematical forecasts and their hashes **before** the following finite-temperature or mode tests.
2. Original grids: direct.py 1200 grid and direct.py 1500 grid. Separately, acquire the new probe modes: probes.py seed heavy, probes.py bridge heavy, probes.py source heavy 1200, probes.py source heavy 1500, probes.py source cold 225. Then direct.py 1200 probe and direct.py 1500 probe. The private bindings send the new output files only to this directory; they do not change the original source or binary. CAMB may still report the previously documented Romberg precision warning on a background integral; the actual source, phase-window, constraint and matching comparisons are scored separately.
3. compare.py and probe_scores.py score the frozen predictions. resolution.py performs the independent small-temperature derivative and finer time steps at the failing near-zero checks. angular.py and contrast_grid.py use the original and reduced k sets and alternative numerical rules to evaluate the shape statistics, not fits. Units are comoving Mpc⁻¹, kelvin and one-dimensional velocity-space power in km/s.
4. After the primary tests, matched_test.py freeze then matched_test.py test constructs the labelled equal-root experiment. tail_moments.py checks how the resulting shape moments join across intervals. stress_test.py tests the additional rest-frame pressure/number pair; the retained probes and default gas prescription remain unchanged.
5. verify.py --seal once, then verify.py without arguments. There are no background services or editor previews. Verification checks timing and hashes of the prospective forecasts, original source integrity, signed controls, change of matching surface, time and source resolution, separate near-zero failures, and both new derived diagnostic identities. The finite frequency band, conditional thermal history and unresolved population of a specific galaxy are not full observational predictions.

# Private local replay

Use retained Windows Python 3.13 with NumPy, SciPy, SymPy and psutil. Read-only: run `python -B verify.py` in this folder. This checks upstream inputs, all retained waveform arrays and the frozen prediction hash; recalculates scores for the two solutions, current and torque budgets, labels, arriving signals and static moments; and checks exact symbolic identities. It starts no long evolution or service.

Full replay should use an empty sibling folder with only the Python and Markdown files, retaining the original charged and transverse stages. Use a single numerical worker. Run in this order with -B:
1. current_source.py, then static_modes.py. The latter freezes the 56/112/224-element predictions and both specified spin profiles in frozen.json. Verify that receipt against the digest enforced by radiate.py before testing them.
2. radiate.py runs the two radial meshes, ordinary, MTS, neutral and reversed-charge controls, and the second static-source profile. readouts.py scores them, leaving all original failures visible.
3. calibrate.py independently refines the frozen prediction, uses the same archived density to reconstruct the baryon label, checks material recoil on tracked labels, and computes the stably differenced proper delays. It does not replace earlier files. paired_work.py and exterior_work.py check matched ordinary/MTS work and the small exterior term.
4. steady.py solves the decaying stationary problem (no outer conducting wall). moment_law.py derives the first two coefficients as exact rationals and compares them to the stationary computations. The unsubtracted quadrature for two opposing currents can report a roundoff warning; it is auxiliary. The integrated-by-parts identity and independent weak-form solution are used to assess the small remaining moment. Read SIGN-AND-SIZE.md for the sign proof.
5. Only a byte-identical replay with the original closeout.json should pass the original file-hash checks. Never overwrite a signed run or relax its frozen tolerance to force a replay.

Output normalizations match the retained stage: divide energy by 2/3 times the square of the small input rotation, and K or A by the rotation amplitude. Spectral computations of the time-dependent field use a causally isolated wall at 14; the static decaying solution instead matches an exterior reaching infinity. The scalar amplitude and compactness multipliers are distinct: the four compactness scales apply only to the stationary ordinary control. Input l is the canonical angular momentum coefficient in the parent reduced length units. For a geometric magnetic dipole μ_g (length²), the SI moment is μ_g c²/sqrt(G μ₀/(4π)), after restoring the length unit and spin amplitude. This conversion is not a determination of those inputs from data. No survey, source outside the retained dust, or remote service is required.

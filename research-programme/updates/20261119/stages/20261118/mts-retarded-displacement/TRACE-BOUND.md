# Which missing stress would suffice?

Instead of assuming a smooth missing metric force in the widest pre-material gap, use the trace equation from the retained metric solver. In x=kτ its normalized density and pressure enter C,xx+h C,x=(D+3P)/2. On two geometries the forcing difference also contains −Δh C′_S if propagated with h_N. Below the metric and readout weights are fixed; an unknown trace residual r satisfies d′+h d=r, where d is the error in C′. The test does not assume that the candidate supplies an independent numerical bound on r yet.

Take L and R as the widest consecutive original knots before 1999. For any kernel K acting on d and d(L)=0, its inducing trace kernel is T[K](t)=I(t)∫_t^R K(x)/I(x) dx, I=exp(∫h). If both metric-drive endpoints and the CDM increment are known, trace directions are orthogonal to I(t)/I(R) and T[1]. Exact heavy-field endpoints, where a heavy field exists, add T[K_h,1] and T[K_h,2]. Subtract the projection of the terminal slow-displacement trace kernel onto these constraints. Then |Δu_s(T)| ≤ ||T[K_s]_perp||₂ ||r||₂, sharply: a unit-norm residual parallel to that kernel attains equality. The upper limit on rms trace residual that suffices for a given absolute displacement error ε is ε/(sqrt(R−L) ||T[K_s]_perp||₂). This is for this cell's remaining unknown component with exact supplied constraints; do not claim a bound on the full history or treat binary32 endpoints as exact measurements.

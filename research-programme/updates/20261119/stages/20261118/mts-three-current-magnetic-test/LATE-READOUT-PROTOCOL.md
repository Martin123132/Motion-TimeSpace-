# Can the apparent ambiguity survive more than one late reading?

Keep the primary calibration clocks at 3, 4, 5. Do not choose new clocks from a favorable signal. Two diagnostics using only the already calculated fields:

1. At predeclared later proper clocks 5.5, 6, 6.4 stack the *linear* residual rows H=F₁(late)T−F₀(late). Normalize each row by the ordinary three-unit-current magnetic channel norm at that clock; energy-normalize the columns with the independent Gram E. The least singular value is a bound on the vector of three late field discrepancies for every matched source of specified nonzero ordinary kinetic cost. Compute H=(F₁−F₀)+F₁(T−I) to reduce cancellation. Report the bound only for these three profiles, both grids, and compare the least singular value to the spectral norm of the grid-to-grid difference on the same scales. Do not use rank at floating-point precision as physical resolution. Fitness to these synthetic fields is not observational evidence.

2. For a detector able to read both late ruler values at 6 and 6.4, choose a *single signed linear combination* of the two clocks with total absolute weight one, using only the coarse response matrices to maximize the smallest energy-normalized scalar-minus-ordinary response. This is a designed detector observable, not a change to source physics. Freeze its coefficients from the coarse matrices before validation with the fine grid. If the resulting matrix is positive definite with eigenvalue margin above numerical grid disagreement, this combination separates all nonzero source directions in the retained family at exact three-field calibration. If not, do not infer the physically distinct theories are indistinguishable. A normalized two-clock combination cannot increase the maximum time-domain readout noise. Report how this bound compares with calibration uncertainty; do not present it as an achievable instrument tolerance.

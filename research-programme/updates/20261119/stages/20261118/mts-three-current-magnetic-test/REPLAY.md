# Reproduce or resume locally

Run the retained Python 3.13 with -B (NumPy, SciPy, mpmath). All paths resolve relative to this stage's unchanged parent branches. To verify an already sealed stage, run python -B verify_results.py only, in this directory. For an independent full replay use a fresh sibling, copy the stage scripts plus its predeclared protocol files; never remove or replace a sealed packet to force a rerun. Single-thread numerical workers, maximum two. Operators respect STOP-REQUESTED. No network, data fit, git or scheduling required.

1. stage.py .025 basis and stage.py .0125 basis evolve the six new basis packets per grid (third unit and two polarizations, in two arms) through all 321 clocks via the retained solver. Valid packets are reused on a restart. Old unit currents and opposing mixture are hash-checked and reused; the old scalar first unit uses the full coupled parent budget file rather than a reconstructed fit. All new currents go through the physical constraint and full evolution. 
2. Once the coarse basis exists, late_readouts.py design fixes the two withheld ruler coefficients, and staged_validation.py freeze fixes the independent .45,−.70,.85 mixture forecast from coarse sources only. staged_validation.py .025 and .0125 can run before the entire fine basis exists. Their start receipts name the prospective forecast. This permits useful computation while waiting for a fine basis, without fitting or viewing the held-out mixture to design the detector. Do not run competing producers for the same pending packet.
3. Once both bases exist, three_response_map.py freezes both full arrays, nominal matched weights and extremal pair; mimic.py freezes the explicit two-clock adversary if one exists. stage.py .025 test and stage.py .0125 test use these weights without rereading late measurements to calibrate. The same fine frozen source weights enter the coarse checks. Valid completed mixture packets are reused. Absent or failed receipts should be investigated, not silently overwritten.
4. Run comparison.py, packet_controls.py, noise_box.py, late_readouts.py test, fractional_bounds.py, sign_history.py and rational_certificate.py to generate the scored evidence. The last script reconstructs the final sign inequalities as exact rational inequalities on the stored basis readouts. Run verify_results.py seal and then verify_results.py in a fresh process. The verifier recomputes all score tables and validating matrix identities from the archived computations, but does not rerun full trajectories.
5. See RESULTS.md for physical interpretation, DERIVATION.md for the equations. Both field and ruler coefficients are in solver units per spin or spin squared respectively. The tolerance is 2×10⁻⁵; errors on a large total and on a small inter-model difference are reported separately. Core constraint samples, mass/flux and independent Green initial-constraint controls are retained in the numerical packets; valid field/ruler tests do not imply every internal discretization diagnostic meets that tolerance.

# Matched galaxies, real to redshift space

Use the high-resolution Uchuu COMB North and South lightcones at the source of the BOSS DR12 comparison, 0.2 <= z_obs < 0.5, using w_cp w_fkp w_npcf per the release. Fixed selected galaxies/weights for every counterfactual. Use mock 0 only to prepare a residual displacement law; freeze before opening galaxy rows of mock 1. Both have the same ΛCDM simulation origin, survey-calibrated selection and potential replications; this is a transfer test of a tracer prescription, not a new independent universe or an MTS simulation. No GLAM files (release warning), raw observations, parent-parameter fitting, or mass-based halo velocity substitution.

Check the published radial velocity against z_obs−z_cos, positions and vector velocities. If angular coordinates use a rotated frame, do not project Cartesian velocities onto sky RA/DEC without establishing that rotation. The direct radial redshift difference is the positional truth. Connect satellites only to an actual, unique, locally colocated host using pid and id, checking periodic replicas and angular/position matching. Quantify missing hosts and potential representation bias; do not assume their velocities vanish. For a measured satellite and matched central, use the satellite-minus-host velocity projected on the satellite's radial direction if the Cartesian frame is verified; otherwise flag the approximation. The halo population is mock truth.

Test a concrete consequence of an independently drawn residual shift: the number-weighted and Fourier-relevant characteristic function, and for distinct-host pairs its factorized prediction versus direct relative residuals. Hosts moving together, centrals and satellites are not interchangeable. Use original/mock cosmology for displacement conversion; do not tune σ to the South residual. Preselect k_parallel=0.025, 0.05, 0.075, 0.10, 0.15 h/Mpc, with the middle four lower-scale-screen probes <=0.10. Report primary errors, not just aggregate passes. At minimum test zero motion, common translation, sign reversal, pair weights, and sample/host coverage; quantify if the effect is testable before mapping a conditional result onto the entire population. Keep mock-only frozen tests distinct from any comparison to already exposed BOSS data.

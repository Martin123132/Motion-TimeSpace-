# The ordinary Newtonian limit under the same source-matching convention

In these units m_N(R₀)=∫₀^R₀ r²D(r)dr is the sum of the initially specified baryonic rest masses. The ordinary GR reference m₀ instead integrates r²D√(1−2m₀/r); the difference is binding, not a different G. For a regular ordinary cloud with initial compactness ≤c_b<1,
    0 ≤ m_N−m₀ ≤ [1−√(1−c_b)] m_N .
For a profile bounded by D_max with total rest mass M_N, 2m₀(r)/r≤min[2D_max r²/3,2M_N/r], giving a prior global bound c_b=2M_N/(3M_N/D_max)^(1/3) when this is <1.

Before shell crossing the matched Newtonian ordinary shell satisfies R_N″=−m_N/R_N², initially at rest. Its tangent Jacobi field is R_N/R₀; its radial one solves J_N″=2m_N J_N/R_N³−D(R₀)(R₀/R_N)². The standard ordinary GR dust solution has exactly the same form using its proper clock, m₀ and the initial proper density instead of D. The familiar exterior Newtonian tide E_r=−2m_N/R³ and E_t=m_N/R³ therefore has a precise source-matching correction. Using the same numerical value of a fitted central mass in two models would hide this distinction.

For an explicit sufficient **combined scalar-to-Newton** bound, apply the comparison in COMOVING-GR-BOUND.md with the Newtonian shell as reference. Replace m₀ by m_N in its kernels, and B_M by B_M+[1−√(1−c_b)]m_N; replace the bound D a_* μ/R₀ on the initial proper density mismatch by D[a_* μ/R₀ +1−√(1−c_b)]. Use the Newtonian reference radius and its own Jacobi bound. The other terms are unchanged because the Newtonian shell has no scalar flux or radial pressure. The source correction tends to zero with both the scalar energy budget and the ordinary binding compactness. The result compares *local elapsed proper time* to Newtonian time with synchronized starts, not a remote gravitational redshift measurement. Identifying an asymptotic coordinate clock adds the explicit factor dt/dτ=W/α and separately requires small redshift and speed differences; a distant spherical shell can change that lapse while leaving the interior experiment unchanged.

This is a finite-time, spherical dust limit within the retained common-metric branch. It neither derives the absolute numerical value of G nor eliminates the need for the local scalar occupation and exterior state. It explains how to bound instead of postulating a pointwise vacuum plateau.

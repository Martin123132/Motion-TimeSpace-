# How to verify or reproduce without overwriting

Read RESULTS.md and PROTOCOL.md first. The closeout fingerprints every script, derivation, CSV and numerical packet in this directory and the seven listed parent inputs. No observational data, fit, massive external engine or download is required. The baseline is ordinary self-gravitating dust and the MTS runs add the retained quadratic scalar. An implicit Einstein metric is not a derived numerical value for G.

**Fast, read-only verification:** use the retained Windows Python 3.13 with NumPy, SciPy and psutil; from this directory run `python -B verify.py`. It re-reads the packets including numerical arrays, validates CSVs, checks source hashes, independently recalculates the nonzero threshold and ruler comparisons from the saved histories, and preserves the failed numerical diagnostics. It does not start background processes. Do not use Python's -O flag. The stage was sealed once with --seal (exclusive create); never reseal a changed packet.

**Full replay:** print the exact serial command list without executing it using `python -B replay_plan.py`. To recompute, work in a new empty sibling directory under the same post-checkpoint-work parent. Copy only the scripts, Markdown and original closeout.json there. Retain the signed upstream directory. Use the printed commands with that directory as the working directory and then run the read-only verifier there. Acquisition filenames encode radial resolution, arm, phase/preparation, weight and applicable time controls. Do not rerun a production command in the signed stage: its outputs use exclusive creation. No jobs or timers must be launched by the reader. Different library versions or machines may round differently; distinguish a byte mismatch from the scale-aware numerical comparisons in the tables.

**Where to look:** independent dust and four-arm tidal signals in dust-independent-1920.csv, retarded-prediction.csv and independent-geodesics-3840.csv; strength and time/space controls in source-scaling.csv and resolved-mesh-controls.csv; numerical failures in metric-reread-3840.csv, balanced-work-3840.csv and moving-independent-integrals.csv. The initial energy ceilings are in initial-norm-certificate.csv; nonzero prospective checks are in small-nonzero-control.csv and small-nonzero-refinement.csv. Run results are finite-time calculations in dimensionless reduced Compton units, not data from a telescope.

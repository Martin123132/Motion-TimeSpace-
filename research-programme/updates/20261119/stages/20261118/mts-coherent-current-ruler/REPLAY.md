# Private reproducibility and assumptions
A read-only check in this completed directory is `python -B validate_mixed.py`. It verifies the linked parent receipts and checks the actual numerical arrays, immutable calibration predictions, analytic moments and physical bounds. It reports numerical accuracy misses separately from structural checks. No server or parallel process is needed to read these results.

For a fresh replay copy only the Python and Markdown files into a **new sibling** of the intact parent stages. Do not execute generating commands over existing packets. Use Python 3.13 with NumPy, SciPy and mpmath, one numerical thread per process. In a shell where each command must succeed before continuing:
1. For spacings .025 and .0125 run `python -B mixed_current.py SPACING 1 0 minus`. For each spacing also run `python -B mixed_current.py SPACING .8 0 minus` and `python -B mixed_current.py SPACING .8 1 minus`. Replace SPACING with the specified number.
2. `python -B response_map.py` compares against the earlier stage's signed predictions and freezes the complete two-shape matrix and the fourth source's result. Only then run `python -B mixed_current.py SPACING 1 0 blind` and `python -B mixed_current.py SPACING 1 0 outside` at both spacings. The blind case is an independent numerical replay of a specified current, not an unseen galaxy.
3. `python -B alias_test.py freeze` takes only two early field samples to specify the alias. Run `python -B alias_test.py .025`, then `python -B alias_test.py .0125`, then `python -B calibration.py`.
4. `python -B matched_branch.py basis`, then `python -B matched_branch.py freeze`, then `python -B matched_branch.py test`. These complete the paired source/ordinary and source/MTS calibration, and run the actual gravitational prediction without fitting to its later values.
5. Run `python -B energy_line.py invisible`, `python -B energy_line.py freeze`, `python -B energy_line.py midpoint`, `python -B energy_line.py compare`, then `python -B exterior_bound.py`. These are separate tests: the finite-duration envelope lives in the three specified current shapes, whereas the proved exterior release bound treats any smooth balanced spin profile on this fixed extremal background.
6. `python -B scalar_limit_check.py` evaluates the scalar-to-ordinary launch bounds on the saved paired preparations. Run `python -B launch_variation.py freeze`, `python -B launch_variation.py test`, and `python -B launch_variation.py refine` in that order for the independent zero-amplitude susceptibility. In the replica only, `python -B validate_mixed.py --seal`, then start a new process for `python -B validate_mixed.py`. Do not fill missing packets from interpolated results. No observations were used to calibrate, validate or set a physical energy cap. The weights and all times in the freeze artifacts make future falsification possible.

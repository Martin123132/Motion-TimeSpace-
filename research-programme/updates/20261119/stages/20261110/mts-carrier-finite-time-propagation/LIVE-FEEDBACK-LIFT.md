# Current-state lift of the derived correction

This is the algebraic interface for the NEXT fully coupled test. It is not a claim that that test has run. It uses the retained native all-species interface rather than adding an independently prescribed new field.

Let X be the exact two-component heavy normal state and R the retained rest/slow-species state. At fixed homogeneous background their linear equations and metric readout have the form

    X'=A*X+G*L*R,
    R'=C*X+D*R,
    zeta=L*R.

A already includes heavy self-gravity. C,D,L are the actual native rest response and constraint, not fitted matrices. The heavy source transformation is

    X=P2*y+h*zeta,

where P2 is the upper-left block of I+K and h its upper-right column. The derived approximate equation retains the rest compensation:

    y'=A_eff*y+g_eff*zeta-P2^-1*h*zeta'.

The rest metric derivative is not an independent input in a live solve:

    zeta'=L'*R+L*R'
          =L*C*P2*y+(L'+L*D+L*C*h*L)*R.

Therefore the coupled reduced system is explicitly closed on CURRENT (y,R):

    y'=[A_eff-P2^-1*h*L*C*P2]*y
       +[g_eff*L-P2^-1*h*(L'+L*D+L*C*h*L)]*R,
    R'=C*P2*y+(D+C*h*L)*R.

The extra terms are the rest-response feedback generated by the coordinate change. Omitting them is not equivalent to the conditional test or the retained equations. No new coupling parameter appears.

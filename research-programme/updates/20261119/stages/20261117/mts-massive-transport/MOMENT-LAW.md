# Two collisionless moment identities for this retained branch

Let A=a mν/Tν,0, v=q/√(q²+A²), I=∫q³ f dq, W=q³f/I, w=−q⁴f′/(4I). The Einstein density source needs M=(4/3)∫w/v. Integrating by parts introduces no Fermi endpoint term: d(q⁴/v)/dq=q³(3/v+v). Thus M=∫W(1/v+v/3)=E+P. This is a property of minimally coupled kinetic matter, not a newly derived MTS coupling. In a discrete background with E=1+ΣW(1/v−1), use the enthalpy from the same E. A normalized monopole source changes only quadrature error and does not substitute for agreement of independently resolved numerical paths.

An independently measurable condition follows directly from the first two Boltzmann equations. Use the **unscaled** per-species moments D=Σw F0/v, V=Σw F1, P3=Σwv F0, S=Σwv F2. On x=kτ, with h=H/k:

    D_x = B c_x − V + h(D−P3)
    V_x = (P3−2S)/3 .

B is the physical enthalpy for the balanced source (the raw discrete hierarchy instead uses (4/3)Σw/v). The pressure and shear in the second identity share the same weights as the streaming of F1; there is no analogue of the independent normalization needed for the metric monopole. In physical-source units the common dilution factors must also be differentiated. Test both identities against *changes* in saved D and V, not against the much larger absolute densities, using the eight late intervals in both branches. These tests concern the indicated collisionless moments, not arbitrary exchange with other species.

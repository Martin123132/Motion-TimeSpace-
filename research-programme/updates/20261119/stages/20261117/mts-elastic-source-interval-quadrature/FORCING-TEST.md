# Prospective scalar forcing test

Use the same frozen case-specific probe indices and direct 32/64 integrals as the interval experiment. This is a numerical development check, not new independent observational data. From each real left state evolve s and d using the two Euler equations in SLIP-EQUATION.md, simultaneously integrating the original finite radiation source difference. At the right node compare, never overwrite or steer the answer toward, the real saved values. Reset only at each original left endpoint as in the direct reference. Do not fit slopes or set endpoint drift to zero. Sum absolute cell errors before normalizing on each four-cell block.

Use two predeclared input paths: (1) interpolate the actual Euler forces F0 and Delta F, opacity, inertia ratio and relative scale linearly on the interval; (2) use four actual adjacent times for cubic Lagrange interpolation of those same five inputs, one on either side where available. Neither interpolates the slip response itself. No mixing or choice based on the result. Where smooth external forcing is inadequate, a solution of the exact slip equation with those inputs can still give the wrong integral. The cubic is a sensitivity check, not a physical law.

Use normalized-time RK4 with 8/16/32 subdivisions, include both refinement differences and the previous independent direct working allowance. Fail on nonpositive opacity or inertia or nonphysical relative scale. For each branch and each candidate require, on both 32/64 histories, maximum of the two relative endpoint errors (old and changed slip separately) and the source integral error each <=2e-5, including numerical allowances. No cross-branch denominator. The full histories and native accepted-step probes are not changed. Even an all-pass on four development blocks would need new blocks and whole-history coverage.

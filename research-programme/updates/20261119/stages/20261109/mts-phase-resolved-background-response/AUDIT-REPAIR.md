# Independent audit layout repair

The first independent audit stopped with a dimension mismatch before producing an accepted result. It used the physical energy map's compact dimension to pad the distinct metric map. Those compact layouts differ by ten coordinates; the resulting audit-only metric matrix incorrectly had1074 rather than1064 entries for MTS.

The source evaluator itself uses its original metric layout, and its saved native packets and projections are unchanged. The repaired independent audit takes the metric compact dimension from its own saved forward matrix and verifies the separate physical, metric and periodic map shapes. It then checks the same map and source identities at the unchanged1e-10 algebra gate.

The failed audit_phase.py and audit-01 receipts/traceback are preserved. audit_phase_v2.py writes a separate audit-02 result. This is an inspected verifier implementation repair, not a repeated numerical fit or a change to source calculations, phase profiles, physical grids or tolerances.

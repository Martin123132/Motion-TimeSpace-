# Second original cell: carried state, unchanged equations

This stage extends original source index4 to8. Each fine/coarse control inherits its OWN exact saved DOP853 endpoint state, phase, channel normalization and full-span step limit. It does not reset the response at the shared boundary. The source vectors, source packets, phase control and phase measure at the boundary are reused bitwise.

The new source integration spacing is determined from the previous accepted spacing and the newly integrated original phase equation before native source evaluation. This is a numerical source quadrature, not a change of the physical bank or its grids. Distributed probes precede the four bulk batches. The source and controlled-source classes retain the original physical equations,256-angle primitive and phase/current cross term. Only the diagnostic endpoints now correspond to original source indices4 and8, and the final integration index is dynamic.

The accepted projection entry is project_cell_v2.py, importing project_response_v2.py. The v2 change corrects a copied metadata label from first-cell-only to second original cell[4,8]; numerical equations are identical to project_response.py. The unused original files are retained because the earlier source freeze recorded their hashes. The unused cell_support.checked_point helper likewise remains untouched; all active point verification uses point_support.checked_point with canonical three-digit minimum-width filenames.

The final-epoch adjoint and physical reference normalization are shared with the first cell. Signed cell integrals therefore add without an intervening reset or extra propagator. An ordinary shared endpoint has zero integration measure and does not double-count a source event. Conditional cell Cauchy expressions add by triangle inequality; they remain numerically evaluated, not certified continuum error bounds. Controls are preserved per cell, and cancellation in the sum cannot promote a failing cell to a pass. Other terms in the full error identity, output-map corrections, other wave families and later cells remain separate.

## 2. Prediction equations and measurement mappings

### 2.1 Minimal late-distance branch: implement this first

Use natural units c=hbar=1 for the field equations, signature (-,+,+,+),
M_R²=(8*pi*G_N)^-1. Physical H below uses km/s/Mpc.

The retained homogeneous sector is equivalently
  L_psi = -g^{ab} partial_a psi_c partial_b psi_c / 2 - m² psi_c² / 2,
  rho_psi = (psi_dot² + m² psi_c²)/2,
  p_psi   = (psi_dot² - m² psi_c²)/2,
  psi_ddot + 3H psi_dot + m² psi_c = 0,
  3 M_R² H² = rho_m + rho_r + rho_Lambda + rho_psi.

Here m is the canonical pole mass/frequency, not a bare unnormalized potential
coefficient. In seconds, m_frequency = mu * H0_SI, with
H0_SI=1000 H0/(3.0856775814913673e22) s^-1.
Rest energy in eV would be hbar[eV s] times that frequency; do not multiply
a value in km/s/Mpc by an eV label.

Define
  N=ln a=-ln(1+z), a_today=1; E=H/H0; ell=ln E; mu=m/H0;
  x=psi_dot/(sqrt(6) M_R H);
  y=m psi_c/(sqrt(6) M_R H);
  Omega_m(N)=Omega_m0 exp(-3N)/E²;
  Omega_r(N)=Omega_r0 exp(-4N)/E²;
  s=d ln H/dN=-3 Omega_m(N)/2 -2 Omega_r(N) -3 x².

Then solve
  x_N = -(3+s)x - (mu/E)y,
  y_N =  (mu/E)x - s y,
  ell_N = s,                         H(z)=H0 exp(ell(-ln(1+z))).

Present boundary values:
  D0=1-Omega_m0-Omega_r0,
  Omega_psi0=f_scalar D0,
  Omega_Lambda=(1-f_scalar)D0,
  x0=-sqrt(Omega_psi0) sin(theta),
  y0= sqrt(Omega_psi0) cos(theta),    ell0=0.

Shoot theta in [0, pi/2-1e-5] until x(N_reg)=0, N_reg=-5.
The implemented branch retains y>=0, E>0, expanding H>0, nonnegative
Lambda and nonnegative present scalar density. theta is determined
conditionally by this boundary problem, not an extra fitted parameter.
Sign-reflected field configurations have the same background stress.

Numerics in S03:
- solve_ivp DOP853 backward from N=0 to N_reg;
- phase root: toms748, xtol=rtol=2e-11, maxiter=40;
- root integrations: rtol=3e-8, atol=3e-10, max_step=0.06;
- final integration: rtol=2e-10, atol=2e-12, max_step=0.025, dense output;
- reject failed root/integration, nonfinite or nonpositive E;
- require max|Omega_m(N)+Omega_r(N)+Omega_Lambda/E²+x²+y²-1|<=2e-6,
  |x(N_reg)|<=2e-5 and sampled y>=-1e-7.

These numerical gates are implementation tolerances, not physical allowances
for nonconservation. The source's claim of a regular phase is a selected
positive/frozen branch, not a global uniqueness theorem over all scalar states.
At finite N_reg, setting x=0 approximates the early regular state; moving the
start is a numerical/state sensitivity test, not an extra fitted parameter.

**Supported handoff range: 0<=z<=3**, including z=0 for normalization only.
The source integrates to exp(5)-1, but that is not a validation of all
redshifts or a license to extrapolate to recombination. Both reference cases
have been checked over the requested 0..3 range. Previous late data extend
to 2.33; z=3 is an interface/reference check rather than new observational
coverage. For earlier cosmology use the explicit radiation route below.

Useful derived diagnostics:
  Omega_psi(N)=x²+y²,
  w_psi=(x²-y²)/(x²+y²) when scalar density is nonzero,
  q=-1-s.
Do not substitute a fitted w(z) for this solution.

### 2.3 Distances and BAO

Let I(z)=integral_0^z dz'/E(z') and c=299792.458 km/s. Then
  D_H = c/(H0 E),   D_M = (c/H0) I,
  D_A = D_M/(1+z),  D_L = (1+z) D_M,
  D_V = [z D_H D_M²]^(1/3),
  mu_distance = 5 log10(D_L/Mpc)+25, only for z>0.

For the minimal runner, one free BAO scale alpha_BAO=c/(H0 r_d) gives
  D_M/r_d = alpha_BAO I,
  D_H/r_d = alpha_BAO/E,
  D_V/r_d = alpha_BAO [z I²/E]^(1/3).

**r_d is not predicted by the minimal model.** Fit a common positive r_d
(or profile alpha_BAO), or declare an external calibration and its covariance.
Do not count both r_d and alpha_BAO as independent once H0 is specified.
SN shape + free-ruler BAO alone do not separately determine H0 and r_d.
Chronometers can supply an absolute rate, conditional on their calibration.

Historical SN scoring uses
  m_b_corr_model = 5 log10[(1+z) I(z)] + Mcal.
Mcal combines absolute brightness and H0-distance normalization; it is NOT
the distance modulus and is NOT itself M_B. At fixed H0,
Mcal=M_B+25+5 log10(c/H0), with c/H0 measured in Mpc.

**Legacy likelihood caveat:** the retained loader selects positive zHD
(fallback zCMB/z), excludes IS_CALIBRATOR rows, and uses m_b_corr with the
corresponding full covariance submatrix. The historical scoring uses that
same z for integration and the (1+z) prefactor. It does not use a separate
heliocentric prefactor. For an exact replay preserve that convention;
for an improved Pantheon release-specific mapping, change and document it
equally for all baselines and MTS and expect different absolute chi².
Do not promote legacy scoring conventions to a fundamental MTS prediction.

# Wavenumber-binding preflight repair

The first wavelength driver stopped BEFORE any solver call when the exact native-order embedding check rejected the half-wave operator. Inspection found three tail recurrence terms still referencing the imported k=5 constant, while the lower recurrence and native operator correctly used the selected physical k. This was a driver binding bug, not evidence against the theory.

The failed worker PID17964 exited; waves-01.end.json records exit1, runs/ contains no solver-status files, and prediction-result.json preserves the failure. The promoted initial state/source checks had already passed. Do not overwrite or accept these failed outputs.

run_wavelengths_bound.py removes the imported fixed wave, binds EVERY recurrence coefficient to the current wave, and adds a static guard against a surviving WAVE identifier. It writes runs-bound/, run-config-bound.json and prediction-bound-result.json, with a fresh receipt. Same frozen waves, seed, promotion, physical grids and tolerances. No numerical trajectory is retried and no test threshold changes.

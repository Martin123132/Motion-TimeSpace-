# Stage224: source replacement reconciled with the saved spectrum

## Decision

The two tested interval repairs are numerically immaterial to the saved
whole-spectrum reference at its recorded sensitivity scale. **Do not commission
another time-step refinement of these intervals by default.** The next physical
step is to insert their energy and pressure corrections into the already derived
calibrated gravity/source interface, with the remaining history kept explicit.

This decision follows an actual signed-spectrum calculation, not a comparison
of source-level discrepancy percentages or an assumption that a small residual
norm means a small stress tensor.

## Ownership resolved

The Stage223 source is already the retained microscopic operator acting on
repaired-minus-original photon and gas histories. Subtracting the old absolute
source again would be an error. Stage197's repair occupies
[0.8707275390625,0.8792724609375]; Stage223 occupies[0.90234375,0.90625].
They are disjoint. Existing frequency weights are already included.

Reused the authenticated Stage166 full reference, Stage167 ready budget and
Stage197 conditional warm correction. Heat normalization, frequency measure,
reference columns and earlier comparison replay all agree. The earlier whole
reference is unchanged; the new conditional diagnostic is

    reference + warm repair + cold repair + unevaluated complement.

The complement includes uncomputed source intervals and any changed earlier
physical incoming history. It has not been assigned zero or declared bounded.
Only the explicitly evaluated terms are stored in the conditional arrays.

## Derived interface compatibility

The two-sided trapezoidal handoff is now expressed as an equivalent forcing on
the original BDF2 operator. The expressions in DERIVATION.md agree with direct
evaluation of D_BDF I-A I from the saved two-state physical packets, at both
boundaries and resolutions, for all baseline/MTS/total/profile/history columns.

This retains the original homogeneous reference evolution. It does not insert
a physical impulse, fitted coupling or zero incoming state. The derived
boundary forcing also passes an independent energy/work/injection conservation
check. Replacing it by the naive endpoint forcing changes its vector by about
49.9% at entry and100% at exit; these are forcing differences, not sky errors.

## Quantitative effect

Across32 configurations: heavy/cold backgrounds, local/cubic saved references,
matching20/40, quadratic/secant source profiles and quarter/eighth histories;
both infrared joins and baseline/MTS/total are retained within each case.

- Maximum combined MTS residual-vector addition / saved MTS residual norm:
  **1.59812362e-10**.
- Maximum combined MTS residual-vector addition / Stage167 partial MTS allowance:

## Validation and preservation

**850 main checks and776 independent checks pass**, zero failures.
Independent checks cover exact stored-input addition, direct Decimal norm
differences, duplicate-addition controls and boundary forcing conservation.
All19,892 consumed/immediate input hashes are rechecked unchanged. The
protected-workbench recent-mtime guard is0, not a new whole-tree snapshot.
No new scattering integrals, source-history integrations or time evolutions
were run. The calculation used one numerical worker and one library thread.
The original bank, temperature curve, grids and tolerance definitions remain
unchanged. Earlier failures and the full original MTS framework are preserved.

The first prepare attempt rejected an unnecessary old-seal lookup before
freezing or numerical execution. The repair instead requires the actual
individually authenticated source files already present in the current manifest;
RUN-NOTES.md records this without relabelling a failed numerical test.

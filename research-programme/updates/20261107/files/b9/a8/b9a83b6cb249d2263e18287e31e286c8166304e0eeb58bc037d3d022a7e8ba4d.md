# Derive the interval-start error before changing the numerical startup

The frozen Stage221 run retains the old global BDF2 schedule and defines
the NEW interval contribution with I_0=I_-1=0. This is a well-defined
discrete attribution, but its fictitious past is not a second-order
right-hand start for the continuous Duhamel integral.

For the elementary A=0, constant F case, the recurrence is

    3 I_n - 4 I_(n-1) + I_(n-2) = 2 h F,
    I_n = (n - 1/2 + 1/(2*3^n)) h F.

The missing half-step contribution is therefore derived, not fitted.
At32 versus64 steps over the same interval, the asymptotic relative
difference is1/127=0.78740157%. The existing baseline/MTS differences
are of this scale; cancellation in their total can magnify it. This
comparison motivates, but does not alone prove, a startup diagnosis.

## Right-hand second-order start

For I'=A(u)I+F(u), I(a)=0, trapezoidal integration for the first step gives

    (2/h I - A_1) I_1 = F_0 + F_1.

Subsequent steps use the original BDF2 recurrence, retaining I_1 and I_0.
For constant F and A=0, I_n=n h F exactly. No fitted taper, new source,
new physical initial condition or change of grid is required.

Here F=B s and B(u)=r(u) B_tilde because M,t,c,chi and the protected
source representation are unchanged. Thus the first step can use the
existing response solver with

    alpha=2/h,
    s_effective=s_1+(r_0/r_1)s_0.

All work/number/paired-energy rows travel with it. This formula applies
to the interval INCREMENT, whose actual right-hand initial value is zero.
It does not reset the unknown physical incoming response. Its comparison
is retained separately from the already frozen original matching runs.

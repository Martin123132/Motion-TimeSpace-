# Stage182: variable-step coupled history restart

The saved equations are M p_u = S(p-Tg), E=e p,
chi(g_u+g)=-1-E_u, and W_u=1+chi*g, with constant chi.
S(u) is the original rate times scattering-minus-emission matrix, evaluated
from the unchanged bank. Only temporal resolution changes.

For new step h and preceding step H, r=h/H, the derivative of the quadratic
interpolant through the last three time points at the new endpoint is

    D y = a y_new - b y_previous + c y_older
    a=(1+2r)/((1+r)h), b=(1+r)/h, c=r^2/((1+r)h).

For r=1 this is BDF2. For the first half step r=1/2, giving coefficients
(4/3,-3/2,1/6)/h. Constants, linear and quadratic functions provide independent
polynomial checks. No first-order startup is inserted.

Set v=b*p_previous-c*p_older and s=b*g_previous-c*g_older, L=aM-S.
The existing coupled solve generalizes without changing its physics:

    f=L^-1 Mv, R=L^-1(-ST)
    g_new=[chi*s-1-e(a*f-v)]/[chi*(a+1)+a*eR]
    p_new=f+R*g_new
    W_new=[b*W_previous-c*W_older+1+chi*g_new]/a.

Reproduce the original constant-step operation ordering for the native control.
The half-step branch must advance its own saved states, not repeatedly reset
to the original history. An earlier-start control quantifies startup sensitivity.

For each frozen finite-width curvature operator C, split the refinement change:

    C[half_full]-C[native]
      = (C[half_thinned]-C[native])
      + (C[half_full]-C[half_thinned]).

The first difference compares evolved states on the same temporal sampling;
the second isolates the interpolation-grid contribution for the half-step run.
This is an exact additive decomposition, not an error estimate or a fitted curve.

At the fixed microscopic anchor operator the gas-only response is linear:

    U_gas_component = K_g_component * C[g].

Evaluate each K independently with zero photon departure and unit gas. Compare
baseline, matched MTS increment and total with the same heavy/cold scalar change.
Their relative gas-only refinement changes coincide by linearity, although their
amplitudes and directions need not coincide. This does not imply that their
FULL photon-plus-gas source changes coincide. Those earlier decisions remain saved.

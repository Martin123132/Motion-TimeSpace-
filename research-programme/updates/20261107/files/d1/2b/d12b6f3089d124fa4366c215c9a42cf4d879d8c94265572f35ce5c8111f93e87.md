# Fixed-formula extension and interpretation

This checkpoint extends the sealed coupled correction, not the theory's
parameterization. Inventory labels half/balanced/double denote k multipliers:
0.32497672865575244,0.6499534573115049,1.2999069146230098.
They should not be confused with literal wavelength multipliers (wavelength
is inverse to k).

The frozen parent derivation is
../mts-coupled-phase-corrector-20261107/DERIVATION.md.
All factors use the same physical native-variable formula:

    U_n=M_n/(i n mu)
    R1=M+M U-U M0-U_N
    (I+U)R1+U_N-M(I+U)=U(R1-M0).

The exact coordinate-conjugate solution is a control only. The corrected
R1 evolution and actual metric derivatives are the tested approximation.

## Why new native contexts matter

Half-k uses native massless-neutrino full hierarchy and native massive
hierarchy order40; balanced/double-k use the retained high-k-tau massless
branch and native massive order16. All are extended to the SAME G192
massive hierarchy for the comparison. Source vectors are derived from each
actual signature, not copied between regimes.

Both live coupling directions remain implemented. No future rest history,
external force replay, fitting or constraint projection is introduced.
The saved G192 native trajectories are comparisons after the forward solves.

- The previously qualified quintic representation is retained from the outset.

Do not interpret an aggregate1e-27 operator ratio as universal machine accuracy:
a large rest-hierarchy normalization can dominate such a ratio.
CHANNEL-NORMS.md and each channel-result.json retain the more informative
separate comparisons. Actual Hamiltonian/momentum constraints provide another
independent protection in the forward tests.

## Forward controls

At each new k: heavy full, heavy exact conjugate, heavy corrected, cold full,
cold corrected. Five solves per label, ten total. Original physical output
grids, initial data, solver tolerances and gates are preserved.
The fresh full run checks that the canonical/live-feedback implementation
agrees with the saved native implementation in that regime.
Corrected/full and corrected/exact comparisons then isolate reduction error.
Cold corrected/full must be the exact identity route.

These differences are numerical/equation errors, not cosmological chi-square
improvements or evidence that MTS outperforms a competing observational model.

## Run receipts and reproduction

be overwritten or automatically retried. Reproduction needs a fresh owned
output directory and cutoff, not deleting old receipts.

hashes. Every result carries its actual qualification, without changing a
failed earlier result to passed.

## Next physical reduction

A three-k numerical qualification licenses a more serious Newtonian-limit
calculation; it is not a uniform limiting theorem by itself. Start from the
same action and source normalization, then derive and bound the terms removed
in weak-field/slow-motion reduction: momentum correction, anisotropic stress,
pressure, metric time dependence and remaining phase response.

The retained stress conventions matter. The existing gauge-invariant identities
in ../mts-second-micromotion-20261107/check_second.py use

    2 k^2 Phi+D+3 H Q/k=0
    Phi-Psi=Pi/k^2
    Psi=-D/(2k^2)-3 H Q/(2k^3)-Pi/k^2.

Pi is the native normalized shear used by this project; importing another
textbook's coefficient without transforming its definition would be wrong.
These identities motivate the terms to bound, not an independent Newtonian
evolution. That next evolution must close on its own instantaneous variables
and the action-derived sources, with matched baseline/MTS initial data.
A force integral supplied by the saved relativistic history is only a replay.

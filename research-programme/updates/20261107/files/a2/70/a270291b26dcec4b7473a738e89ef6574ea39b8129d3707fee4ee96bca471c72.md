photon state term of event32 (maximum2.040839338e-10). The aggregate alone

## Reusable implementation and measured cost

- evaluators(original): construct the unchanged basis and event evaluators.
- evaluate_event(parameters,bundle,models,virtual_scalar,event_weight):
  call the original60-digit production wrapper and return the finite map.
- sum_events(event_matrices): compensated primitive/component assembly.
- apply_coefficients(matrix,coefficients,join,digits=80): act on arbitrary
  (97,N) high/low coefficient arrays within the stated repair space.

The API restores the caller's mpmath precision and original precise_state
hook on exit. Shape, join, finite-value and precision guards are tested.

reusable module, not yet a standalone distribution.

and frequency. Stage201's coefficient-space evaluator and Stage200's histories
are unchanged. Preparation authenticates the parent seal, payloads and inputs.

    python -B source205.py prepare

    python -B source205.py freeze
    python -B source205.py actual --seconds 6000
    python -B assess205.py assess

# Why Stage133 adds a source attribution before further carry

The completed second-interval extension changes the small MTS gas endpoint
by about37--250% of its previous correction, while baseline changes are
about0.09--0.15%. This exceeds the predeclared1% sensitivity diagnostic;
the failed checks are retained. It is not a250% change in gas temperature.
The common-kernel versus physical-event source error remains much smaller.

Before extending through more epochs, use the already saved three inner
trajectories to decompose the source change exactly on the same response
grid, without new trajectories or fits:

Delta S = (S_control - S_previous)
        + (S_reset - S_control)
        + (S_carry - S_reset).

The three terms are reference reconstruction, operator update, and carried
initial-state memory. All use the same physical-event source at the new
temperature knots. Reference reconstruction includes replacing the old
coarse/interpolated source with newly sampled original-law states and
matched-order physical events; it is not labelled pure temperature
interpolation, particularly in the wide window where older source values
can use event order8 rather than the current matched order6.

Keep the accepted first interval and post1300 tail fixed in every packet.
Control/reset source packets are deliberately counterfactual bookkeeping
paths after640, not alternative continuously evolved cosmologies. Only
the carry candidate is the accepted continuous trajectory.

Each difference is propagated independently through the same linear
response equations. Their signed sum must reproduce the already saved
continuation response within the existing1e-4 superposition diagnostic.
Apply this decomposition identically to baseline and both MTS columns
in both backgrounds and both matching windows. Do not infer a physical
MTS preference from a numerically sensitive cancellation.

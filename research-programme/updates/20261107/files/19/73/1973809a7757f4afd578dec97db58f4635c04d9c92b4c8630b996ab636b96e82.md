## Event-level construction

Write the source test-function jump as a column a and the input feature
jump for join j as a coefficient column f_j. The input jump is f_j^T q.
The weak event contribution is thus

    a (f_j^T q) = (a f_j^T) q.

The stable soft/Born difference used by precise_history201.Soft is

    (a-a_B)(f_j^T q) + a_B[(f_j-f_Bj)^T q]
      = [(a-a_B)f_j^T + a_B(f_j-f_Bj)^T]q.

Keep this finite, subtracted form; do not independently integrate large
unsubtracted terms and expect the small matrix to survive cancellation.

Virtual terms are scalar multiples of a_B f_Bj^T. State terms consist of
phase/population scalar multiples of this Born matrix, observable shifts
(delta a)f_Bj^T+a_B(delta f_j)^T, and the same fixed velocity stencil applied
to Born matrices. Their original factors of1/2, signs and normalization
come from the unmodified evaluator; none are redefined by the lift.

Quadrature, finite counterterms, state stencils, moment-row reconstruction,
component addition and the final negative event weight are linear operations
independent of q. They therefore define matrices L_cj(theta) such that

    Delta S_cj(theta;q) = L_cj(theta) q,
    L_cj = -sum_events W_event(theta) R_cj,event(theta).

For each join, L_cj has98 output rows and97 active input columns.
The four primitive components are baseline,real difference,virtual,state.
MTS and total are formed by their EXISTING component sums.
A complete aggregate can be stored as6 x98 x97 x2 high/low arrays per
temperature: no additional fitted physical coefficient is introduced.

This identity is algebraic for the defined unrounded finite rule.
Floating-point evaluation need not commute exactly with coefficient
contraction. Its implementation must retain the repaired subtraction,
high/low representation and80-digit protected moment calculations, and
must be tested against the saved direct evaluations.

## Columnwise moment identities

source_tangent.evaluate reconstructs the protected rows from energy E,
number N and gas G:

    row0=E,
    row1=N/norm0,
    row2=(E-mean*N)/norm1,
    row97=G.

The constants norm0,norm1,mean are fixed by the saved basis, not fitted.
Consequently the lifted matrix obeys, componentwise and joinwise,

    row0 - mean*norm0*row1 - norm1*row2 = 0.

Where the retained paired event law has E+G=0, it also obeys

    row0 + row97 = 0.

These are column identities, hence apply to every input vector in the
retained repair space, not only a selected history. They do not imply
photon-number conservation for emission/absorption, nor prove the spacetime
Noether/Bianchi identity of the parent field theory.

Verify these column identities using the original moment construction;
do not hide a failed lift by projecting an arbitrary erroneous matrix onto
the identities after the comparison.

## Bounds using the existing photon norm, without a gas-norm parameter

Let the saved photon mass matrix be M=C C^T, with C the lower Cholesky
factor. Existing source tests use the weak-photon dual norm and history
tests use the primal coefficient norm:

    ||v||_(M^-1)=||C^-1 v||_2,
    ||phi||_M=||C^T phi||_2.

Partition one lifted component/join into output weak-photon rows1:97
and gas row97, and input photon coordinates0:96 and gas coordinate96:

    v_gamma = A phi + a g,
    v_gas   = b phi + d g.

Then, for a history error(delta phi,delta g),

    ||delta v_gamma||_(M^-1)
      <= ||C^-1 A C^-T||_2 ||delta phi||_M
         + ||C^-1 a||_2 |delta g|,

    |delta v_gas|
      <= ||b C^-T||_2 ||delta phi||_M + |d| |delta g|.

The proof is substitution phi=C^-T(C^T phi), followed by the operator
norm inequality and triangle inequality. No arbitrary combined gas/photon
weight is required. Apply the same inequalities to a DIFFERENCE of two
operator matrices to bound its contraction on any allowed history.

For an interpolated operator L_tilde and computed history q_hat,

    L_tilde q_hat - L q
      = (L_tilde-L)q_hat + L(q_hat-q).

This separates operator-temperature approximation from physical history
error. Each term can be bounded by the blocks above if actual operator and
history-error bounds are supplied. Observed mesh differences alone do not
provide those rigorous bounds. Pointwise operator checks likewise do not
establish a uniform temperature bound.

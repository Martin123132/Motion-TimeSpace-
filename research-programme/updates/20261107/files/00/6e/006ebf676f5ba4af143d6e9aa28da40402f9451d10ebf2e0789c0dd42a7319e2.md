The third divided difference of (R-b)_+ vanishes identically when all four stencil points are on the same side of b: the sampled function is then either zero or affine. Only stencils straddling b can contribute. Apply the unchanged native template to these exact support values.

This algebraic support classification must precede a strict row-wise disjointness check. The existing full native field covector was already exactly zero in the source/boundary buffer.

The daughter uses the exact piecewise-affine support identity, NOT a relaxed source-force tolerance. It also compares the analytic-support hinge image with the unreduced divided-difference evaluation, bounding its finite-precision cancellation error.

# Post-probe diagnostic: identify the source of large gas sensitivity

Added after observing Stage124 probe outputs,not retroactively predeclared.
The new source values differ strongly near the first epoch interval.
The operator correction is small in source norm yet changes the tiny gas
endpoint strongly. Before interpreting this,we explicitly test linear
superposition and the Compton/DC/BR gas-component cancellation.

Using the already saved110-knot source variants,split direct-minus-linear
forcing into interval0 and all other sampled intervals. Evolve each
difference on the same2048 response steps with zero initial difference.
Also evolve direct-minus-assembled forcing alone. No new inner evolution,
frequency points,source operators or fitted parameters are introduced.

Require reconstructed gas increments to agree with differences of the saved
responses within1e-7 peak-scaled tolerance. DC/BR forcing and their response
columns must remain bitwise unchanged for the operator-only difference.
Report sum(abs(component endpoint))/abs(total endpoint),signed component
endpoints and signed interval contributions. These reveal cancellation;
they are not probabilities or positive fractions of an error budget.
All inherited raw gas equation tests remain visible.
This is double-precision attribution,not a high-precision certification.

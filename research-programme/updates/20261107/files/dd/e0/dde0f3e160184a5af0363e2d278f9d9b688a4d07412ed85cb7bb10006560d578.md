# Stage120: isolate the coupled response time step

Parent: `../fixed-grid-time-refinement-20261013/results/stage-integrity.json`.
Stage119's source and inner prediction files are read directly, not regenerated.

The physical response equations remain
M z' = R[K(z-t b)+D],
chi(b'+b) = -R t^T[K(z-t b)+D],
work' = chi b.
The forcing D is exactly the saved three-component collision residual; the
total and each component are carried together. The unresolved replacement
q-Vp and all joining terms are unchanged. Final radiation is Vz+q-Vp.

Backward Euler is used for the first step; later steps use BDF2. With
alpha=1/h or3/(2h), the physical histories are z_prev/h or
(2 z_prev-z_older/2)/h, with analogous gas/work histories.
The independent checks use these physical equations, whereas the reused
solver eliminates gas in energy coordinates. Cancellation in the raw gas
row remains an explicit recorded diagnostic.

Only the response step is halved. The old2049 coordinates coincide with
every second state of the new4097; compare directly, without interpolating
the old solution at newly introduced times. Gas difference denominators use
the new full4097-state peak, the new final-quarter peak, and absolute endpoint
separately. An additional peak-amplitude difference diagnoses changes in
sampled extrema but is not interchangeable with the common-time difference.

For context, compare absolute Stage120 changes against absolute Stage119
inner-refinement changes; also report both normalized by the same Stage119
gas peak or endpoint. This is a scale comparison, not an additive error budget:
interaction, forcing interpolation and window dependence are not removed.

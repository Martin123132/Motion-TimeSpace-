# Stage146 reuse and restart notes

This child continues the existing photon-history calculation. It changes
numerical evaluation of saved sources,not the action,physical quadrature,
temperature nodes,background,history profiles,or response integrator.

## Source reuse

- Five actual temperatures at u/U=.5,.5625,.625,.6875,.75.
- 29952 saved unweighted event arrays; original weights and ordering verified.
- No new physical event or virtual-loop evaluations.
- The analytic leading-control quadrature is reevaluated at the SAME nodes,
  factoring its two constant test functions before accumulation.

  arbitrary-precision event physics. Higher modes use compensated summation.
- Raw Stage145 predictions,failed checks,and local-only result remain sealed.

## Controlled continuation

The readiness packet is authoritative: only a true allowed_routes entry
permits that route's response. Every active/transfer phase has its own
completion packet and restart arrays. The inherited 96-mode,1024-step
integrator is imported unchanged; heavy/cold backgrounds and both joins
receive the same treatment. The nonzero baseline and old window are reused.

An already completed packet must be verified,not overwritten. If a job stops
mid-phase,preserve its unfinished directory separately before restarting;
do not replace or modify a completed/sealed packet. No previous long inner
history is rerun. Limit execution to two single-core below-normal workers.

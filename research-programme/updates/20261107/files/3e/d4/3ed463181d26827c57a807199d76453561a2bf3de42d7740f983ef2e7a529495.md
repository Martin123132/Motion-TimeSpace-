## Exact modified-operator identity

Let u=1/r and positive two-point deposition give E[U]=u,variance V,grid
endpoints a,b. For a Mellin test v=x^q,the source event symbol is
F_q(u)=(u^(1-q)-u+u^(2+q)-u^2)/2.
The moment-calibrated error is exactly
delta S=c(S_deposited-S_physical)+(c-1)S_physical,
c=lambda_physical/lambda_deposited.
For exact lambda_physical=m_physical/2,this is also
m_physical*(S_deposited/m_deposited-S_physical/m_physical).
It vanishes on the number and energy constraints but not arbitrary shapes.

The deposited energy-eigenvalue bias is exactly
delta lambda=sum w V(a+b+u-1)/2,
because E[U^3]-u^3=V(a+b+u),E[U^2]-u^2=V.
The leading local source error is V F_q''(u)/2. For a general test v,
F''(u)=[x^2/u^3 v''(x/u)+2(v(xu)-v(x))
        +4xu v'(xu)+x^2 u^2 v''(xu)]/2.
These show why energy-moment normalization does not remove shape error.
The leading expansion is explanatory,not asserted to approximate every
near-grid-scale mode. Exact deposited identities are checked separately.

The weak operator is dual to the slope pairing integral x v f dx.
compact_defect multiplies the slope by x and the fixed matching window,
so the source quadrature uses the same measure. This is not an arbitrary
change of particle-density convention.

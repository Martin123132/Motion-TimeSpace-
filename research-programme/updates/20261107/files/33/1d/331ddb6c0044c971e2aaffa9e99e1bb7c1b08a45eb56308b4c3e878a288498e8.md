# Stage178 — finite-width product rule for the virtual source

Let t=ln(theta/theta0). The incident vector h(t) contains both photon departures
and the saved gas departure. The existing virtual/Born action is linear in h:

    V(t;h)=A(t)h
    A(t)h = -w(t) [vacuum(t)+loop(t)]/2 * L(t) B(t;h).

Here L contains the test-function jumps, B the photon difference plus gas
recoil term, and w the entire saved quadrature weight. All operator kinematics,
evaluation frequencies, loop coefficient and weights stay at t when h changes.
The frequency basis and all historical interpolation rules stay fixed.

Write S_ab=A(a*s)h(b*s), F_a=A(a*s)h(0), and V0=A(0)h(0).
For either s=.01 or .005:

    C_fixed = (F_plus - 2V0 + F_minus)/s^2
    C_mixed = (S_pp - S_pm - S_mp + S_mm)/(2s^2)
    C_history = (S_pp + S_pm + S_mp + S_mm - 2F_plus - 2F_minus)/(2s^2)
    C_moving = C_fixed + C_mixed + C_history.

C_mixed = 2 J_s[A] J_s[h]; C_history = A_average C_s[h].
These are exact finite-width identities, not a smooth-derivative assumption.
History curvature is still weighted by the average operator at that width.
Thus changing widths also changes that average; do not call this a complete
separation of every operator effect at all orders.

Form DeltaC = C_.01 - C_.005 before rounding, event by event, using saved
high/low inputs and crossed actions, then sum at 80 digits; repeat at 100.
Report each term's signed projection onto DeltaC_virtual and DeltaC_matched
in the inherited mass-dual photon metric. Include the nonvirtual matched
remainder, so the total attribution closes rather than losing its contribution.
Signed shares can be negative or exceed 100%; they are not causal percentages.

New cross actions use cached loop scalars, not new virtual integration.
Original moving/fixed diagonals are reevaluated as reproduction controls.
An independent Born linearity test evaluates summed, differenced and zero
histories at each operator temperature without changing the frozen source bank.
Baseline curvature and full baseline+MTS outcomes remain the saved controls;
new real-baseline crossed integrals are outside this diagnostic's scope.

This distinguishes mixed first-difference response from transmitted finite-width
history curvature. It does not by itself distinguish physical history evolution
from history discretization error. The original 1.03659637% matched curvature
flag, frozen target predictions and their original tolerances remain intact.

# Stage202: extending the same history response to a weighted pair

For each retained fixed-temperature event the history jump is linear:

    R[phi,g] = phi(x_h)-phi(x_i)+sign(omega)phi(x_s)+E_e g.

The real subtraction, fixed virtual factor, and phase/state derivative and
velocity-stencil terms preserve this linearity. Stage201's derivation and
precision implementation remain authoritative; no new physical ansatz is
introduced here. The unchanged tails cancel from the history increment, with
the original blend retained. Thus for each component and incoming node,

    delta S_x = S_x[delta phi,0]+S_x[0,delta g].

Stage201 computes the fixed spline features before contracting their event
differences with the high/low history coefficients. Reuse that representation
for both the prediction and the absolute source, without constructing absolute
results from the prediction. The evaluator is shared, so this tests numerical
linearity/precision, not independent physical correctness.

## Where the original frequency weight enters

`stage165_common.parameters_and_weight` (through the saved source module) uses

    W = w_e * reflection * w_x * x^2/expm1(x)/I3
        * 2*pi*w_angle * born_differential_over_thomson.

The inherited microscopic `weighted` function applies `-W` once to every
event packet. The incoming-frequency weight w_x is therefore already present
in the saved x=14 packets and the new neighbouring packets. Their correct
partial-panel contribution is the sum of the weighted event packets, not a
second multiplication by w_x and not an average divided by their weight sum.

At a common temperature and with the same histories:

    delta S_pair = delta S_14 + delta S_16.435...
    S_pair[history] = S_14[history] + S_16.435...[history].

Freeze the first relation from increment-only evaluations before evaluating the
new absolute source for the second. Test their difference on the small-correction
scale as well as the absolute-source scale. Test the two individual contributions
and the pair separately: cancellation can make a pair more sensitive than its
parts. A positive-weight sum need not improve a relative error when signed source
vectors cancel; no acceptance follows merely from the node test passing.

The two nodes come from the saved seven-point rule over 8<=x<=20. The sum is a
partial quadrature contribution, not a controlled approximation to the missing
five nodes or the whole population integral. Complete that panel before
returning to temperature continuation and the final radiation/gas response.

# Stage179 — isolate curvature of the incident history at a fixed operator

The linear virtual/Born source is V(t;h)=A(t)h, with all quadrature weights,
kinematics and vacuum/loop factors included in A. Incident h includes both
photon and gas departures. The fixed anchor operator is A0=A(0).

Stage178 established, exactly at either finite width s=.01 or .005,

    C_moving = C_fixed + C_mixed + H_s
    H_s = A_average_s C_s[h]
    A_average_s = (A(+s)+A(-s))/2.

Now evaluate four missing actions A0 h(+s), A0 h(-s), using the original
anchor operator and the SAME saved histories. Define

    U_s = A0 C_s[h]
        = [A0 h(+s)-2 A0 h0+A0 h(-s)]/s^2
    W_s = H_s-U_s = (A_average_s-A0) C_s[h].

With Delta denoting coarse minus fine width, the matched discrepancy is

    DeltaC_matched = DeltaC_fixed + DeltaC_mixed
                  + DeltaU + DeltaW + DeltaC_nonvirtual.

The nonvirtual term is the original real-minus-control difference plus state
response. Reconstruct it from the saved primitive event components, not from
subtraction of rounded final sums. Compute U, W and all event/component sums
at80digits, independently repeat at100digits, and only then cast diagnostic
vectors to float for the inherited mass-dual photon metric.

The anchor reproduction control is evaluated alongside all four side histories.
The anchor operator uses the anchor event velocity, energy, scattering angle,
temperature, weight, loop scalar and vacuum factor even for a side history.
No side-temperature operator parameter is allowed into those new actions.

U separates finite-width history curvature as seen by one fixed operator from
the average-operator correction W. U still measures the saved history: it does
not alone prove interpolation error or separate physical from numerical curvature.
The split is exact for this finite quadrature and representation, not a proof
of a classical second derivative or a continuum/integral error bound.

For a component X and reference R, signed share is <X,R>/<R,R> in the
inherited mass-dual photon inner product. Also report ||X||/||R||. Shares can
be negative or exceed100%; norms are not scalar-added as though vectors aligned.
Keep cancellation of the full curvature separate from cancellation of the
coarse/fine discrepancy. No old prediction or acceptance decision is replaced.

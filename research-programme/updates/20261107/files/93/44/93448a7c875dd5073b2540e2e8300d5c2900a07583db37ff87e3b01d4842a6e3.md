# Post-computation interpretation: memory and a finite sampling endpoint

Written after the preregistered4/8/16 runs. These deductions do not change
the experimental gates, initial state, response grid or saved trajectories.

## Derived conditional memory kernel

For the consumed fixed-grid system, set b(t)=f(t)-u'(t), and let U(t,s)
solve dU/dt=L(t)U with U(s,s)=I. Variation of constants gives exactly

    e(t)=U(t,t0)e0 + integral_t0^t U(t,s)b(s) ds.
    S(t)=A(t)U(t,t0)e0 + integral_t0^t K(t,s)b(s) ds,
    K(t,s)=A(t)U(t,s).

A(t) is the already implemented linear raw-minus-overlap source map,
including the fixed matching window. This identifies how a history of
driving produces the source; it introduces no fitted relaxation cutoff.
It is a conditional finite-grid identity, not a derivation of the parent
action, microscopic initial state, or an approximation-free collision law.

The first interval contains49 baseline driver knots and15 window-history
knots. Its frozen-coefficient/constant-drive approximation is not uniformly
accurate: the MTS source mismatch reaches about62percent of component-sum
norm by the interval's end. Therefore retain the time-dependent U and b;
do not replace the whole interval by one initial exponential.

## Why the next sampling test is finite

The consumed solver is
`../matched-low-frequency-feedback-20261012/propagate_matched_feedback.py`.
It evaluates the source at t_j=t0+(tf-t0)j/2048. There are32 such updates
in the first of64 original source intervals. They coincide mathematically
with inner steps20,40,...,640 on the40960-step inner grid.

The present16-subinterval source saves40,80,...,640, leaving16 response
evaluation sites interpolated, including the first one at inner step20.
Replay and source-evaluate the missing odd sites20,60,...,620 next. This
gives the actual retained inner-trajectory source at every response update
in interval0, without changing the response scheme or frequency grid.

At that fixed response mesh, inserting still finer source nodes cannot
change the recurrence if its values at those32 evaluation sites are held
fixed (apart from roundoff). By induction the same history, matrix and
right-hand side yield the same response at every step.

The validator checks coordinate agreement and an intentionally nonzero
between-step perturbation that vanishes at all32 update sites. This is a
sampling-contract check, not a physical accuracy check: an unresolved
between-step source pulse could matter to a finer or integrated response.
Once the32-site test is complete, any remaining time-integration question
belongs to the response discretization, not endless source halving at an
unchanged response grid. Other63 intervals remain a separate issue.

## Initialization ownership

The retained e0=0 matches a chosen initial reconstruction. A parent-owned
initial memory would determine the first term A(t)U(t,t0)e0; it is not set
by the algebra above. Do not choose e0 to restore a preferred sign.

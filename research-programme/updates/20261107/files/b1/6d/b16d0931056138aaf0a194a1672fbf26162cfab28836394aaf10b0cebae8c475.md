# Precise source interface for the actual carried history

The event-Hessian readout is now connected to the retained real/pole
subtraction. This is a pointwise source-interface qualification, not a new
temperature history, scattering bank or quadrature rule. The physical state
is the saved cell424 state; it is not relabelled as the unfinished endpoint.

The source expression is inherited from
`finite-real-mixed-source-20261026/integrate236.py:paired,ray_integral`
and `source-readout-bridge-20261102/full_tail_integrand.py:panel_block`.
The stable reference-only identity is inherited from
`source-readout-bridge-20261102/reference_region_repair.py`.
The derived coupling is `EVENT-COUPLING-DERIVATION.md`.

## Notation and algebra

Let L0,R0 be Born weak/source factors, Delta L_+,Delta L_- their real
emission/absorption changes, and R_ref=R0+c M with
c=2n(1+n)/(1+2n). M contains both the soft background times the equilibrium
wave and the Born density response times the soft wave. Both terms and all
578 history coordinates are retained. Let Delta R_s=R_s-R_ref.

At local soft energy k=x*theta/doppler, define

    D_+=(1+n) rho_+, D_-=n rho_-,
    S=D_++D_-, D=D_+-D_-, U=S-P(1+2n)/k,
    Le=(Delta L_++Delta L_-)/2, Lo=(Delta L_+-Delta L_-)/2,
    Re=(Delta R_++Delta R_-)/2, Ro=(Delta R_+-Delta R_-)/2.

For the domain with both real branches, the retained subtracted source is

    L0 [U R_ref + S Re + D Ro]
    + Le [S(R_ref+Re) + D Ro]
    + Lo [S Ro + D(R_ref+Re)].

Expanding the brackets recovers
D_+ L_+ R_+ + D_- L_- R_- - P(1+2n)L0 R_ref/k.
This is the existing even/odd compensation, with the actual-history readout
kept at high precision rather than rounded before subtraction.

In the absorption-only or reference-only domain the inherited expression
also restores P L0 R0/k. Combine this analytically with the pole term:

    -P(1+2n) R_ref/k + P R0/k
      = -2P n [R0+(1+n)M]/k.

The absorption-only source is therefore

    D_- L_- R_- - 2P n L0 [R0+(1+n)M]/k.

The reference-only source omits the first term. This extends the existing
stable reference identity to the absorption-only branch without dropping
any term. No restoration is added to the both-real branch: its retained
convention is preserved exactly. This note does not independently rederive
the finite/virtual renormalization prescription.

Every point is multiplied once by its original radial measure, local
temperature Jacobian, event weight, angular weight and
1/[2(2l+1)]. The retained separator logarithm remains a separate required
term. Complete inclusive assembly still also needs the matched virtual and
state terms; selected point probes cannot replace the full integral.

## Qualification contract

The new implementation is `precise_compensated_source.py`. Test positions
are chosen before evaluation from the original radial26 nodes: lowest soft
node, the old sensitive panel9 node, last both-real node, first/last
absorption-only nodes, and first/last reference-only nodes. If selection
duplicates a node, test it once. Both source modes, both joins, l0/1/2,
all physical/difference columns and radiation/gas rows are compared.

The primary reference evaluates the un-rearranged retained expression at
100 digits using the existing precision oracle and its independent weak
contraction. The80-digit candidate uses the derived bounded readout and
stable algebra. Geometry, history, grids, weights and the1e-10 tolerance
remain fixed. Native float assembly is diagnosed separately against the
same reference; failures must be retained, not hidden by changing the gate.

High/low packets retain the tested values and paired differences. They are
selected-point results only. The test never propagates a partial source or
silently assigns zero to a missing inclusive component.

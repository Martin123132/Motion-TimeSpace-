## Next derivation: use the actual gas-energy equation

Source owner for the saved histories:

  saved nonlocal emission/scattering banks and calls the coupled engine.
- ../infrared-source-domain-20261008/nonlocal_common.py imports that engine.
- ../emitting-thermal-background-20261008/evolve_emitting_background.py contains
  the coupled profile/gas solve, BDF2 recurrence and saved energy/work variables.

Reading that engine gives, in its scaled variables and expansion coordinate u,

    E = energy_row * profile,  chi = constant gas heat capacity,
    E + chi*g + W = 0,
    W_u = 1 + chi*g,
    chi*(g_u + g) = -1 - E_u.

Thus the gas curvature obeys

    g_uu = -g_u - E_uu/chi.

Along the already used t=-Delta u parameterization, g_tt=g_uu. The implicit
solver uses backward Euler for its first step and BDF2 thereafter. Its actual
late-time discrete contract is

    D_BDF2 E_i + chi*D_BDF2 g_i + 1 + chi*g_i = 0,
    D_BDF2 f_i = (3f_i-4f_(i-1)+f_(i-2))/(2 Delta u).

Here D_BDF2 denotes the BDF2 FIRST derivative, not a second derivative.
For clarity, code should name it bdf2_first_derivative. The continuous second
derivative relation must not be passed off as an already tested discrete identity.

The profile equation in the same engine is

    M profile_u = rate*(scattering-damping)*(profile-template*g),
    E_u = energy_row * profile_u.

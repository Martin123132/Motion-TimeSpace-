# Native radiation/matter feedback for the joint canonical action

This continues the retained action and the preceding second-order mean. It does
not introduce a new fluid law, matter coupling parameter or saved source forcing.

## 1. Two metric forcing channels, derived from the action

The retained canonical equations give

    h'=(P_eta-6P_h)/a^2-3F
    eta'=P_h/a^2+F/2
    F=sum_I v_I d_I.

The native flat synchronous variables are z=h'/(2k) and
sigma=(h'+6eta')/(2k). Therefore, off the metric constraint surface as well,

    z=(P_eta-6P_h)/(2ka^2)-3F/(2k)
    sigma=P_eta/(2ka^2).

The F terms cancel exactly in sigma. This is a coupling law from the retained
joint action, not a coefficient inferred from observed histories.

CDM's existing synchronous relation delta_c=-h/2 is retained with its original
integration constant fixed by the same initial seed. Native eta*k and delta_c,
and the canonical scalar coordinates, are removed from the rest vector to avoid
duplicating dynamical variables. Metric momenta remain explicit; their constraints
are not reset after integration.

## 2. Native rest-source rows

Let R_z and R_sigma be the conformal-time source vectors in the rest equations.
In the retained non-tight-coupling regime the owned equations.f90 gives:

- baryon density: R_z=-k;
- photon and massless-neutrino monopoles: R_z=-4k/3;
- each of the five massive-neutrino monopoles: R_z=-4k/3;
- explicit photon/neutrino quadrupoles: R_sigma=8k/15.

Other rows have zero direct metric forcing in the retained regime. Native
streaming, Thomson drag, polarization and thermal-background coefficients are
left in the native internal operator. Extra thermal perturbations, unresolved
relativistic expansions, radiation-streaming approximations, massive-fluid
approximations and non-owned branches remain guarded out.

### Existing massless-neutrino approximation

Some saved wavelengths activate the native high-k-tau massless-neutrino
approximation. That row is instead

    pi_r'=-3 pi_r/tau-delta_r'
         =-3 pi_r/tau+k q_r+(4k/3)z.

For that row only, R_z=4k/3 and R_sigma=0. This is an imported, already retained
native approximation, not an MTS derivation or a changed comparison baseline.
The first adapter rejected this flag; REGIME-REPAIR.md records the inspected
correction and preserves the failed receipt. No tolerance or native flag changed.

## 3. Preserve the actual native internal operator

For a current rest state Y, with scalar/metric coordinates set to zero for this
one decomposition evaluation, call the existing native RHS and observer.
Subtract exactly the two metric-source rows evaluated from that SAME current Y:

    D Y = [native_rhs(Y)-R_z z_native(Y)-R_sigma sigma_native(Y)]/H.

No future perturbation history is supplied. The existing native operator,
collision terms and state-dependent source evaluation are used at every RHS
call. Since the linear rest equations depend on scalar/metric variables only
through these two source channels in the guarded regime,

    Y_N=D Y+[R_z r_z(theta)+R_sigma r_sigma]Z/H.

This decomposition is independently checked against DLL columns for eta, CDM
and both canonical scalar pairs, as well as arbitrary combined current states.

The five massive-neutrino angular chains retain the existing G192 extension.
All moments ell>=3 are evolved with the same Galerkin recurrence, and all
lower moments and species feed back. A projected native tail closure is NOT
mistaken for that extended recurrence. The separate extension is verified
against the previously owned extension function.

## 4. Rest sources back into the action

Current native rest pressure P_rest and anisotropic stress Pi_rest give

    l_h=-a^2(P_rest/2-Pi_rest/3)/H
    l_eta=2a^2 Pi_rest/H,

with all other entries zero. The full coupled action equations are

    Z_N=J(KZ+l(Y))
    Y_N=D Y+[R_z r_z+R_sigma r_sigma]Z/H.

Density/current terms remain in the original constraint rows and diagnostics.
Rest pressure/stress is calculated from the CURRENT evolved rest state, not
read from a prior solution or replaced by fitted closure parameters.

## 5. Both directions under the same canonical mean

For Z=S W, the exact source direction is S^T l(Y), while the feedback into
rest species is

    [R_z r_z(theta)+R_sigma r_sigma]S W/H.

The preceding order2 action determines S[2]=I+X+X^2/2, X=JG. This stage derives
the zero Laurent coefficient of r_z S[2] and r_sigma S[2] using the same finite
convolution as the source and Hessian. The mean coupled equations use

    W_N=J(Kmean W+Bmean l(Y))
    Y_N=D Y+[R_z r_z,mean+R_sigma r_sigma,mean]W/H.

Thus both directions are derived from the retained equations. Calling only
S^T l with saved future l(t) would have been an open-source replay; it is not
what these forward runs do.

The background-only coefficient table uses the ORIGINAL physical N nodes.
Independent non-midpoint evaluations and every-second-node comparisons test its
interpolation. No perturbation data are used to choose the coefficients.

## 6. Prospective forward comparison and constraint checks

The declared first matched test is heavy-balanced and cold-balanced, each full
action and order2 mean, G192, DOP853 rtol2e-12/atol2e-14, original half-cap steps
and physical output grids. Initial data are the same freshly reconstructed
owned native seed, with the exact canonical map for W. No subsequent projection
onto constraints or fit to the comparison histories is made.

The saved full history is opened for comparison only after each model's two
forward solves. Rest sources during integration come only from the new current
state. Cold mean is exactly the identity treatment.

Physical regression uses the same retained observable formulas and1e-30
normalization floor as the previous comparison. It is accompanied by separate,
non-tautological canonical and kinematic constraint checks. In particular:

    z_kin=H h_N/(2k), eta'_kin=H eta_N
    sigma_kin=z_kin+3eta'_kin/k.

For mean reconstruction the actual derivative is S_N W+S W_N, with S_N reused
from the sealed exact-map calculation on the identical grid. Hamiltonian and
momentum constraints are checked with both canonical and actual kinematic
rates. A constraint-derived native observer alone cannot qualify a model whose
own metric velocities disagree.

A failed forward comparison must be retained and diagnosed. Passing algebraic
coupling checks does not override it; further wavelengths wait for this result.

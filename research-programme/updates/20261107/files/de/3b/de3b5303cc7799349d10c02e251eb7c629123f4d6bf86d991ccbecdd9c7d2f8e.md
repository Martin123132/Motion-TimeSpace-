# Independent support map: Euler equation, null kinetic direction and compatibility

Private derivation and protocol, 27 September 2026. This attempts the
minimal independent-map route suggested by the preceding shape-work result.
It is an explicit extension being tested, not an already signed parent action.
All old source-fitted states, operators and current prescriptions are retained.

## 1. Extend the map, not the coefficients

Let r=chi(t,x), J=chi_x>0, W=chi_t, g=u_x/J and

    alpha=r^2/(N sqrt(F)), beta=r^2 N sqrt(F), T=u_t-W*g.

The inherited wave density, expressed for this independent map, is

    L_w=J*(alpha*T^2-beta*g^2)/2.

The Gram term is unchanged: L_G=-U_G, U_G=sum (S gamma)*(D u)^2/2,
gamma=beta/J. In particular it contains no independent chi_t term at
zero metric shift. Map variations considered here vanish at the source
anchor and outer endpoints, so the dust coordinate/velocity does not vary.
The old horizontal-shift prescription is kept; its first derivative with
respect to metric shift must not be confused with a new zero-shift inertia.

## 2. Derive the kinetic structure before solving accelerations

With configuration and metric held fixed, differentiate with respect to
(u_t,chi_t):

    p_u=J alpha T,                 p_chi=-g*p_u,
    H_velocity=J alpha [[1,-g],[-g,g^2]].

This positive semidefinite matrix has an exact null vector (g,1). The
primary Legendre relation is p_chi+g*p_u=0. Holding u_t fixed would show
a positive chi_t coefficient J alpha g^2, but that is not the Schur
complement when u_t is allowed to respond. The Schur complement is zero.
U_G, having no velocities, cannot lift this null direction.

At fixed configuration the simultaneous velocity variation
delta u_t=g*delta chi_t leaves T, wave density and pressure unchanged;
Gram density and dust also remain unchanged. Thus the inherited radial
constraint forcing has no variation along the exact null direction.
Eliminating that same stationary radial geometry does not manufacture
an inertia for this direction. This statement does not introduce or solve
the missing full metric-shift equations.

## 3. The missing map equation is a compatibility constraint

Use the Euler convention E=L_q-d_t L_qdot-d_x L_qx. For a compact map
deformation delta chi=eta, delta u=g*eta (a fixed Eulerian field), the
kinematic relation J_t=W_x gives

    delta g=(g_x/J)*eta,     delta T=(T_x/J)*eta,
    delta L_w=partial_x[eta*(alpha*T^2-beta*g^2)/2].

After all cell-face/boundary terms are included, this is the wave
reparameterization identity E_chi,w+g*E_u,w=0 in weak form. The Gram
potential contributes the already derived shape work, so

    integral eta*E_chi + (eta*g)*E_u = -B_G[eta*g,eta].

Therefore a solution of BOTH independent-map and scalar Euler equations
must satisfy B_G[eta*g,eta]=0 for every allowed compact shape test. The
null-direction combination contains no independent acceleration that
can simply be tuned to cancel a nonzero B_G. In Hamiltonian language this
is a secondary compatibility condition from preserving the primary
Legendre relation; its later closure/classification still needs analysis.

A nonzero B_G does not prove that no different constrained equilibrium
exists. It does show that the old state cannot be promoted to a solution
of this enlarged system merely by assigning a support acceleration.

## 4. Keep this distinct from the radial-current equation

The preceding calculation found

    R=B_G+d_t(J_horizontal-J_minimal)+explicit projection/Euler terms.

Thus the map compatibility functional B_G is not identical to the measured
radial residual R in the retained horizontal extension. Adding an equation
named 'support dynamics' is not by itself a proof that both equations close.
A new equilibrium can change the current derivative; this comparison does
not assert its value stays fixed on a different solution.

For finite P2/material spaces, replace eta*g by its projected field profile v.
The exact unprojected continuum identity and the finite projection defect
must remain distinct. In particular the enlarged matter kinetic form is

    Q(delta u_t,delta chi_t)=integral dx J alpha*(delta u_t-g*delta chi_t)^2.

On the represented near-null profile (v,eta), its value is precisely the
positive norm of v-eta*g, not a newly derived physical support mass.

and 4376 field grids, retaining the original physical Gram support. Reuse
the completed dynamics; no new nonlinear solve or initial-condition change.

- For each of the three compact profiles, evaluate the exact velocity-null

  C=integral k*(eta*g)*(eta*g)^T, k=J alpha, and the independent direct

- Independently evaluate B_G at each restored centre. Reproduce the sealed
  third-grid shape work to 2e-18; compare fine/third force and near-null

- Record all test outcomes and absolute/relative changes. Zero Gram force

## Constructive consequence to investigate

The alternatives are now sharply distinguished: solve a genuinely
constrained support equilibrium (with fresh consistency/initial-data checks),
or derive an operator/metric transport completion from the parent geometry.
If support is only a coordinate label, its weighted quadratic form must
transform under an actual pullback P as K_new=P^(-T) K_old P^(-1), and a
time-dependent pullback uses the connection Omega=P_dot P^(-1). These are
necessary change-of-representation identities, not a physical completion
obtained merely by subtracting B_G. The physical operator, metric variations
and the existing current must still be derived together.

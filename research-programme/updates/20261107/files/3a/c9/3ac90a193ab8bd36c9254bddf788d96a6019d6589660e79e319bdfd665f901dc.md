# Native curvature compatibility comes before the third-jet test

The initial transmission pair fixes native values and first slopes, but it does not ensure a twice-time-differentiable common field trace. At an ordinary moving interface, continuity gives

    v_ddot = q_tt_minus + a_X*g_minus = q_tt_plus + a_X*g_plus

on the zero-rate slice. Substitute the one-sided regular bulk equation q_tt=c^2*k+d*g. The missing ordinary-native corner condition is therefore

    c^2*[k] + (d+a_X)*[g] = 0.

This is distinct from the distinguished source corner already tested. Here a_X is the acceleration of the actual native knot, equal to its retained source-map displacement times the computed source acceleration. Neither a_X nor a new support inertia is fitted. A failure means this initial field cannot start a classical solution with the assumed second time traces; it does not exclude a weaker solution or another initial field.

There is an explicit fixed-geometry repair. Keep the values and one-sided first slopes and retain the old mean curvature k_mean. Set

    j_k_required = -(d+a_X)*[g]/c^2,
    k_minus_new = k_mean-j_k_required/2,
    k_plus_new = k_mean+j_k_required/2.

On each unchanged native interval [L,U], construct the unique quintic Hermite polynomial from the value, outgoing/incoming first slope and outgoing/incoming second derivative at its endpoints. This produces an actual continuous piecewise-polynomial function, not just a residual target. It retains the native potential and the initial field/pressure transmission conditions at fixed metric because values and first slopes are unchanged. It replaces the arbitrary two-parabola interior interpolation.

For x=(R-L)/h, its six basis polynomials are

    H00=1-10x^3+15x^4-6x^5, H01=10x^3-15x^4+6x^5,
    H10=x-6x^3+8x^4-3x^5, H11=-4x^3+7x^4-3x^5,
    H20=(x^2-3x^3+3x^4-x^5)/2, H21=(x^3-2x^4+x^5)/2,
    q=v_L*H00+v_U*H01+h*g_L*H10+h*g_U*H11+h^2*k_L*H20+h^2*k_U*H21.

Each native corner is repaired algebraically on the inherited metric and source acceleration. The interior wave energy changes and must be evaluated. The next live solve must update the metric and source acceleration and retest the corner; the frozen repair is not promoted to a live trajectory. The degree-seven third-jet lift previously derived remains useful AFTER this lower-order compatibility condition has been addressed. The new quintic function also requires a suitable live discretization rather than pretending that P2 represents it exactly.

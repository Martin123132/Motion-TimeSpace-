# Native radial-constraint check for the kernel construction

The first kernel-family probe uses the inherited radial solver, whose stored Gram load is the fixed-reference form. Although the canonical source is affine to rounding and the new field annihilates the native operator analytically, those facts must not silently equate two represented loads.

For the exact constructed native-null family the physical native Gram load is identically zero. Keep the first run unchanged and use a daughter to evaluate its solved metric directly against that native right-hand side. If g_old is the inherited represented Gram density, subtract precisely

    delta m_R = kappa*R^2*F*g_old,
    delta nu_R = kappa*R*g_old

from the old radial right-hand side, integrate using the existing radial rule and boundary equations, and evaluate the residual again. Record the maximum discarded old load and both residuals. This is a source-derived zero, established by the common-quadratic/compensated-hinge identity, not a fitted suppression. It validates the numerical radial constraint to the declared 8e-14 tolerance, not an exact continuous metric solution.

The actual initial source-profile change may only be rounding: report it numerically rather than implying a new physical distribution. The rates are deliberately reset to zero. The test continues to reject dynamical invariance of the simple family under the flat radial-wave control and to retain the curved interior diagnostic.

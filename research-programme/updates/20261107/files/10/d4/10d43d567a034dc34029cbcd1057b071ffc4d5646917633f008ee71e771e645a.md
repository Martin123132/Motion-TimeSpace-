# Conditions for a controlled Newtonian limit

The terminal-output identity separates source smallness from propagation.
For each observable, define the exact gains

    C_force = integral |G_alpha+Y G_z| dN
    C_time  = integral |G_z| dN.

The physical source split gives the sufficient bound

    |ell e(T)| <= C_force (||M||infinity+||S||infinity)
                 + C_time ||T||infinity

for exactly matched initial data. These constants depend on the retained
candidate operator/background and chosen readout, not on the unknown error
or a fitted density correction. A parameter family has the stated terminal
Newtonian limit if these gains stay bounded while the displayed sources
vanish (or their products vanish). A uniform-in-time theorem additionally
requires these bounds uniformly for all terminal times. Normalized readouts
must not introduce a vanishing reference denominator.

The current code evaluates both the sharper actual residual-integral budget
and this gain-times-source-envelope estimate. Its source maxima and integrals
are numerical original-grid estimates; they are not rigorously certified
continuous suprema. That numerical limitation does not change the exact
conditional inequality or its explicit hypotheses.

This also exposes why H/k alone was insufficient: dust-force T=3Phi_g'/k.
A rapidly oscillating scalar can have a large instantaneous time derivative
even with small potential amplitude. Discarding that term by assumption would
be precisely the missing closure, so it is retained here.

For a genuinely derived phase term f_n exp(i n theta), n nonzero and
mu=theta_N nonzero, integration by parts instead gives

    |integral f_n exp(i n theta) dN|
      <= |f_n(T)/(n mu(T))| + |f_n(N0)/(n mu(N0))|
         + integral |d[f_n/(n mu)]/dN| dN.

This is an exact alternative estimate, not a claim that the last derivative
is small. The already-retained coupled phase correction supplies a possible
route to deriving f_n and its full derivative. Any application must include
the adjoint's phase dependence; treating it as slowly varying without a
derivation would invalidate the argument. Evaluate the present source/gain
budgets first, then use the dominant term to choose that next calculation.

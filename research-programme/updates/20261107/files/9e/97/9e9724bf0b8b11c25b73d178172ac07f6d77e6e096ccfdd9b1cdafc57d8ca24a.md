# BDF2 source-endpoint matching correction

The qualified source produced consistent source-representation comparisons and
energy/number ledgers, but its isolated added-interval response changed1.56–1.79%
between the original2048/4096 grids. The merged result passed; normalizing only
by that larger result would hide the new interval's error. Retain all48 failed
small-contribution mesh checks.

For y'=A(u)y+b(u) with an attributed source switched off immediately after u_b,
the state is continuous but y'_before-y'_after=b(u_b). A BDF2 update using the
uncorrected pre-jump older state extrapolates that old derivative into the
source-free tail. Its virtual older value on the post-jump smooth continuation is

    y_(b-h)^after = y_(b-h)^before + h*b(u_b) + O(h^2).

Substitution in (3*y_new/2-2*y_b+y_old/2)/h=A_new*y_new gives an effective
first post-cut load -b(u_b)/2. Apply this once, then use the ordinary homogeneous
updates. This is an integration endpoint correction, not a physical negative
source pulse or a new tail. The actual microscopic source and its support are
unchanged. In the current code b includes the background rate, so use
-0.5*rate_at_cut/rate_next times the last source vector. Both baseline and MTS,
both source representations, all passive ledgers and both meshes use the same
correction. The original BE/BDF schedule and all grid nodes stay unchanged.

Scalar control: y'=constant until a grid-aligned cutoff, then y'=0. Uncorrected
BDF2 adds h*source/2 in the long tail. The corrected first tail update leaves y
exactly at the cutoff state. This proves removal of that leading endpoint term,
not a uniform stiff-system error theorem: the omitted higher derivatives can
contain A*b. The actual coupled system must still pass the same mesh gates.

Implementation is additive in qualified-continuation/endpoint-matched/; original
responses and failed comparisons are retained. No response tolerance is changed.

# Finite-event Planck bound

In `planck_remainder.py`, A(x)=x/expm1(x) decreases and
B(y)=y/(1-exp(-y)) increases for positive arguments. For each frequency
cell [a,b] and all saved event ratios r in [r_min,r_max],

    A(b) B(r_min a) <= F_P(x,r) <= A(a) B(r_max b).

This provides a continuous frequency-interval bound for the finite
quadrature event range, not merely sampled frequency maxima. The
256 fixed cells tighten a monotonic bound; they are not fitted frequencies.
The positive Dirichlet estimate is tested on the predicted common-band
spectra using physical shifted endpoints and no shift-grid deposition.

This conductance correction alone is NOT a complete next-order
Compton operator. Recoil changes the frequency map as well as the
cross section; both and the associated detailed-balance weights must be
kept in a full common-space calculation. The saved ratio/rate list is
not enough to reconstruct all recoil kinematics. No full-population
Juttner tail, higher-order emission, or plasma bound is asserted here.
The opposite energy-test value is recorded for the gas, but the gas
history is NOT re-evolved in this conditional diagnostic.

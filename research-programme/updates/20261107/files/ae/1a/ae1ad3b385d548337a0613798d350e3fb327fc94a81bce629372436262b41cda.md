# Stage198 — connecting a microscopic-source correction to thermal history

## Two different states

Let h=(p_h,g_h,W_h) be the photon/gas history supplied to the microscopic source,
and Y=(p,g,W,N,J) the response driven by that source. Stage189 repaired h;
Stages190–196 evaluated the changed source F(theta,h); Stage197 propagated its
difference. These operations do not identify delta h with delta Y.

With the saved response operator held fixed, define

    delta s(u)=F(theta(u),h_candidate(u))-F(theta(u),h_original(u))
    delta Y'=A(u) delta Y+B(u) delta s(u).

If the history operator also differs, the history difference obeys

    delta h'=A_candidate delta h+(A_candidate-A_original)h_original

with common affine forcing cancelled. Its source effect is, where the source is
differentiable (or piecewise C1 along the segment),

    delta s = integral_0^1 D_h F(theta,h_original+t delta h) delta h dt.

Only when F is affine in the changed variables does this reduce exactly to a
single constant kernel. No such global affine reduction is assumed here.
If the RESPONSE operator itself is changed, an additional operator-difference
forcing acts on the old response. That is a different extension; it is not
silently included in Stage197 or198. The original response bank stays fixed.

## Derived physical matching law

Integrate the first-order equation across an interface u_c. With finite
coefficients and locally bounded source, and no delta-function impulse,

    [delta Y]_-^+ = 0.

At one-sided differentiability points,

    [delta Y'] = (A_+-A_-)delta Y(u_c)
                +B_+delta s_+-B_-delta s_-.

A corner or finite source jump can change the derivative without resetting the
photon/gas state or its stored work. It does not supply a physical impulse.
For the continuous original bank A and input map B, only B[delta s] remains.
One cannot enforce both zero outgoing state and this law unless the accumulated
state really is zero or a compensating physical impulse has been specified.

Let G be the propagator for the unchanged response operator. Then

    delta Y(c)=G(c,a)delta Y(a)+integral_a^c G(c,u)B(u)delta s(u)du
    delta Y(f)=G(f,c)delta Y(c)+integral_c^f G(f,u)B(u)delta s(u)du.

Substitution proves that arbitrary internal cuts cancel. For the locally known
interval I=[a,b], the whole correction decomposes as

    delta Y(f)=G(f,a)delta Y(a)+Y_I(f)
                 +integral_b^f G(f,u)B(u)delta s(u)du.

Stage197 supplies Y_I, not the first or last term. Its zero initial state is the
definition of a source contribution. It does not prove the physical matching
state vanishes. This stage supplies the interface states and transfer operators
which make these terms composable without inventing a taper.

Energy accounting is also matched: for the measured source-pair defect,

    (E+chi*g+W-J)'=0,  J'=rate*(s_E+s_gas).

For number bookkeeping, n[p]-N is invariant when N integrates the actual
collision/emission number source. The ledger offsets travel across the join;
they are not new free parameters. The source's gas row is never set to -s_E
merely to pass the check.

## BDF2 matching is a numerical requirement, not new physical memory

For a fixed global update schedule the linear step has the form

    Y_n=L_n Y_(n-1)+R_n Y_(n-2)+d_n.

The exact discrete connection acts on Z_n=(Y_n,Y_(n-1)):

    Z_n = [[L_n,R_n],[I,0]] Z_(n-1) + (d_n,0).

Artificial cuts must preserve both stored states and the BE/BDF2 schedule.
Splitting d into left/right pieces on that common schedule preserves additivity.
Starting each piece with a new BE step would instead change the numerical
problem. The pre-existing BE step after the Stage197 attribution interval is
retained for comparison; it discards the older state at that specific interface.

At a later ordinary BDF2 cut c, write H_current,H_previous for the outgoing
transfer from its two states. Composition obeys

    G_discrete(f,b)=H_current G_discrete(c,b)
                     +H_previous G_discrete(c-h,b).

This identity is tested at the saved colder fraction0.90625. The known
interval's state there is a prediction for that contribution, not a prediction
of the uncomputed microscopic source at that temperature.

## Quantitative boundary-to-spectrum control

Use the inherited positive mass/heat norm

    ||v||_H^2=p^T M p+chi*g^2.

Map whitened coordinates q to a physical photon/gas interface state using the
Cholesky factor of M and sqrt(chi). Energy-coordinate conversion is exact for
the saved representation. Choose W=-E-chi*g and N=n[p], J=0 when constructing
test directions, so their energy and number ledger offsets vanish. These
passive ledger choices do not alter photon/gas dynamics.

Let T_b be this interface map and R the inherited temperature/mu/y-removed
residual readout. For the frozen numerical transfer,

    K=diag(sqrt(measure))*chi*R*G_discrete(f,b)*T_b
    ||residual_boundary|| <= sigma_max(K) ||v||_H.

The algebraic operator-norm inequality is exact; computed singular values are
floating-point estimates, not certified continuum bounds. Check both original
meshes and a maximizing direction by a separate forward evolution. Report the
boundary norm that would consume Stage167's partial MTS allowance, without
pretending the actual unknown exterior matching state meets that bound. No
Stage167 MTS allowance is assigned to the baseline.

# Newtonian density variables without dropping geometry

This is a dictionary within the retained linear equations, not a new theory,
fit, gauge-generator proof for every MTS field, or a replacement parent action.

For the retained pressureless component,

    delta_n'=-theta+3Phi',   theta'+Htheta=k^2Psi.

Define coordinate-volume number contrast delta_count=delta_n-3Phi.
Then delta_count'=-theta exactly, even when Phi varies rapidly. Geometrically
the linear spatial-volume element is a^3(1-3Phi), so this is the perturbation
in particle number per coordinate volume rather than physical number density.
The physical readout is delta_n=delta_count+3Phi; discarding that dictionary
would change what is being compared.

Let Rc=a^2 rho_c/M_Pl^2, Dother=D-Rc delta_n, and Qother=Q-Rc theta/k.
With all other sectors STILL LIVE, the exact retained GR constraint becomes

    (2k^2+3Rc)Phi=-Rc delta_count-Dother-3H Q/k
    Psi=Phi-Pi/k^2.

The retained Poisson-spatial candidate instead satisfies

    (2k^2+3Rc)Psi=-Rc delta_count-Dother,  Phi=Psi.

No new gravitational coupling has been inserted. The denominator follows
from the physical source and volume conversion. The full current/shear terms
remain explicit in GR; the existing response bounds control their omission.

## Formal single-dust subcase

Only in a single-pressureless-source subcase (not assumed for the present
MTS/radiation mixture), Q=Rc theta/k, Pi=0 and Dother=0. The GR count-density
equation then reads

    delta_count'' + H[1+3Rc/(2k^2+3Rc)]delta_count'
      - [k^2 Rc/(2k^2+3Rc)]delta_count=0.

The Poisson-spatial version lacks the additional current-induced damping.
As epsilon=3Rc/(2k^2) goes to zero, both recover the Newtonian source
coefficient Rc/2 with fractional coefficient error epsilon/(1+epsilon).
This is a derived finite-mode expression and explicit limiting condition,
not evidence that the current mixture satisfies the single-dust assumptions.

## What was checked

volume_dictionary.py checks the CDM density/current readouts, number
continuity, transformed constraint and inverse observable map for both
saved GR and Poisson-spatial runs, MTS and cold. No new integration is needed.
Other density/current sources are saved, not discarded.

The large dust-force/GR density difference cannot simply be declared a
gauge artifact: that branch actually modified the dynamics. The dictionary
instead identifies a more faithful way to formulate a Newtonian comparison
while preserving the observable map. Initial physical states must remain
matched; count-density initial values may differ if the metric differs.

This explains why keeping spatial-metric time response and bounding its
effect is preferable to assuming Phi'=0. The metric-time primitive is an
error-analysis transformation; it is not automatically the canonical
volume dictionary for every field. Those roles must remain distinct.

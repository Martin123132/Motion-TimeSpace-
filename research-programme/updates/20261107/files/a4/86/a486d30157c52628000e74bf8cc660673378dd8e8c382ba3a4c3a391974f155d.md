# Stage215 — operator temperature change separated from history change

At each fixed anchor temperature retain
Delta S_cj(theta;q)=L_cj(theta)q on the97-dimensional repair space.
The basis/features and target q are held fixed exactly as in Stage213.
Only physical event parameters and their original weights change with
temperature. This avoids reintroducing the rejected source interpolation
that used different histories at different anchors.

Form the already specified prediction
L_pred=(3/8)L_w+(3/4)L_m-(1/8)L_c.
Then its tested history error is exactly E q, E=L_pred-L_target.

With M=C C^T and E partitioned into photon/gas blocks A,a,b,d:
||E_gamma q||_(M^-1) <= ||C^-1 A C^-T||2 ||phi||_M
                       + ||C^-1 a||2 |g|;
|E_gas q| <= ||b C^-T||2 ||phi||_M + |d| |g|.

These follow from Euclidean induced norms after transforming the photon
coordinates. They require no arbitrary combined photon/gas weighting.
Compare each error-block norm to its corresponding target-block norm;
that is an operator-block comparison, not a bound on relative source
error for every q. Cancellations or a target nullspace can make such a
relative source claim invalid.

Use the absolute inequalities for the actual histories, and separately
test (L_pred-L_target)q directly. Reproduce the previously frozen Stage213
source forecast as an independent representation check. Do not infer
uniform-in-temperature control or a fixed source-only closure from a
pointwise operator test.

Energy-exchange and number/energy reconstruction identities are linear
row identities, hence remain valid under these fixed signed interpolation
weights. Component sums likewise commute with interpolation mathematically;
the compensated implementation is checked numerically.

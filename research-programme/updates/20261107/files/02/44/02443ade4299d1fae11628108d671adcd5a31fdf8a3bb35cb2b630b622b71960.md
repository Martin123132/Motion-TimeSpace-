# Stage189 — separate retained-state precision from step-size error

The inherited reduced equations are

    M p' = S(u)(p - T g)
    e^T p' + chi(g' + g) + 1 = 0
    W' = 1 + chi g.

For step h and previous nominal spacing H, r=h/H,
a=(1+2r)/(1+r), c=r^2/(1+r). With dp_old=p-p_old and dg_old=g-g_old,

    A = a M - h S
    f = A^-1 [c M dp_old + h S(p - T g)]
    R = A^-1 [-h S T]
    den = chi(a+h) + a e^T R
    dg = [c(e^T dp_old+chi dg_old) - a e^T f - h(1+chi g)] / den
    dp = f + R dg
    dW = [c(W-W_old) + h(1+chi(g+dg))] / a.

The next state is (p+dp,g+dg,W+dW). These are the Stage188 equations, now
used throughout the existing short interval. For equal consecutive steps
a=3/2,c=1/2. At the very first refined step H is the native restart spacing,
so r=1/2 on half and r=1/4 on quarter. Substituting ratio one there would
change the numerical initial-value problem and invalidate this comparison.

Carry the state as decimal high precision between updates, including the anchor;
converting only the last probe to high precision cannot undo earlier roundoff.
Physical matrices, initial input states and coefficient time evaluations remain
the saved binary64 representation. Numerical precision is not physical accuracy.

The extra binary64 increment replay uses the same full-matrix system and lets us
decompose, at fixed grid and sampling rule,

    new80 - saved_old = (new80 - new64_increment)
                       + (new64_increment - saved_old).

The second term includes arithmetic ordering, assembly and solver representation,
not just state storage. Old positive-definite solves may use one matrix triangle;
the new general solves use the full inherited matrix, as Stage188 did. Do not
claim that this decomposition isolates only the act of writing a float to disk.

Compute each term after the same equation-based probe sampling, in 80-digit
arithmetic, to avoid mixing sample rounding with evolution rounding.
For the saved-old comparator reuse Stage188's decimal probe values exactly.

At probe half-widths .01 and .005,

    C_coarse = (g_plus-2g_anchor+g_minus)*10000
    C_fine = (g_plus_half-2g_anchor+g_minus_half)*40000
    D = C_coarse-C_fine.

D has weights (60000,10000,10000,-40000,-40000) in the original probe ordering.
Use absolute changes to describe sensitivity, while retaining its own fixed
relative gate. An unresolved tiny D is not automatically a failed total spectrum.

The source projection remains U_component=K_component*C[g] for the unchanged
gas-only kernels. Identical fractional changes in baseline/MTS channels follow
by linearity and do not constitute independent physical evidence. The complete
microscopic source also depends on photons and the changing operator; its old
1.036596% result stays in force until recomputed with those dependencies.

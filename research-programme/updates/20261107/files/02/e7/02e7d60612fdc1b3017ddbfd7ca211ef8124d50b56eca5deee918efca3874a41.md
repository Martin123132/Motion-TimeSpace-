# Stage239 — derived exact scattering accelerator, verified on saved sources

## What changed

The existing six-permutation Dirac amplitude has an exactly derived rational
spin-summed intensity. The final-electron square root disappears through
spin completeness; its remaining frequency dependence is a polynomial
numerator divided by known kinematic factors. Coefficients are obtained by
matrix multiplication and polynomial convolution, once per direction.
No amplitude samples, source data or fit are used to construct them.

DERIVATION.md gives the kinematic identities, all six amplitude coefficients,
the intensity expression and its soft-pole residue. The implementation is
rational239.py:RationalDirection. It inherits the same event kinematics,
leading-control Gram form, thermal stimulation and phase-space factors.
Full-minus-leading and soft subtractions retain arbitrary precision.

This is the same retained physics evaluated more cheaply, not a new fitted
model or a new observational result. It makes expanding the Stage238
source-to-gravity interface more affordable.

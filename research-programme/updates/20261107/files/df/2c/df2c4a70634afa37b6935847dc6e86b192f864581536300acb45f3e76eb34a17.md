# Boundary-corrected constrained-state search

The first state-search and its live-feedback probes used source-pinned tests eta=xi-D*xi(source). That reproduces the old unpinned shape-work experiment, but the archived domain is approximately[5.2,6.8], not[5,7]. These tests do not fix the outer endpoints. RESULTS-20260927-geometric-pullback-and-current.md already records this distinction. The first positive-definiteness certificates therefore concern those unpinned Gram equations, not the intended fixed-boundary compatibility problem. They are retained as comparison evidence and are superseded for that interpretation.

The correct inherited test removes the piecewise affine interpolant through source and both endpoints:

    eta_pinned=xi-D*xi(source)-(1-D)*xi(endpoint_on_this_side),
    eta_pinned,r=xi_r-D_r*(xi(source)-xi(endpoint_on_this_side)).

There is an exact efficient correction because the shape-work functional is linear in its test. Put L_left=(1-D) on the left half and zero on the right, and similarly L_right. Both vanish at the source; their one-sided derivatives are -D_r. Then, label by label,

    Q_pinned,i=Q_old,i-xi_i(endpoint_left)*Q_Lleft
                          -xi_i(endpoint_right)*Q_Lright.

This changes the test functions as required by the actual boundary conditions. It does not change the state family, geometry, Gram support, potential, material norm, or solver tolerances. The two endpoint-generator matrices are independently built from the action. Direct variations of the fully pinned potential check the corrected matrices. The original pinned three-test result from27September is a mandatory replay control.

The daughter reuses the existing high-precision conditioned basis and the previously integrated norm/potential matrices. It reruns all4/7/10-dimensional nonzero searches and13 force tests under the corrected boundary condition. Exact positivity certificates must be recomputed for these matrices. Any new live-feedback trial must use the corrected candidate; previous candidate metrics are not silently relabeled.

Passive operator pullback is ALREADY derived in RESULTS-20260927-geometric-pullback-and-current.md and preserves the on-shell current. It must not be proposed again as a physical force repair. A later coupling change requires genuine native-kernel/source geometric variation from the parent action, not subtraction of the residual or another passive conjugation.

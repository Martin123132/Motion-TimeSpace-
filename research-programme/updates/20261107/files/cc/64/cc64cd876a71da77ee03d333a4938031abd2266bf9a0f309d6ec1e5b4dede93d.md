# Metric variation at fixed reduced coordinate

This supplements DERIVATION.md without changing its frozen tests.

The displayed D, Q_s and P_s are the original canonical stress tensor EXPRESSED in C, not a license to discard induced metric variations of the field transformation.

Let the phase-space action be S[X,y,g], with X=(d,pi), and let X=F(C,y,g). For algebraic transformations the Euler covectors obey
E_C=F_C^T E_X,
E_y,new=E_y,old+F_y^T E_X,
E_g,new=E_g,old+F_g^T E_X.
For derivative-dependent F, each transpose is the adjoint Frechet derivative, with the corresponding endpoint terms. This is the variational chain rule; it must be applied to the complete parent action. On the exact parent shell E_X=0 the metric sources agree. Off shell they need not.

In our fixed-background, linear second map F=T L(C+P_y y):
F_C=T L, F_y=T L P_y,
so the additional spectator Euler covector is P_y^T E_C. The finite candidate-minus-parent term is P_y^T Delta E_C with Delta E_C=-det(L)J Delta C_N, already numerically checked in the scalar sector.

An explicit metric-coordinate example uses native etak=k eta. The saved coefficient table includes native_support=1 for etak (observer.f90 returns etak/k). With ell_eta the complex Q_mic row for etak, the full forcing derivative with respect to eta, at fixed other native state entries, is the real/imaginary pair of
P_eta_complex=J0 kappa A* k/H+k ell_eta.
Consequently the induced eta Euler term is P_eta^T E_C, not zero by assumption. This formula is analytically derived here; this stage has NOT numerically evaluated its complete metric/other-sector Euler equation. The next variational construction must carry it alongside the boundary trace momentum -a²v d/2.

# Stage57 — field transfers to measured clustering

## Retained theory, new observable map

The input is Stage56's physical cold+baryon density transfer T_d and its
Newtonian velocity transfer T_v=-theta_cb/H_conformal, evaluated at z=.38.
Both come from the same retained slow/heavy native field evolution. No new
action, mass, heavy fraction or primordial normalization is introduced.
Galaxy density is approximated by b times cb density, and galaxies are assumed
to share the cb velocity. These tracer assumptions are explicit; galaxy bias is
not being derived from the parent action here.

For a unit primordial curvature amplitude, linear number conservation under
the redshift-space position shift gives

\[
 \delta_g^s({\bf k})=[bT_d(k)+\mu^2T_v(k)]\mathcal R({\bf k}),\qquad
 P_{\cal R}^{\rm dimensional}(k)={2\pi^2\over k^3}A_s(k/k_*)^{n_s-1}.
\]

Define P_dd=T_d^2 P_R, P_dv=T_d T_v P_R, P_vv=T_v^2 P_R. Angular projection
then gives, without assuming scale-independent growth,

\[
 P_0=b^2P_{dd}+{2b\over3}P_{dv}+{1\over5}P_{vv},\quad
 P_2={4b\over3}P_{dv}+{4\over7}P_{vv},\quad
 P_4={8\over35}P_{vv}.
\]

This is why one cannot simply multiply an LCDM galaxy spectrum by a fitted
matter-suppression ratio. Density, cross and velocity terms are retained
separately before angular projection and survey convolution.

## Geometry and units

The source catalog coordinates use a flat fiducial Omega_m=.31 background and
H0=100 in the file header, i.e. numerical distances in Mpc/h. The unused zeff=0
header is not the survey redshift; the release's Table1 gives z_eff=.38 for z1.
Let D_f=2997.92458 integral_0^z dz/E_f(z), E_f^2=.31(1+z)^3+.69, and let
D and H be the retained model's physical native background outputs. With
h=.7, define the scaled-coordinate factors

\[
 q_\perp={hD\over D_f},\quad q_\parallel={100hE_f\over H},\quad
 s(\mu_f)=\sqrt{{1-\mu_f^2\over q_\perp^2}+{\mu_f^2\over q_\parallel^2}},
 \quad k=h k_f s,\quad \mu={\mu_f\over q_\parallel s}.
\]

Here k_f is numerical h/Mpc, whereas k is physical Mpc^-1. Therefore

\[
 P_f(k_f,\mu_f)={h^3\over q_\perp^2q_\parallel}
 [bT_d(k)+\mu^2T_v(k)]^2P_R(k).
\]

No sound-horizon factor is introduced: this is a direct coordinate map, not
the BAO alpha convention. Numerical angular integration projects P_f onto
Legendre multipoles. Independent tests recover the identity-geometry formulas
above and the equivalent physical-coordinate formula with fiducial h=1.

AP remapping also creates higher even multipoles. We retain ell6/8 diagnostics,
but the released operator used here accepts only ell0/2/4 input. This is a
declared multipole truncation, not an assertion that those higher terms vanish.

## Actual survey operator

The Beutler–McDonald release supplies a leading-wide-angle map M and a
window/binning/integral-constraint operator W. The prediction is W M p,
with input p ordered P0,P2,P4. The actual files give M=(2000,1200),
W=(200,2000), and C=(200,200); the landing page's M label is transposed.
Use file dimensions and the paper's multiplication convention, not that label.
All five output multipoles are computed before selecting the observed rows.
Input bins cover 0.. .4 h/Mpc; output bins have width .01 h/Mpc. The raw data
are independently rebinned by mode counts, and agree exactly with the author's
pinned reader. No matrix is inverted to deconvolve the measurements.

After selecting the nominal output-bin centers and chosen multipoles, use the
corresponding submatrix of C before inversion. The source has2048 mocks; the
reported Hartlap-corrected quadratic form multiplies the raw form by
(2048-p-2)/(2048-1), where p is the selected data dimension per cap. This is
an approximate finite-covariance treatment, not an exact marginalized likelihood.
The two disjoint sky caps are treated independently. Neither the overlapping
Stage56 compressed rows nor Stage53 distances are added to this score.

## Equal nuisance fitting and injection test

Write the convolved model as b^2 A+b B+C+N D, where the first three columns
are the density-density, density-velocity and velocity-velocity contributions,
and D is a constant input monopole passed through the same operator. N is a
residual white-noise term; the header's Poisson noise is not subtracted again.
At fixed b the optimum N is its covariance-weighted linear projection, clipped
to the predeclared bounds. A bounded one-dimensional bias search is checked
against a separate dense profile grid. Every physical branch gets the same
bounds and two nuisance parameters per cap; no free velocity amplitude is fitted
to the observed data in this stage.

The separate compression experiment uses noiseless predictions, not observations.
An LCDM density template normalized by its sigma8 is assigned free B=b*sigma8,
F and N. It is passed through the same geometry and survey operator as the
truth, isolating shape-compression effects. Compare recovered F with the truth's
computed cb velocity rms. A non-starting-point injection verifies actual
optimizer recovery; the ordinary self-template smoke test is not the only test.
This does not reproduce the full SDSS nonlinear estimator or its nuisance model.

## What remains outside this approximation

The native transfer is linear. Galaxy formation bias, nonlinear density and
velocity evolution, pairwise velocity dispersion, redshift evolution across
the bin, relativistic light-cone terms, higher wide-angle orders, and omitted
AP multipoles are not all supplied by these leading formulas. Quantify these
effects with shared corrections and mock controls before promoting a relative
diagnostic score into cosmological evidence. A +/-100% change of input power
above .2 h/Mpc tests window leakage, not arbitrary nonlinear errors inside the
fitted range or beyond the released .4 h/Mpc input support.

# Stage198 — thermal-history matching derived and tested

## Main result

The seven-frequency microscopic-source correction now has explicit interface
states and tested transfer operators connecting it to the surrounding saved
temperature history. Both baseline and MTS receive the same construction.

The joining rule follows from the existing equations: with finite source and
coefficients and no impulse, photon/gas response and its ledgers are continuous.
An incoming response propagates homogeneously; subsequent source adds a separate
forced contribution. The local source repair is not switched off by resetting
the state, and a repaired background history is not substituted for the induced
microscopic response. See `DERIVATION.md` and `MATCHING-CONTRACT.json`.

This closes the tested numerical matching interface. The actual source outside
the verified local temperature domain remains to be derived/evaluated; it has
not been assigned zero or replaced with a fitted taper.

## Quantitative matching budget

For boundary v=(p,g), use ||v||_H^2=p^T M p+chi*g^2. The numerical inequality is

    ||final residual from v|| <= kappa ||v||_H.

Fine-mesh kappa is4.012232951e-10 heavy and4.011029651e-10 cold. In this metric,
an incoming boundary perturbation of about3.60067255e-11 heavy or3.60506188e-11
cold would saturate the saved Stage167 partial MTS allowance in the worst
direction. This gives a concrete requirement to check against a future derived
incoming state; it does not establish that the unknown state satisfies it.
The bound is for the frozen numerical response, not a certified continuum bound.
The MTS allowance is not assigned to the baseline.

Negative controls are informative rather than forced to fail: erasing the
previous BDF state at the middle join changes the fine-grid exit MTS residual
by about0.211% and baseline by0.286%, failing the strict joining identity.
Erasing gas violates state continuity but has only about8.6e-12 relative effect
on this exit MTS residual, below the1e-8 spectral comparison gate. The latter
is not reported as a detected spectral failure.

The three preserved arithmetic attempts retain1,59 and4 failed checks. The
first loses gas digits in an energy-first Schur complement; the second loses
small-energy digits in the opposite complement; the third narrowly misses tiny
energy-map readouts owing to accumulation in a nearly conserved row. The final
paired solve and derived ledger-row evaluation fix these representation issues.
See `STABLE-CONNECTION.md`; no historical failure was relabelled as a pass.

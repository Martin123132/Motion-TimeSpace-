# Finite-time return-feedback bound without a small-gain veto

DERIVATION.md section5 gives the rate-mediated return force -xi R_bg.
Its small-gain condition is sufficient, not necessary. The causal structure
gives a stronger finite-time alternative that does not reject a branch merely
because a coarse norm exceeds one.

On the retained finite interval [s0,S], let Y(s)=sup_(s0<=v<=s)|xi(v)|.
Choose Stage225's common end-of-interval canonical majorants, so G is a uniform
source-to-output gain on every prefix. With integrable return-force envelopes
B_R>=||R_bg||_dual and J_R>=|compatible energy moment of R_bg|, define

    h(u)=chi J_R(u)+chi^(3/2)(S-u) B_R(u)+chi epsilon_E B_R(u).

From the forced kinetic energy inequality applied on each prefix,

    sup_(v<=s)|q_return(v)| <= integral_s0^s h(u)Y(u)du.

If M bounds the external plus independent incoming gravitational response
uniformly, then

    Y(s) <= M + G integral_s0^s h(u)Y(u)du
          <= M exp(G integral_s0^s h(u)du).

Thus finite, sourced return-force norms yield a finite, explicit enhancement
without a new damping gap or a requirement that G integral h<1. This is an
upper bound, not a claimed rate of physical exponential growth. It can be
loose; actual signed response can be much smaller. It controls the named
linearized block system, not nonlinear global stability.

The compatible return energy moment vanishes exactly when the reference
collision and emission exchanges are balanced between photons and gas.
That cancellation must be verified from the actual reference operator;
background injection and finite-precision defects must not be erased.
For a perfectly balanced pair, only gas expansion work and the explicitly
retained representation defect enter h. This identifies the suppression
mechanism rather than asserting that a numerically small source is harmless.

No fitted feedback coefficient is introduced. To turn this theorem into a
numerical closed-response bound, evaluate B_R and J_R from the authenticated
reference photon/gas history and existing rate-dependent collision operator
across this same interval. The microscopic correction source itself is not
the reference history and cannot stand in for it.

Independent controls in feedback226.py compare direct coupled evolution
with and without the rate-return term, show its first variation, and test
this bound. These dimensionless controls validate the derivation; they are
not additional MTS parameter calibrations.

# Compact baseline wave current and its velocity derivative

This is an algebraic daughter of the existing wave-current density, not an extra field or closure. Spatial faces, native terms, dust and gravitational currents are unchanged and must still be included by the integral owner.

## Definitions at a fixed physical point

Let `v` denote the interpolated material field rate, `g=q_R`, `W` the map speed, `T=v-W*g`, and `g_dot=v_R-W_R*g`. Write

`A=(alpha_t+W*alpha_R+W_R*alpha)*T + alpha*(q_ddot-W_dot*g-W*g_dot)`,

`F=alpha*W*T+beta*g`, `E=(alpha*T^2+beta*g^2)/2`,

`I_h=integral_source^R h(r) dr`, `V_h=interpolate(v_node*I_h(node))`,

`U_h=T*I_h-V_h`.

The inherited metric identity is `beta_t=-beta*alpha_t/alpha`. The original wave current is

`J_h=-A*V_h-F*(V_h)_R + [E_dot+(W_R+alpha_t/alpha)*E]*I_h+E*W*h`.

Subtract `T*A` inside the energy bracket before floating evaluation. Using `alpha_dot=alpha_t+W*alpha_R`, `beta_dot=-beta*alpha_t/alpha+W*beta_R`, the exact remaining coefficient is

`H= W*(beta_R*g^2-alpha_R*T^2)/2 + beta*g*v_R-W_R*E`.

Consequently

**`J_h=A*U_h-F*(V_h)_R+H*I_h+E*W*h`.**

The troublesome acceleration appears only as `A*U_h`; the independent expanded energy-rate cancellation is gone. Primitive differences can be factored as

`I_h(R)-I_h(r_i)=(R-r_i)*sum_{j=0}^h[(R-6)^(h-j)*(r_i-6)^j]/(h+1)`

for h=0,1,2. Thus `U_h=sum_i basis_i*v_i*(I_h(R)-I_h(r_i))-W*g*I_h`. This is a rearrangement, not a license to set a small term to zero.

## Velocity column

At fixed position let the existing velocity direction give `delta v=d`, `delta W=w`; then `delta T=d-w*g`. This is precisely the compensated numerator structure already constructed for C2. For a direction that holds spatial geometry fixed,

`delta J_h=delta A*U_h+A*delta U_h-delta F*(V_h)_R-F*delta(V_h)_R+delta H*I_h+(delta E*W+E*w)*h`.

Here `delta U_h=delta T*I_h-interpolate(d_node*I_h(node))`. Metric coefficients and their time/radial derivatives must also be differentiated along the archived velocity response; the induced acceleration response is not optional. The derivative identity is exact, but this checkpoint only tests the baseline kernel on actual third-grid points. It does not yet replace the integrated C1 column or supply a new error bound.

## Validation scope

The symbolic checker proves the energy reduction, the current identity and its general directional derivative. The point probe compares the new current to the independently implemented original high-precision density using the actual archived packet, in both branches. Binary arithmetic differences are reported, not used as an assumed integration improvement. Before any baseline replacement, integrate with both completed rules, hold the non-wave terms fixed, and retain the difference between source representations.

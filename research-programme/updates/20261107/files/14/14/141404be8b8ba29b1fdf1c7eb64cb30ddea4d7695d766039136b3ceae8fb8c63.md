## 1. Constructed position derivative

Let the compensated old-coordinate mode be e=(z-w_field,-w_source), with
independent edge-affine support displacement eta fixed in material labels.
With R(xi,lambda), J=R_xi and L=R_lambda,

    U = eta + D*e_source,
    delta lambda_cut = -U/L,
    delta xi = -(U+L*delta lambda)/J.

The calculation differentiates the wave gradients, convective temporal
derivative, material integration measure, moving label cuts, source density,
source velocity and native pushforward. Source/native interval endpoints
use their one-sided traces. The native factor is rebuilt on physical cell
and interaction radii, including its compensated source hinge.

For physical native factors f and sampling S,

    load = S^T(f^2/2), delta load = S^T(f*delta f),
    H_native(R) = sum p(lambda)*load(lambda)/L.

There is no extra1/J here: the physical kernel already contains the affine
normalization. The response X solves the inherited linear radial equations
with fixed inner mass and the differentiated outer lapse boundary.

## 4. Derived next solve: existing-field reaction, then force/current

Let p_hat and F_hat denote the old momentum and force after inserting the
radial constraint solution, without assuming that this insertion itself
defines a new reduced variational action. Define Ppos as the position
derivative of p_hat along(e,eta), and Fvel as the velocity derivative of
F_hat along that mode. The existing live operator is

    L_live = M + P_metric*A_old.

Because the completed velocity momentum is zero along the background,

    delta p_hat = s*(Ppos+L_live*edot),
    r1 = Ppos+L_live*edot-Fvel.

The required old acceleration reaction a1 satisfies L_live*a1=-r1.
There is a useful algebraic simplification. Compute only

    b1 = L_live^(-1)(Ppos-Fvel),
    a1 = -edot-b1,
    delta old acceleration after reaction = edot-b1,
    delta Y_t after reaction = X+Vdot-A_old(b1).

This avoids an unnecessary intermediate cancellation of A_old(edot).
It introduces no fitted coefficient, extra support inertia or guessed
force. Ppos/Fvel and the resulting b1 still need to be evaluated from the
actual material/native functional; no numerical b1 solve is claimed here.

The exact counterexample is Lagrangian=(qdot-f(q)*sdot)^2/2
+epsilon*sdot^2/2-U(q). At base sdot=sddot=0, the mode(f(q),1) has zero
old momentum variation, yet its transported acceleration produces
delta E_q=2*f'(q)*qdot. Therefore momentum orthogonality alone is not a
valid shortcut for setting r1=0, in either MTS or the reference.

Next, calculate Ppos/Fvel, solve b1 with the existing live inverse, and
assemble the corrected C1 force/three-current column beside the owned C2.
Test their joint rank/compatibility on the same four controls, retaining
quadrature sensitivity and testing inferred amplitudes rather than treating
an arbitrarily large linear amplitude as a finite-amplitude solution.

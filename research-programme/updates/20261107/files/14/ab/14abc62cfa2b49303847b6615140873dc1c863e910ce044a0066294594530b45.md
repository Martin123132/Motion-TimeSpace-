# Pre-production setup notes

An initial import pointed at the common module instead of the existing
EnergyCoordinates implementation. It was corrected before preflight or
production files were fingerprinted. The frozen production import is the
actual Stage106 evolve_stable_late_refinement implementation.

The first hidden-worker launcher incorrectly quoted a path containing
spaces. Both processes exited before source evaluation. Their logs and
launch receipt remain. The corrected v2 launcher uses ordinary quoted
arguments, distinct logs and a separate receipt; it launches exactly two
one-core workers. Do not relaunch an existing worker without inspecting it.

The preflight temperature identity entry is redundant. The source assembler
independently checks the new temperatures against the reused .5U anchor
and theta(u)=theta(.5U) exp[-(u-.5U)], rather than counting that redundant
entry as evidence of a newly tested physical law.

New-window results are a sourced96-mode first-order pilot. The separate
Stage141 inner-defect feedback has not been recomputed for the new window.
The old corrected baseline/window results remain intact and the two scopes
are labeled separately. Numerical source-curve interpolation and physical
event quadrature are not the same uncertainty.

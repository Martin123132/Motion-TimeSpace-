# Constant-preserving source-centered coordinates

The first split-label trial reduces the reference-fine position-force
resolution discrepancy from 1.8599e-4 to 9.1594e-10 in the inherited
inverse norm. It still fails the original momentum replay gate:
1.033e-15 versus 2e-16. Its baseline-force quadrature also disagrees
with the original material integral. Preserve those results as failed,
not a completed k0 solve.

The new diagnostic representation removes two cancellation mechanisms:
interpolating a source position of order six to resolve a displacement
of order its thin collar width, and subtracting order-six coordinates
to find local positions in cells as small as 2.44e-6.

Let Rstar be the exact represented mesh anchor, sigma(lambda) the
interpolation of source_nodal-Rstar, and x=xi-Rstar. On each affine
side of the anchor,

    R-Rstar = sigma(lambda)+J(lambda)*x,
    x = ((R-Rstar)-sigma(lambda))/J(lambda),
    J_left = 1+(sigma-width*lambda)/(Rstar-inner_reference),
    J_right = 1-(sigma-width*lambda)/(outer_reference-Rstar).

Use rational reference-edge differences before conversion to binary64.
Construct radial quadrature nodes from anchor-subtracted cell edges,
and evaluate metric cell polynomials in those same small offsets.
Find label cuts with the SAME centered interpolation used for samples.
This preserves constant source translations without relying on a
rounded cardinal row summing to exactly one.

This changes numerical evaluation, not the intended polynomial map or
physical parameters. It is not assumed to succeed: original momentum,
force, quadrature, mixed-jet and live inverse gates all remain intact.
The source/native material covectors remain unchanged in this trial.

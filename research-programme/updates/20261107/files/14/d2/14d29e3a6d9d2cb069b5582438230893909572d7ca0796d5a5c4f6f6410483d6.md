# Two-sided source acceleration compatibility of the quadratic null family

This is a specific conditional obstruction for the constructed classical time-symmetric null family, not a no-go theorem for MTS or for weak solutions.

The inherited source field node is pinned: q(t,b(t))=0. At an instant with q_t=0 and b_dot=0, a twice-time-differentiable one-sided trace must satisfy

    q_tt(b-) + b_ddot*q_R(b-) = 0,
    q_tt(b+) + b_ddot*q_R(b+) = 0.

At the native-Gram-null slice the extra first force vanishes. The one-sided interior wave equation has

    q_tt = c^2*q_RR + d*q_R,
    c=N*sqrt(F), d=2*c^2/R+c*c_R.

If c^2 and d have common continuous traces at b, the equal-curvature quadratic family gives

    2a*c_b^2 + (d_b+b_ddot)*p_- = 0,
    2a*c_b^2 + (d_b+b_ddot)*p_+ = 0.

When a!=0 and p_-!=p_+, subtraction requires b_ddot=-d_b, then either equation requires2a*c_b^2=0. In the untrapped nonzero-lapse chart this is impossible. No single choice of source acceleration fixes both sides.

For the natural-boundary-compatible family,

    p_-=2a*(b-L), p_+=-2a*(U-b),
    b_ddot_required,left=-d_b-c_b^2/(b-L),
    b_ddot_required,right=-d_b+c_b^2/(U-b).

Their gap is c_b^2*(1/(b-L)+1/(U-b))>0. It does not shrink by rescaling a except by setting the field exactly zero, where division by the slopes is no longer permitted.

If metric derivative traces differ, the equality instead demands

    d_+ - d_- = c_b^2*(1/(b-L)+1/(U-b))

for common c_b. The calculation records the actual one-sided numerical drift spread rather than assuming an arbitrary compensating jump. A surface/interface force not present in the current action cannot be added merely to impose this relation.

The initial field can still be valid finite-dimensional or weak initial data. Its finite Galerkin acceleration exists, but boundary/source layers or non-smooth temporal traces may appear; the classical quartic time argument then needs a spatial-limit check. This distinction is why the actual coupled acceleration and both-grid native gates are also computed.

The exact pin is part of the present source-fitted field model. This derivation does not establish that every future MTS parent action must impose that pin. Any change to it requires deriving the source coupling and variational interface law, not silently deleting the source equation.

## Derivation result: use the driven memory law, not a straight-line start

The starting step obeys (I-hL1)e1=h f1-(u1-u0), not simply e1=h*b0.
A naive linear slope differs from the frozen implicit first step by
about80–132 times its max-node norm; this is a stiffness diagnostic,
not an error bar on total gas temperature. Diagonal rates are not asserted
to be physical decay eigenvalues.

There are49 baseline and15 window-history driving knots inside the first
coarse interval. A single frozen initial drive matches the first saved
40-step source point to about0.10percent baseline and4.4–4.7percent MTS,
but its source mismatch grows to1.64–1.66percent baseline and62.4–62.7percent
MTS at the end (component-sum normalization).
The time-dependent drive cannot be replaced by one initial exponential.

The exact conditional kernel is K(t,s)=A(t)U(t,s), with U generated by the
retained inner operator. Its source contains both a propagated initial
memory and the time integral of driving. See `FOLLOWUP.md`.
The inherited zero initial defect is a reconstruction matching condition;
it was not fitted, changed, or newly derived from the parent action.

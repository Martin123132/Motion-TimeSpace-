# Nonzero kernel family and its preservation test

## Why test outside the multiplicative search family?

The four-, seven- and ten-dimensional searches multiply the old localized wave by compact polynomial profiles. A separator in any of these spaces cannot exclude a field outside it. In particular, the inherited source-hinge compensation admits an explicit nonzero piecewise-quadratic kernel family. This is a consequence of the existing operator, not a new cancellation term.

Let L < b < U be the two physical annular boundaries and the pinned source. For an amplitude a != 0 set

    q(R) = a*(R-L)*(R-b), L <= R <= b,
    q(R) = a*(R-b)*(R-U), b <= R <= U.

The three pinned values are zero. The source derivative jump is j=a*(L-U). Subtract the existing compensated hinge j*(R-b)_+. Both pieces then equal the same quadratic a*(R-L)*(R-b). Ordinary first-derivative jumps vanish and all second-derivative jumps vanish. Thus the compensated third-difference kernel, its template image D_R q, and U_G vanish exactly. Since U_G is a quadratic norm, all its first variations also vanish, including the complete native shape force, for any finite admissible variation. No action coefficient is changed.

Consequently nonzero instantaneous map-compatible fields exist outside the previous trial family. This is not an equilibrium or an invariant evolution. Nor does it establish that all operator-null fields have this form: finite native sampling can have additional unresolved null modes.

## Material representation and explicit changes

To represent this family without silently increasing material polynomial degree, choose source positions b(mu)=b0+width*mu, matching the old central source, while L(mu)=L0+width*mu and U(mu)=U0+width*mu. Physical cell maps are translated copies and the nodal field is material-constant. This changes the non-affine part of the old source profile. Set field and source rates to zero: these are new time-symmetric initial data, not a continuation of the old trajectory.

Choose a by matching the old central-layer positive weighted L2 field norm in the old metric. This is an amplitude convention, not energy conservation or a force fit. A fresh radial metric solve must use these actual new fields and rates. Test the native operator on both exact analytic samples and the retained floating-cardinal representation; record interpolation leakage rather than rounding it to zero.

## Preservation is a separate equation

An algebraic curve q(t) in the kernel satisfies D(t)q(t)=0 and therefore its differentiated kinematic identities. It does not follow that the wave and source Euler equations generate that curve.

There is already an exact flat radial-wave control. On either open side, with sigma=L or U,

    q=a*(R-b)*(R-sigma),
    q_tt = q_RR + 2*q_R/R = a*(6-2*(b+sigma)/R).

Its third radial derivative is 12*a*(b+sigma)/R^4, nonzero for positive radii and nonzero a. Any twice-time-differentiable curve in the stated piecewise-quadratic family has piecewise-quadratic q_tt, whose third radial derivative is zero. Changing a(t) or b(t) cannot remove this mismatch. Thus this simple null family is not invariant under even the flat radial wave equation. This is a specific flat-control rejection of that invariant-family proposal, not a proof about all curved or parent-coupled solutions.

At the fixed outer boundary the flat acceleration limit is a*(4-2*b/U), nonzero for L<b<U and a!=0. It also fails the second-order classical fixed-Dirichlet corner compatibility. A weak wave solution may still exist; it would leave this smooth restricted family.

For the actual fresh curved geometry, put c=N*sqrt(F). At the time-symmetric instant, the interior scalar equation gives

    q_tt = c^2*q_RR + (2*c^2/R+c*c_R)*q_R.

Record this acceleration at interior points and its best piecewise-quadratic least-squares residual, without fitting away or modifying the equation. This is an interior preservation diagnostic, not a full coupled weak-Euler/source-acceleration solve.

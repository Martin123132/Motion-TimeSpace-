# Stage135: continuous, temperature-dependent source evolution

The Stage132 derived unscaled cubic kernel and Stage133 linear weak-source
cache are reused unchanged. This step extends the same numerical solution,
not a new model, fit, frequency refinement, or reset at an original epoch.

For each response-update site, physical Doppler event coefficients are
evaluated at the inherited thermal parameter. Both backgrounds share that
parameter but retain their own clocks, emission and external histories.
The negative whole-band Toeplitz-symbol bound is checked at each coefficient
knot. Convex coefficient interpolation preserves that bound between knots.
The BDF2 weighted-norm identity includes volume and ghost-boundary work;
it is a stability diagnostic, not physical radiation-energy conservation.

The exact linear relation A(theta)=sum_j k_j(theta) A_j assembles the common
weak source from saved fixed-shift matrices. Independent off-grid physical
events remain the reference at all 257 new-block knots in both windows.
Seventeen direct common-kernel evaluations per window test the cache.
The endpoint at5120 is copied only after its equality checks pass.

The corrected inner trajectory carries both BDF and outer time levels from
the Stage134 restart. Global0--640,640--1280,1280--5120 and5120--10240
join at exact shared endpoints. Source reconstruction uses the complete
prefix beginning at zero; only the newly covered sites replace the saved
source template. The earlier prefix and later restored source stay unchanged.

The physical source extension and common-minus-physical source are each
propagated as independent difference forcings. This avoids interpreting
cancellation of tiny gas-response numbers as a new physical effect.
The later source is restored at10260 only to measure this finite extension;
the endpoint restart at10240 remains available for continuous continuation.
This stage covers one quarter of the saved time-coordinate span, not
necessarily one quarter of physical elapsed time or integrated response.

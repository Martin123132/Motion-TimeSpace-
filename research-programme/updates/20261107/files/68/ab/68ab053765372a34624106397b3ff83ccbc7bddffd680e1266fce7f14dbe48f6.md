# Stored support endpoints and polynomial coverage

The first real event-split run stopped at its strict domain guard, before any
force rule completed. The separate support-extent diagnostic identifies the
reason: the reference-fine material support extends beyond the registered
background polynomial edges by 2.220446049250313e-16 at each end. This is an
endpoint-rounding discrepancy, not an unresolved macroscopic exterior domain.
The response polynomials cover a wider domain.

The original material evaluator clips the selected polynomial INDEX while
allowing the polynomial coordinate to reach the material endpoint. The revised
event integrator uses that SAME endpoint convention. Its volume partition
includes the actual material support endpoints rather than silently truncating
the integral at the registered background endpoints. It separately accumulates
the weak base/variation force outside the registered metric interval, reports
both extents, and requires those contributions to satisfy the existing raw
2e-15 and inverse 2e-11 thresholds. The guard is thus replaced by an explicit
numerical bound on the inherited polynomial continuation, not a tolerance
relaxation or a new exterior solution.

The earlier failed domain-check attempt is retained. Manufactured checks of the
revised implementation still pass all11 checks; they do not have this endpoint
rounding issue. Reference and MTS runs will apply the same separate extension
checks. No old metric, response, or native coefficient is changed.

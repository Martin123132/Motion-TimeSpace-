# First normalized collective-interaction test

3 October 2026. Private condensate branch; saved framework untouched.

## What we actually accomplished

The interaction is now an executable, normalized integral equation.
It retains amplitude/phase mixing and virtual relative frequencies.
The problematic phase logarithm is integrated analytically instead of
being hidden behind a small numerical cutoff.

Sixteen finite-matrix tests were completed. The largest positive static
eigenvalue in the finer fixed-cutoff test is about0.0000142; a collective
static onset would require1. The tested weak-coupling example is therefore
nowhere near that onset in this leading-exchange calculation.

Cutoff extension was tested separately from infrared resolution. At a
fixed infrared grid, extending the integration cutoff from2 to8 changes
the positive eigenvalue by only about0.104%. Infrared refinement still
changes it by roughly4.8%, so the result is not labeled a converged
continuum theorem. Positive-weight bounds were also checked on the saved
finite matrices.

## What this tells us

Keeping the phase exchange matters mathematically, but does not by itself
supply a static collective tensor in the weak example tested. This gives
us a useful constraint on the physical mechanism instead of another
unsourced coefficient to fill in.

We also derived symmetry relations tying the phase interaction directly
to the radial stiffness and state amplitude. Those quantities cannot
be tuned independently while keeping the same candidate action.

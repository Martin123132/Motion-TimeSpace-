# Derived history-to-source transport, without a source-only closure

This derivation concerns the retained semidiscrete kinetic equations. It does
not replace their parent field action or assume a new gravitational limit.
Use u=ln(a/a0); primes here mean d/du, not d/d ln(theta).

## 1. Transport the actual history repair

Collect the photon/gas history in y. Write its retained candidate equation as

    y_c' = A_c(u) y_c + f(u).

The comparison y_b is the saved original-bank reference, including its specified
interpolation. Define its differential defect relative to the original
operator A_b by

    r_b = y_b' - A_b y_b - f.

For q=y_c-y_b, subtraction gives the exact identity

    q' = A_c q + (A_c-A_b) y_b - r_b.

Setting r_b=0 would assert that the stored interpolant exactly solves the
original ODE. That is not assumed. At interpolation corners use one-sided
derivatives and the actual matching states. The same physical forcing f is
used in both branches; if a future branch changes it, its difference must
also appear on the right, not be absorbed into q.

Let U_c(u,v) be the fundamental propagator for A_c. Variation of constants
gives

    q(u) = U_c(u,u0) q(u0)
           + integral_(u0)^u U_c(u,v)[(A_c-A_b)y_b-r_b](v) dv.

The source repair is therefore

    Delta S(u) = L(u) U_c(u,u0) q(u0)
       + integral_(u0)^u L(u) U_c(u,v)[(A_c-A_b)y_b-r_b](v) dv.

The source memory is fixed by the retained operators and initial history;
there is no adjustable memory kernel in this identity. Stage200's saved
equation evolution already supplies q at the sampled points. A polynomial
through source values need not preserve this history transport.

## 2. When may the history be eliminated?

Differentiating the source repair yields

    Delta S' = R q + L d,
    R = L' + L A_c,  d = (A_c-A_b)y_b-r_b.

For a history-independent linear source equation

    Delta S' = B(u) Delta S + L d

to hold for every allowed q in the full retained state space, one must have
R=B L. In finite dimensions this is equivalent to

    ker(L) subset ker(R),

or R(I-L^+ L)=0 for an exact Moore-Penrose inverse. If this condition holds,
B=R L^+ is one possible extension on the source space. If only a restricted
reachable history subspace is intended, the condition must be checked on
that subspace; it cannot be inferred from one history trajectory.

Proof: R=B L kills ker(L). Conversely, if R kills ker(L), define B(Lq)=Rq;
this is well defined because two preimages differ by an element of ker(L).
Extend B arbitrarily to a complementary subspace. Numerical rank thresholds
and operator uncertainties would need their own bounds before using this
criterion as a numerical closure certificate.

No rank/closure claim for the actual MTS microscopic map is made here. The
criterion states precisely what a proposed source-only temperature law must
establish, instead of hiding evolving photon/gas information in a fitted curve.

## 3. Conservation is necessary, not a shape-accuracy certificate

For the shared photon-plus-gas energy row c, if c^T L_i=0 at each retained
temperature, then c^T E=c^T H=c^T T=0 in ERROR-DECOMPOSITION.md. Temperature
interpolation can therefore preserve energy exchange while giving the wrong
spectral shape and source amplitude.

An exact illustrative counterexample is

    A = [[0,1],[0,0]], L = [[1,0],[-1,0]], c=(1,1).

The histories q_1=(0,0) and q_2=(u,1) both solve q'=Aq. At u=0 their sources
are equal to zero, but their derivatives are respectively(0,0) and(1,-1).
Energy exchange vanishes for both at every u. Here ker(L) is not contained
in ker(LA), so no source-only B can supply the missing history. This is a
counterexample to assuming closure from conservation, not a claim that the
actual MTS operator equals this toy matrix.

## 4. Constructive next calculation

Keep q(u) from the physical history equations. At an uninspected interior
temperature, a history-aware operator interpolation would evaluate the
anchor maps on that SAME target history:

    Delta S_pred(u*) = sum_i w_i L(u_i) q(u*).

This differs from the rejected sum_i w_i L(u_i)q(u_i). It removes history
interpolation from the construction rather than fitting its error. It still
requires an independent test of the changing operator and retains any
numerical/quadrature errors. Evaluating it at the already inspected Stage208
temperature would be diagnostic, not a fresh held-out test.

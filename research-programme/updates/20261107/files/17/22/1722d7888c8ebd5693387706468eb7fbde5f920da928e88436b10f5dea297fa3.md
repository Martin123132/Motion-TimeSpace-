# Stage209: interpolate operators, not differently evolved histories

The retained linearized microscopic repair is Delta S(t)=L(t)q(t), where q
contains photon coefficients and gas departure relative to the saved original
bank. Stage208 showed that interpolating L(t_i)q(t_i) can lose the actual
history evolution. Its failed forecasts and post-test diagnostics stay intact.

Instead, first obtain q_* from the existing physical evolution at the chosen
target. Apply every anchor event operator to that SAME q_*:

    P_* = (3/8)L_w q_* + (3/4)L_m q_* - (1/8)L_c q_*.

The anchors are equally spaced in t=ln(theta/theta0): warm -0.015, middle
-0.04347789207803197, cold -0.07195578415606393. The prospective target is
their warm quarter, t_*=-0.029238946039015983. The weights are the exact
quadratic Lagrange weights at normalized coordinate1/4 for nodes0,1/2,1.
They reproduce degrees0,1,2 and were specified in Stage208 before this test.

Because each term uses q_*, the history-interpolation error is absent:

    P_* - Delta S(t_*) = [(3/8)L_w+(3/4)L_m-(1/8)L_c-L_*]q_*.

This identity does not set the remaining operator error to zero. For a C3
operator in compatible input/output norms, with Delta=t_c-t_w, the bound is

    ||P_*-Delta S(t_*)|| <= |Delta|^3 sup||L'''|| ||q_*|| /128.

No uniform derivative bound is asserted here, particularly across inherited
finite-domain or interpolation corners. Direct new-temperature evaluation
tests the approximation. The operator interpolation is a numerical predictor,
not a new fundamental coefficient, fitted physical law, or claimed positive
evolution generator. The original evolution bank remains unchanged.

using its retained variable-step equations,80-digit state arithmetic and100-
digit endpoint checks. Both half/quarter histories are kept. Fixed infrared
tails cancel in each repair; the original blend and dimensionless frequency

Temperature-dependent kinematics, distributions, real/soft/virtual/state
terms and original event weights stay inside each L_i. Saved L_i q_i source
values cannot replace the new cross-history evaluations. Reuse their exact

Baseline, MTS, total and primitive components receive the same construction,

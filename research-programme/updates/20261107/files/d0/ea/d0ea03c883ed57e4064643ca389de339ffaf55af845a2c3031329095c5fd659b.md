# Bounded extension: invariant-preserving interpolation

The cached-grid prediction is complete and retained. The coarse joint
grid/angular control misses the5% baseline shape gate. Examination finds
a specific interpolation error,not a newly adjustable physical rate.

For slope f=Phi/x,constant chemical potential means f proportional to
exp(-log x). Ordinary interpolation linear in log x overestimates this
convex function. Its cached discrete chemical-potential eigenvalue is

    delta0=sum_j stencil_j exp(-j Delta)+lambda1,

although the continuum soft Compton value is exactly zero. On the
downstream interval delta0/lambda1=0.0473..0.1496 for the old fine mesh
and0.1899..0.5303 on the old coarse mesh.

To remove this known bias,for an event log shift d between j Delta and
(j+1)Delta,use the positive interpolation weights

    w_hi=[1-exp(-(d-j Delta))]/[1-exp(-Delta)], w_lo=1-w_hi.

They reproduce BOTH1 and exp(-d) exactly. Thus the constant slope
temperature mode remains exact and a constant Phi is annihilated by
soft Compton. No parameter is fitted,no rate is rescaled,and no
projection is imposed on a completed spectrum.

This is a bounded scope extension to the original no-new-event-table
plan. The old binned stencils cannot recover individual Doppler shifts.
Reevaluate ONLY the small already-derived soft velocity/angular
quadrature at65 downstream temperatures,once,then reuse it for both
backgrounds and two mesh spacings. This is not a finite-frequency
Compton/DC source sweep or a parent history run.

All old predictions,failures and acceptance thresholds remain untouched.

# Precision of the actual flux traces and subcell coordinates

The first executed implementation is retained. Two representation-sensitive
operations are tested in a separate revision, without changing the force law:

- Pull metric cuts back with Decimal arithmetic, using the rational material
  edges and stored source interpolation. Evaluate test functions at the resulting
  local coordinates directly. Subtracting rounded physical endpoints and then
  dividing by a tiny cell width can corrupt an endpoint test that is exactly 0
  or 1. Quadrature spans and local endpoints are formed before conversion to
  binary64; metric values still use the registered stored polynomials.
- Precompute the exact represented left/right metric and response jumps at
  their fixed polynomial cuts in Decimal arithmetic. Background jumps do not
  depend on material label. Evaluate the flux jump from those small increments,
  rather than subtracting two large binary64 fluxes.

At a radial cut interior to a material cell, write d for right-minus-left,
f=1-2m/R and L=dnu+log1p(df/f)/2. Then

    d beta = beta_left expm1(L),
    d alpha = alpha_left expm1(-L),
    d Phi = d alpha T W + d beta g.

For H=alpha A+beta B, keep the material values g,T,W,U and their variations
fixed across this artificial cut. With v_f=delta f and

    d(v_f/f) = (d v_f - (v_f_left/f_left) d f)/f_right,
    d ell = d(delta nu) + d(v_f/f)/2,

the exact coefficient differences are dA=-TW d ell and dB=g d ell.
Thus dH=dalpha A_left+alpha_right dA+dbeta B_left+beta_right dB.
The variations of mass and log lapse include BOTH response jumps and stored
RHS jumps multiplied by U. No trace is set to zero by assumption.

These are arithmetic changes to a diagnostic, not a claim that the wave-force
gate has passed. The old output, failed quadrature comparisons, native repair,
and all scientific inputs remain immutable. Manufactured nonzero-jump examples
and actual weak/flux comparisons will test the implementation independently.

# Stage130 replay adapter

The inherited Stage129 replay entry point accepts the selector "balanced".
In this child only, that selector reads results/balanced-coefficients/bank.npz,
which contains the SOURCE-ADJOINT pairing described in DERIVATION.md.
It is NOT the Stage129 pair-total repair. The wrapper changes storage,
provenance and bank ownership only; the evolution equations stay identical.
The Stage129 balanced trajectory is reused as the comparison, never edited.
Source/current high-order outer forcing and boundary prescription are held
fixed; these hybrid approximations require their own later consistency test.

# Stage64: a conditioned source variable, not changed physics

The Stage63 native comparison isolated an inherited accuracy defect in the early slow-field velocity, where its absolute magnitude lies below the old integration tolerance. This stage regenerates the full history and propagates the correction through the existing native matching and observational machinery.

## Exact variable change

Use the inherited normalization x=phi/sqrt(6) in reduced-Planck units, N=ln a, E=H/H0, mu=m/H0 and u=dx/dN. Standard and heavy densities below are normalized to3H0^2/(8pi G). The retained equations are

    E^2 = (rho_standard + rho_heavy + mu^2 x^2)/(1-u^2)
    u_N = -(3+h)u - mu^2 x/E^2
    h = [-3(rho_standard+p_standard)/2 + rho_heavy,N/2]/E^2 - 3u^2.

Let x0 be the shooting amplitude, r=x/x0 and W=E^2 u/(mu^2 x0). During the frozen, radiation-dominated start W approaches-1/5 rather than an unresolvably small velocity. The exact transformed equations are

    r_N = mu^2 W/E^2
    W_N = (h-3)W-r.

There is no approximation in this change of variables. Set X=E^2, A=rho_standard+rho_heavy+mu^2 x0^2 r^2. Friedmann becomes

    X^2-A X-mu^4 x0^2 W^2=0,
    X=(A+sqrt(A^2+4mu^4 x0^2 W^2))/2,
    u=mu^2 x0 W/X.

The positive root is selected; positive standard density makes it well conditioned. A common small absolute tolerance now controls order-one r and W, rather than treating the physical u as indistinguishable from zero. Both base and tighter runs use this representation.

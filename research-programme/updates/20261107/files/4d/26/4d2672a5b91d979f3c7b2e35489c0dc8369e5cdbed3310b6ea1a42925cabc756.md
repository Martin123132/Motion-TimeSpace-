## Variable-step rule and stable increment representation

Let h be the new partial step and H the preceding saved nominal step.
For r=h/H, set

    a=(1+2r)/(1+r), c=r^2/(1+r), b=1+r=a+c.
    y' at new = [a*y_new-b*y_current+c*y_older]/h.

The weights reproduce derivatives of constant, linear and quadratic polynomials.
Let dp_old=p_current-p_older and dg_old=g_current-g_older.
Writing p_new=p_current+dp, g_new=g_current+dg avoids forming large1/h
history vectors before subtraction. Define

    A=a*M-h*S
    f=A^-1[c*M*dp_old+h*S*(p_current-T*g_current)]
    response=A^-1[-h*S*T]
    denominator=chi*(a+h)+a*e^T*response
    dg={c*(e^T*dp_old+chi*dg_old)-a*e^T*f
        -h*(1+chi*g_current)}/denominator
    dp=f+response*dg
    dW={c*(W_current-W_older)+h*(1+chi*g_new)}/a.

These are the same coupled BDF equations, not a new closure. The denominator
must remain positive. Check the scaled kinetic equation and the gas/work
equations; integrated e^T p+chi*g+W inherits the saved near-zero constant.

The stored nominal previous step H differs slightly from subtraction of two
binary coordinates. Preserve H to match the original scheme and record both.
Every target here is either an exact node or many binary ulps away; no
near-node snapping is necessary. The anchor is exactly a node on all grids.

## Controls and precision

For each off-node target, calculate:
1. One partial step h from the saved two states.
2. Two steps h/2: the first uses previous spacing H, the second h/2. Both use
   the appropriate physical coefficient matrix at their endpoint.
3. Replay a full nominal step H at the saved right-node coefficient time.

For quarter grids repeat the single partial result at100digits. Preserve
decimal state values before curvature cancellation; conversion to float is
reserved for final diagnostic arrays/source projections. Primary arithmetic
uses80digits. The operators and original states are still the inherited
binary data; the extra digits control arithmetic, not physical input error.

A partial step is not an exact continuous solution. Its split control and
cross-grid tests are necessary. The full-step replay is a numerical scheme
control, not new evidence for the physics. The physical coefficient API
continues to use binary64 coordinates, including the split midpoint; that
representation is recorded and not advertised as arbitrary-precision physics.

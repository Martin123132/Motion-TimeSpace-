## The actual source injection map

The saved twofold response code carries the protected energy row separately.
In exact arithmetic its representation map R is

    (R s)_j = (s_w)_j                         for j != 1,
    (R s)_1 = (s_E - sum_(j != 1) t_j (s_w)_j)/t_1.

Thus t^T R s=s_E. This is the existing energy-coordinate representation,
not permission to repair a physical moment inconsistency: its difference
from the original weak rows must pass the unchanged source-rewrite check.
The current Forcing.at uses the two supported entries of t and an 80-digit
split. It does NOT replace the measured gas row by -s_E. An older
EnergyCoordinates.source helper does make that replacement; do not use that
older helper to wire this extension.

In physical photon coefficients the response equations corresponding to the
saved update are

    M p' = r [K(p-t g) + R s],
    chi (g'+g) = -r t^T K(p-t g) + r s_g,
    W' = chi g,
    N' = r c^T [K(p-t g) + R s],
    J' = r (s_E+s_g).

Here E=t^T M p, W is expansion work, N is the integrated number source and
J is the measured integrated energy-pair defect. In this physical ordering
Y=(p,g,W,N,J), the source injection B is therefore explicitly

    B s = (r M^-1 R s,
           r s_g/chi,
           0,
           r c^T R s,
           r(s_E+s_g)).

The code instead evolves 96 energy coordinates with p=T z. Transform the
first block with its existing EnergyCoordinates tests/mass/transform; do not
mistake the source's energy row or q's coefficient indices for z. Stored-mass
rounding rewrites, high/low splits and measured equation residuals remain
implementation checks rather than exact floating-point identities.

Summing the photon energy and gas equations gives

    (E+chi g+W-J)'=0.

The number identity is (c^T M p-N)'=0. This is a bookkeeping identity with
the actual emission/collision number source, not conservation of photon
number. The passive W,N,J rows must travel with the response through joins.

## A history-retaining connection, without a source-only closure

The already derived finite source map gives delta s=L(u)q on its stated
linearized domain. The retained repaired history obeys

    q' = A_c q + h,
    h = (A_c-A_b)y_b-r_b,
    r_b = y_b' - A_b y_b - f.

Keep the native reference residual r_b. With A_r the unchanged response
operator, the two equations combine to

    [ q      ]' = [ A_c    0   ] [ q      ] + [ h ],
    [ deltaY ]    [ B L    A_r ] [ deltaY ]   [ 0 ].

This triangular system retains the full incident state. It does not need
the unproved projection condition for an autonomous source-only equation.
It also does not identify q with deltaY, add L a second time to A_r, or
claim reciprocal self-consistent backreaction beyond the retained model.
Such extensions require their own equations and an accounting of which
collision terms are already in A_c and A_r.

At present the reusable operator covers the last incoming frequency. The
seven-frequency direct SOURCE panel is complete, but that does not make L
a complete seven-frequency OPERATOR. B L currently represents this node's
weighted contribution. Other incoming frequencies and bands must be retained
from qualified sources or evaluated before a full-source propagation claim.

## Error transport and interfaces

For the same prescribed history q, let E_L=L_prediction-L_direct. If the
two compared responses start at the same state and use the same A_r,B, then

    e_Y' = A_r e_Y + B E_L q,
    e_Y(b) = integral_a^b G_r(b,u) B(u) E_L(u) q(u) du.

For different numerical histories, the exact source difference additionally
contains L_prediction delta q when q_prediction=q_direct+delta q. Numerical
history, operator interpolation and response integration errors stay separate.
Stage216's pointwise block errors do not supply a uniform bound for this
integral; neither is its norm a measured final-spectrum uncertainty yet.

Physical incoming response and sources outside a tested interval remain in
the Stage198 composition formula. Zero initial response defines only that
interval's attributable contribution, not the full physical state. Finite
source/coefficient corners preserve Y continuously, without a fitted taper.
Preserve both BDF2 states and the saved restart schedule at every interface.

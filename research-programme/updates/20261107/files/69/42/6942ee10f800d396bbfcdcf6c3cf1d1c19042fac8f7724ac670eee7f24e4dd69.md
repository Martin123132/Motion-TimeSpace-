## A constructive correction already derived

Before judging reduced outputs, the remainder's carrier harmonics were extracted algebraically. R contains a phase-independent part: deleting all R is not the same as deleting only rapid oscillations.

With omega=am, gamma=k^2/(2omega H), kappa=k/(2H), exact canonical/trace equations and mu=omega/H:
```text
R0 = i/(2mu) {
 [9/4+gamma^2+3omega |A|^2/(8a^2 H^2)] B
 + kappa z(3-i gamma) A
 + 3omega A^2 B*/(16a^2 H^2)
}.
```
The gravitational terms come from parent background/metric feedback, not fitting this discrepancy. `mean_remainder.py` verifies the constant-harmonic extraction. `trace_harmonics.py` independently derives the required metric/background harmonics from stress, continuity and Einstein equations; it verifies the cancellation
```text
z_N=-(D+3 deltaP)/(2kH)-z R_background/(3H^2).
```
For flat Friedmann R_background=3H^2, the final term is -z. The perturbation-pressure harmonic remains even though explicit flux/background-pressure terms cancel.

This harmonic extraction freezes a,H,A,B,z and other species. It is a conditional leading correction, not a completed autonomous reduction: the inverse map and A still contain micromotion, and dense-background/phase defects remain separate.

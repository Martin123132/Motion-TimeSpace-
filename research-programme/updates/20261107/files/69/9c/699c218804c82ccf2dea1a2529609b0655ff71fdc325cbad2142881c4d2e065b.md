# Differentiate edge data before label interpolation

The native channel experiment identifies interpolation-before-spatial-
differentiation as the main arithmetic problem. The ordinary wave-force
code contains the same ordering in its moving-edge gradient:

    eta_R = ((cardinal . eta_right) - (cardinal . eta_left))/(h J).

The reference mesh is fixed across labels, so linearity gives exactly

    eta_R = (cardinal . ((eta_right - eta_left)/h))/J.

Compute the nodal edge differences and divide by the represented cell
width in Decimal, then store the slope coefficients as binary64 before
label evaluation. This avoids subtracting two already-rounded interpolated
edge positions in a tiny cell. The existing wave field-gradient code
already differentiates its nodal polynomial before label interpolation.

Nothing about the weak force, integration domain, action, background,
test functions, metric centers, or source/cardinal definition is changed.
The independent complex derivative uses the same corrected kinematics.
Both ordinary and compensated summation are retained. First compare
reference-fine radial/label24/28 and32/36 with the unchanged2e-11 gate,
before expanding the experiment to the other controls.

This is a smaller arithmetic repair than implementing integration by
parts. No face or moving-cut contribution is removed or newly certified;
the previously derived jump-complete flux alternative remains available
if this same-weak-form experiment does not settle the force precision.
The high-label baseline comparison is still retained unchanged.

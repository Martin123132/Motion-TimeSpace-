# Post-result attribution

Added after the preregistered32-site test showed that the MTS gas endpoint
increments did not continue the Stage125 contraction pattern. This is a
diagnosis, not a changed acceptance threshold or a refit.

The fixed recurrence is linear in its external source. The direct32-minus-
retabulated16 source difference is supported on the16 new odd sites.
Split it into the hat at the first response site(step20) and the remaining
15 hats. Propagate each through the unchanged response, and compare their
sum with the original response difference.

Separately propagate the difference between the direct refinement increment
and the assembled refinement increment. This source is Compton-only; its
DC/BR columns and responses must vanish. It tests whether fresh source
adjoints, rather than only the evolving unresolved state, dominate the
endpoint shift. Baseline and both MTS joins receive identical tests.

All three sources are diagnostic signed differences of already evaluated
candidate sources, not new backgrounds or independently fitted signals.
The scripts retain original raw gas residual gates. Closure comparisons
use a1e-7 peak operand scale, matching prior response-control precision.

Linear superposition can establish attribution within this recurrence;
it cannot certify the continuous-time response, approximation-free collision
operators, or a parent-owned initial-memory condition.

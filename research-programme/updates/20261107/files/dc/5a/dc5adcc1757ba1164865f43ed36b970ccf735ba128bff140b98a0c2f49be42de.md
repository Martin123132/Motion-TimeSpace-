# Minimal repair: retain precision before native spatial differentiation

The off-grid arithmetic-channel experiment isolates most of the difference
to two quantities: interpolated field direction and interpolated edge
direction. The changes in beta direction contribute around1e-18 in the
inherited inverse norm, versus1e-9 to1e-8 for those two directions.
The signed channels telescope to the full arithmetic change. Their norms
must not be added as scalars, because cancellation is possible.

The native energy contains spatial slope/curvature jumps. Rounding each
interpolated nodal direction BEFORE those differences loses cancellations
which later Decimal differentiation cannot recover. Increasing the label
rule then samples a different sequence of these rounding perturbations.
This is the mechanism tested here, not an assumption that all outstanding
quadrature error is arithmetic.

Keep the same binary64 cardinal values and Gauss nodes/weights, same
stored directions, and same background physical_data packet. Change only
where rounding occurs:

    delta q(label) = sum_j Decimal(cardinal_j) Decimal(delta q_j)
    delta edge(label) = sum_j Decimal(cardinal_j) Decimal(delta edge_j)
                       + displacement * sum_j Decimal(cardinal_j) Decimal(delta source_j).

Pass these values directly into the existing native kernel's directional
derivative. Form beta and beta_R variations through the unchanged metric
evaluator with the corrected edge motion. Accumulate the label projection
in Decimal and round only the completed covector to binary64. Also retain
an ordinary-summation result as a diagnostic. No tolerance, coupling,
background solution, cardinal polynomial, or physical kernel is changed.

Test orders48/64/96 on both MTS grids and native-disabled reference probes
on both grids. At least two successive comparisons on each MTS grid must
pass the unchanged2e-11 inverse-norm gate before using the repair in a
native-only live-response update. Existing reference/MTS wave-force gates
are independent and remain attached. A small paired-rule difference is
not promoted to a rigorous integration-error bound.

# C1 velocity response: derived, independently checked, integrated

## Result in plain language

The repaired wave current now has an explicit velocity-response law, including the moving mesh, the old-field acceleration reaction, the instantaneous metric response and its induced time response. The dust–gravity response is also derived and integrated on a common measure. These are calculated replacements for the three C1 current entries, not another list of missing coefficients.

The historical calculation is reproduced in dedicated controls. Reassembling all 24 matched reference/MTS cases leaves the numerical compatibility verdict unchanged, including with the original error budgets locked. The remaining nominal h2 mismatch is essentially unchanged. Therefore this C1 arithmetic repair is not, on these fixed parent fields, the mechanism that closes that mismatch. The next substantive question concerns realizable parent perturbations and finite evolution, rather than another higher-order rerun of this same C1 column.

## Derivation and independent oracle

See `DERIVATION-20261001-C1-coefficient-current-response.md` and `DERIVATION-20261001-C1-integral-contract.md`.

The velocity derivative is taken at fixed field/source positions, spatial interfaces and measure. In particular, the mesh-speed variation contains both the edge generator and the source-speed term. It is not a position derivative and is not just source advection.

The analytic derivative was checked on 96 actual wave points and 24 source points per branch against 105-digit symmetric perturbations of the unreduced original expression. Two perturbation sizes were used. Relative wave-oracle discrepancies were below 7.82e-50 and 7.82e-60 respectively; the dust/gravity discrepancies were below 1.26e-67. These numbers concern evaluation of the specified stored inputs, not the accuracy of the physical model or continuum solution.

Omitting the edge-generator speed changes the sampled response by about 0.00488435 in both branches. Omitting the induced metric-time response changes it by 1.16e-20/reference and 3.46e-18/MTS. Both omissions are detected; neither was silently adopted as an approximation.

# Reference zero-potential sampling convention

The first position runner stopped before density construction: its sampling
shape assertion incorrectly required the disabled reference potential's
empty matrix to equal the enabled native template. The reference owns zero
factor rows by design. Attempt01 is preserved unchanged as a failed setup
check. The v2 runner explicitly checks zero factor rows for reference and
retains the exact template/sampling comparison for MTS. No physics equation
or numerical accuracy gate changes.

# Joint canonical micromotion from the action

This follows the completed joint-Hamiltonian test, without changing its equations or tolerance.

Write the exact rotating scalar/metric Hessian as
K(N,theta)=Kbar(N)+sum_{n=2,4}[K_nc(N)cos(n theta)+K_ns(N)sin(n theta)].
The symmetric harmonic matrices are computed from the derived action, not fitted to a perturbation trajectory. The fourth harmonic comes from the gravitational F² term. Rest-species source values are kept as separate linear/action-source slots.

Define the symmetric quadratic generating matrix
Gmat=sum_{n=2,4}[K_nc sin(n theta)-K_ns cos(n theta)]/(n mu),
and the canonical map
Z=S W, S=exp(J Gmat),
J=diag(J2,J2,J2,J2).
Because Gmat is symmetric, S^T J S=J exactly. This acts on both scalar pairs and both metric pairs; leaving the metric rows unchanged would not be this transformation.

## Exact action chain

For a time-dependent canonical S, the transformed action has
Knew=S^T K S+S^T J S_N,
lnew=S^T l.
The second term is mandatory. The full flow identity is
S J(Knew W+lnew)+S_N W=J(K S W+l).
This is tested independently in the frozen-coefficient case. It is not a replacement of gravity by prescribed forcing.

The actual derivative is

The derivative of each Fourier coefficient holds the carrier angle independent while differentiating its actual background arguments. Those arguments can themselves have micromotion; they must NOT be presumed slowly varying.

# Correct the source through the coupled Hessian

The first P7 construction reduces the measured ordinary shape second jet from 1.41425e-4 to 7.13091e-12. Its source second jet instead increases from 3.72090e-8 to 7.09903e-7. The local positive coefficient U_JJ is not the response of the solved field/source acceleration to an initial third-derivative change. Repeating that scalar division is therefore not the next method.

## Actual response operator

Let theta contain the 15 source third-derivative jumps, one at each actual material vertex. Source-split septic Hermite lifts give independent changes of theta while preserving every native value and all first/second endpoint derivatives. Preserve the source third-derivative mean; each lift has ell_minus=-1/2 and ell_plus=+1/2. They are initial-profile degrees of freedom, not new constants in the theory.

At fixed initial radial metric, differentiate the complete equation H(q)*a=F(q):

```
H*delta_a = delta_F - delta_H*a
```

The field-field mass block is unchanged by these lifts. The field/source cross block and source inertia are not unchanged and must be differentiated. Writing the reference gradient as g and the velocity-induced field component as m=-displacement*g/jacobian,

```
delta_m = -displacement*delta_g/jacobian
delta_F_field = -integral beta_ref*delta_g*test_gradient
delta_F_source = -integral beta_ref,source*g*delta_g
delta_H_field,source = integral alpha_ref*delta_m*test_value
delta_H_source,source = integral 2*alpha_ref*m*delta_m
```

All material interpolation factors and proper-clock inertia remain in the inherited Hessian. The initial native force is unchanged in this frozen geometry because its defining native values and source first-derivative jump are unchanged.

For T=U_J, form its exact field covector at the current geometry and its source-map derivative, including the spatial beta derivative. Contract these with the solved delta_a for all 15 lifts. This produces a 15-by-15 coupled response matrix R. Solve R*delta_theta=-T_ddot, using the measured kinetic-inclusive T_ddot at the actual vertices. No diagonal floor, truncated singular mode or damping coefficient is introduced.

The observed condition number is 1.00810. The fixed-metric linear solve predicts a source residual 2.12e-22 from 7.10e-7 with maximum source third-jump change 0.260281. Those are construction diagnostics only: the new profile must be independently solved with fresh radial geometry and its second jets recomputed.

# Exact finite real event and a stable mixed vertex

This derives the real-event integrand to be assembled next. It does not call
the soft reference the whole real source. All formulae retain the original
three-body geometry, photon occupations and independently computed recoil.

For photon signs s_j=-1 incoming,+1 outgoing, write

    A_j=n_j+1_(s_j<0), B_j=n_j+1_(s_j>0)=A_j+s_j,
    g_i=(E_i-Ebar)/T, g_f=g_i-Delta E_e/T,
    F1=g_i r+sum A_j h_j, R1=g_f r+sum B_j h_j,
    D1=F1-R1=-Delta E_e r/T-sum s_j h_j.

The Stage233 mixed coefficients can be evaluated without subtracting two
large soft occupation products:

    d_photon,j = A_j D1-s_j R1+s_j(A_j+B_j)h_j,
    d_gas = (g_i-g_f)(g_i+g_f-2)r
              +(g_i-g_f)sum A_j h_j-g_f sum s_j h_j,
    d_velocity = [p_i D1-Delta p_e(R1-r)]/T,
    d_density = D1.

These are algebraic rearrangements, not a soft-frequency expansion. In
particular use the independently stored Delta E_e instead of subtracting
two nearly equal relativistic electron energies. Compute Ebar-1 before
converting from80-digit arithmetic, so the rest energy is not subtracted
from a rounded thermal mean. The real235.py prototype checks this exact
rearrangement on actual saved real events and near the explicit spectral floor.

Let J_em(q),J_abs(q) be the lab-frame weak projections of these exact
coefficients, with their respective signed soft photon and recoil. Let rho
be the original real density including hard-photon equilibrium stimulation.
At the retained perturbative order the finite real mixed contribution is

    (event_weight/2) int dOmega dq [
       (1+n_s) rho_em J_em + n_s rho_abs J_abs
       -a_Omega/q * (spontaneous_window J_B
                    +2 m(q) [n_s J_B+w_s h_B,s J_eq
                          +w_s D_B L_B wave_s^T/(2l+1)])].

The emission and absorption terms have their own original ordering domains.
The subtraction is elastic; the soft photon is not removed from J_em/J_abs.
Add the source-owned spontaneous logarithm and the profile conversion in
DERIVATION.md, then the Stage234 virtual and this stage's displaced-state terms.
The original square/positive weak convention has the opposite sign to J here.

The finite domain starts at the original x=1e-6. The output basis contains
photon-number tests that do not vanish at x=0, so a regular-test zero-floor
argument cannot be applied to every row. Keep unresolved lower-domain and
upper-domain terms explicit; do not manufacture an infrared plateau or cutoff.

Implementation still needs cancellation-safe integration of the paired real
remainders, not separate subtraction of two large completed integrals. The
stable coefficient prototype is not by itself a certificate for that quadrature.

## Reproduction

The safe entry point is `python -B run_stage169.py <operation>` with operations
`forecast --model heavy`, `forecast --model cold`, `compare`, `rates`,
`validate`, or `seal`. It sets the library environment before any SciPy import.
The last two commands reproduce the ORIGINAL validation/sealing route, which
intentionally remains blocked by the retained 60 derivative-check failures.
For the final scoped audit use `audit_original_steps.py`, then
`finalize_temperature_validation.py`, then `seal_temperature_law_final.py`;
these scripts also set the thread environment before importing numerical code.
Its `--help` dry run is checked. Do not run all producers against completed
folders; they intentionally refuse to overwrite them.

Use Python313 with `-B` and set OPENBLAS_NUM_THREADS, OMP_NUM_THREADS and
MKL_NUM_THREADS to 1 in the launching process BEFORE Python imports SciPy.
Workers set below-normal priority and one-core affinity. The initial wrapper
imported SciPy before the inherited environment setup, creating idle/spinning
library threads on that single core. Its empty first output folder is retained
as `heavy-m20-thread-init-stall`; only that verified task-owned process was
stopped, before it wrote a state. Production was relaunched with those launch
environment variables set correctly. Unrelated processes were untouched.

Sequential corrected commands, each in a new empty output destination:

1. `replay_legacy_reference.py` recovers the old feedback trajectory from its
   saved source and checks equality with the saved terminal photons and full
   energy/gas/work histories. Existing recovered trajectories are reused.
2. `run_hybrid_forecast.py --model heavy`, then `--model cold`, freeze both
   matching choices, 128/256-step predictions and constant-initial controls.
3. `run_hybrid_check.py` reads the target only after all forecasts are saved.
4. `run_rate_derivation.py` tests the analytic DC/BR temperature derivatives
   and the residual nonautonomy example.
5. `run_temperature_validation.py` runs the independent readout, original-equation,
   exact-arithmetic, input authentication and protected-workbench checks.
6. The original `seal_temperature_law.py` remains unused/blocked. The final
   sequence after the retained failed audit is `audit_original_steps.py`,
   `finalize_temperature_validation.py`, `seal_temperature_law_final.py`.
   See AUDIT-PRECISION.md for the narrower, explicitly sampled accepted scope.

These scripts deliberately refuse to overwrite existing run directories.
Do not rerun the producers in place. Use their saved packets for inspection.
The single-core production commands are sequential, not a fan-out.

# Stage141 supplementary check: isolate this block's source discrepancy

The newest MTS addition is becoming small relative to the accumulated
common-versus-physical source difference. Comparing those two numbers alone
would mix previous intervals' discrepancies into this interval's diagnosis.
This supplementary calculation uses saved source packets and the unchanged
2048-step linear response. No evolution,physical event,grid or fit is changed.

Let C,P be the current common and physical sources, and C0,P0 the preceding
stage's sources expanded onto the same knots. Propagate

    delta_error_source = (C-P) - (C0-P0).

Earlier sites are bitwise unchanged,so this
forcing vanishes outside the newly covered sites. All non-Compton source
components vanish as well. These support statements are checked exactly.
The propagated gas contribution is compared with the independent physical
extension response already saved,for baseline and both MTS columns.
Peak and endpoint ratios are retained;near-zero endpoints are flagged.

This measures a block-specific source approximation discrepancy. It is not
a bound on all numerical errors,inner-trajectory error,physical model error,
or the uncomputed remainder. The source quadrature order is unchanged.
The original stage acceptance thresholds are not relaxed.

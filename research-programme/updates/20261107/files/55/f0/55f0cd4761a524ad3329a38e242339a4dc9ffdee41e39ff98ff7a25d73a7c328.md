# Position-time loading for the C0 response

This private stage constructs the mixed loading needed by
B0 = D0(Y_q v + Y_v a), before solving the remaining position reaction.
No coefficients are fitted. Both reference/MTS cases and both grids use
the same tests. The completed C1/C2 evidence is immutable.

## 1. The two-parameter family

At fixed material label and reference coordinate set

    q(s,t) = q + s e + t v + s t edot,
    v(s,t) = v + s edot + t a,
    R(s,t) = R + s U + t W + s t V,
    U = eta + D e_source, W = D v_source, V = D edot_source.

The independent support is at zero velocity and acceleration. Acceleration
a is held fixed in D0. This is a local jet, not an evolved history.
Mixed differentiation therefore does not insert a guessed eddot.

For J=R_xi, g=q_xi/J and T=v_field-Wg:

    g_s = (q_xi,s - g J_s)/J,
    g_t = (q_xi,t - g J_t)/J,
    g_st = (q_xi,st - g_s J_t - g_t J_s - g J_st)/J,
    T_s = edot_field - W_s g - W g_s,
    T_t = a_field - W_t g - W g_t,
    T_st = -W_s g_t - W_t g_s - W g_st.

These give the full mixed weak wave loads by differentiating J T^2 and
J g^2, including the transported test h(R). A four-component automatic
derivative is compared with these explicit product/quotient formulas.
Material orders48/64 and spatial orders8/12 are compared.

## 2. A pushforward identity with boundary terms

For a source/native node R(lambda;s,t), define its load L(lambda;s,t).
The physical Eulerian density is the pushforward

    rho(R) = integral w(lambda) L(lambda) delta(R-R(lambda)) d lambda.

For source number density L=1. For native loading,
L=Sampling^T(image^2/2); there is no extra spatial Jacobian.
With J_label=R_lambda, U=R_s, W=R_t and V=R_st:

    rho_st = w L_st/J_label - d_R B + d_R^2 C,
    B = w (L_s W + L_t U + L V)/J_label,
    C = w L U W/J_label.

All terms are distributions on the full physical radial line. The weight
w=6(lambda+1/2)(1/2-lambda) vanishes at its endpoints, so C=0 there but
its radial derivative generally does not vanish. In addition to the
ordinary interior derivative, the mixed density contains endpoint atoms:

    lower: +w'(lower) L U W/J_label^2,
    upper: -w'(upper) L U W/J_label^2.

For this weight both coefficients have the factor +6. They can have
either sign through U W. They are signed derivatives of a moving
density, not newly postulated masses or forces. Coincident endpoints
retain their individual owners and velocities; do not average them.

Against any smooth h the exact mixed weak moment is

    integral w [L_st h + (L_s W+L_t U+L V) h'
                         + L U W h''] d lambda.

The numerical test separately integrates the regular Eulerian expression,
adds the endpoint atoms, and compares with this material identity for
h=1,(R-6),(R-6)^2. Decimal70 arithmetic and high-precision Gauss rules
prevent cancellation at the thin source boundary from masquerading as
physical failure. An independent native mixed derivative differentiates
the existing exact shape tangent with signed Decimal perturbations at
two step sizes; off-grid values check the label expansion.

## 3. Consequence for the metric mixed response

For Y_R=f(R,Y,loads), the smooth mixed equation is

    (B0)_R = f_Y B0 + D0(f_Y) Y_t + D0(f_load loads_t).

The fixed-radius mixed boundary datum is

    B0_nu(Rout) + B0_mu(Rout)/(Rout-2mu)
        = -2 delta_mu(Rout) mu_t(Rout)/(Rout-2mu)^2.

Each native atom must be multiplied by f_gram; each source number atom
by f_rho evaluated with that source's limiting velocity. The resulting
atom is a jump in B0. This agrees with the continuity identity
[B0] = -U [Y_t,R] for a single moving interface. A solver that inserts
only smooth interior arrays would omit this term. Wave label-integrals
have no such atom when the averaged load and its first variation are
continuous; their mixed regular traces must still be retained.

This stage evaluates mixed weak loading and endpoint data. It does not
claim that the full collocation B0, old Euler reaction k0, or C0
force/current column is already solved. Those use the resulting data,
the saved deltaY=X+A_old(edot), and the existing live inverse.

# The remaining medium derivative has an explicit kernel, not a guessed scaling

The statistical vertex now has an implementation. The other term in the mixed
source is the derivative of the photon-cut amplitude/phase under the photon
distribution. The already derived Stage84 radial decomposition provides it.
This is not the gas-temperature coefficient r in the electron distribution.
Changing T_e at fixed photon occupation does not justify changing a photon-cut
mass by2r. Electron-density thermal cuts are also not supplied by this argument.

At each rest-frame direction n, the source-owned finite matrix is

    C0 + Cext + sum_p C_p/(omega^2-a_p^2),

after removing the separately matched soft coefficient. All C's are independent
of the photon occupation. The actual phase-space measure is omega N(omega,n)
domega, apart from the known e^2/[2(2pi)^3] and angular measure. Consequently

    delta M_fin(n) = (C0+Cext) delta I0(n)
                   + sum_p C_p delta Ip(n),
    delta I0 = integral omega delta N(omega,n) domega,
    delta Ip = PV integral omega delta N(omega,n)/(omega^2-a_p^2) domega
               -i pi sign(D_p') delta N(a_p,n)/2.

Dirac coefficients include the original on-shell spinor sandwiches and external
finite terms. Do not replace them with an identity matrix or drop the absorptive
term when eventually forming polarized transfer. This is an exact functional
derivative within the retained one-photon-cut, first-loop-order sector because
that sector is linear in N; it is not a thermal Taylor expansion of the poles.

For a given ray, let d=u.n, x=omega d/T_star and z_p=a_p d/T_star. In the scalar
intensity convention delta N=n(x)(1+n(x))h(x,n_lab), so

    delta I0=(T_star/d)^2 integral x n(1+n)h dx,
    delta Ip=PV integral x n(1+n)h/(x^2-z_p^2) dx
              -i pi sign(D_p') n(z_p)(1+n(z_p))h(z_p,n_lab)/2.

Every saved full-basis spectral coefficient therefore owns a definite radial
linear functional. Directional h must use the lab ray obtained by boosting n,
not the unboosted rest direction. A cached final scalar is insufficient to
reconstruct these directional coefficients; reuse the source-owned C matrices
or reconstruct that finite decomposition, not a new fitted temperature law.

## Two necessary limits and a forbidden shortcut

For a common photon-temperature change eta, h=eta x:

    delta I0/eta = pi^2 (T_star/d)^2/3,
    delta Ip/eta = -z J'(z)
                  -i pi sign(D_p') z n(z)(1+n(z))/2,
    J(z)=[log(z/(2pi))-Re digamma(i z/(2pi))]/2,
    -z J'(z)=-1/2+Re[i z polygamma(1,i z/(2pi))/(4pi)].

The constant part scales as T^2. The pole part does NOT generally scale as T^2.
medium233.py tests these derivatives at BOTH actual pole positions along ALL
eight angular rays used by each of the three cached event loop calculations.
Its finite-difference test changes the analytic radial formula only; it does
not run new virtual-amplitude integrations or replace the cache.

For the isotropic photon-cut mass shift already owned by Stage84,

    delta(m_e^2)_thermal = (4 alpha/pi) integral omega N(omega) domega,
    directional variation = (4 alpha/pi) integral omega delta N(omega) domega

where the second line is for an isotropic perturbation (not a scalar substitute
for a general anisotropic self-energy). Planck N gives2pi alpha T^2/3 and its
temperature derivative gives twice that value per eta. Those quantities are
thermal mass corrections, not a derivation of the vacuum electron mass.

## Infrared and matching ownership

For a specified finite interval [a,b], write f(x)=x n(1+n)h. For a pole z inside,

    PV integral_a^b f(x)/(x^2-z^2) dx
      = [integral_a^b (f(x)-f(z))/(x-z) dx
         +f(z) log((b-z)/(z-a))-integral_a^b f(x)/(x+z) dx]/(2z).

The near-pole value is f'(z), which can be evaluated from the saved splines.
Below1e-6 and above60 the retained profiles are not defined by this stage;
their contributions stay explicit rather than being set to zero. Both current
tail joins are included INSIDE the declared domain.

The old soft virtual/real coefficients cancel direction by direction for a
COMMON arbitrary N. Differentiating this exact identity gives the cancellation
for delta N, provided the same profile, normalization and distribution variation
are used in both terms. This does not prove convergence of photon production
outside the supplied spectrum, nor justify dropping finite boundary terms.

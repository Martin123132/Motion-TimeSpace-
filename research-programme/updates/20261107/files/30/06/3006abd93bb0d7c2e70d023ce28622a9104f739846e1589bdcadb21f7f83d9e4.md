# Stage197: a supported interval contribution, not a global extrapolation

Write the inherited linear response as Y' = A(u)Y + B(u)S(u), with photon
coefficients, gas, expansion work and photon-number bookkeeping in Y. For a
fixed saved operator, subtraction gives

    deltaY(u_f) = G(u_f,u_a) deltaY(u_a)
                  + integral_[u_a,u_f] G(u_f,u) B(u) deltaS(u) du.

The present calculation evaluates only the integral over I, a grid-contained
subset of the physically evaluated temperature stencil. Its initial state is
zero by the definition of this contribution. After I the contribution evolves
homogeneously to the saved final epoch. This does not set the actual unknown
correction outside I, or its matching state, to zero. No taper or global cutoff
is proposed. The exact tested domain is f=0.875-xi/log(10), |xi|<=0.01.

For each physical site, sum the original weighted event packets in compensated
twofold arithmetic, including the low part of every source coefficient. The
source update is candidate minus original, not a curvature-error percentage.
Keep control (baseline), difference+virtual+state (MTS increment), and total.
The bank-half/quarter differences separate history precision from the smooth
local candidate; candidate-half/quarter measure retained history-step sensitivity.

Between evaluated sites use a frozen composite quadratic in xi, with a linear
five-site control. This local numerical reconstruction is conditional; agreement
between them is sensitivity evidence, not an upper bound on interpolation error.

The saved radiation equations are

    M p' = rate [S(p-T g) + s_photon]
    chi(g'+g) = rate[-T^T S(p-T g) + s_gas]
    W' = chi g.

In the energy-coordinate basis, s_E is independent energy and d=s_E+s_gas.
For a BDF derivative alpha*y-history,

    g_free = (history_E + chi*history_g + rate*d)/(chi*(alpha+1))
    c_E = alpha/(chi*(alpha+1)),  g=g_free-c_E E
    [alpha*M_c-rate*P + coupling*c_E*e_E^T] state
        = M_c history + rate*force + coupling*g_free,
    coupling=-rate*tests*S*T.

This retains the measured source-pair defect rather than setting s_gas=-s_E.
The injected ledger integrates rate*d, so E+chi*g+W-injected is conserved by
the discrete equations. Photon-number production is carried independently.
The same small energy-coordinate rewrite as Stage166 is measured against the
unchanged 1e-10 gate. It is not a physical conservation proof.

## What can be predicted without inserting a closure

The source's total temperature derivatives include changing L as well as h.
Saved endpoint source values alone do not determine these derivatives. We
therefore freeze an explicit numerical continuation and test it against the
physical event equations; we do not declare that continuation an exact law.

Use the three available physical anchors t_c, t_w=-0.015 and t_m=-0.0125,
where t_c=-0.07195578415606393. The first interior test is t_*=(t_c+t_w)/2.
For each retained event, component and history mesh, the unique quadratic
interpolant is

    Q(t_*) = sum_i w_i(t_*) Delta S(t_i),
    w_i(t) = product_(j!=i) (t-t_j)/(t_i-t_j).

These coefficients follow from polynomial reproduction, not data fitting.
A separate endpoint secant is frozen as a diagnostic. The primary quadratic
is not replaced or retuned after seeing the new microscopic result.
On a genuinely C3 segment its norm remainder obeys

    ||Delta S(t_*)-Q(t_*)|| <= |product_i(t_*-t_i)| sup||Delta S'''||/6.

This is conditional: no third-derivative bound has been established, and saved
reference interpolation can have corners. The bound is not asserted across
such corners. The direct interior test decides whether this numerical
continuation is usable there. A pass at one point is not a uniform bound.

Evaluate the new Delta S directly on high/low Delta p and Delta g, using the
Stage201 coefficient-space representation. This uses the already derived

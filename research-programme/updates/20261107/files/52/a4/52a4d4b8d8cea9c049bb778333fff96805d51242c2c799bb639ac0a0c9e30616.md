# Zero-numerator metric repair

The first analysis used a protective floor inside a common norm helper for both numerators and denominators. An exactly zero residual divided by an exactly zero reference was consequently reported as 1 instead of 0. This affected zero/absent-component diagnostics, not the nonzero physical conservation residuals or saved readouts.

`check_pressure.py`, `balance-result.json`, `balance/`, and their original receipts are retained as superseded diagnostic evidence. `check_pressure_corrected.py` uses the true numerator norm and floors only denominators. Accepted results are under `balance-corrected/`. No field evolution, pressure readout, interpolation input or tolerance was changed or rerun. The real heavy-branch continuity discrepancy remains an explicit physical/numerical-background finding, not a passing result created by this repair.

# Correct the inherited superposition test's channel denominator

The first short heavy/local response passed all source, photon/gas equation, energy/work and number tests, but six inherited combined-channel superposition tests failed. Their numerator was `combined-physical-reference`; the copied denominator was the numerical-reference channel alone. In this task that arithmetic reference is extremely small compared with the physical increment, unlike the original test's intended main-response channel. This magnifies ordinary independent linear-solve roundoff by many orders of magnitude. The separate source and physical-equation checks did not fail.

Correct each relative equality test to use the channel on its own right-hand side: reference for `start+end=reference`, combined for `physical+reference=combined`. The threshold remains exactly 1e-8. This matches the existing `close` helper used for the same linear identities throughout the project. The old reference-normalized number remains a diagnostic; the original failed smoke packet and original scripts remain immutable. It is not relabeled as a physical cancellation failure or silently removed from the history.

This change does not alter a source, operator, solver, response, curve, band, parameter or threshold. An independent regression constructs a well-conditioned combined response with a tiny reference to demonstrate the denominator error, and verifies that a real 1e-6 combined-response corruption still fails the unchanged 1e-8 threshold. Numerical-reference contributions continue to be solved and saved independently, rather than estimated by subtracting two large trajectories.

## What was derived

Write the coupled transformed generator as M=M0+V, with V containing the
nonzero phase coefficients of the action/source/feedback blocks. Define

    U=sum_(n!=0) M_n exp(i n theta)/(i n mu),  theta_N=mu.

Its actual native-coordinate action is low-rank:

    U(w,y)=(A w+B E y, R C w).

E selects the15 pressure/shear source slots; R contains the original native
expansion/shear source vectors. No new canonical variables are invented for
the collisional rest equations. Both coupling directions use the current
evolving state, not a saved future perturbation history.

The inverse is exactly an8x8 Schur complement:

    v_w=(I+A-B E R C)^-1(x_w-B E x_y)
    v_y=x_y-R C v_w.

The full time derivative includes all physical coefficient factors:

    U_N=sum_(n!=0) exp(i n theta)
        [M_n+(M_n,N-(mu_N/mu)M_n)/(i n mu)].

Its native coefficient derivative is numerically represented on the original
background nodes and independently checked. We do not pretend that every
native thermal coefficient now has a closed-form analytic derivative.

The first corrected generator is

    R1=M+M U-U M0-U_N.

It has an explicit discarded term, not an unstated averaging assumption:

    (I+U)R1+U_N-M(I+U)=U(R1-M0).

For comparison the exact conjugate is
Rexact=(I+U)^-1[M(I+U)-U_N]. This is only a coordinate-equivalent control.
R1 is the tested approximation. It retains residual phase dependence;
no phase-free fluid or computational speedup is claimed.

Matched initial data pass through both S and I+U. The actual reconstructed
metric derivative includes S_N, U_N and the coupled state evolution.
No constraint projection or manually repaired metric rate is used.

# Full fixed-temperature microscopic response to the repaired histories

## Scope and linearity from the implemented equations

The argument concerns the retained linearized weak source, not arbitrary
nonlinear photon populations. At fixed temperature and event kinematics the
source tests, intensities, background Bose factors, electron population weights,
phase-space factors and loop coefficient are independent of the departure
history (phi,g). In `rectangular-matched-source-20261008/rectangular_weak.py`,
the history-dependent right jump is

    R[phi,g] = phi(x_h)-phi(x_i) + sign(omega) phi(x_s) + E_e g.

Omit the soft term for a Born event. The left jump L contains only the fixed
test functions and electron energy transfer. Therefore the event product L R
is linear in (phi,g), not bilinear in two histories. `SplitReal.event_products`
changes the intensity for control/difference, not this dependence.

The real contribution integrates a linear product and its linear soft
subtraction. The virtual term is c_virtual L_B R_B, with fixed c_virtual. The
state term contains fixed multiples of L_B R_B, delta_L R_B + L_B delta_R,
and fixed finite-difference combinations of Born products at shifted velocities.
Here delta_R=phi'(x_h) delta_x + g delta_E. Every term remains linear in the
history. The high-precision moment/soft repair changes their numerical
representation, not that algebra. Relevant sources also include
`nodewise-source-remainder-20261008/split_real.py`,
`endpoint-state-precision-20261019/precise_soft_shifts.py`, and
`endpoint-soft-subtraction-20261019/probe_state_roundoff.py`.

Consequently, for each retained component c and fixed theta,

    S_c(theta;phi+delta_phi,g+delta_g)-S_c(theta;phi,g)
       = S_c(theta;delta_phi,0)+S_c(theta;0,delta_g).

There is no dropped cross term or Taylor remainder in this identity for the
implemented linearized functional. It must not be extrapolated to a different
temperature: changing theta changes the operator, distributions and event
weights. Nor does it prove that this approximation equals the exact nonlinear
microscopic theory. The numerical test shares the event evaluator; it checks
its history representation and superposition, not an independent physics model.

## The increment retains the original low-frequency connection

Each stored joined spectrum has the form

    phi_j(x) = (1-b_j(x)) phi_tail(x) + b_j(x) Psi(x) p,

with the saved fixed quintic blend b_j and two existing join intervals. The
stored tail is unchanged in this history repair. Hence

    delta_phi_j(x) = b_j(x) Psi(x) delta_p,
    delta_g = g_repaired-g_original.

Compute delta_p and delta_g with 80-digit arithmetic from the Stage200 state
strings and the exact binary values of the saved original reference. Only then
convert the increments to the inherited sampling representation. Build their
cubic splines on the same 24,001 log-frequency nodes. Cubic spline interpolation
with fixed knots and boundary rule is linear; its derivative is linear too.
Thus the infrared tails cancel, but the blending function is not discarded.
The common first column x is a test mode, not an inhomogeneous history term;
the source uses departure columns after that first column.

Direct absolute repaired spectra are reconstructed independently by the existing
Stage199 recipe, using unchanged tails and the full new profile. This makes the
increment-versus-absolute comparison sensitive to a mistaken join or lost small
increment. It does not turn a shared source evaluator into independent physical
evidence. Conversion/accumulation roundoff is diagnosed separately.

## Frozen prediction and numerical measures

For each half/quarter history compute P_c=S_c[delta_phi,0] and G_c=S_c[0,delta_g]
for every original event. Save both terms and freeze Delta_c=P_c+G_c before
running the absolute evaluations. Then compare Delta_c against
S_c[repaired]-S_c[original], using compensated high/low source pairs. Perform the
same comparison for baseline (control), MTS (difference+virtual+state), and
their total. No coefficient is adjusted to the comparison.

Use ||v||_(M^-1)=sqrt(v_photon^T M^-1 v_photon) for the 96 weak photon entries;
use the absolute gas entry separately. Preserve energy+gas=0, number/energy
moment representation, and the component closure. A zero correction is a
negative forecast when the actual correction is nonzero. Photon-only/gas-only
omissions quantify which part matters instead of presuming one dominates.

Summing this one x=14 node does not supply the original incoming-frequency
integral. The next adjacent frequencies and then the original seven-node weighted
sum are needed before returning to temperature continuation/final response.

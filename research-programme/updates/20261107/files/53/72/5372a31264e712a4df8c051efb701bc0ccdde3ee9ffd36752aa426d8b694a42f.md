# Stage98: removing an artificial azimuthal fourth moment

The same thermal source contains the normalized electron azimuthal integral

    A[f] = (1/(2*pi)) integral_0^(2*pi) f(phi) dphi,
    A_N[f] = (1/N) sum_(j=0)^(N-1) f(2*pi*j/N).

For an integer harmonic m, summing the finite geometric series gives
A_N[exp(i*m*phi)] = 1 when N divides m and 0 otherwise. The continuum
value is zero for every nonzero m. Consequently A_8-A_4 removes exactly
the aliases m=4 modulo8; it does not bound the remaining m=8 aliases.

At fixed perpendicular speed v_perp, use v_x=v_perp*cos(phi) and
v_y=v_perp*sin(phi). The exact continuum angular moments are

    A[v_x^4] = 3*v_perp^4/8,
    A[v_x^2*v_y^2] = v_perp^4/8,
    A[v_x^4 - 3*v_x^2*v_y^2] = 0.

The four-direction grid instead gives v_perp^4/2 and0. The eight-direction
grid recovers both exact moments and their isotropic relation. Thus this
refinement removes a specific artificial fourth-moment anisotropy, rather
than merely increasing a node count. It does not change the physical electron
distribution, particle mass, coupling, radial measure or polar rule. Nor does
it by itself establish full three-dimensional isotropy or source convergence.

## Same source and verified reuse

Let J=(D,V,S,C0) denote the unchanged integrand blocks. Shared physical nodes
have identical incoming energy, scattering angle and electron velocity, but
half the azimuth weight. Reuse their component arrays only after checking
sealed hashes and physical identities; recompute weights. The16 additional
velocities receive actual owned loop and state calculations, not interpolated
coefficients. The existing exact angular-tensor factorization is reused.

The complete source is still

    C = Gaccurate + K + D + V + S,    K=C0-Gsampled.

K uses compact128 incoming quadrature; D/V/S use seed4, all at hard5. Gsampled
and Gaccurate are the previously analytically electron-integrated leading
terms and remain unchanged. This is the same linear control-variate estimator
as the parent. Nothing is discarded or fitted.

For each block, Delta_az=J_az8-J_az4 is computed at the same component-specific
incoming resolution. Its component-sum norm budget uses the NEW complete
finite remainder as denominator. Inherited hard/incoming differences are
retained, not silently recomputed on the finer electron grid. Each difference
is passed through the unchanged linear photon/gas response, so the independent
energy/work identities and the response sensitivity are directly checked.

These computed differences are not continuum error bounds. Electron polar
and radial accuracy, mixed-grid effects, internal-loop precision, domain/tails
and full physical-history feedback are separate questions. The next use of
this work is a better-founded physical prediction, not a fitted correction.

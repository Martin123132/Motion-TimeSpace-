# Stage199: physical continuation rather than a taper

Set t=ln(theta/theta0), u=ln(a/a0); the saved background gives dt/du=-1.
Let h=(p,g,W) be the input history and S(t)=F(t,h(t)) the microscopic source.
The retained collision/emission history equation is

    M p_u = K(t)(p-T g),
    e.p_u + chi g_u = -1-chi g,
    W_u = 1+chi g.

K=rate*(B-D) retains the saved emission and background. The separate candidate
B=B0+t B1+t^2 B2/2 uses previously differentiated physical collision integrals;
it does not overwrite the original interpolated bank. Continuing a history
therefore requires evolving both p and g, not rescaling a scalar source.
Its common initial condition remains the old saved warm restart. We continue
its existing state pair, including the accumulated work, rather than restart
the candidate at the newly tested cold point.

Where differentiable, the chain rule gives

    S_t = F_t + D_h F h_t,
    S_tt = F_tt + 2 D_h F_t h_t + D_h^2 F[h_t,h_t] + D_h F h_tt,
    h_t = -h_u,  h_tt = h_uu.

This includes the changing scattering operator, recoil/thermal weights, gas
capacity and photon history. The saved hard finite-domain masks and piecewise
bank/tail interpolation require one-sided treatment at corners. No global
smoothness bound is inferred from these formulas.

The already computed microscopic values give a no-new-fit, one-sided numerical
Taylor jet at t_c=-0.01, spacing h=0.005:

    S'_c = (-3 S_c+4 S_(c+h)-S_(c+2h))/(2h),
    S''_c = (S_c-2 S_(c+h)+S_(c+2h))/h^2,
    S_pred(c-h) = 3 S_c-3 S_(c+h)+S_(c+2h).

These are finite-difference estimates of the total derivatives, not exact
analytic third-derivative control or newly derived fundamental coefficients.
For a C3 scalar component the quadratic interpolation remainder at c-h is
-h^3 S'''(xi); vector norm control requires a bound on the vector derivative.
We therefore freeze the extrapolation and test the actual physical source at
the independent target before using it. The same linear weights act on the
candidate-minus-original source using compensated saved representations.

The induced response delta Y remains distinct from delta h. Once qualified,
the new source is added through Stage198's inhomogeneous propagation with the
saved boundary state and BDF schedule. This is an attributed extension, not a
proof that earlier or later uncomputed source terms vanish. Failed target
predictions block that extension instead of being absorbed by a fitted taper.

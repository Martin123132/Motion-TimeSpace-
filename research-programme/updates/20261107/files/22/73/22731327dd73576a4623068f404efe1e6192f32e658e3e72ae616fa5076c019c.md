# Source action determines the reciprocal pairing

Write the slope-field generator as
G f(x)=sum_a w_a [f(r_a x)-f(x)]+lambda f(x).
With pairing <v,f>=integral_0^infinity x v(x) f(x) dx, changing variables
gives G* v=sum_a w_a r_a^-2 v(x/r_a)+(lambda-sum_a w_a)v(x).
This bulk identity assumes integrability; finite boundaries add flux terms.

The saved physical weak source action is
A v=sum_a w_a/(2r_a) [v(r_a x)-v(x)+(v(x/r_a)-v(x))/r_a].
It has an exact positive generator representation: each event (r,w)
contributes inner events (r,w/2) and (1/r,w/(2r^3)), and
lambda_star=sum_a w_a(1-r_a^-1-r_a^-2+r_a^-3)/2=m/2.
Substitution proves G_star*=A for EVERY test function, not just v=1,x.
No assertion of exact finite-event reciprocity is needed.

For a grid pair r>1 with deposited weights k_plus,k_minus:
k_plus_star=(k_plus+r^3 k_minus)/2,
k_minus_star=(k_minus+r^-3 k_plus)/2.
These obey k_minus_star=k_plus_star/r^3 and are nonnegative.
For v=x^q define S(q)=sum w/(2r)[r^q-1+(r^-q-1)/r].
For f=x^p define sigma(p)=sum k[r^p-1]+lambda_star.
The entire Mellin-symbol identity is sigma(-q-2)=S(q), including complex q.
In particular sigma(-1)=sigma(-2)=0 and sigma(-3)=lambda_star.

The Stage129 two-point deposition alters m. Normalize all off-diagonal
paired rates by lambda_physical/lambda_deposited and reset the diagonal
to minus their sum. This is moment calibration from the saved physical
kernel, not an empirical fit. Saved lambda equals physical m/2 to tested
quadrature accuracy; retain that lambda to isolate pairing shape.
The normalized grid action equals the normalized adjoint of the deposited
event action exactly. It need NOT equal the original physical-event action:
that spatial consistency error is explicitly measured.

For comparison Stage129 preserved pair totals before normalization:
k_plus_total=(k_plus+k_minus)/(1+r^-3).
Both schemes match moments; only the source pairing is the adjoint of
the saved deposited weak action. Matching moments cannot pick a unique
redistribution. Physical-event comparisons remain the accuracy benchmark.

## Finite interval identity

For log grid x_i, W_i=h x_i^2 and restricted generator G_N, define the
full bulk test-function action A_h v at every interior point using v
continued beyond the domain. Then exactly
<W v,G_N f>=<W A_h v,f>-B(v,f),
B=h sum_i x_i^2 f_i sum_(j: i-j outside) k_j exp(-2jh) v(x_(i-j)).
An imposed inflow b adds <W v,b> to the left-hand side.
This boundary term is not zero just because bulk number/energy identities
hold. Discrete weighted adjoint checks will distinguish truncation from
a collision moment failure. The identity is for the grid pairing, not a
certificate of continuum quadrature or the full coupled history.

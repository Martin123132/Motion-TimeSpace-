# Independent driver cross-check

The first final-validation attempt stopped on an auxiliary1e-12 relative
comparison of the saved outer driver against a freshly multiplied basis
and interpolated coefficients. Both versions represent the same analytic
driver but associate interpolation and dot products differently.

A separate check found maximum baseline output-relative differences of
3.83e-12, with differences <=7.43e-16 relative to the absolute dot-product
operands across the four reference/coarse cases. The baseline coefficient
sum cancels strongly. The final validator therefore reports both output
relative difference and usage of a128-epsilon absolute-operand roundoff
allowance, rather than declaring those differing floating-point operation
orders equal to1e-12 relative to the cancelling output.

This is a numerical driver cross-check, not a new physical error bound.
No reconstruction, source or response was changed. No1% refinement gate,
raw gas1e-7 gate, invariant gate or scientific failure was relaxed. The
original validation exception occurred before a validation status or
completion marker was written; the empty validation directory was reused
only after this issue was explicitly diagnosed.

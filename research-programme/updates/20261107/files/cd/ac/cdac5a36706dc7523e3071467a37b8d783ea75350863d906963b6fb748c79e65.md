# Stage153 — what can actually be separated from saved calculations

Let H_n be the cold source at incoming order n, P the frozen cubic prediction,
and E_n=H_n-P. All source norms below use the saved mass-dual norm and the
common scale ||H4||. Thus E6=E4+(H5-H4)+(H6-H5), exactly.
The separately normed D,V,S changes supply observed conservative finite-step
budgets b54 and b65 without cancellation credit.

A shrinking step does not prove ||H*-H6||<=b65. A shared bias,an untested axis,
and a non-monotone future step remain possible. No Richardson or geometric
tail is assumed. We report all saved rules and explicitly conditional balls
of radii b65 and b54+b65,not statistical confidence intervals.

For a hypothetical cold-source radius r, reverse triangle and triangle give
||H*-P||/||H*|| >= max(||E6||-r,0)/(||H6||+r).
This bound concerns a fixed P. It is conditional on r being a real bound.
The exact minimum Hilbert-space displacement from H6 needed to satisfy
||H-P|| <= t||H|| is distance to the Apollonius ball:
center=P/(1-t^2), radius=t||P||/(1-t^2), t=.01.
This is a finite-dimensional geometric diagnostic,not an estimate of the
physical remainder. We independently verify its boundary construction.

Predictor-anchor errors matter too. Relative interval coordinates are
0,1/4,1/2,1,with the cold point at3/4. Exact Lagrange weights are
(1/4,-1,3/2,1/4), whose absolute sum is3:
P=A/4-W+3C/2+B/4.
A,W,C,B are the saved sources at f=.75,.8125,.875,1 respectively.

If H6=H*+epsilon_H and saved anchors=exact anchors+epsilon_i, then
E6=I_true+epsilon_H-sum_i w_i epsilon_i,
where I_true=H*-sum_i w_i A_i_true.
Consequently a genuine pure-interpolation bound requires BOTH the cold-source
radius rH and weighted anchor radii rA=sum_i |w_i|r_i:
||I_true||/||H*|| >= max(||E6||-rH-rA,0)/(||H6||+rH).
All quantities share a physical norm; we report values divided by ||H4||.
Anchor continuum radii are not supplied by a same-event arithmetic check.
Weights3/2 at the centre and-1 at the warm quarter make these especially
important. No arbitrary anchor radius is silently set to zero.

For each saved linear response map L and the already fixed cold bubble b,
L[b E6]=L[b E4]+L[b delta54]+L[b delta65].
Use the separately evolved small increments,not only subtraction of large
histories. Compare their sum with the independent saved revised-minus-frozen
trajectory,then project baseline,MTS,and their sums with the same linear
temperature/mu/y/residual map. Same steps,frequency grid,operators and sources;
no new integration. Baseline cancels in matched differences but is retained,
nonzero,and subjected to the same projection and reconstruction checks.

The diagnostic propagates a cold-anchor miss through the previously declared
bubble. It does not determine the true error profile between temperature
anchors. Source separation,propagated conditional sensitivity,and unresolved
anchor/integration errors are reported as distinct results.

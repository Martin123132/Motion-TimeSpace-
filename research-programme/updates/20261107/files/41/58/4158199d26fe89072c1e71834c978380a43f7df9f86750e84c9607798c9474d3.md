## What was derived

The piecewise transport identity is

    D_material L + U_R L = D_Eulerian L + d_R(U L).

Its integrated boundary identity includes outer endpoints, moving
material faces and fixed radial coefficient cuts with right-minus-left
jumps. We kept the actual derivative of each stored primitive distinct
from the separately stored radial coefficient. Nothing was silently
identified or set to zero.

On the actual fine-grid data, independently accumulated bulk terms and
the saved boundary terms explain the old cross-method discrepancy. At
the high rule, the largest decomposition closure residual is2.86e-19
for the reference and1.26e-18 for MTS; current-row closure residuals are
at most5.81e-21. The numerical fundamental-theorem defect includes
quadrature AND floating arithmetic, not necessarily quadrature alone.

Pointwise evaluations on333actual points per branch first exposed a
binary64 failure: MTS relative transport error2.4485e-10 exceeds the
1e-10 local diagnostic gate. That original failed run is retained.
At20worst/distributed points per branch,96-digit evaluation of the same
input data gives identity residuals1.48e-50/reference and6.02e-49/MTS.
Two central steps1e-24 and1e-28 give identical binary64-rounded
derivatives. This checks arithmetic; it does not add precision to the
physical inputs or supply a uniform continuum error bound.

The current reduction uses primitive differences across each element:

    Delta_i = integral_Ri^R h,
    S0 = sum_i b_i*v_i*Delta_i,
    S1 = sum_i b'_i*v_i*Delta_i,
    J = A*(S0-W*g*I) + Phi*S1 + Q*I + E*W*h,
    Q = -alpha*W*T*v_R
        -(W*alpha_R+alpha*W_R)*T^2/2
        +(W*beta_R-beta*W_R)*g^2/2.

Here I=integral_source^R h, T=v-Wg, Phi=alpha*W*T+beta*g and A is the
existing material momentum rate. This follows exactly from V=v*I-S0
and V_R=v_R*I-S1. Polynomial divided differences avoid subtracting
rounded primitive values, and the exact Eulerian local-coordinate
rational rewrite avoids a redundant multiplication/division roundtrip.
The action, input coefficients and physical assumptions are unchanged.

Symbolic identity, finite-family toys and actual high-precision probes
pass28validation/provenance checks. The worst sampled current-derivative
arithmetic error decreases about1815-fold, from1.574e-14 to8.674e-18.
This is a sampled arithmetic improvement, NOT an1815-fold improvement
in observational fit or accuracy everywhere.

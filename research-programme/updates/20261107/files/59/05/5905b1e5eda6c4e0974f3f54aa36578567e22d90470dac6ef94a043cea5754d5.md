## The mathematical step: let position balance force

For the instantaneous system

    B + C0*s + C1*sdot + C2*sddot = 0,

the C0 force is nonzero, so exactly eliminate s rather than divide by the very small C2 force:

    s = -(B_F+C1_F*sdot+C2_F*sddot)/C0_F.

With r=C0_J/C0_F, the three remaining current equations are

    d + G1*sdot + G2*sddot = 0,
    d=B_J-r*B_F, Gi=Ci_J-r*Ci_F.

For independent G1,G2, the left-null projection of d is the central compatibility obstruction. This is equivalent algebra, not a new parameter or a subtracted reference baseline. The12manufactured checks cover compatible and incompatible systems, exact elimination, column/row unit transformations, degenerate columns and unresolved/zero pivots.

# Boundary-complete position-column integral

The prior C0 helper and its 12 actual probes are immutable. This stage
implements the equivalent fixed-Eulerian representation derived there.
It reuses the corrected reaction k0 and mixed metric-time response H,
without solving or refitting either again.

For each material cell, with baseline left endpoint a, width w, local
coordinate t, and endpoint movements U_left and U_right, a fixed physical
radius has perturbed material coordinate

    t_epsilon = (w*t-epsilon*U_left)
                /(w+epsilon*(U_right-U_left)).

All field, velocity, acceleration and fixed material test polynomials
are evaluated at this coordinate. Physical gradients divide by the
perturbed width. Native current primitives use moved node radii and
moved source origin. At fixed physical R, the metric family is
Y+epsilon*P and Y_t+epsilon*H; material transport must not be added again.
The physical integration measure is fixed in this representation.

For each force/current density L the complete wave derivative is

    integral delta_Eulerian L dR
      - sum_material_faces U [L]
      + U_outer L_outer - U_inner L_inner,

where [L] is right minus left. Fixed radial metric cuts have no moving
location term in this representation. Volume quadrature is split at the
union of base, position, time, and mixed-response radial grids. For each
radial quadrature point, layer quadrature splits at material-face
crossings; material-face integrals split at radial-cut crossings. Outer
terms are explicitly computed, even if support pins make them zero.
The inherited polynomial centers are preserved.

Manufactured tests compare this implementation to the separately
derived material product rule, and to an independently rebuilt moving
two-cell family with a fixed radial cut. Both omitted-material-face and
omitted-outer controls must fail. A separate coefficient-cut toy validates
the native/source layer-event sign below.

## Coefficient events in the native and source currents

A material evaluation point R_j(label) crossing a fixed radial cut R_c
has delta label_c=-U_j/R_j'. For monotone R_j'>0 the layer-integrated
first variation has the additional atom

    weight(label_c) * U_j/R_j' * [L_j].

This applies both to native coefficient samples and to the source-clock
current evaluated at the moving source. The code verifies monotonicity
using the source polynomial's derivative extrema; other edge maps are
convex combinations of the source and the positive-width outer map.
Crossings strictly inside the layer interval are enumerated, not sampled
on a convenient global quadrature grid. Endpoint weight vanishes.

At fixed native kernel geometry the force and each current are linear
in beta_j and beta_R,j. If image is the kernel image and S is its sampling
operator, then

    dload(test) = S^T[image * dimage(test)],
    force_beta = dload(raw support test),
    force_beta_R = load * eta_native,
    current_beta = -dload(field_rate * I_node)
                   + load_dot * I_native + load*W_native*h_native,
    current_beta_R = W_native*load*I_native.

These coefficient covectors are checked against the full existing native
force/current calculation. They evaluate each cut jump without subtracting
two large complete native sums. Beta and beta_R jumps come from one-sided
70-digit evaluations of the registered base metric polynomials. This
differentiates the represented physical function, not floating-point
rounding steps. Source-clock jumps use the same one-sided metric traces.

Regular native/source derivatives use material orders48/64; wave volume
and faces use radial/label24/28 and32/36. Gravity uses radial24/32 split
at all response grids. The paired C0 component gate remains2e-17 in code
units. Failures are retained rather than changing that tolerance.

## Scope and next decision

Each completed rule is saved before the next expensive stage. The new
integral is a numerical construction; acceptance additionally requires
paired stability and propagation of the saved k0/H sensitivity. The
initial runner does not claim to have propagated that sensitivity or
solved the three-amplitude system. If the integral pair fails, inspect
wave volume, face, native, source and gravity separately before attempting
an amplitude fit. Existing C1/C2 and older precision warnings remain.

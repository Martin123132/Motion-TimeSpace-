# Complete the collision operator on the original seven-node panel

For the retained photon/gas input q with two fixed-zero infrared-tail
repairs, each saved event is linear. Original quadrature weights are
already part of its coefficient matrix. The full panel is therefore

    L_panel(theta_j) = sum_(i=0..6) L_i(theta_j).

At the original target history q_star, use the already frozen weights

    L_hat_star = 3/8 L_panel(theta_warm)
               + 3/4 L_panel(theta_middle)
               - 1/8 L_panel(theta_cold),
    S_hat_star = L_hat_star q_star.

Linearity permits interchanging sums over events, original frequencies
and temperature anchors, and contraction with the SAME q_star. It does
not permit interpolation of source values evaluated at differing q.
The construction tests this commutation against every new event source,
individual node forecast and the independently saved full-panel source.

Component ordering is baseline, real_difference, virtual, state, MTS,
total, with MTS=real_difference+virtual+state and total=baseline+MTS.
Preserve moment rows and paired photon/gas exchange columnwise before
contracting, using the original mass/basis. Do not repair a failed
physical comparison by changing a moment row after aggregation.

Stage217 supplies the physical source-to-response map B(u). Once this
panel passes, the short-interval contribution has the explicit form

    deltaY' = A_r(u) deltaY + B(u) L_panel(theta(u)) q(u),
    q' = A_c(u) q + h(u),
    h = (A_c-A_b)y_b - r_b,
    r_b = y_b' - A_b y_b - f.

No equality q=deltaY and no r_b=0 are assumed. At this stage L_panel is
constructed at three anchors; its continuum continuation has not been
numerically certified. A forthcoming controlled interval test must keep
incoming response, actual q history, two BDF2 states, paired energy ledger
and separate operator-temperature/history/time-step errors.

A completed panel is an exact representation within the fixed finite
quadrature and retained input space, up to the checked precision. It is
not an extrapolation beyond the original8–20 band, a nonlinear closure,
or a new cosmological fit.

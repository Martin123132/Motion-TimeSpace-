# Eliminate the nodal derivative cancellation in the baseline current

The first compact-current probe proved the identity at 90 digits but showed no uniform improvement of binary arithmetic on actual points. Compacting the energy-rate bracket alone is therefore insufficient. One remaining cancellation is the derivative of the interpolated nodal product `v_i*I_h(r_i)`: the three nodal derivative terms contain a large common constant which should cancel exactly.

Let x be local cell position, L the separation between the stored physical endpoint coordinates, and v(x)=v0+v1*x+v2*x^2. Define

`I_h(r_left+L*x)=sum_{k=0}^{h+1} i_k*x^k`,

`i_0=[(r_left-6)^(h+1)-(source-6)^(h+1)]/(h+1)`,

`i_k=binomial(h+1,k)*(r_left-6)^(h+1-k)*L^k/(h+1)`, for k>=1.

Construct i0 by a factored difference and multiply these coefficients with v to give `r(x)=sum_{k=0}^{5} r_k*x^k` (zero pad for h<2). Interpolation on {0,1/2,1} maps

`P2[x^k]=b_k*x+c_k*x^2`, where `b_k=2^(2-k)-1`, `c_k=2-2^(2-k)`, for k>=1.

The derivative is therefore

`(V_h)_R=[sum_{k=1}^5 r_k*(b_k+2*c_k*x)]/physical_width`.

The constant r0 never enters this derivative: there is nothing large to subtract numerically. Furthermore,

`r(x)-P2[r](x)=x*(x-1/2)*(x-1)*[r3+r4*(x+3/2)+r5*(x^2+3*x/2+7/4)]`.

Thus the acceleration multiplier is

`U_h=rate(x)*[I_h(R)-I_h(r_left+L*x)] + (r-P2[r])(x) - W*g*I_h(R)`.

The first term is essential: the archived floating point R and local coordinate need not map exactly onto the archived endpoint coordinates. Do not silently set it to zero or replace L by another width. Use the same factored primitive difference to evaluate it. The derivative denominator remains the inherited packet physical_width.

This preserves the exact stored-packet mathematics while removing a cancellation in its evaluation. Test the polynomial interpolation formulas symbolically and re-run the same 96 actual points in both branches against the independent 90-digit original density. Integration and changes to B/C1 are subsequent steps, not inferred from a point test.

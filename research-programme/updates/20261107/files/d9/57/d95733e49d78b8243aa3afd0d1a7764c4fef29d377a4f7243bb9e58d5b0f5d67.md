# Resolve the baseline rather than choosing a preferred integration method

The existing reference controls expose a disagreement between the original
material-order64 force and the split-label Eulerian force. Increasing the
original spatial rule alone did not remove it. Before assigning the error
to either representation, vary the ORIGINAL label rule with its spatial
partition and the action fixed.

The bounded diagnostic evaluates material orders48,64,96,128,256,512 at
spatial order12. It records successive differences, disagreement with both
saved Eulerian rules, component scales, and the location of the largest
force disagreement. The original64 row must replay its saved authority.
All rows are diagnostic, with no tolerance relaxation or numerical acceptance.
No assumption is made that the highest rule is converged.

This first localization uses the reference-fine control because it already
shows the discrepancy without the MTS native term. It cannot establish an
MTS-specific effect. Any adopted repair must subsequently use the same
method and gates on both reference and MTS controls.

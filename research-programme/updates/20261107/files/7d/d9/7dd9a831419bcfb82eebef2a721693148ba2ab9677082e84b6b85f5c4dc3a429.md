## Interpretation and next calculation
This is a controlled numerical sensitivity result: baseline gas is stable
against this change, but the MTS gas response has a resolved time-step
dependence. The two-level difference is not a total-error bound, measured
asymptotic order or observational success. The65-knot source interpolation,
response time step and window dependence remain separate.

First make a cheap2048-to4096 response-step control using these same saved
sources. Then halve the INNER step again (10240 to20480) on the same frequency
grid, retain both backgrounds/baseline/MTS, and test whether the MTS gas
differences contract relative to this stage. Do not extrapolate a final value
or fit a cutoff. This order avoids another long reconstruction if the cheap
response control reveals a different bottleneck.

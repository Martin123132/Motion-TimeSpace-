# Matter–gravity transport: derived identity, completed integrals, coupled test

## What moved forward

The dust and gravity baseline currents now have an exact common-measure formulation, implemented and checked on both actual branches:

    C = N/(kappa*sqrt(F))
    D_dust = kappa*mass*(w/J)*sqrt(F)*N/ell
    j_dust = C*v*D_dust
    B_dust[h] + B_gravity[h] = integral C*(m_t+v*D_dust)*h dr.

The remaining quantity R=m_t+v*D_dust is explicitly retained. It vanishes in the pressureless material-mass-conserving control, not automatically in the coupled scalar/Gram system. The actual combined current is nonzero; neither it nor the independently computed metric-time response was set to a desired value. The derivation also supplies the radial equation for R and its interface accounting.

Derivation: `DERIVATION-20261001-matter-gravity-transport-remainder.md`.

# Event-split volume and face integration

The fixed-label flux implementation passes the actual weak/flux comparison and
the manufactured moving-family derivative test. A single global label rule is
nevertheless inefficient: the stored force contains radial-polynomial and
material-face crossing events. A separate implementation integrates each term
on its own exact event partition, without dropping a boundary contribution.

1. Volume: physical radial intervals include every background/response cut AND
   the positions of every material face at both label endpoints. At each radial
   node, split the label integral where it crosses a material face. Integrate
   Phi_R N and H_R N; independently retain the old weak integrands on the same
   rule as a numerical cross-check.
2. Material faces: split their label integrals at crossings with all fixed
   radial cuts. Evaluate the two cell traces at exact local endpoints 0 and 1.
   Deposit the jump on their shared field node. The pinned source node remains
   absent. Retain inner/outer endpoint terms separately.
3. Radial cuts: at each fixed physical cut, split labels at material faces.
   Use the precise represented metric/response jumps to evaluate [Phi], [H],
   and -[Phi] U N_R. No radial jump is suppressed as numerical noise.

The maps must be monotone in the label over this saved background. Reversed
face maps or insufficient metric-domain coverage are errors, not silently
clipped physical data. The existing centered inverse map is used; comparisons
use unchanged tolerances. Coincident interior cuts are counted, not assumed
absent. Endpoint Gauss nodes do not sample the generic isolated crossing itself.

An independent manufactured moving-family check validates the event algorithm:
nonzero metric jumps, a different response grid, nonzero outer tests, and a
moving material geometry are all present. Compare against differentiation of
the original weak integral after rebuilding its partition for each perturbation.
Omitting jumps, moving-cut loads, or endpoints must fail separate negative
controls. This checks the complete implementation, not just a symbolic identity.

The first event-helper attempt failed before numerical integration because a
code-extraction error included the wrong class method. It is preserved in its
failed evidence folder. The separate corrected helper passes its manufactured
tests. Neither that coding failure nor a low-order label failure is a physics
result. Real-reference validation precedes any reaction update or MTS adoption.

# Coupled near-identity normal form and its explicit remainder

## Parent and time convention

The previously verified amplitude equation, in N=ln(a), is B_N=S+exp(2i theta)C. The same physical fields, background and metric are retained:

```text
mu = theta_N, gamma = k^2/(2 omega H), kappa = k/(2H)
S = -i gamma B - kappa z A + i(mu-omega/H)B
C = (3/2-i gamma) B* + kappa z A*.
```

A is the validated background amplitude and z is the CURRENT coupled metric source. All other perturbation states evolve with the native operator. Carrier defects are retained.

## Exact cancellation, not guessed averaging

Let J=exp(2i theta)/(2i mu) and b=B-JC. Then

```text
J_N = exp(2i theta) - J mu_N/mu
b_N = S + R
R = -J(C_N-mu_N C/mu).
```

C_N must include B_N, A_N, z_N and coefficient derivatives. In particular,

```text
C_N = -i gamma_N B* +(3/2-i gamma)(B_N)*
    + kappa_N z A* + kappa z_N A* + kappa z(A_N)*
gamma_N = -gamma(1+H_N/H)
kappa_N = -kappa H_N/H.
```

The native flat synchronous constraint gives z=(D_s/(2k)+k eta)/H. Therefore z_N=(D_s'/(2k)+k eta')/H^2-(H_N/H)z. The code uses the actual stored all-sector density rates and current eta rate, not a future metric trajectory.

For the full control, b_N=S+R is retained. The declared first reduced candidate uses b_N=S. This is an approximation to test, not an assumed new physical law.

## Metric feedback makes the map implicit but soluble

The scalar density satisfies D_h=omega Re(A B*)/a^2, so at fixed other states

```text
z = z_other + xi dot (Re B, Im B)
xi = omega/(2 k H a^2) (Re A, Im A).
```

Thus b=B-JC is a two-real-dimensional linear system T B_real=b_real+forcing, with T=I-K. The columns of K are the real/imaginary parts of

```text
J[(3/2-i gamma) conjugate(e_j) + kappa xi_j A*],
e_1=1, e_2=i.
```

The inverse retains the B-dependence of z. No metric coefficient is treated as a prescribed external force. For s=||K||_infinity<1, the Neumann bound gives ||T^-1||_infinity<=1/(1-s).

An analytic sufficient bound at each represented background point is

```text
s <= sqrt(2)/(2|mu|) [sqrt(9/4+gamma^2)+R_h/(2H^2)]
R_h=(v^2+omega^2 phi^2)/2.
```

This follows from the real multiplication/conjugation matrix norm and the rank-one metric term. Numerical sampling of this expression is not itself a continuous-interval certificate; the actual inverse gate is checked at every queried RHS point.

## Quantified derivative defect and honest conservation test

Dropping R changes b_N by -R while the other state derivatives stay native. Hence

```text
Delta B_N = -T^-1 R
||Delta B_N||_infinity <= ||R||_infinity/(1-s).
```

This is an instantaneous derivative-defect bound, not a global trajectory-error estimate. Reconstruct Delta d_N, Delta u_N by the inverse carrier map. The induced physical stress-rate changes are

```text
Delta D_s' = H[v Delta u_N + omega^2 phi Delta d_N]
Delta Q_s' = H k v Delta d_N.
```

They are added to the saved stress derivatives before testing raw conservation. The original canonical u coordinate need no longer equal the derivative of d in the reduced candidate; that mismatch cannot be hidden by reading canonical RHS values.

For consistency of the geometric readout, the corresponding sigma and Weyl derivative corrections are

```text
Delta sigma' = Delta D_s'/(2kH) + 3 Delta Q_s'/(2k^2)
Delta Weyl' = -[Delta D_s'+3H Delta Q_s'/k]/(2k^2).
```

The heavy scalar has no anisotropic stress, and the other instantaneous derivatives are unchanged. Independent metric/force integral replays then expose the actual approximation error.

The prior finite-window pressure identity acquires the additional term

```text
-< beta H [v Delta d_N + phi Delta u_N] >
beta = 2 omega^2/(4 omega^2+k^2).
```

This term is recorded separately as normal_defect; it is not folded into a tiny background interpolation error. The same equations with zero corrections apply to the cold identity control.

## Numerical derivative qualification

H_N/H uses the retained background-only log-H spline; A_N uses actual dense background derivatives. The source-derived Friedmann derivative is recorded as an independent cross-check. Before every evolution, the exact full map's time chain rule is tested using five-point differences at steps1e-6 and5e-7 in N. This is numerical differentiation, so its gate is2e-5, not an exact-algebra claim; inverse and source algebra retain1e-10.

Full remainder-retaining controls must reproduce the prior forward solution. Reduced cases must separately pass numerical convergence/accounted dynamics before their approximation accuracy and raw conservation are judged. A rejected reduced candidate is not relabeled a successful physical limit.

# Stage94 development notes

All work is additive beside the sealed Stage93 files. Cached Gaussian rules
are read-only arrays; only their affine/logarithmic interval mapping changes.
The leading-source helper's quadrature callable is changed in memory within
a try/finally block, restored immediately and recorded through module hashes;
the inherited source file is never edited.

No failed scientific packet is silently rerun or overwritten. Run configurations
and node source hashes are checked before resuming an interrupted calculation.
COMPLETE/status, not a final progress.json still labelled running, establishes
completion. A source lookup for a non-existent population filename was corrected
using the actual directory listing before any implementation depended on it.

After radial testing, any renewed exact-amplitude calculation must be justified
by a new integration dimension or an independent rule comparison, not repeated
blanket precision work. The angular runner changes the soft angular grid only;
virtual/state corrections are independent of that soft grid and are reused at
their original exact population nodes. No new virtual-loop calculation is made.

# Preserve the center of the represented metric polynomial

The stored radial polynomial is defined using its solver center c_j:

    z=2*(R-c_j)/length_j.

Changing to a source-centered coordinate r=R-a must therefore use

    z=2*(r-(c_j-a))/length_j.

It must not silently replace c_j-a with a newly rounded midpoint of the
shifted edges. The two expressions are equal in exact arithmetic, but
binary64 stores c_j after its original midpoint rounding. Recomputing a
different midpoint changes the represented polynomial, not just the
notation used to evaluate it. Small changes can matter in steep derivative
profiles and must be measured rather than presumed negligible.

The registered-center evaluator preserves the owned center. Test it against
the original evaluator at identical representable physical radii on all
four saved backgrounds, including first and second radial derivatives.
The existing recentered evaluator is retained as a comparison. This probe
does not itself establish a force-level repair: any replacement must also
pass the force/reaction integration checks with the original tolerances.

No stored coefficient, edge, physical parameter, or previous script is
changed. The new evaluator is a separate versioned candidate.

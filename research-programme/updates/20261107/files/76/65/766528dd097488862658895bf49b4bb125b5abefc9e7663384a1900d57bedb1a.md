# Stage186 execution

One sequential Python313 worker, -B -u, below-normal priority, single-thread BLAS.
Commands: curvature_stage186.py prepare; curvature_stage186.py derive;
analyse_stage186.py analyse; analyse_stage186.py validate;
precision_stage186.py; finish_stage186.py.
All artifacts are in this child. The derive phase writes its prediction hash
before analysis loads Stage185 target matrices. No physical target integration
is repeated. Parent seals and consumed files are checked before/after.

The saved targets have already been examined in Stage185, so this is retrospective
testing of a newly derived coefficient. Never claim a blind independent holdout.
No live scattering bank, tolerance, history or handoff is modified.

After validation, write the result/next-target notes, seal the child, then prepend
only additive resume headers. Do not rerun a sealed child in place.

Development note: the first anchor calculation passed its numerical checks but
failed before saving because this new child's results directory had not been
created. No frozen coefficient or target analysis existed. The save-directory
initialization was repaired and this single anchor calculation repeated, with
identical inputs and gates. No existing scientific payload was overwritten.

The first analysis retained one centered boundary-split rounding failure. The
additive precision pass reconstructs fixed-mask differences from the saved live
and boundary operands and accounts explicitly for their prior rounding residual.
It does not rerun any physical quadrature, overwrite the original failure, or
change a tolerance. See PRECISION-NOTES.md and results/precision/status.json.

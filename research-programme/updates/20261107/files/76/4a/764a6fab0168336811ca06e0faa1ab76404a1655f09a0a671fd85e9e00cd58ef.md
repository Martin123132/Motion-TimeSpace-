# Trigonometric normal-form correction

The first direct four-dimensional tensor run passed the quadrupole checks,
then rejected an octupole component because the default trigonometric
simplifier left the factor

    -sin(2theta)+cos(2theta)*tan(theta)+tan(theta)

unevaluated. This factor is identically zero wherever that chart expression
is defined; multiplying by cos(theta) gives
-2*sin(theta)*cos(theta)^2+sin(theta)*(cos(2theta)+1)=0.

The checker now applies an additional exact trigonometric normal form if
the default form is nonzero. No field equation, source, boundary condition,
or numerical tolerance was changed. The successful run rechecks both
multipoles from the beginning rather than skipping the component.

# Stage187 execution and reuse

Use Python313 with -B -u. The script sets single-thread numerical libraries and
the inherited below-normal, single-core worker policy. Execute phases sequentially:

1. smooth_stage187.py prepare
2. smooth_stage187.py structure
3. smooth_stage187.py edge --index 0, then --index 1
4. smooth_stage187.py evolve --model heavy --grid native (then half, quarter)
5. smooth_stage187.py evolve --model cold --grid native (then half, quarter)
6. assess_stage187.py assess, then validate
7. finish_stage187.py after writing result and next-stage notes

No live bank or saved history is replaced. Each new edge calculation and each
candidate history writes an individual status and hash before the next starts.
The original bank trajectories are reused and checked by forced-difference
reconstruction, rather than six redundant reruns. Their three-grid curvature
array must reproduce the existing Stage183 result bitwise.

The derivation and structural gates are frozen before evolution. Two new physical
temperature checks are needed solely for the small restart/end-grid margins
outside the prior +/-0.01 domain. No new microscopic source or virtual integral
is calculated. All baseline/MTS source projections reuse the saved gas kernels.

Compile via Python compile(source, filename, 'exec') or -B imports; do not create
bytecode. Seal the finished child, then only prepend additive resume headers.
No subagents, GitHub, global package changes or unrelated-process operations.

The first assessment reached its JSON save but rejected a NumPy boolean in a
comparison row. That serialization field was converted to a native bool. All
six completed histories and both endpoint calculations were reused without
rerunning. The already saved comparison NPZ is checked bitwise on the repeated
assessment and retained rather than overwritten. No physics or gate changed.

# Check the small return, not only the common solution

The original150 full-block/Schur controls pass, but their common-solution
normalization alone cannot resolve a one-step relative return near1e-24.
Those results are retained and are not promoted to that stronger claim.

At the same physical matrices, sources and80-digit arithmetic, independently
compute the direct block solution minus the no-return solution. Compare this
difference against the Schur formula

    delta xi = -sign*loop/(1+sign*loop) * xi_free.

Compare thermal and canonical-field increments as well, for each baseline,
MTS and total component separately. The relative gate remains1e-10 but is
applied to the increment itself. A zero-return negative control must fail
that comparison. Original bank, step sizes and source predictions are unchanged.

The original probe output is frozen as a supplement input. No new microscopic
integrals or histories are acquired. These small physical-matrix solves
are repeated only because the initial report did not retain their full
high-precision solution vectors; the expensive source/envelope work is reused.

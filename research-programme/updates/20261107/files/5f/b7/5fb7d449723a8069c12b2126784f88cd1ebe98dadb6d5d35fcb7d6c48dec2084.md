# Exact background radial time forcing: construction, not a new assumption

The existing radial equations in `scripts/annular_candidate_radial_constraint_20260920.py` are Y_R=f(R,Y,E,G,H,rho,V), Y=(mu,nu), N=exp(nu), F=1-2mu/R, C=sqrt(N^2-V^2/F), E=<T^2>, G=<q_R^2>, H=the inherited Gram density. This note differentiates THESE conditional annular equations; it does not assert a new covariant action or replace the native kernel.

At fixed physical R, their exact time derivative is

    (Y_t)_R = f_Y Y_t + B,
    D_t = E_t/(2 N^2 F) + G_t/2 + H_t,
    B_mu = kappa R^2 F D_t
         + kappa ms sqrt(F) N/C rho_t
         + kappa ms rho N V/(sqrt(F) C^3) V_t,
    B_nu = kappa R D_t
         + kappa ms V^2/(R N F^(3/2) C) rho_t
         + kappa ms rho/(R N F^(3/2)) (2V/C + V^3/(F C^3)) V_t.

There is no division by V or rho. Zero velocity and zero density are regular. For fixed inner/outer radii and fixed central mass, mu_t(inner)=0 and nu_t(outer)=-mu_t(outer)/(R_outer F_outer). The already implemented radial Jacobian and tangent boundary solve can therefore be reused. The new implementation is `scripts/annular_radial_time_forcing_20260928.py`; `scripts/derive_annular_radial_time_forcing_20260928.py` checks all source columns symbolically and against independent complex derivatives of the actual original radial_rhs, including simultaneous geometry variation.

## What supplies the time derivatives without probe subtraction

For a piecewise wave density f transported by a continuous cell velocity W, its weak derivative against a fixed radial test h is

    d/dt sum_cells integral f h dR
       = sum_cells integral [f_dot_ALE h + W f h_R + W_R f h] dR.

Equivalently, interior Eulerian terms are f_dot_ALE-W f_R, and a moving interior interface contributes -W[f] delta(R-R_face), with [f]=f_right-f_left. Thus E_t and G_t require the cell terms AND interface transport. Omitting the latter is not an exact derivative of the existing broken-cell action.

For the native Gram pushforward write

    H(R) = sum_i integral a_i(lambda) delta(R-R_i(lambda)) dlambda,
    a_i = w(lambda) U_i/J_i,
    H_t = sum_i integral [a_dot_i delta - a_i V_i delta'] dlambda,
    <H_t,h> = sum_i integral [a_dot_i h(R_i) + a_i V_i h_R(R_i)] dlambda.

Here J_i is the inherited spatial Jacobian, U_i is the inherited native nodal load, and V_i=dot(R_i). For native image u=Dq, dot(u)=D dot(q)+dot(D)q, so dot(U_i) follows directly from the quadratic load and the existing native-kernel tangent. Also a_dot_i=w*(dot(U_i)/J_i-U_i*dot(J_i)/J_i^2). No fitting coefficient is introduced.

For the source pushforward rho(R)=integral w(lambda) delta(R-b(lambda)) dlambda, rho_t=-partial_R(rho V). Where the label map is invertible, V_t=b_ddot(lambda(R))-V V_R. Use the weak source formula at support edges rather than divide by vanishing density.

The LOCAL forcing derivative is implemented and independently checked in this stage. Its full wave/interface/native/source weak projection onto the owned radial grid is the next calculation, followed by the coupled old-Euler solve and the same reference/MTS current comparison. This avoids merely decreasing the time-probe step. The formulas state precisely which transport terms must be retained; they do not assert that the full background tangent has already been evaluated.

# Cycle 3: the field and metric equations predict each branch's signed drift

On the saved interval **89.33456575–89.42743046 conformal Mpc**, both the matched model and the native wave predict the change in the constraint from their own left states. All predictions were frozen together before scoring. The errors below use the finer source subdivision on each gravity clock and the actual phase-crossing forecast, not the secondary archive-interpolated forecast.

| Native wave | (+0.283717, +0.898977) | 0.01352% | 0.00805% |
| Matched minus native | (+4.262372, −9.816140) | 0.00264% | 0.000833% |

The denominator in each row is that row's **own** saved complex drift magnitude. The fine saved drifts are (+4.546072, −8.917098) and (+0.283642, +0.898975) ×10⁻²⁰ respectively. The smaller native result was not graded on the larger matched scale. Including half-substeps and both endpoint conventions, all **24 endpoint comparisons** pass the unchanged **0.5%** criterion; the largest error is **0.2011%**, native wave on the coarse clock with half-substeps. All 51 additional controls pass; the coarse/fine signed difference of the primary branch-contrast forecasts is 0.000307% of the fine contrast.

**What produces the contrast.** In the retained work convention, project each signed term on the direction of the final matched-minus-native drift. On the fine clock the complementary metric work supplies **+355.24%**, the heavy sector **−254.59%**, ordinary matter **−0.56%**, and the difference in supplied geometric work U **−0.09%**. These signed contributions sum to 100%; they are neither probabilities nor independent force strengths. The coarse shares are +355.23%, −254.58%, −0.56% and −0.09%. The field-rate part of the complementary metric term supplies +351.64 percentage points, versus +3.60 from its changing weight. In contrast the native heavy field-rate and changing-weight terms cancel very strongly: the *combined* heavy work is the useful quantity, not either large intermediate by itself. On each individual branch the ordinary and metric terms are large; the ordinary **difference between branches** is small.

**Prediction and boundary audit.** There is no saved full 90-variable state at each exact cycle crossing for this particular prepared trajectory. We therefore reconstructed and froze the left launches from the switch using only the switch state, background, frozen pressure/stress and supplied forcing. From each launch a classical RK4 solver advanced matter, angular moments and Φ by the momentum equation; it never reset Φ from the energy constraint. For C = U − Σ(W·x + external work), we independently integrated W·x′ and W′·x by stage quadrature, with only the prescribed source increments supplied. Supplied U and external work are inputs, not new predictions. The archived calculation used a different RK rule and a discrete product formula. Right-hand states, cycle work and photon outputs were not inputs to this prediction. The cycle was selected from the previous study: this is an endpoint-masked consistency test, not a new empirical holdout.

Only after the freeze did we read the saved cycle ledger and reconstruct the left and right boundaries of the cumulative work from the original stored impulses. Those two procedures agree to better than 5×10⁻¹⁶ relative to the cycle change. The primary forecast stops at the true phase crossing; the secondary forecast accounts for the archive's fractional cell at either end. On the fine clock this second convention gives 0.000745% error for the native wave and 0.0000657% for the branch difference. No photon gap was fitted or rescored, no state promoted, and no time window extended.

**Next:** write the heavy work in terms of energy and current so that field-rate and coefficient cancellations happen algebraically. Pair it with the complementary metric work and freeze predictions on cycles 2 and 4 from their own left states, without using cycle 3 to set an amplitude. That tests whether the cancellation found here carries across the other complete cycles.

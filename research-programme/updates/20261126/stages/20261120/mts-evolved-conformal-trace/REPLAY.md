# Reproduction and scope

Use retained local Python, NumPy, SciPy and SymPy. All calculations are serial or at most two single-threaded workers; no external data, fit, new halo amplitude or prior. Existing upstream and local stop markers apply. Outputs are written once and compared on repeat. From this directory:

1. Fast integrity check: `python -B verify.py`. See the sealed parent normal-energy stage and its upstream seals for the original full-domain states and Newton normalization.
2. Analytic fixtures: `python -B controls.py`, `python -B tidal_controls.py`, `python -B edge_system.py`. These test the two formulas on time-dependent inhomogeneous dust, spherical-background angular perturbations, pure harmonic shifts, analytic curvature and a momentum fixture. They do not validate the particular physical formation conditions.
3. The 17 (grid,q,steps,padding) combinations are listed in verify.py. For each, run `python -B campaign.py GRID Q STEPS PAD FLAG` separately for wave (0) and cold (1); each makes all three signed/no-host states. Continue with `python -B readout.py GRID Q STEPS PAD 1` and `python -B tidal.py GRID Q STEPS PAD 1`. The coarser scalar comparison also uses readout flag 0 for the original nonlocal annuli where saved. Do not replace the original 120-Mpc Cauchy data with a small standalone box. PAD 7/8 sample a short edge patch on that original preparation, with continued/reflected far boundaries.
4. `python -B edge_prediction.py` uses only the original launch fields; `python -B preparation_test.py` uses the alternate saved native formation and exactly rechecks its archived overlap before producing a separate prediction. Both retain the original graph in the fixed-point continuation. For coarse comparisons run compare.py and tidal_compare.py; for refined comparisons run `python -B budget.py`. All shell joins, force signs and no-host subtractions are kept. See `refined-budget.csv` for each quarter and aperture, not only final maxima.
5. Recheck the seal. No process is required to keep these results available. The scalar surface change, physical divergence projection, Newton reference and the independently unspecified exterior harmonic are distinct quantities.

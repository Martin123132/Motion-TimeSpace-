# Offline replay

Use the retained Python 3.13 numerical environment (NumPy and SciPy) inside this directory with the sibling stages present. Use -B and set OPENBLAS_NUM_THREADS, MKL_NUM_THREADS, and OMP_NUM_THREADS to 1. No downloads, services or concurrent workers are needed. Runs stop on a mismatched archived output rather than silently replacing it; for independent regeneration with a different library build use a separate copy alongside the inherited inputs. No fitting.

- Read PROTOCOL.md for the frozen source and readout choices. validate.py checks every file in the preceding two inventories and the six specific original LMC forcings; the stage's own seal is external-pinned in the parent resume note. Run python -B validate.py for the lightweight integrity/numerics check.
- signed_potential.py 4 8 rings computes both source quadratures and independent Newton ring readouts. For wave_transfer.py use (mesh,quadrature,occupations) arguments: 0 4 0 1, then 1 4 0 1, then 1 8 0 1. These produce signed moments, both eigenvalue derivatives, stationary states/forces and their multipole decompositions.
- increment_check.py 0 4 0 1 and 1 8 0 1 independently solve in displacements, bypassing cancellation. branch_state.py reconstructs the initial/changed Hamiltonian consistently for the other steps.
- new_satellite.py uses arguments (mesh,quadrature,basis,occupations): 0 4 40 0 1; 1 8 64 0 1; 1 8 96 0 1. Each run checks the six inherited forcings and retains both 8/16 substep readouts. Run common_sky.py 64 and common_sky.py 96. The 96-basis archive is the final comparison; the 64-basis archive and coarse run are controls. Both t=0 entries use the sealed old satellite calculation. The NFW is a static baseline, not an independently re-evolved collisionless halo.
- assembly_bound.py followed by nonlinear_trap.py each take one triplet (mesh,quadrature,occupation): 0 4 0; 0 4 1; 1 8 0; 1 8 1. These do not integrate a guessed formation history. complex_controls.py independently evaluates the underlying isolated complex field energy for real/imaginary perturbations with smooth, broadband and central-cell profiles. All 36 control states satisfy the analytic inequalities; maximum absolute direct/expanded energy difference is 3.36×10⁻¹² in solver units. Those checks support but do not replace the energy argument.
- validate.py --seal generates an inventory only if the existing one is absent or identical. Run validate.py without options again to verify it. All CSVs have headers; archive units and scope in RESULTS.md and DERIVATION.md. Hashes pin this local work, not independent observational confirmation.

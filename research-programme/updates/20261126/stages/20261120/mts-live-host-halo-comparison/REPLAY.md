# Local replay (no account, fit or GitHub job)

From this directory, with the existing 64-bit Python 3.13, NumPy and SciPy, run `python -B verify_live_wave.py` for the short offline check. It rechecks the parent inventory, six actual forcing-bank hashes, archive-member and native-DLL receipts, the stored ground/response densities, independent number and mass integrals, signed-band accounting, changes under numerical refinements, and this directory's SHA-256 seal. It starts no service. Derived CSV writers refuse nonidentical overwrites.

Calculation order, only if reproducing the actual stage in its original neighboring directory layout:
1. `python -B acquire_host.py` verifies existing archive members offline; only absent members trigger bounded HTTP downloads. The published full ZIP checksum is publisher metadata, not a local hash of the entire ZIP.
2. `python -B native_build.py` verifies/uses the cached native evaluator; an uncached build requires the pinned distributions in native-build.csv, Microsoft x64 C++ Build Tools and the noted GSL package. The recorded binary checksum identifies this particular build, not a promise that a different toolchain produces an identical DLL. Source: [Agama at the recorded revision](https://github.com/GalacticDynamics-Oxford/Agama/tree/f302756b8af2b763db58e278e30478517dc8eea3). Only runtime/toolchain cache data are outside the private stage; no system install.
3. Run field_controls.py, then body.py with coarse, main, check individually, then compare_host.py. These compute the native/source, centre-frame, static NFW and live-halo controls. Use the `-B` flag throughout. No force calculation at an undefined point-centre is needed.
4. Run common_wave.py with arguments `0 1 3` (10 modes; 18 modes; and 18 in the enlarged radial box). Run common_response.py with space-separated cases `0:0:40 0:1:40 0:2:40 1:0:64 1:1:64 1:2:64 1:0:88 1:1:88 1:2:88 3:0:64 3:1:64 3:2:64`. One numerical worker, one BLAS thread. No recomputation of the expensive satellite scattering/forcing bank. Each case emits a six-history response table and six present-epoch density packets. Occupations 0 and 1 preserve the old particle numbers; 2 is calibrated only to the original outer circular speed. Units are in DERIVATION.md.
5. Run response_scores.py, matched_control.py, then verify_live_wave.py. Never replace a prior seal. No Galaxy Lab files, protected jobs or publication work are involved.

Primary products: common-forces.csv (per-site source decomposition), density-redistribution.csv (inner mass and global cancellation), common-compression.csv, common-band-test.csv, independent-refinements.csv, same-anchor-nfw-summary.csv, and vertical-compression.csv (archived host/retained-source comparisons). Data credit: Eugene Vasiliev, [Welcome again, Magellanic Clouds!](https://zenodo.org/records/8015660), CC BY 4.0. Six alternate source simulations, not a sample of independent observed outcomes. No fitting data were added.

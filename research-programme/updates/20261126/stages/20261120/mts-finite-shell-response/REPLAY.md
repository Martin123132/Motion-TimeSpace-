# Local verification and replay

Run from this directory with the retained Python 3.13, NumPy, SciPy and SymPy. Use `python -B verify.py` for the quick evidence check; this verifies every file against the existing seal and the predecessor against its pinned seal. No new observations, external downloads, installations, GPUs, or agents required. Keep one numerical thread per process and no more than two workers. The full calculation does **not** need to be repeated just to read the results. All scripts honor the directory-level work hold before writing; content that already exists is compared, not replaced.

## Forecasts and controls

- The eight original freezes were generated with `python -B evolution.py MODEL GRID RATE prediction` for MODEL cold/heavy, GRID 0/1 and RATE 1/2. Only afterwards run the modes zero, plus, minus, weakplus and weakminus on each pair. `python -B report.py` reconstructs the comparisons. Files store complete readouts and conservation receipts, **not** the several-million-piece endpoint state. The physical starting states are hash-pinned by the predecessor. The verifier checks the original forecast-file dates as well as hashes; a plain copy that does not preserve times is not an original timing receipt.
- `python -B native_compare.py` runs the matched, previously used joined nodal representation. `python -B wave_current.py GRID 2` computes the frozen local link current and its decomposition for each of GRID 0,1,2,3. Also run GRID 3 at RATE 1 for the temporal check. For the two highest meshes `python -B high_controls.py GRID 2` verifies those predictions on an independent pair of signed trajectories. `python -B controls.py` tests the folded mass quadrature, moving cut derivatives and oriented wave link identity on manufactured data.
- `python -B arrival.py MODEL GRID SUBSTEPS SIGN` predicts first entry of a tagged material label into the distant shell, writes the forecast, then follows the nonlinear trajectories. Tested cold grid zero at eight substeps with signs −1, 0, +1; cold at grid zero/16 and grid one/8 at sign zero; heavy at grid zero/8 at sign zero. Pass signs as integers with ASCII minus (e.g. `-1`). A blank observed contact means none by the short stopping time.
- `python -B light_history.py MODEL GRID 16 tangent` for both models on grids 0/1 and heavy additionally on grids 2/3. At grid zero only, run positive, negative, weakpositive, weaknegative *after* the tangent packet exists. `python -B clock_transfer.py` and `python -B clock_extra.py` read the compact local metric histories without repeating any matter advance. The dense output covers one light crossing after the short pulse-evolution window, not light propagation through the whole universe.
- `python -B slip.py` reconstructs the boundary-independent stress combination from **two previously archived formation snapshots**, with independent quadrature, a wave-derivative check and exact electrovac controls. A leading post-Newtonian source prediction on those data must not be treated as an Einstein-evolved metric measurement.
- The original scripts have a hard limit on material segment count; do not simply extend the fine-mesh duration until it exhausts memory. A new physical window requires its own protocol, exact starting-state provenance and separate safety budget.

No task-owned helper, preview or simulation is required to stay open. There are no modifications to sealed input stages, Galaxy Lab, public GitHub or the original formalization workbench.

# Local replay and evidence boundary

Use Python 3.13 with the retained NumPy and SciPy. From this directory, `python -B verify.py` rechecks the result tables, frozen initial data, 175 predecessor file hashes and this stage's exact file inventory. It makes no network requests and starts no worker. If the upstream data change, do not reseal to silence a mismatch. Outputs are mutually checked, not overwritten. “Within target” in the time test means the *absolute normalized residual* is at most the inherited 2e-5; the normalizer includes the Hubble rate times the potential span. It is not a posterior probability.

**Static constraints.** Run `python -B solve.py cold start` for each combination of cold/heavy and start/end, then `python -B sensitivity.py cold start` for the same four pairs. `python -B independent.py` runs the analytic controls. Read DERIVATION.md for the material continuation, coordinates and units. The old source prediction is pinned to the previous stage; it is not used as a lapse boundary value. The mass test includes current.

**Time-dependent original sources.** Each `history-*.npz` has a paired `before-evolution-*.json`. To replay e.g. the finest heavy end: `python -B history.py heavy end 2 8 .00625 24 balanced-regular`. Other filenames encode the same arguments (branch, epoch, wave/source refinement g, steps n, core rc, domain L, lift). The raw and regular-origin movies are intentionally separate. Run `python -B optical.py`, `python -B light_controls.py`, and `python -B wave_generator.py` for the optical outputs, independent pulse-spacing and wave projection tests. These include the original discrepancies.

**Actual relativistic transport.** For the independent matter-generator controls use `python -B material.py start 1 .00625`; the other three inputs are encoded by the material table names. The short cold metric-coupled midpoint evolutions use `python -B geodesic_history.py start 1 8 projected-geodesic .00625` (and each of the other four configurations in live_check.py; prefix the listed scheme with 'projected-'). A doubled label mesh represents the same initial mass profile, not a new physical preparation. The end comparison is taken backwards from the saved epoch. Run `python -B canonical_wave.py` to check the scalar-action current on both lifts, then `python -B live_check.py` for the five cold histories and the eight regular-origin heavy snapshot checks. Use one numerical thread per worker and at most two workers. Intermediate and final data are local only. The first evidence seal used `python -B verify.py seal`; normal verification never requests a new seal.

The saved states are cosmological formation fixtures, not Milky Way measurements. The ordinary-foreground/occupation test requested separately already exists in [the crossed galaxy calculation](../mts-foreground-occupation-cross/RESULTS.md), distinct from this spherical calculation. Neither its measured bands nor its scores set any value here.

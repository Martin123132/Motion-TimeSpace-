# Local replay and evidence boundaries

Use the retained Python 3.13 with NumPy, SciPy and mpmath, `-B`, one numerical thread per worker and at most two workers. All paths resolve against this stage and the sealed sibling stages. Do not run in older stage folders. Numeric products are write-once: repeating a calculation at an existing path must reproduce the archived bytes. A stop request is checked on the inherited path hierarchy and in this stage's own folder. No foreground data downloads, installations, service or GitHub changes are needed.

1. Start with `python -B checks.py`. It checks the prior hash inventory, nonlinear host-difference algebra, preserved zero solution, and original-vs-lifted field rates. Run `run_pair.py original 1 4 33 66 132 264` and its `adm` counterpart with Python. Each case saves the zero-host trajectory increment and the separately evolved finite host difference from the same launch.
2. Run `readouts.py original`, `readouts.py adm`, `readouts.py assess`. Those include 46-digit material and constraint diagnostics. Run `number_chart.py check`, then `number_chart.py original` and `number_chart.py adm`. Use `readouts.py original number`, `readouts.py adm number`, `readouts.py assess number`; these use the existing unchanged cold trajectories. Unit tests include non-negligible offsets and not just linear responses.
3. Run `source_terms.py` and `prepared_state.py` for the read-only finite current analysis. Run `phase_prediction.py` to freeze both windows, without using the longer clock. Only then run `new_clock.py original` and `new_clock.py adm`; each checks that freeze before using up to 820 steps per member. The longer clock is 25⅝ out of 4096 fast rotations, not the complete physical clock.
4. `forecast_controls.py` checks the directional derivatives, integral kernels and exact input-table phase identity. `slow_phase.py` derives and decomposes the phase's nonoscillatory and carrier contributions. Run `newton_pressure.py` and `native_window.py` for the separate weak Newton operator and native detector comparison. `cross_checks.py` compares the chart and original-branch errors, projected constraint split and per-window phase conversion effect.
5. `judge.py original`, `judge.py adm`, `judge.py newton`, `judge.py gates` score against the frozen current and same-clock Newton normalization. `ablate.py` removes or reverses terms from the analytic prediction only. `canonical.py original` and `canonical.py adm` are diagnostic re-evolutions after seeing the original result, not independent held-out tests; `canonical_controls.py` checks their changed monopole gradient against the calibrated representation. The 410/820-step cold comparisons are reused, not recalculated.
6. Run `finite_q_pressure.py` to transfer the finite-geometry coefficient from the two lower-speed preparations to the higher one. Run `verify.py` to verify the finished package; only its first packaging uses `verify.py seal`. It checks the source chain, all counts, raw prediction-vs-measurement differences and fine/shortcut comparisons, verifies the current inventory, and repeats one longer-window wave trajectory. The current seal excludes itself. A green inventory is necessary for replayability, not evidence for a physical claim on its own.

The mathematical source construction is independent of observations. Source forecasts are for this specific formation and approximate time interval. `rate` in the forecast tables is the local monopole rate of coordinate heavy number times its retained normalization; `charge` is the accumulated number difference in the same convention, and neither denotes electric charge. `total` in the material error tables is the local Eulerian energy change. The tidal tests use the proper observer's two finite widths. The fixed-coordinate windows in the three-speed pressure-operator comparison are for one material term, not proper tidal measurements or the LMC force bands.

# Local reproduction

Python 3.13, the retained NumPy/SciPy/mpmath installation, one numerical thread per worker. The sibling folders named in scope.py are inputs. Do not run the stages' own saving methods on the input folders. The checkpoints here do not change any observation, formation file, galaxy code or public repository.

- The initial publisher used `python -B freeze.py`. This verifies the predecessor, independently replays the q=128 stress calculation, generates the two q=1024 gravity forecasts and canonical matter forecast, and pins the protocol and worker. No fitted parameter is inferred from the new target.
- Run `python -B worker.py original 128 128` and the same for adm, then the two at 512. A full trajectory has four new proper-clock endpoints, and each signed trajectory also evolves the zero control. `python -B worker.py original 16384 4096 --sign 1` resolves four steps per rotation up to the first quarter. A full-equivalent label is not a claim that the last three quarters are carrier-resolved. The additional finer control, when listed in the results, uses `original 32768 8192 --sign 1`. Epoch restarts contain the evolved coordinates, trace samples and hashes; the worker reads a contiguous chain of verified receipts before continuing. Use only one owner per distinct trajectory.
- Run `python -B read_clock.py 128 512 16384 32768` after the target workers exit. Profiles and both tidal measurements are paired by physical time. Source and passive work reconstructions use `transport.py`, `pressure.py` and `work.py`; `compare.py` compares time resolutions on common clocks.
- `python -B verify.py` checks receipt chains, finite full states, the clock and frozen-input hashes, completeness and uniqueness of the signed tidal grid, the numerical result tables and the byte-level stage inventory. Only first packaging uses `--seal`. Creating the new folder's `STOP-REQUESTED` is an owner hold. No server, preview or scheduler is required.

After the primary failure: `space.py 320 original`, its ADM counterpart, and the same at 80 test spatial error for the positive host. They write to separate folders; they do not overwrite the frozen primary grid. Run `compatibility.py` and `ruler.py`. Run `origin_mode.py GRID FORM SIZE` at 160 and 320 for original with 24 and 40 cells and ADM with 24 cells. Follow with `constraints.py`, `tangent.py`, `tangent_flow.py`, `compatible_flat.py` (also uses the installed SymPy), and `work_precision.py`. None of these repairs or masks the primary full-clock measurements. The optional 32,768-step control was not used for this checkpoint: actual spatial refinement and the regularity/constraint tests were the discriminating controls.

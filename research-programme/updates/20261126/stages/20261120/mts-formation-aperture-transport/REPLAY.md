# What to replay

Everything is local. The sealed predecessor is identified in common.py. It must be a sibling folder, with its own original upstream inputs still in place. Use the retained Python with NumPy and SciPy, one numerical thread per process. No new catalogues, target velocities, GitHub operations or worker infrastructure.

1. `python -B verify.py` checks prior checksums and all sealed local files, all eight evolution receipts (both branches × levels × time steps), sky-independent population accounting, the frozen impulse matrix, measured responses and the source-to-metric tests. It checks experiment bookkeeping and the controls explicitly specified in the code; it does not declare every comparison physically converged.
2. To regenerate trajectories, `python -B collect.py heavy 0 1` produces six local wave/metric histories and a receipt. Repeat for cold and levels 0/1, time factors 1/2. Each original interval uses ceil(2048 × factor × Δln a) steps. Level 0 is the original 6.25-comoving-kpc metric/wave grid; level 1 halves the spacing on the same initial state, holding the original oriented dust elements fixed. This does not double the number of independent particle labels.
3. `python -B transport.py 0 1 160` reuses the heavy packets, with 160 sine functions per proper aperture. Analyses use 96 and 160 for each pair. `controls.py` checks analytic flux, the open-boundary sign, a changing projector, its rank change and the cosine potential. `coupling.py` and `current_to_lapse.py` use the saved fields for the physical density/metric/current comparison.
4. `python -B action_flux.py 0 1 4 8` replays the same wave with internal Gauss samples of the discrete current (all four level/time combinations). `python -B momentum_constraint.py heavy 0 1` checks the fixed-comoving test with the contemporaneous velocity and potential (both branches, all four combinations). `python -B flow_constraint.py heavy 0 1` separately integrates the current along each actual drift and diagnoses the two intervening wave phase kicks (native/base and fine/refined, both branches). Positive comoving radial current denotes outward flow. The weak force components here and the observed LMC scores belong to **different physical preparations**.
5. The independent impulse experiment has two ordered commands: `python -B susceptibility.py freeze` then `python -B susceptibility.py test`. The test reads and verifies the prediction file; it does not estimate response coefficients from the observed shifts. Source profiles A/B/C and multiple signs, times, amplitudes and meshes are specified in the protocol. Nulls are scaled by the geometric mean of diagonal responses. Read the full results including the coarser failures.
6. Writers reject differing prior outputs; do not overwrite a sealed packet to change its physics. Use a separate local successor if assumptions change. The several hundred MB of local wave samples contain numerical arrays, not new observations. No long-running job is required to read the reports.
7. Local null repair: `python -B local_impulse.py freeze`, then `local_impulse.py heavy` and `local_impulse.py cold` via the same Python. Run each with `--short` to evaluate the smaller time windows, differencing the two signed source loads before the final linear Poisson integral to reduce subtraction error. Disjoint streaming gradients and the compact wave gradient predict zero without modifying the measured readout. Lastly `python -B local_impulse.py freeze --compact` and `python -B local_impulse.py heavy --compact` check fourth and sixth order on the same states. They use link weights (4/3, −1/12) and (3/2, −3/20, 1/90); neither stencil spans the gap between A and C. Cold is unchanged by the order of the wave kinetic term.

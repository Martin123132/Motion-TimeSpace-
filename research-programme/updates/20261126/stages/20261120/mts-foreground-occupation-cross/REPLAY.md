# Reproduce locally

Use the saved Python scientific environment, python -B, one numerical thread per worker, inside this stage with its sealed sibling folders. The stage does not download new data, start servers or modify the parent checkpoints. Do not use A/H and B/L as if their occupations or common outer speeds were identical. For replay, each writer verifies existing bytes and refuses conflicting overwrites; use a separate copy if changing numerical libraries.

1. census_gate.py calculates the three physical solar apertures including donor subtraction and the central bar at the Sun. cross_equilibria.py recomputes the missing low-occupation A cells, four 224.03-km/s anchors and two local derivative check points. The high-occupation cells on B and A were already solved, and low-occupation B comes from the preceding stage. Crossed cells use particle number, not a transported eigenvector.
2. cross_histories.py 64 anchorA anchorB cut1 cut2 low0 low1 low2 low3 low4 low5 low6 low7 low8 low9 low10 low11. Then cross_histories.py 88 cut1 cut2 low0 low11 for the basis controls. Every low case uses its own saved history; each named calibration anchor uses all six. Density, first-order number and independent Poisson-derived forces are checked before writing rows.
3. compare_sources.py constructs the signed factorial table and physically constrained panels. force_direction.py derives the allowed force direction for every f in each census interval; a grid inside those intervals independently checks the analytical extrema. speed_response.py needs the stream outputs from the next step.
4. stream_check.py evaluates the two stationary stream sites. It uses independent direct measured-disk ring quadratures (12 and 18), computes the azimuthally averaged E3 replacement after removing the point monopole already counted, and adds only the signed 0.4 transfer. The native disk/bulge is read directly. The Poisson potential on the wave elements gives wave accelerations; a separate integrated multipole expansion checks them. Both q and the linear strength combination are written for both models. The comparison targets and limitations are frozen in STREAM-PROTOCOL.md.
5. speed_response.py derives velocity sensitivities and tests the MTS derivatives by two separate stationary solves. shell_budget.py computes the exterior-shell and shape budget, including actual enclosed mass and its independent force check. anchor_width.py re-solves on the source endpoints at the actual external ±1.91 km/s statistical error; computes the stream predictions, and inverts the *necessary* spherical-shell bound. Drive those states with cross_histories.py 64 anchorA_lower anchorA_upper cut1_lower cut1_upper cut2_lower cut2_upper. width_panel.py compares both models site by site.
6. verify.py --seal writes the stage inventory. A separate verify.py invocation rehashes and checks it, the original source hashes, signed panels, identities and precision flags. Neither call resumes any calculation outside this folder. The digest is stored in ../CURRENT_LOCAL_RESUME.md.

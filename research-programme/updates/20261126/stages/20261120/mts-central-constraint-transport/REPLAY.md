# Local replay

Use the retained Python 3.13 with `-B`, NumPy and SciPy plus the parent's usual dependencies. Run here, one numerical thread per process and at most two workers. Use a fresh copy of the stage in this parent directory to regenerate; sealed outputs compare byte-for-byte on a repeat. No downloads, fitted parameters, package changes, remote repo activity, or left-behind service. The original signed and unsigned formation inputs are never overwritten.

1. `python -B controls.py` checks both formulations on the off-constraint analytic sources, on exact dust, and under the transformation of wave momentum. `core.py original 160 8 FLAG` replays the original matched q=64 control and saves the four *actual* increments for every sign. `core.py adm 160 8 FLAG` changes only the derived off-shell formulation. Use both flags (0 wave, 1 matched cold). New increments and raw diagnostic rows are in the corresponding NPZ/CSV pair; times are 1/4, 1/2, 3/4, 1 of the retained 273.43 years. `score.py METHOD 160 8` assembles both signed contrasts and the time-integration subdivisions. The original endpoints must equal the sealed predecessor's values, not just pass a loose numerical gate.
2. `launch_rate.py`, then `score.py impulse`: compare independently evaluated curved and Newton launch impulses without adding an overlapping correction to the remotely predicted shell. `launch_constraints.py source` and `launch_constraints.py compare`: analytic wave kernel controls and the original ADM initial forecast. `representation.py`: original launch-only budget from spherical harmonics, face jumps and both evolution forms. These scripts use the saved formation and supplied Robin environment.
3. For each seed 0, 1, −1 run `lift.py SEED 1` (unrefined inputs must reproduce the original packet) and `lift.py SEED 2` (half-element solve). The scalar RHS and actual potential/derivative and matter-input checks are saved separately. `lift-x2-s*-receipt.csv` pins the new packets. In `linear-check-x2-off0-s0.csv` the wave/no-host monopole has amplitude around 10⁻¹⁰²: its ∼0.001 fractional fixed-point difference is of order 10⁻¹⁰⁵ *absolute*, unlike the physical angular component of order 10⁻⁹. Neither that relative number nor the solver iteration threshold alone bounds the detector observable.
4. `lift_prediction.py` writes the forecast for both formulations before the new evolutions. Run `core.py lifted-original 160 8 FLAG` and `core.py lifted-adm 160 8 FLAG` for both flags, then score both. The half-element failure is retained. For each seed run `green.py SEED` to perform the original-resolution integral constraint solve including the iterative normal graph, then `lift_prediction.py green` to freeze that initial-only forecast. Run and score `green-original` and `green-adm` in the same way. The recorded pre-evolution forecast hashes are required by `overview.py`. These pre-evolution tests cover the new numerical preparations, not new observational data.
5. `origin_budget.py VARIANT` for each of original, lifted, green; then `origin_budget.py assess`, `arithmetic.py`, and `overview.py`. The signed source-contract test uses the actual final elliptic RHS, not an inferred source from two detector outputs. Decimal curvature rereads use 40 digits on the *existing double-precision field*, not an arbitrary-precision evolution. The aperture/renewed native representation and secondary sampling budget are distinct. The two prognostic schemes do not have the same off-shell error propagation.
6. For each flag use `mesh_checks.py GRID STEPS EDGE FLAG` at (160,4,3), (200,4,3), (160,4,4) to check the repaired retained formulation's actual time, spatial and central boundary errors. Run `mesh_checks.py assess`. The standard-ADM alternative is tested at the common main resolution, **not** assumed converged merely because the retained formulation is. `verify.py` verifies all 36 saved four-epoch evolution packets, the earlier sealed inputs and decisions, every CSV's structure and the saved file hashes. The historical first invocation `verify.py seal` made the write-once seal.

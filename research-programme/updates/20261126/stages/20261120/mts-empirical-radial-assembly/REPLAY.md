# Local reproduction and input ownership

No fits, network requests, Google/GitHub actions, rescheduling, or changes to another lab are necessary. Use the retained Python with NumPy, SciPy and PyMuPDF. Run each command as python -B from this stage. All output writers refuse to replace different bytes. The hold-file checks, saved foreground and original protected files remain in force. Paths and immutable inputs are checked by the verifier.

1. The locally retained primary PDFs are van Dokkum et al. arXiv:1304.2391v2 (https://arxiv.org/pdf/1304.2391) and Ratcliffe et al. arXiv:2509.02691v1 (https://arxiv.org/pdf/2509.02691); hashes are enforced before use. Run profiles.py and aperture.py for the Fig. 3 vector ordinates, Fig. 4 aperture masses, plotted bootstrap ranges and cross-panel checks. The unresolved factor in the naive aperture mass is documented, not silently applied to the end census. The plots' errors are not a dynamical source covariance.
2. history.py 4-primary 8-primary 8-common 8-narrow generates both cosmological clocks and the ordinary stellar spherical potentials. archaeology.py produces Table A.1 and a second family of inputs. Only the assigned measured stellar fraction evolves.
3. radial.py ORDER VARIANT CLOCK LAW STEPS anchorA cut1 cut2. Exact tuples of the 84 runs are recorded one per row in radial-certificates.csv; the names after the branch are those arguments in order. The initial state is solved afresh for each source history, not tuned to the sky. The time unit is that of the retained wave; 32, 64 and 128 are integration steps per unit, not ages in Myr. Each output contains both endpoints, all intermediate data knots and the stationary controls.
4. post_disk.py VARIANT LAW STEPS anchorA cut1 cut2. Use the six tuples listed in assembly_readouts.py (primary linear, all25, all50, all75; mwbirth and mwpresent linear), each at steps=32,64. The incoming state uses the same saved radial 64-step run in both resolutions. The central-timing stress test was designated primary; both other fraction choices are secondary, reported together, never selected by their score. All 65 equally spaced readouts and all six direct satellite histories count. For the two anchorA cases without an energy exclusion, repeat primary all25 and all75 at steps=128 for anchorA only.
5. lmc_sign_test.py reads both original LMC domains and both original preparations, checking saved input digests and all eight signed totals. assembly_readouts.py rechecks the incoming energy and overlap and scores the disk batch and static controls. precision_rich_cases.py compares both additional refinements. verify_local.py verifies prior inventories, linked response data, number and energy identities, runs and stage digest. Repeat without changes for a file-integrity read, not independent physical replication.

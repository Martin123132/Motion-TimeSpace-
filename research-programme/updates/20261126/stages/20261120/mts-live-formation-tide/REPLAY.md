# Reproduction and restart

Use the retained Python 3.13 and project CAMB with -B. Libraries run single-threaded. Everything in this stage is local. Check verify_stage.py before deciding to start a calculation; the saved results and restarts are already complete. Do not change an existing packet to try a different case. The source transfer and original wave preparation are pinned to the 37-file formation-tide release. No new sky data, curve fit or GitHub action.

**Inputs.** native_input.py heavy cold obtains the original 99 common modes, native lapse and all material currents on a short dense time grid. It checks original background and solver hashes, identical initial primordial selection and matching of the initial data to the older branch. Nonrelativistic species and outer FLRW matching follow the previous calculation. No physical initial density is inferred from a force score.

**Short-window matrix.** evolve.py MODEL --tides lin,1,-1,.5,-.5 uses edge=24, band=12, angular order 4, n=16 by default. Repeat the five runs with --band 16 --order 6 --steps 32. On each model also use, separately: default with --mono 0, --steps 32, --edge 12, --wall vacuum or --gravity oneway (lin only); the 16/6/32 core with --mono 0 or --edge 36 (lin); 16/4/32 with lin and 1; 20/6/48 with lin and both monopole choices. Each filename records the settings. Radial band is in inverse comoving Mpc; l is maximum even Legendre degree. The imaginary part divided by 10⁻¹⁶ of a lin run is its infinitesimal tidal response and the real part is the evolved spherical solution.

**Sources and material checks.** material_force.py MODEL --tides lin,1,-1 compares integrated actual acceleration with material displacement in the short window; repeat lin with --mono 0. Use --sources matter for the short lin run, then --sources matter --intervals 8 --steps 64 --tides lin,1,-1 and a separate lin run with --mono 0. material_volume.py MODEL runs 64 steps with 12 surface-angle nodes for lin,+1,−1; --order 16 --tides lin,1 is the independent angular refinement. Entire material-volume geometry, cap number and the integral of physical cone flux are saved. It compares available halfway and final coefficient/marker/flux packets against the independent material-force run. direct_gravity.py MODEL --freeze 0 replays the independent raw Poisson evolution with native reference shapes; omit --freeze for frozen core, and repeat frozen with --band 20. These separate equations calculate rather than overwrite physical fields.

**Current exchange.** current_swap.py freeze records the first two windows' counterfactual forecast before testing; only run current_swap.py test --pin c319123bcd4919a9e3b44bb13530d8d5c7b358f97a374d56fa3b4bd0a09aa6f0 against that forecast. source_gravity.py reconstructs all four physical preparations' accelerations from inner and outer source moments, independently of the momentum-based force integral. readout.py summarizes numerical sensitivities and signed interventions. paired_transfer.py computes the second, homogeneous finite-time transfer forecast: windows 4 and 8 were known by this point; the longer windows had not been tested on the finite evolving patch.

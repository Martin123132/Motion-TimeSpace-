# Replay and provenance

Everything is local. Use retained Python 3.13 with `-B`; the parent stage imports and checks the retained CAMB installation. All numerical libraries run on one thread. No need to reacquire inputs or rerun a physical evolution to read the result. Run `python -B verify.py` from this folder to verify the sealed stage and parent.

1. **Environment.** `stage.py heavy cold` extends both native environments and verifies the earlier 42 epochs mode by mode. `long_chart.py` constructs guarded interpolation tiles; it never extrapolates the older patch. Units, filters, cold/wave masses and source release are inherited. The two extended arrays retain 99 initial Fourier modes and 228 new epochs per branch.
2. **Window 8 to 64.** For each model (heavy, cold), `advance.py MODEL lin,swap,1,-1` advances the full live field. `advance.py MODEL lin,swap --method fixed` uses the raw Poisson reconstruction with frozen interpolation reference in the interior (not frozen physical fields). Every block stores parent restart and environment hashes. `results.py` regenerates the physical and numerical comparison tables. In trajectory.csv, finite-case ball change and integrated current are both multiplied by the tide sign, whereas finite shapes are signed as actually simulated. The full finite current is stored in the packets.
3. **Prospective crossing.** `crossing_forecast.py` reads windows ≤64 only, producing the pinned forecast. Only afterward, `stage.py heavy cold --holdout` obtained 32 more native epochs per branch. For each model run `advance.py MODEL lin,swap --begin 64 --end 72`, repeat with `swap --method fixed` and with `swap --sub 16`, always for the same 64–72 range. The fine-time restart intentionally forks the matching spectral n8 window-64 state. `crossover_test.py` reads the dense held-out trajectories, recomputes slopes and bracketed roots, and verifies the original prediction hash. `paired_source.py` compares signed source integrals across all four intervention pairs.
4. **Real finite background tangent.** `radial_response.py MODEL` derives the velocity-only change from the initial density and donor velocity, without reading measured shape differences; repeat separately with `--uniform`, `--sub 16` or `--band 20`. All start from a=.01, not the later target. Physical, switched-force and balanced controls share one dynamics implementation; only the physical response is compared to the unswitched path as a prediction. The binary series axes are [epoch, field, scenario, aperture]; the named fields and cases both happen to have length six. `response_readout.py` verifies the flux axis against its independently stored integral and the cold pressure degeneracy before making comparisons.
5. **Homogeneous common-potential startup.** `compensated_source.py freeze` records analytic coefficients and prospective time predictions; `compensated_source.py test cdcb144b4d5315b4c32574c89dfe2ceca51e066ae87b75217c08fa95d7aa5944` integrates the rescaled summed equations with two numerical resolutions, with and without wave pressure. `species_control.py` separately advances aV and density for every species; the exact dust null is assessed on component scales, not divided by zero.
6. **Seal.** All readers compare any existing generated output to its recomputed bytes; they do not replace it. `verify.py --seal` creates the seal only once. The historical pre-verification stopping point is retained in RESTART-STATUS.md; RESULTS.md and the seal supersede it.

The holdout refers to new **simulation epochs**; neither these amplitudes nor these tests use Galactic force bands. The signed crossing and homogeneous pressure response do not select the boundary or occupation of a present-day halo.

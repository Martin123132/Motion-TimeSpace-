# Local restart and numerical conventions

Keep this directory next to the original aperture, live-halo and LMC stages. Use the retained 64-bit Python 3.13, NumPy, SciPy and local cached predecessor dependencies. No downloads, service, new fit or GitHub access are needed. Single numerical thread. The original 227-file derivation is in the sibling mts-lmc-fixed-occupation-axisymmetric-20261119 directory; it is a calculation on different grounds, not an addend.

- Verify the sealed stage with `python -B verify_stage.py`. Checks the parent census inventory, six actual LMC bank hashes, primary stellar files, normalized density and column integrals, two ring-force orders, number constraints and calibrations, and regenerates the independent density, force, band and solar-height readouts. Then verifies the local seal. Writers refuse a different overwrite. Preserve this directory rather than resetting it.
- Production order: measured_source.py (freeze protocol and source); gravity_field.py (preliminary elliptic-ring quadrature); prepare_field.py rings (split quadrature at all measured height knots); prepare_field.py coarse 0 and prepare_field.py fine 1. Numerical response: history_wave.py coarse 0 40 OCC, then history_wave.py fine 1 64 OCC for OCC 0,1,2. Finish with paired_readout.py and angular_requirement.py. Seal only a new stage.
- Radial stellar input: sibling mts-population-resolved-gravity-20261119/authors-surfm-remnants-260820.txt; measured two-sided local vertical populations: authors-density-dtr-sn-260424.fits and archive-axis-witness.fits there. HI/H2: mts-mw-baryon-apertures-20261120/measured-inner-neutral.csv, its source PDF, and census_profile.py. Each species' radial disk excludes the separately deprojected central column. Brown dwarfs and ionized gas have separately labelled assumptions; the 0.11 Gum contribution is excluded. Folded stellar tail beyond the 2.878-kpc common observed support contributes only 0.74–0.98% of the adopted normalized vertical columns. The forced response is to an imposed satellite field, not a live response of baryons.
- Original shell banks have 320 radial intervals, maximum incident harmonic 40, quadrature 36, 16 temporal substeps; the doubled-step control samples the same immutable histories. Initial state has no added disturbance at the first saved epoch. The sky and response grid of each of the two retained mesh settings is reused exactly. We use no resampling into a new time history, density correction to enforce the answer, or force/coupling fit.
- For the ordinary potential, the spherical Green function acts on projections of 4πGρ onto normalized even harmonics. Interior moments are weighted by (r′/r)^l and exterior moments by (r/r′)^l; divide by −(2l+1) in the potential. Central Abel density is treated spherically, projecting only its excess over the retained disk, not adding a second bulge. The wave matrix needs only source degrees up to twice its highest angular degree by polynomial orthogonality. Probe forces are independently integrated in cylindrical coordinates with the azimuthal kernel 4K(m)/sqrt((R+R′)²+(z−z′)²), m=4RR′/((R+R′)²+(z−z′)²). Quadrature splits both at the probe and the measured knots. Preliminary unsplit vertical quadrature is retained for comparison, not used to set the final forces.
- The wave-state packets store the mass-weighted stationary wave, chemical shift, grid/order and mass. Each response packet stores mass-weighted real displacement, dimensionless even density multipoles and the unchanged radial grid. With mass unit M/(gᵀg) and length L the physical density unit is M_unit/(4πL³). Integrating the monopole inside both spheres and outside them is independent of the probe force readout.
- Primary tables: fine-mesh1-k64-occ{0,1,2}-bands.csv (absolute signed values and original bands); independent-mass-flow.csv; even-dark-requirement.csv; angular-potential-requirement.csv; solar-evolved-compression.csv; fine-mesh1-heights.csv (column and radial split); refinement.csv. Files named coarse and the separate pre-split ring quadrature are controls. Directions, model and frame must be matched before taking differences. No material-centre correction on the new baryons or full nonaxisymmetric dynamics is implied.

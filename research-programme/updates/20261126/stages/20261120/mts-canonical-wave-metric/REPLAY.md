# Replay without disturbing any earlier calculation

Use the retained Python 3.13 with NumPy and SciPy; no installs, network calls or observational downloads. From this folder `python -B verify.py` is the quick evidence check; the 108-file predecessor and its seal are pinned. Outputs use exclusive creation, or byte-for-byte comparison if present. Do not use a sealing command to hide a mismatch. Run at most two numerical workers; each is single-threaded. All arrays are local.

- `controls.py`, `phase_controls.py` and `trace_controls.py` (all with `python -B`) test the two-sign propagator, independent dense exponential, finite shell energy in a static varying lapse, and Schwarzschild/charged analytic trace and outer slope.
- The wave commands take `EPOCH REFINEMENT STEPS LIFT` e.g. `python -B coupled.py start 1 8 balanced`. For each of start/end the base run used g1/n8 balanced. `work.py` added component-resolved work for g2/n8 balanced; `phase_work.py` used g2/n16 balanced and g2/n8 coordinate and retained both ordinary samples and resolved fast-phase integrals. `trace_run.py` used g3/n8 balanced, retaining a separate un-used Einstein trace diagnostic. All finish at |Δη|=0.084 Mpc, both sign sectors present; NPZ restarts contain both canonical wave arrays, all stream positions/momenta/masses, scale and radial grid.
- `assess.py TAG` checks a saved movie e.g. TAG=end-g2-n16-balanced. `energy.py TAG` analyzes the ordinary finite-time samples from runs with work packets. `sector_readout.py TAG` separates the two instantaneous frequency components at both endpoints; run on the two epochs with g2/n16 balanced and g2/n8 coordinate. These are local field amplitudes on the chosen foliation, not observations of particle production.
- `cold_trace.py start` (and end) instruments a replay of the existing projected cold geodesic solution, requiring its generated packet to match the earlier bytes rather than changing its archive. `edge_match.py` evaluates the trace-compatible pressure boundary on cold and heavy, both epochs and both original boxes.
- `transport_error.py MODEL EPOCH` integrates the difference of the projected and continuum local dust equations over each shell and its faces. The independent late heavy label trial was frozen with `label_trial.py freeze` before `label_trial.py run`; the freeze refuses to run in the presence of its target trajectory. To replicate the timing protocol, use a separate local output folder at the same level with pinned inputs; preserve the original evidence. Its perturbed label number, not the physical opacity, source mass, occupation or radial force, is changed. `assess.py end-g3-n8-balanced-labels2` evaluates its metric/flux results.
- `summarize.py` produces the four primary CSV tables and the common integrated-rate/optical comparisons for all ten original runs. The extra held-out label trial is recorded separately, not counted as an independent physical state. The initial seal was made only after these checks. The verification compares the frozen trial file and trajectory's original modification times; copying without preserving times cannot reproduce that original timing receipt.

# From an external quadrupolar source to a central Jacobi reading

## Reproduction

Run with the retained Python 3.13, NumPy, SciPy and SymPy, one numerical thread, in this directory. The scripts compare against existing files on replay and do not edit ancestors. `python -B detector.py` constructs both Newton time refinements; `python -B curved.py GRID STEPS EDGE` uses the four triples (120,4,3), (160,4,3), (160,8,3), (160,4,4). Then `python -B compare_detector.py`, `python -B tensor_forecast.py source`, `python -B tensor_forecast.py score`, and `python -B checks.py`. `python -B verify.py` validates the encodings, row coverage, numerical conclusions and file digests without repeating an evolution. All output is local; no extra data downloads or servers.

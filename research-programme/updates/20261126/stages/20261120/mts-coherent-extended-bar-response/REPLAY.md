# Offline replay and file map

Use the local Python 3.13 scientific environment with -B, the neighboring sealed parent stages, and the existing verified Agama host reader for the live comparison. The parent imports restrict numerical libraries to one thread. No new fits, external downloads, services or subagents. Each generator refuses to overwrite a different byte sequence; use an isolated stage copy when changing dependencies.

1. extended_source.py coarse fine extra computes the 48/68/84 degree stellar potential banks with even m≤32. direct_azimuth.py 12 20 28 gives the independent real-space stellar force. source_checks.py compares it with the truncated multipole representation; prior exact direct radial and polar forces are not overwritten.
2. rotating_pair.py takes occupation (0 or 1), wave grid, source bank, era (old/new), and a list of even m. For each occupation run new with (broad,coarse), (fine,fine), (high,extra), (edge,fine), for even m=2 to 32 inclusive. The high grid has 16 channels/m, 256 radial steps per length out to 48 lengths; edge tests a 60-length boundary independently against fine. For each occupation also run old with (fine,fine) and m=2,16,32 to reproduce just the old central-star column. Finally run new (high,extra) with arguments 2@31.48 and 2@35.10 for the ring-quadrupole speed-endpoint checks; the fiducial frequency never changes in the main panel.

Per harmonic: response files separate central and extended driven forces, their sum, an independent Green readout and both quadratures on the sky; energy files store direct source work and outgoing flux incl. unresolved high-m raw differences; exchange files store the reciprocal correction and independent matrix check.
4. compare.py combines only like backgrounds. Numeric NFW matching, frozen measurements, t=1 compact ordinary forces and m=0 satellite wave are from the preceding stage. All 384 signed rows retain separate terms. Its 96-basis satellite results are used without rerunning stale ground histories. The stellar compact-lens integral is unchanged.
5. ring_test.py 14 20 28 test performs the independent cylindrical m=2 potential calculation, then projects all six direct satellite fields. tide_null.py computes the subsequent constant-tide-cancelled statistic; sensitivity.py records the two preset speed endpoints and geometry/noise sensitivities. live_control.py decodes the 24 saved live-halo initial/final potential files in two representations, explicitly checking the cached library hash first.
6. verify.py checks stage integrity, upstream inventories and selected archived source bytes, CSV parseability, frozen panels, old-state replay, refinement, reciprocity, ring integrals and live controls. It does not test the astrophysical completeness of the foreground or state. verify.py --seal writes the stage inventory and verifies it; running verify.py again restores no files and rechecks all hashes. The external inventory digest is recorded in the parent restart note.

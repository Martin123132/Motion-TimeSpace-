# Local replay

Use the existing Python 3.13 and NumPy, SciPy and SymPy. From this directory run with `-B`; use no more than two workers and one numerical thread per worker. A repeat in a fresh sibling copy can reuse the original sealed preparation; any existing output must match byte-for-byte. The zero, positive and negative host runs are each necessary.

1. `python -B fixtures_ref.py` freezes the launch forecasts, checks manufactured multipoles, the physical sources against their original saved nodes, and exact inhomogeneous dust. `python -B scalar_ref_control.py` checks a finite non-reference scalar perturbation. The checked dust monopole uses an independently integrated exact, finite proper aperture. Its angular component is a coordinate deformation and must not generate a physical quadrupole.
2. `python -B ref_evolve.py 160 8 3 adm 0 1` and the same with `original` instead of `adm` produce the two main histories. The three numeric arguments are cells/Mpc, temporal subdivision parameter and outer radius in Mpc. Repeat both schemes at `160 4 3`, `200 4 3` and `160 4 4` for the unchanged time, mesh and wall tests. Each NPZ stores four actual twenty-field increments and its native radius. The accompanying CSV contains both Jacobi readings and three matter-stress terms at each width/time; each is a scaled change, not an absolute acceleration.
3. `python -B analyze_ref.py`, then `python -B analyze_ref.py all` retest the old scalar-plus-transverse prediction and the prospective curvature-split prediction, keeping the thresholds and normalization. `python -B swap_readers.py adm` and the same with `original` compare both readers on the same final archived increments, old and new. The switched combinations are diagnostic only, not additional physical evolutions. Both diagonal combinations have to reproduce the original records.
4. `python -B newton_signal.py` tests the pure matched Newton prediction with and without the previously calculated stress contribution; unlike the transported scalar comparison this does not use a curved exterior reconstruction. `python -B verify_ref.py` checks the inventory, reproduces the reported comparisons from the members and compares every sealed file hash. Only the first completed packaging used the extra argument `seal`. No Galaxy Lab files, observational samples or public repositories are required or changed by this calculation.

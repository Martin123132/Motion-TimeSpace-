# Local reproduction

Use the retained Python 3.13 with NumPy, SciPy and SymPy, in this directory, with `-B`. No network, installation, fits or observational data. Work is single-threaded per numerical worker; at most two workers may run together. Do not run more processes just to monitor. Owner stop markers remain in force. The private data and code are write-once/compare-on-repeat. No parent file or earlier receipt is rewritten.

1. `python -B verify.py` checks parent digests, training-free inputs, the full saved packet and readout inventory, the reported gates (including the original failed result) and the stage seal. The stage does not require a server or an active process.
2. `python -B form.py 144:4:-1 144:5:1 144:5:-1 168:4:1 168:4:-1` creates **only** missing extended formation states. It does not need to repeat the archived positive 144/4 state. Use a fresh isolated copy for regeneration rather than modifying sealed inputs. The exterior mesh starts from the old continuous preparation, with its old inner portion checked at launch, and integrates the same cosmological equations/sampling times. This is not an extrapolation of the terminal 120-Mpc state. The two pressure switch states are already present in each matter history.
3. For each pair `120 5`, `144 4`, `144 5`, `168 4`, run `python -B launch_data.py EDGE RATE` then `python -B newton_ext.py EDGE RATE`. The first pair is a control: all available fields of every reconstructed launch packet must be identical to the sealed originals. Its original signed Newton shell results are independently reassembled. The other three solve the constraints on their larger domains. The tables named forecast contain initial-field predictions; they do not read the observed evolution.
4. For each of the three enlarged pairs and each of q=16,32, run `python -B propagate.py EDGE RATE Q inner outer near middle`. Each patch and flag covers three host signs (0,+,−), with four saved proper-time increments. On the 144/4, q=32 preparation also run `fine outerfine inner:9` for spatial and temporal tests. On 144/5, q=32 run `whole fine cut`: the single unbroken evolution across all 6–120 Mpc, the fine two-sided interface and the same fine mesh stopped exactly at the old evolution wall. Saved NPZ packets permit rereading without rerunning that evolution. The tallies of local face terms use the two end faces, **not** the sum of mismatched interior faces.
5. `python -B layer.py` tests manufactured fields, exact curved-coordinate dust and an independent oscillatory tail integral. Then run `python -B layer.py EDGE RATE Q outer` for the six enlarged cases and `python -B layer.py 144 4 32 outerfine`. This is a calculation on saved snapshots, not another formation run. Two different exterior witness shells independently predict the point quantities at 120 Mpc. `python -B native_weyl.py` reads the separately retained native scalar and stress history, not the environmental density or any galactic observations.
6. Run `python -B report_data.py`, `python -B whole_check.py` and `python -B wall_split.py`. See the member and host-subtracted tables as well as the signed contrasts. The individual branches are numbered 0 (wave on) and 1 (matched cold/pressure off); 2 in native-weyl-check is their difference. Nominal ppm in the **parent mechanical** budget always use the old full secular Newton change on the same clock, aperture and seed. These numbers cannot be interpreted as percent changes in each tiny physical term, a likelihood, or a sky fit. Native-Weyl checks instead use their own peak over the four times; individual branch relative checks use the corresponding branch's own host excess.
7. `python -B localize.py` gives the additive spatial decomposition of the whole-minus-patch change on L144/h5 at q=32. Run `python -B layer.py EDGE RATE Q near` for the six q=16/32 cases and `python -B layer.py 144 5 32 whole`. Then `python -B two_faces.py` checks both point traces from witnesses outside the measured interval. `python -B physical_units.py` supplies the native Weyl prediction per physical kpc and rechecks the common proper clock against each native branch.
8. Prospective [q=64 rule](FROZEN-Q64.md): `python -B q64.py launch`; `python -B propagate.py 144 5 64 near near:9` and `python -B propagate.py 144 5 64 middle inner outer`; `python -B layer.py 144 5 64 near` and `python -B layer.py 144 5 64 outer`; then `python -B q64.py score`. These do not replace the validation grids or use the measured quadrupolar source in the test interval to construct the answer. No samples are independent sky observations.

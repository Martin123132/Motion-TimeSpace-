# Local replay and restart

Use the retained 64-bit Python 3.13 with NumPy/SciPy and the project’s compiled cosmology library. Work in this directory. No remote data or rebuild is needed. Single-thread numerical settings are set before importing numerical libraries. No long-running worker is needed to read or verify this checkpoint.

- Read-only check: `python -B verify_infall.py`. Checks saved trajectories, current from an independent spatial derivative, material radius, matched interventions, nulls, refinements, uncrossed states and the local/upstream hashes. `--test` runs those numerical tests before seal verification. `--seal` is the original, write-once authoring path.
- Original controls: run `python -B matrix.py heavy` and `python -B matrix.py cold`, then `python -B independent_runs.py converge` and `python -B independent_runs.py physics`. The earlier finite-volume tables save key snapshots; do **not** use its partially kicked state as an uncrossed restart. The independent solver tests for crossing before mutating either field and saves its complete final state.
- The secondary +2σ check uses spectral_run(model,"anchorA","heavy",dx,24.,steps,2.) for both models on (.025,256) and (.0125,512). For the heavy-only exterior comparison use treatment="compensated" on (dx,L,steps,ν) = (.0125,24,512,1), (.00625,24,512,1), (.0125,40,512,1), (.00625,24,512,2), (.00625,24,1024,1), (.003125,24,1024,1). Use floating point for L and ν as in the batch drivers. No fixed outer dust crossing is overridden.
- `python -B linear_control.py` and `python -B native_balance.py` reproduce the original linear limits. `python -B radiation_switch.py` repeats the five-mode intervention; run again with `--full` for the independent 99-mode panels. `python -B constraint_residual.py` reconstructs the radiation contribution to the metric discrepancy. These run the retained native parametrization, including original early matching; they do not modify it.
- `python -B matched_hierarchy.py --collapse`, then `--counterfactuals`, `--volume` and `--fine-volume` perform the radiation-corrected preparations, transplant controls and independent volume check. Omitting a flag recomputes the linear comparison only. Stage output writers refuse to replace differing files. When porting to a different numerical runtime, compare in a separate stage, not by discarding a reference hash.

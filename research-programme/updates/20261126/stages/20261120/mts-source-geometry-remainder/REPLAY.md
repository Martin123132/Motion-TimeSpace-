# Reproducing this initial-state calculation

Use the retained local Python 3.13 / NumPy / SciPy / SymPy environment in this directory, beside the original pinned stages. No downloads, public updates, or ongoing workers. Each command is a serial CPU job with one numerical thread. Generated CSVs compare byte for byte if already present; changed results cannot silently overwrite this release.

1. Read [the fixed test](PREDICTION.md). Run `python -B predict.py 24`, `python -B predict.py 40` and `python -B predict.py 24 cold`. These read only preparation inputs for the forecasts (and the prior stage's code/integrity manifest); no evolved cloud-tide series or fit coefficients are imported. Source paths and SHA-256 links are checked by `predict.py` and the inherited input loaders. The archived launch packet contains an old point reading as metadata used by the common class constructor; no forecast evaluates it. The separate global rebuild explicitly sets this unused attribute to None.
2. `python -B score.py` pins the raw forecast hashes before opening Newtonian reference values and prior evolved scores. `python -B mechanism.py` tests the geometric identity and closed one-return formula and isolates the different field groups; `python -B environment.py` transfers the prescribed surroundings. `python -B transfer.py` repeats the fixed four iterations at the two other previously scored spatial resolutions. `python -B compare.py` compares the results and combines the independent weak-field microscopic stress forecast with the new proper-mass/geometry and surroundings terms.
3. `python -B constraint_input.py` rebuilds from the signed 120-Mpc formation inputs and returns the first analytic source response *before* comparing the corresponding archived launch arrays. It does not use point or final tide data. `python -B constraint_score.py` compares both extra sources, normal energy/stress only, normal momentum only, and neither; the original dust control is shared exactly. None of these controls fits a new coupling. `python -B verify.py` checks the saved artifacts.

# Offline reproduction and provenance

From this directory use the retained Python 3.13 with NumPy, SciPy and the parent's already installed cosmology environment. The numerical library threads are limited to one. No additional data acquisition, fits or edits to ancestor checkpoints. Output writers compare existing files or use exclusive temporary creation; do not remove an earlier run to force a different answer. The public repo was not changed.

**Read-only:** `python -B verify.py` verifies pinned parents, source and output inventories, every frozen prediction, signed controls, independent elliptic and launch checks, time/grid/box comparisons, the source-ablation limits, and both sign tests. The tabular checks can be regenerated byte for byte using the existing packets. Exact hashes are for the saved installation; when porting also compare numerical diagnostics.

**Calculation order** (for a fresh sibling copy containing the sources, with the same retained parent directories):
1. `python -B campaign.py heavy:96:176:free heavy:72:176:free heavy:48:176:free heavy:36:176:free cold:96:176:free cold:36:176:free cold:72:176:free`. Native global Fourier solutions restart from the saved first epoch (or a checked new first-epoch solve where this grid was absent). Do not extrapolate the cosmological reference. Packages record the hash of their starting packet. Apply the available endpoint histories separately for each model: `MODEL:36:176:restrict`, `MODEL:36:176:metric`, `MODEL:36:176:full`. Also run `heavy:96:352:free heavy:36:352:full heavy:36:352:free`. The full/restrict/metric runs start from *the restriction of the wide state* at the same epoch, not from a different seed. Readout is produced by `python -B readout.py` and `python -B interface_identity.py`. Forces in these packets are from the local domain plus the common Fourier reference; the exterior readout is deliberately recorded separately in the explicit comparison.
2. `python -B shell_forecast.py` freezes the signed quartic launch law. `python -B shell_test.py`, then `python -B shell_test.py --balanced` and `python -B roundoff.py` retain both the failed constant-gradient representation and its repair on identical data. No retuning of the 20 ppm target. The analytic and numerical estimates are in separate columns; a factor of 16 on time doubling is not itself a precision certificate on its coefficient.
3. `python -B retarded.py` freezes the finite-time purely exterior source forecast. `python -B outer_history.py 0 1 2 3 4 5 6` and `python -B outer_history.py score` run the full live measurements and matched controls (including time refinement, radial refinement and moving the outer domain beyond the measurement shell). `python -B tidal_readout.py` translates this part of the common metric into a test-body relative acceleration. This is a simulated formation seed; not all sky sources or all matter beyond 96 Mpc are included.
4. `python -B collar_response.py heavy:120:4:tangent cold:120:4:tangent heavy:96:4:tangent` derives and runs the first variation. For the same 120-Mpc domain also use `MODEL:120:4:0.25` and `MODEL:120:4:-0.25` for both models. The signed drive partition is an accounting check only. `python -B quadratic.py heavy:120:4 cold:120:4` independently solves both coefficient equations. `python -B seed_scores.py freeze` emits the prospective signed prediction, then `python -B seed_scores.py open 7ccfefef8ce58af02e8a8e8bf333b2d9484b0c1680837444cd2e59cd8b8d66b0` opens the reversed seed via fresh finite-amplitude evolutions on both branches. The positive sign was already exposed. Rebuild score tables only with `python -B seed_scores.py score`. No Galactic force value enters these equations.
5. The frozen numbers are also checked on independent meshes. Run `python -B -c "from outer_history import trial; [trial(model,edge,rate,176) for model in ('heavy','cold') for edge,rate in ((120,5),(144,4))]"`, then `python -B collar_response.py heavy:120:5:-1 cold:120:5:-1` and `python -B robustness.py`. Compare at the same physical radius; exclude an artificial edge when the bigger box does not contain that saved probe. These reruns do not change the frozen prediction.
6. In the original directory verification should always use `python -B verify.py`. The one-time seal is created only with `--seal` on a completed release. No service, scheduler, or persistent computation is needed.

# Local evidence trail

Use the retained Python 3.13, with NumPy, SciPy and SymPy. The scripts pin the previous canonical wave/metric release and its imported machinery; the original mass arrays, clock radii and numerical scales are immutable. No online data or install needed; do not run more than two one-thread workers. All dimensional quantities use c=1 and comoving Mpc unless the source specifies otherwise.

1. `python -B controls.py` checks the momentum transform and reproduces the old Galerkin equations at zero shift. Before each evolution's first step the actual RHS generates a paired prospective shift from the same Cauchy data, not a fit to later residuals.
2. `python -B evolve.py MODEL EPOCH KIND STEPS LEVEL` uses cold/heavy, start/end, plain/translated. Both epochs and branches use n8 b0; both branches also use translated n16 at the late epoch on b0 and b1. Set MTS_STREAM_EVENTS=1 for every case except original late translated n8 b0 (those first runs have no detailed event packets). For the two b1 finer-kick runs also set MTS_STREAM_KICK_SAMPLES=1: retain exact inner kick coefficients and a wider lapse/spatial metric movie. The filename tag is MODEL-EPOCH-KIND-nSTEPS-bLEVEL. Never rerun in-place with different observation flags or overwrite old packets.
3. `measure.py TAG` yields the raw measurements, including absolute sites, all spans, null-clock links and both independent wave energy terms and occupation checks. `time_faces.py TAG` integrates the actual crossing-sensitive dust pressure; `face_controls.py` checks it against direct instantaneous stress. All script invocations use Python -B.
4. `source_budget.py TAG ...` derives the trace-gradient identity symbolically and computes the smooth enthalpy, metric and material error contributions. The latter is a trapezoidal **two-endpoint** estimate, not a sampled integral or a bound. `transport_budget.py TAG ...` integrates the separate weak-gravity prediction from the discrepancy between the physical stream velocity and the velocity of its linear position element. For b1 the kick along the path is recorded, not estimated. `species.py` decomposes the enthalpy with the source-checked physical slow-field table, massive-neutrino table and radiation; explicitly compare the same H derivative with a cubic derivative, not a new fit.
5. `slow_response.py TAG` for each late b1 run: advance the retained, Planck-normalized slow scalar on the wider metric history; test finite-time pressure and momentum against its own homogeneous drive. The uniform initial normal velocity is conditional, not the recovered galactic state. A flat zero response and an independent analytic spherical wave with nonzero pressure/current test the implementation's signs. Data files contain edge, spatial and temporal trials; a per-drive discrepancy is distinct from one normalized to the larger GR signal.
6. `status_tables.py` builds the signed results, not just positive tests. `verify.py` checks the archive against its local seal and hashes all 130 immediately preceding stage files. Only the initial release uses `verify.py seal`; do not reseal a mismatch. New immutable outputs must be written to a separate directory for changed assumptions. No external services, GitHub or Galaxy Lab files are involved.

# Local reproduction and scope

Use the local Python 3.13 / SciPy / NumPy / SymPy environment. Each command is finite and single-threaded. No network, process management, or publication is needed. Generated files compare byte-for-byte on replay. Use this directory alongside its [pinned predecessor](../mts-source-geometry-remainder/RESULTS.md). The incoming matter histories and global matching are unchanged.

1. For each seed 0, 1, −1, run `python -B transfer.py SEED` using the signed integer instead of SEED. Then run `python -B controls.py` and `python -B assess.py`. Inputs come from the original formation source (not bundled here), normal graph (not bundled here), two global constraints (not bundled here) and proper ruler (not bundled here). These source transfers use one unperturbed global geometry per preparation and do not take differences of two switched geometries. The saved raw forecasts are fingerprinted before opening the prior switched scores.
2. For each of the three seeds run `python -B switch_control.py SEED`, then `python -B diagnose.py` once. These are validation-only nonlinear solves, at the old switch and two symmetric rescalings. The previous preparation function is reused with its source constructor passed a strength; no upstream file is edited.
3. For each seed run `python -B green.py SEED`; then run `python -B green_score.py`. The Green solution uses end-matched radial moments integrated directly on each source element. For each seed run `python -B unit_switch.py SEED`; then `python -B unit_score.py`. This unit-strength control recomputes the scalar potential and normal data on a shear constructed by adding differentiated solutions, so an ill-conditioned subtraction is not required for the small vector signal.
4. For each seed run `python -B weak_source.py SEED`; then `python -B weak_score.py`. [The source specification](WEAK-SOURCE.md) followed the leading-source comparison; the original switched comparator is not used to select any coefficient. `python -B verify.py` checks the complete release. No exports, temporary servers or continuing jobs.

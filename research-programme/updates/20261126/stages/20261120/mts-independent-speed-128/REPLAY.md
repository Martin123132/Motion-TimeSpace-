# Private local replay

The source, two control branches, clock, two proper apertures, speed-independent Newton reference and 20-ppm gate are inherited. The q parameter counts the local mechanical contraction, not an observed speed. No fits, downloads or release changes.

Use the retained Python 3.13, NumPy, SciPy and SymPy with `-B`; one numerical thread per worker, at most two workers. Run in a clean sibling copy (same parent for pinned imports). Outputs are write-once; a replay against an existing result must produce identical bytes. The owner stop markers are checked in the long loops.

1. Run `python -B predict_speed.py` **first**. It replays the original q=64 tensor source before writing the independent q=128 and long-path forecasts and their digest. No q=128 curved field data enter this stage. `python -B prepare_speed.py 0 1 -1` builds six new Green/normal-graph launches, each with a source packet and receipt. `python -B evolve_speed.py calibrate` must match the archived q=64 initial arrays and final RHS and check q=128 source consistency.
2. Run `python -B evolve_speed.py adm 160 8 3 0 1` and the equivalent with `original`. Repeat with numeric triples `160 4 3`, `200 4 3`, `160 4 4` in both cases. They give the independent time-, space- and domain-refinement comparisons. Each restart holds four full twenty-field increments. Run `python -B resolve_scores.py primary`, then `python -B resolve_scores.py` for the complete paired gates.
3. `python -B independent_wave.py` independently integrates the finite-travel initial-source tensor response at the archived and discriminating speeds. It uses the same source but a different spatial operator/propagator, analytic eigenmode controls, two domains and three grids. The phase bound in its CSV is for the named finite-domain discretization. The causal domain column is for the stated clock and must not be ignored.
4. `python -B phase_stride.py original 64`, then repeat for q=128 and both levels with `adm`. `python -B phase_stride.py assess` compares the clocks against resolved members. These intentionally coarse diagnostics do not replace the controlled main trajectories or validate larger q by themselves.
5. `python -B material_history.py` reconstructs two time samplings of the signed evolving mechanical tensor from a separate Newton calculation. `python -B driven_wave.py` compares frozen, changing and expanding-source propagations with analytic oscillator and scale-factor fixtures. These are supplementary source tests, not replacements for the original frozen forecast or observations. See [equations](DRIVEN-DERIVATION.md).
6. `python -B summarize_speed.py` reports effect sizes. `python -B verify_speed.py` recomputes decisions, reopens field packets, and checks the  earlier seals and the current inventory. Only the first completed packaging uses the extra `seal` argument.

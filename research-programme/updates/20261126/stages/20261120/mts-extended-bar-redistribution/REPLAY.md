# Replaying this local calculation

Use the retained local Python 3.13 environment and sibling releases. Set no new velocity, sky threshold, halo mass, or viewing angle from the outcomes. Each worker forces single-thread BLAS and writes only under this stage, refusing to overwrite a differing result. No server, compiler, fitter, subagent or background timer is needed. Run from this folder with Python -B. The optional source-acquisition step is not needed offline.

1. `python -B inventory.py` checks the sealed bytes, paths, data row widths and numerical controls. The digest of this stage's seal is recorded outside it in the parent resume file.
2. `python -B long_source.py` and `python -B mass_certificate.py` rebuild the source-only budgets and admissible normalization choices. `source_receipt.py` optionally rechecks the remote arXiv pages and the pinned author GitHub revision. The source numbers and formulas needed for offline use are already local. The HTML rendering may change even if the paper does not.
3. `python -B annular_force.py 8 14 20 -8 -14 -20` checks the separable Newton integrals at the two force radii. Positive arguments select 4.5–6 kpc and negative ones the whole retained disk. `orientation_range.py ORDER TILE_WIDTH_DEG` checks the much broader variable-shape envelope: (8,0.5), (14,0.5), (14,0.25), (20,0.25). `mean_source_moments.py` supplies the independently checked exterior ordinary potential, not a wave solution.
4. `python -B lens_transfer.py 6 12 18 24 28 36` reuses the saved surveyed directions, transfer columns, OGLE clump cells and EROS exposure proxies. The early optical calculation retains the ordinary source and windows but does not resolve every tiny differential component. At orders 18/24 split explicitly at the two discrete source distances and the narrow radial layer of the negligible short22 annular contribution. At 28/36 also split at each crossing of a projected bar axis: its generalized-ellipse angular power can be below one, so integrating across the derivative cusp needlessly loses relative precision. This resolves all eleven remaining ray discrepancies without changing the physics.
5. Run `compare_transfers.py` at 12, 24 and **36** (the last is authoritative), `metric_contract.py`, then `validation.py --final`, each with Python -B. Use a separate copied stage if changing numerical libraries. Published observations and original cutoffs are not to be changed to force a pass.

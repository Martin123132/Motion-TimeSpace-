# Checking the saved phase-resolved gravity stage

Run `py -3.13 -B verify_stage.py` here, with NumPy and SciPy installed. Keep BLAS/OMP at one thread. Verification reuses the saved arrays; it does not run a new gravity evolution, fetch observations or publish anything. It needs the adjacent retained stages at their original relative paths. The seal records the complete local stage, including packet hashes; this is not a statement that the raw packets should be published. The verifier refuses Python's -O mode. Only an explicit --seal can create a missing seal.

The native replay and frozen phase predictions precede comparison: prepare_angles, gravity_phase (native and matter), physical_check and score_gravity. geometric_source reconstructs U; gravity_phase geometry_U and the corresponding scores, propagation, constraint budget, pressure transfer and moment readout quantify what changes. incoming_state and score_incoming test the incoming canonical data; carry_state, evolve_carried (primary and control) and report_carried (carried and one_period) deposit the two causal preparations.

prepare_micro, micro_response and score_micro isolate the first-order source change; past_legs and stitch_past preserve the two independently generated incoming source histories. At the common Cauchy surface the first attempted backward packet failed an exact equality check: use the retained stitch_past implementation with the original forward integration span, not a relaxed equality test. micro_memory, then evolve_micro primary and control evolve both complete preparations on both gravity grids. The forecast receipts identify the packet versions used for comparison. reference_accuracy tests how the temporal reference depends on its definition. split_sources p16 and p32, combined_load, score_combined and load_attribution isolate the density numerator without changing the accepted momentum calculation. Run each distinct generator as a separate interpreter in any new reproduction; some historic scripts share module names. Never recompute over the sealed working copy.

The fixed score is the maximum absolute error of the change from the first supported center, divided by the maximum absolute resolved reference change on the same six centers, separately for each route. It is not the error relative to the absolute mean pressure or an observed spectrum. See RESULTS.md for the direct, reduced and change-of-variable checks, including the failing density route.

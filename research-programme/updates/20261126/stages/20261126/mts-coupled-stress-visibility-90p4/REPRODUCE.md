# Reproduction
Use the retained Python 3.13, NumPy and SciPy environment and the sealed parent banks. Set BLAS/OpenMP to one thread, disable bytecode caches, and use an isolated copy of this directory when replaying. Run from this directory; the research workspace and relative archive layout are assumed. The tests use no observational fit or network download.

1. Run project_feedback.py, then check_source.py. This freezes the increment and independently checks it on the saved native metric. The input and output modes are not interchangeable (782 legs, five triangle outputs; one original scattering probe).
2. Run transport.py separately with prefix, bridge, late, scatter-mid, scatter-late and score, in this order. Prefix reuses the exactly unchanged first cycle and wave solution. The later steps carry all 77 bins, both gravity routes and the signed incoming photon hierarchy. Each invocation is a separate Python process because the retained historical loaders bind paths at import time.
3. Run all-angular/all_angles.py, then all-angular/carry.py separately with the same six arguments. That comparator derives both incoming collisionless shear jets from the momentum hierarchy. It holds the incoming fields fixed, not the later measured current.
4. Run audit_visibility.py for signed changes, bounds and controls. Unmodified wave and early-history packets must replay identically. A positive signed change in the route difference is a worsening. The magnitude of the complex correction bounds how much it could improve the result even with the most favorable direction; do not use that bound as a fitted rescaling.
5. In order run phase-average/phase_stress.py, phase-average/current_rate.py, and phase-average/transported_pair.py, each first without arguments and then with score. Predictions are written before computing the two-sided slow-intercept targets. Interpret phase averaging only on the stated supported centers. Run verify_stage.py to verify this local snapshot.

For a compact scientific release, the equations, designs, results, source scripts, portable score JSONs and checks are the useful pieces. The phase-average forecasts are small; bulky local integration restart packets, private path receipts and machine-specific photon provenance need not be published. This note is not a push or visibility change.

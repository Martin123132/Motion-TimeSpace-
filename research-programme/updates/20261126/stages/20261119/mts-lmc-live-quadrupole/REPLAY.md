# Reproduce locally, one numerical process at a time

Inputs are the existing six [Vasiliev simulations, v1](https://doi.org/10.5281/zenodo.8015660), retained wave–Poisson backgrounds, and prior signed sky comparisons, via the sibling stages named in quad_io.py. No redownload, halo fit, GitHub access, or GPU is needed. Python 3.13, NumPy/SciPy, Windows MSVC for the small projection library. Use python -B from this stage and do not write into an earlier checkpoint. Sealed packets are write-once; use a separate working copy for an alternate build.

1. build.cmd compiles source_quadrupole.cpp using the previous stage’s pinned radial interpolation and angular recurrence. incident.py check is independent Cartesian quadrature. analytic.py tests a translated tesseral quadratic of known complex phase, the uniform-acceleration null, and the exact response to a constant complex drive switched on at rest. incident.py all 192 24 28 16 generates complex incident shells on 193 radii through l=24, 28-point knot-split quadrature and 16 time samples per archived shape interval. The native satellite l≤6 bank is never changed.
2. spatial.py 64 0 1 produces the primary force-enriched Hermitian mode spaces for the two archived grounds. spatial.py 88 0 1 adds independent ordinary radial orbitals, spatial.py 64 2 3 enlarges the wave boundary from 30 to 40 ground lengths. Outputs retain the full-mesh static Gram separately from the reduced propagator.
3. quad_evolve.py CASE 64 192 24 28 16 1 24 16 propagates both preparations (zero or equilibrium/slope for the *remaining* modes). Use its labelled score rows; the inherited already-counted terms stay fixed. For time, shell radius and incident degree controls on cases 0/1, replace the last three arguments with respectively 1 24 8, 2 24 16, 1 16 16. Use the corresponding 88-orbital or larger domain operators for the spatial controls. Scores are in 10⁻¹⁰ m/s²; states contain complex displacement/velocity with the first mode at index zero. recovery/ compares the tracked mode with the old workflow, not merely two sizes of the new calculation. azimuth/ lists predicted wave changes separately, not a fabricated azimuthal measurement.
4. forcing_bound.py CASE 64 192 24 28 16 bounds the incident energy on the **whole finite m=2 mesh** after removing the lowest mode. joint_budget.py CASE combines the entire m=2 and fixed-number m=0 source ceilings using both saved incident banks. These work upper bounds are not fits; their dual-norm calculations include unresolved propagated modes. Run for cases 0 and 1. See DERIVATION.md and JOINT-TEST.md.
5. independent.py shell 192 24 28 16 checks unsampled source times/radii; independent.py CASE 64 192 24 28 16 tests six complex normal modes against an adaptive ODE integration. compare_runs.py collects spatial/temporal sensitivity. verify_quad.py seal writes the stage seal; verify_quad.py independently re-reads files and replay inputs and verifies it. All numerical libraries use one thread. No servers or scheduled computations.

For the angular-completeness challenge, run build_complete.cmd and complete_angular.py bank, then complete_angular.py CASE for cases 0 and 1. This second library allows degree 70 with 96 aligned-frame azimuths; recompute both incident sectors on 129 radii, eight time subdivisions and 48 quadrature points per satellite-knot split. full_shell_controls.py compares the resulting complete angular vectors with a direct 192 × 384 Cartesian sky integration. The highest required incident degrees follow from the actual angular product of the stationary ground and trial wave, rather than an arbitrary numerical cutoff. For the coarse angular-complete time test (four subdivisions), archive intervals still coincide with polynomial block boundaries. Compare complete-angular-test tables with the saved witnesses from the primary joint budget, not by reoptimizing witnesses after seeing the challenge.

Run force_ledger.py before verification to prepare the unified component-by-component sky ledger. It decomposes the total separately for every hemisphere, foreground and history without replacing the prior files.

The original observational gates and the 2e-5 accuracy target have different meanings. A source interpolation or boundary variation that exceeds 2e-5 relative to a small wave is reported as such; it does not by itself change a signed force decision. Conversely, getting the same band outcome on two meshes does not show that a small signal is accurate to 2e-5 in infinite space.

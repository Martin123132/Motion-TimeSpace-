# Reproduce locally

From this directory, the read-only `python -B verify.py` checks the sealed outputs, parent files, numerical control rows and unchanged force bands. Running that file directly matters: several independent older stages also have modules named verify. DERIVATION.md defines units, signs, equal-and-opposite exchange and the frame choices. Inputs stay under their original sibling stage paths.

For regeneration use a fresh sibling directory with the same source files, retained Python 3.13/NumPy/SciPy, the retained predecessor libraries, and one numerical thread. No downloads or fitting. Build the independent gas-ring evaluator with build.cmd in the MSVC x64 build environment. Do not overwrite the previous sealed stages. In order, each of these is a Python script run with `-B`:
1. ordinary_measure.py: use argument pairs `8 1`, `6 1`, `8 2`. material_drive.py combines the component measures and previously archived incident banks; drive files keep complex x−iy physical accelerations.
2. coupled.py: use each case 0 and 1 with substeps 16 and 8. The three cases of physics (prescribed origin, one-way extended centre, reciprocal extended centre) use the same ground and source bank. state files store kpc, km/s and (km/s)²/kpc. The native mode amplitudes and scaled sky are also included. For the targeted time refinement run time_midpoints.py, then coupled.py with `0 32` and `1 32`; these two runs select only L2M11.
3. virtual_force.py and then angular_readout.py perform independent extended-body work/projection comparisons. direct_gas.py takes `base all` and `fine all` for the direct full-azimuth gas checks at the present epoch, using the archived radial satellite coefficients/derivatives and positions, not fitted external forces.
4. recoil_kernel.py, then assess.py collect transfer functions, signed timings, direct force differences and source-error bounds. Coupled kernels accept a correction to the *ordinary* acceleration expressed in the same planar axes. An extra external wave correction would require a different input operator. The observer projections are at the actual retained azimuth. Do not sum mutually exclusive acceleration-reference choices.
5. Remove only this build's intermediate object, export and import-library files, leaving the local DLL for replay. In a fresh directory `verify.py seal` records the inventory, and `verify.py` verifies it again. Reproducibility across different compiler/library versions is numerical rather than a guarantee of identical executable bytes. No network, GUI, publication or persistent worker is needed.

# Local reproduction

The immutable inputs are the sibling LMC tidal-history release (seal starts 531ea26b) and its finite-bar and rotating-bar parents. Reuse its six Vasiliev full-potential histories, coordinates and direct site forces. No downloads, GPU, fitter or changed satellite mass are required. Run from this stage with the retained Python environment, NumPy/SciPy and the previous stages' dependencies. Use Python -B; source scripts restrict numerical libraries to one thread. Use a separate directory for a different compiler/numerical library build rather than replacing sealed outputs.

1. On Windows with the retained MSVC 2022 build tools, build_shell.cmd compiles shell_projection.cpp. shell_bank.py all 192 32 32 8 and shell_bank.py all 320 40 36 16 construct the two independent shell banks (radial intervals, highest Galactic degree, quadrature nodes per split, time subdivisions per archived shape). Check angular-source-controls, analytic-checks and off-snapshot-field-check. In this construction the relative orbit and original coefficient knots are never changed by the refinement.
2. axis_operator.py KEEP 0 1 builds both backgrounds. Ordinary radial bases used 48, 80 and 112 low radial orbitals per angular channel. Negative KEEP adds full-space, source-independent force adjoints to |KEEP| ordinary orbitals, before imposing the fixed-number tangent constraint; the tested values are -64 and -100. Adjoint samples at inverse-time scales 0, 1, 4, 12 use the explicitly sign-definite shifted response equations (real representation of imaginary frequency), not satellite or observational target fits. Case IDs 2 and 3 repeat the corresponding inner foregrounds with a larger outer box.
3. axis_response.py CASE KEEP RES ELL NQ SUB VIA evolves all six histories. Main output uses -100 320 40 36 16 16. Filenames retain the control settings; the stdout force pair is the **last** preparation evaluated, so use the explicitly labelled rows, not stdout, to select the zero-start prediction. In the state packets x and y are coefficients of the *mass-weighted radial* field; delta_rho_multipoles is the dimensionless density without its mass/length conversion. The sky_time columns are (radial, polar, spherical radial) for each northern probe.
4. static_control.py solves the full fixed-number, zero-frequency spatial problem. stationary_replay.py differentiates the independently iterated nonlinear stationary solution. axis_density.py separates density multipoles, incident angular sources, enclosed mass/flux. lookback.py partitions the **linear amplitude** by lookback; actions cannot be added that way. axis_requirement.py derives four-readout lower bounds and verifies its dual and reconstructed fields. These readout inequalities are diagnostics, not an external source to feed back into the model.
5. score_summary.py, budget_axis.py, refinement_budget.py and edge_audit.py collect the retained tests. Verification and restart instructions accompany the final results. Inherited angular/radial source inputs and numerical tolerances have not been recalibrated to the measurements.

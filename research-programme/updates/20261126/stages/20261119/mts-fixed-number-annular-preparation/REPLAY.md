# Private reproduction
Use the existing local Python with NumPy and SciPy. Run in this stage directory with python -B (one numerical thread). No external data, other chat or server is needed.

1. prepare.py 0 and prepare.py 1 each reconstruct the foreground corridor, calculate the full spatial susceptibility, and solve the finite stationary number and outer-force constraints. Repeat with 2 and 3 for the larger domain. The inner and outer ring masses/potentials come from the existing annular source routine evaluated on the actual wave mesh.
2. test_skies.py 0 1 2 3 checks the preserved signed histories in the original units, computes the any-monotone-schedule support certificates, and tests NFW under both normalization conventions.
3. rate_test.py 0 1 and ramp_controls.py test the duration-dependent preparations and apply exactly the same fixed stellar endpoints to NFW. The benchmark does not calibrate any coefficients to the inner force bands.
4. checks.py verifies the parent seal, calibration inequalities, independent physical wave-density quadrature, source/control comparisons, basis and domain tests, analytic oscillator and full input and output inventory. checks.py seal writes the first inventory in a fresh copy. Numerical writers are create-only; a replay stops if an existing result would change.

Use native/ for final CSVs and states. Top-level numerical files are retained exploratory smooth-readout controls, not authoritative arbitrary-field certificates. For the two primary cases, stationary-*.csv records mass/number and residuals, forces-*.csv splits ordinary and wave changes, radial-profile-*.csv gives actual mass transport, ramp-states-*.csv gives the time-resolved source preparation at its endpoint, and history-envelopes-*.csv gives the allowed linear component ranges. For any claimed upper bound, the multiplier and unconstrained comparator are in monotone-support-*.csv. The energy-witness rows use only the frozen constraints, not a selected best fit.

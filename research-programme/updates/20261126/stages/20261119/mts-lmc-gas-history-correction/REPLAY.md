# Local replay

Run `python -B verify_gas.py` here to check the final inventory and primary controls without starting new orbits or editing previous stages. Python 3.13, NumPy, SciPy and the same installed parent dependencies are used; all numerical workers run single-threaded. This stage does not build a new native binary. It uses the previous sealed gas-ring and harmonic-projection libraries. The originals remain in their directories.

For regeneration in a fresh sibling directory, use the code and documents here and the same sibling stages. Run these files with Python -B:
1. compact.py for pilot/reference/extra source tests, then gas_history.py with the six orbit names `L2M10 L2M10first L2M11 L3M10 L3M10rad L3M11 midpoints`. The last name selects only the extra L2M11 half-steps. Previous direct gas results, original incident-field coordinates and refined midpoint profiles are reused. New direct-force packets save every 128 samples; a complete matching packet is reused rather than overwritten.
2. spatial_controls.py checks the compressed spatial integral and analytic controls. between_epochs.py with the same **six orbit names only** saves predictions before testing new physical times. The frozen CSV digest is carried in every result row. No observational holdout is implied.
3. propagate_gas.py with the six orbit names applies the response to both grounds, both gas components, the same static baseline and both observing conventions. The old field evolution isn't rerun. history_budget.py frames the enclosed impulse and nested time errors; terminal_check.py checks the solution with a different final-time integration and physical spatial moments.
4. tidal_contrasts.py and tidal_figure.py make the frame-invariant force diagnostics. source_energy.py computes the phase-free source-energy challenge. It reads the original Galerkin mapping, but does not re-evolve the baseline, tune a parameter, or assume the actual lower-space energy bounds all high modes. The quadrupole parent's angular-complete tables cite the witness directions from the **16-substep construction**, including their alternate-sampling ceilings; reproduce both prior supports from the saved Gram matrices before adding m=1.
5. verify_gas.py seal only to make the first inventory in a fresh copy, and verify_gas.py without arguments thereafter. No network, fitting, or permanent process is needed.

Authoritative inputs: mts-lmc-ordinary-centre-recoil-20261119 (kernels, gas geometry, old forces, modes, static NFW comparison), mts-lmc-differential-centroid-20261119 (incident bank, eigenfunctions), mts-lmc-live-quadrupole-20261119 (joint support witnesses), mts-lmc-tidal-history-20261119 (six Vasiliev archives), plus the earlier retained Gaia Figure 9 band and preparation files reached by their pinned dependencies. See RESULTS.md for the scientific scope. No other repo receives these local results.

# Local replay

Read [the frozen design](DESIGN.md) and [results](RESULTS.md). One numerical thread, Python 3.13 with NumPy, SciPy and SymPy, run with assertions enabled and -B. No external packages need to be fetched on the retained installation. Use this stage's own directory as working directory; no jobs, services, downloads or subagents are needed. Generated tables are compared byte-for-byte if they already exist rather than overwritten.

1. Run `python -B response.py` for the analytic finite measure. `python -B direct.py 0`, `python -B direct.py 1`, `python -B direct.py 2` change the determinant and gauge action directly. Run `python -B precision.py` next, retaining the failed coarse differences. Each configuration is a separate small job if resource-limited.
2. `python -B real_measure.py` uses real fields, explicit orbit summation before the logarithm and finite local gauge transformations. `python -B ward_controls.py` checks both longitudinal legs, Bose interchange and the removal of contact terms. `python -B flavor.py` independently builds spatially nonuniform full four-dimensional color matrices and tests the light–strange factorization.
3. `python -B maxwell.py` and `python -B improved.py` derive and directly measure the two false Maxwell readings, their matched subtraction, and the local improved source. `python -B transport.py` carries the change to the same fully reweighted two-flavor fixture using both analytic covariance transport and independently changed finite actions.
4. `python -B check.py` compares the independent evaluations and the two pinned projection banks. `python -B verify.py` validates inputs, table schemas/counts, checks, local links and the file seal. The first seal is written by `python -B verify.py --seal` only after original runs, using create-or-compare semantics. The code does not touch earlier stages.
5. In `direct-*.csv` and `precision-*.csv`, “direct” is the closed plane-wave partial derivative of the finite orbit measure, not experimental data. The per-configuration entries resolve contributions to the normalized orbit derivative. `real-partition.csv` is a direct derivative of the explicit translated log partition, not the mean of its logarithms. All magnitudes in fixture readouts are per-site in lattice units unless explicitly stated otherwise.

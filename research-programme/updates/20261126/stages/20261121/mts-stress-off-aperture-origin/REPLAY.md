# Local files and replay

Additional fine-grid sensitivity gates: `python -B sampling_phases.py 1` and `python -B sampling_phases.py -1` evaluate all three coarse observation phases and full-grid interpolation alternatives. For the independent [centre bound](CENTRE-BOUND.md), run `python -B central_bound.py GRID SIGN` for 320, 640 and 960 on each sign after the trajectories have completed. These read the saved packets only. The original forecasts are never refrozen with these observations.
All inputs are the earlier [sealed formation and stress counterfactual](../mts-conserved-stress-intervention/RESULTS.md) or its existing preparation/clock parents. The additional 320 and 960 evolutions use the same numerical Python environment (NumPy, SciPy, SymPy) and the same compiled dependencies as the retained solver. The local scripts configure numerical libraries for one thread. From this directory:

1. Run `python -B aperture_origin.py` for the signed energy, true ruler and extrinsic-curvature budget. Each contribution is in ppm of the *narrow* original Newton signal, including the original wide band after rescaling. The density operator is only defined without an exterior assumption for the narrow-minus-wide difference.
2. Run `python -B current_projection.py`, then `python -B scalar_limit.py` and `python -B outer_current.py`. These read only the saved original 320/640 trajectories. They use the actual material current, independent high-precision constraint reader and the same homogeneous reference for both signs. The compact three-window test does not replace the original two. `two-window-current.csv` retains the single unresolved exterior moment rather than assigning it zero.
3. Positive refinement: `python -B finer_grid.py freeze`, then `python -B finer_grid.py 0` (wave), `python -B finer_grid.py 1` (cold), and `python -B finer_grid.py grade`. Negative replication: `python -B negative_mesh.py all`. Completed packets are not re-evolved when replayed. A packet without a matching receipt is a reason to investigate, not permission to overwrite a state.
4. For the separate measurement audit run `python -B ruler_sampling.py GRID SIGN` and `python -B crossed_sampling.py GRID SIGN` for (640,+1), (640,−1), (960,+1). These resample identical stored fields, not the dynamics. `point` samples coarse cell centres. `conservative` interpolates the integral of the fine profile at coarse faces and differentiates the reconstructed primitive; equal face differences preserve coarse cell averages before resampling to fine centres. These are sensitivity tests, not replacements for the published observations. The negative 960 route tests the original full moving-distance readout; no resampling stress test on that route is implied.
5. Run `python -B grid_budget.py` and `python -B verify.py`. Neither verification nor replay writes to the source bank or the Galaxy repository. Completed output files reject mismatched contents. The finer-mesh forecasts have separate receipts tied to their programs and inputs. No new observed astronomical data are used.

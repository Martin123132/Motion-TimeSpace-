# Private replay and scope

Use the retained Python 3.13 with NumPy, SciPy, requests and h5py. Set BLAS/OpenMP thread counts to one, run in this folder with bytecode disabled, and leave protected processes alone. The old stellar seal and its own predecessors are checked by the import chain. Use existing numeric packets before considering another download. The snapshot catalogues are public FIRE-2 data; all MTS inputs and products remain local. Dataset selection is an engineering test, not a new observational holdout.

1. The eight receipts in `gas/` identify every source URL, remote identity, raw field and packet hash. Only when rebuilding the data in a separate location, `read_gas.py` takes an explicit future ISO-8601 cutoff less than four hours away. It reads selected HDF ranges rather than full snapshots. Do not remove packet receipts to force a retry.
2. Run `controls.py`, `ancestry.py`, then `material_exchange_bounds.py` for the conservative carrier assignment, two minimum-exchange choices, end-source potentials and sharp independent scalar bounds. `metric_clock.py` checks the clock operator; `operator_control.py` checks the tangent/transpose against central differences at a predecessor source.
3. `wave_exchange.py` constructs the mass response of the five wave readouts and advances both preparations on each specified source. `uncertainty.py`, `travel_floor.py`, `hidden_exchange.py` and `live_clock.py` give separately labelled conditional locality, transport, retention and launch-feedback checks. Files report proper lengths in kpc, time in Myr, masses in solar masses, accelerations in m/s² and dimensionless clock-rate contrasts unless column labels say otherwise.
4. `catalog_links.py` accepts the same kind of cutoff and skips completed pointer packets. Native gas ID hashes are matched to the acquisition receipts before computing catalogue indices. Pointer receipts (not bundled here) record the identity, full data-column hash and count for each official table. Only selected witness pairs are cached locally; verification of the provider's full column from source requires the original remote bytes. `catalog_result.py` applies the more restrictive identity rule, repeats the mass bounds and runs the two wave preparations at both 16 and 32 time subdivisions.
5. Run `return_provenance.py` for the sharp amount of stellar return into final gas, the explicit missing birth witness, the tighter wave-only tangent limits, and direct nonlinear checks of the clock-specific extremal plans. These are not the same plans as the ordinary-clock extrema.
6. `python -B validate_exchange.py --seal` reconstructs the checks and compares the complete manifest if present. Local outputs are immutable on replay in the same numerical environment; to try a different assumption, use a new stage. The large local packets contain material from the cited simulation and are not proposed for distribution. No service or scheduler is required.

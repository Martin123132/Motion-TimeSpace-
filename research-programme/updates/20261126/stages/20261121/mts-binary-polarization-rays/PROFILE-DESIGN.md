# Bounded real-data check, frozen before opening the target profile

The MeerTime MSP Census catalogue lists J1537+1155 (B1534+12), six observations. Spiewak et al., DOI 10.1017/pasa.2022.19, released a summed full-Stokes profile per pulsar, Zenodo 5347875 v1 (CC BY 4.0). Acquire only the published CSV and 11.17 MB compressed profile archive transiently; retain the single target profile, catalogue row and hashes. Never infer six phase-labelled observations from a single sum. Do not treat the catalogue timing precision as a polarization splitting uncertainty.

If FITS headers confirm calibrated Stokes I,Q,U,V, one subintegration and eight bands, independently apply channel scale/offset/weights, preserve channel ordering, and measure pulse-shape response only. At trial linear eigenbasis angle χ relative to the stored Stokes axes use Qχ=Q cos(2χ)+U sin(2χ), p±=(I±Qχ)/2. The total with opposite shifts ±δ/2 is I−δ Qχ'/2 at first order, whereas a common offset gives −I'. Test actual profile shifts versus this derivative, both coefficient signs and multiple angles; δ in pulse turns, no conversion to absolute arrival time without the spin period. No assumption that p± correspond to intrinsic emission states or that any χ is the true on-sky eigenbasis.

Freeze harmonic cutoffs 8,16,32 before examining the shapes. In each available frequency channel separately project the trial derivative orthogonally to a constant, amplitude and common phase shift; allow separate nuisances per channel. Normalize each block by the norm of its own retained I derivative. Compute minimum and maximum residual response over χ from the two-column Gram matrix, averaging equal-weight valid channels and checking lower versus upper band halves. These are shape diagnostics, not noise-weighted Fisher information, an independent baseline template, TOAs, or a likelihood. Reproduce made-up achromatic shifts with different shapes held fixed as an implementation check only. Do not choose harmonic cutoff, angle, structure, or coupling to optimize any observed residual.

# Reproduce the helicity replacement and the two-charge test

Local Python 3.13.13, NumPy 2.4.6, SciPy 1.17.1, PyMuPDF 1.28.0 for optional acquisition. Use one thread (OPENBLAS_NUM_THREADS=1, OMP_NUM_THREADS=1, MKL_NUM_THREADS=1). From this directory:

1. Optional: `python -B digitize.py` reads the two versioned arXiv PDFs into memory and checks their exact hashes; `--prefix` can point to a local prefix followed by the arXiv identifiers and .pdf. Checks vector paths, axes, color and existing CSV bytes before reuse. Seven small numeric tables supplied; no network needed for the steps below. [Dai & Pennington v2](https://arxiv.org/abs/1404.7524v2), Figs. 2, 3, 16; PDF SHA-256 `181bb0619921c12105f3ec83f059375fb3d4eb1b5494f992ae652847a819cd94`. [García-Martín & Moussallam v1](https://arxiv.org/abs/1006.5373v1), Fig. 6, lower axis; PDF SHA-256 `df6cb335ea2e599857572cc79360cd354922655c7954467ef7a8047834414663`. The signed dispersion equation is not digitized from a modulus plot.
2. `python -B compare.py` generates both signed isospin amplitudes, the alternative source and sign reversals, separate cut/subtraction choices, all frozen predictions, per-bin and per-aperture phase bounds. Directly retains original like-helicity bin powers and checks the old opposite-helicity Born integrals. The dispersion bank spacing is 0.5 MeV; rerunning bin integration with 1 MeV bank spacing and fewer integration nodes changes individual opposite-helicity predictions/envelopes by at most 0.00030 nb per unit absolute cosine. Exactly reproducing the tabulated input is not evidence it is physically precise.
3. `python -B joint.py` verifies the correlated 7% label in the original [Mark II v1 table](https://doi.org/10.17182/hepdata.22881.v1/t2); produces the normalization/positivity comparisons and 54 phase-floor combinations. Neutral inputs are [Belle v1](https://doi.org/10.17182/hepdata.50151.v1), Tables 1–4. Data are already included and sealed in the older source stages. No published normalization shift is applied to the central model.
4. `python -B matched_gravity.py` calculates the three finite-transfer kernels, compares independent combinations of the raw integrals, reproduces the preceding central and pointwise-only bounds and carries the previously omitted normalization into the bounds. Same on-shell cut convention as [Bellazzini et al.](https://arxiv.org/abs/2108.05896) and the retained matching equations (not bundled here).
5. `python -B validate.py` tests the direct Born/angular projection, isospin, both upper-rim signs, independent Cauchy-weighted evaluation near the pole (including near-neighbor panels), higher quadrature order, the new spacelike/timelike Omnès transform against direct integrals, the two different plotted moduli, all aperture sums, the phase-free counterexample cell and the file manifest. The larger phase-free floor exceeding one deterministic box is not a p-value. Do not use optimized Python. The optional `--seal` creates a manifest **only if absent**; subsequent replays use no flag.

The S-wave stage and its upstream signed and angular inputs are hash-verified on import. No free local coefficient, arbitrary phase, charge ratio, experimental normalization or photon amplitude has been tuned to reduce the reported central residuals. Profiling the common scale is a separate declared diagnostic.

The source for the time refinement is the [previous verified stage](../mts-stress-off-aperture-origin/RESULTS.md), seal 5d2e26333f2fa05e9a8497ce3e95b1930ec3d21f4c204e2ae85ae0055806c87e. The clock and physical design SHA-256 values are respectively 76b5b4630a54b063b0e70c3b752b91d190a2ddecbe0cb60788f1adafd1b60d46 and 674ea3c6c8356b965c7a80957e2df169c56723176954ac00bf8d3678d9be05ff. The frozen negative and positive half-step evolutions have already finished. Do not restart workers to inspect this stage.

With the installed Python 3.13, NumPy, SciPy and SymPy, from this folder the following operations replay existing states without evolving either formation again. The numerical environment is constrained to a single numerical thread per worker; never run more than two workers. Retain -B.

1. `python -B time_scores.py` regenerates or byte-compares the late and full signed tables. `python -B verify_clock.py` decodes all 80 stress-withdrawn packets, reconstructs the detectors from the fields and verifies raw constraints, 4 bitwise replays and inherited-versus-local clock shifts.
2. `python -B transfer.py score` compares the 16 unmodified physical states to their stress-withdrawn partners. `python -B source_normalization.py` checks strip and unbounded degeneracy controls before computing intervals. This does not optimize the theory coefficients.
3. `python -B clock_phase.py`, `python -B maxwell_dual.py`, `python -B maxwell_energy.py`, `python -B maxwell_stress_source.py`, and `python -B maxwell_vector_onset.py` replay the analytical controls. The finite packets here are algebraic/Fourier weak-field calculations and do not modify the cosmological histories.
4. `python -B verify_stage.py seal` reconstructs the native-source observations and compares raw constraints, checks native/withdrawn spherical equivalence, recalculates the coupled source decisions and separate-normalization bounds, checks all data-table counts and local links, and checks the file manifest byte for byte if it exists. Its seal covers the full stage, including both sets of numerical packets. The original form uses an older module also named transfer; the verifier loads this stage's scoring file by explicit path, without changing either solver.

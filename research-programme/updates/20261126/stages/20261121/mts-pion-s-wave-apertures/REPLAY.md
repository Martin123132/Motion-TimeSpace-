# Offline replay and source provenance

The four small digitized tables are supplied. Nothing needs to be downloaded for the physics checks. Run from this directory with Python 3.13.13, NumPy 2.4.6 and SciPy 1.17.1, one numerical thread, bytecode writes disabled. Do not run optimized Python: the controls use assertions. On Windows set OPENBLAS_NUM_THREADS, OMP_NUM_THREADS and MKL_NUM_THREADS to 1. The complete order is:

1. Optional acquisition replay: `python -B extract.py --pdf <path-to-arXiv-1404.7524v2.pdf>` with PyMuPDF 1.28.0; without the PDF argument it requests the [versioned paper](https://arxiv.org/pdf/1404.7524v2). SHA-256 of PDF: `181bb0619921c12105f3ec83f059375fb3d4eb1b5494f992ae652847a819cd94`. The extractor checks vector axes, marker positions, figure captions and the exact four saved tables. Argand grid 0.30–0.90 GeV, 25 MeV for I=0 and 100 MeV for I=2, bounded interpolation only. The second figure independently checks normalization, not exposure or uncertainty.
2. `python -B angular_test.py` — reads the verified predecessor inputs, compares five frozen wave choices, writes the aperture decomposition, rate floors, bin-level and S-independent contrasts. No missing systematic is filled as a measured error. The largest alternative interpolation effect on the substituted prediction is 0.11234 nb per unit absolute cosine; energy quadrature refinement changes it by <0.000001 in the same units. The fixed isoscalar D is unchanged under direct full-range projection to <2.8e-15.
3. `python -B spin_bound.py` — overlap and full-bin count logic, summed-charge moment bounds, algebraic witnesses on all original bins. Checked 16 versus 24 energy nodes per smooth panel, with 48 versus 72 angular nodes per bin. The small positive margin for the negative-sign witness is checked as a residual, not relative to the much larger total rate. No replacement of the pion stress.
4. `python -B neutral_cone.py` — deterministic positivity and error-box comparisons for all ten Belle W bins. Checks synthetic controls and constructs actual complex nuisance moments for each reported upper bound.
5. `python -B verify.py` — independently recomputes the reference integral with the former direct signed integration, verifies curvature and angular projection controls, the stored dual weights and primal rates without invoking the optimizer, and checks every local file against the seal. `--seal` is for initial creation only; it refuses to replace an existing seal. Later reruns should not use it.

[Mark II angular input](https://doi.org/10.17182/hepdata.22881.v1/t2) and [Belle neutral input](https://doi.org/10.17182/hepdata.50151.v1) Tables 1–4 are the pinned local JSON files described in the input conventions (not bundled here). [The S-wave source](https://doi.org/10.1103/PhysRevD.90.036004) discusses the experimental input and normalization treatment on pp. 24–26 (arXiv PDF page numbering); these are not independent holdouts. No source normalization shifts are applied here. The signed D and pion stress (not bundled here) and [previous inelastic work](../mts-six-pion-rescattering/RESULTS.md) remain external fixed inputs, not rerun to tune these waves. The import verifies the three previous stage manifests and their listed files before use. This local packet does not alter those files, the astrophysical comparison or the published repo.

# Private replay

Use the existing Python 3.13 environment (NumPy, SciPy, h5py, requests). All nested source imports are the retained local project; do not substitute public release-law snapshots for these frozen local states. All scripts are single-process. Set OPENBLAS_NUM_THREADS, MKL_NUM_THREADS and OMP_NUM_THREADS to 1 before starting, and use Python's -B switch. No new fit, upload, simulation or entire snapshot download is needed. Leave existing seal, original banks and their tolerances unchanged.

1. The 24 local species receipts in inputs/ give precise per-piece URLs, ETags, lengths, acquisition bytes, SHA-256 hashes, headers, scale factors, centres and full particle counts. Adjacent snapshot files contain only grouped masses/counts and aperture positions/masses; only 590 also contains aperture velocities. IDs are not needed; no cross-epoch individual-particle matching is asserted. Do **not** re-fetch verified packets. Only if rebuilding inputs separately, acquire.py takes a future explicit UTC cutoff within four hours and re-verifies existing completed receipts.
2. Run particle_readout.py for steps 32 and 64 and snapshots 589, 590, 591 (two positional integer arguments per call). It checks the retained archive on entry. Run compare.py, drift_control.py and analytic_controls.py; then density_slopes.py, virial.py and reservoir.py, in that order. Each output writer compares to existing saved bytes rather than silently replacing them. Pin the same numerical environment for byte-identical replay.
3. Run exterior_exchange.py to test the actual exterior supply, separate regional weighting from true net mass change, and compare the distinct conditional conserving input. Run verify.py for receipt, coverage, identity and convergence checks. An existing seal.json can be checked by recomputing the SHA-256 of every relative path it contains. Use verify.py --seal for the complete manifest check including documentation. This verifies the numerical artifacts, not a fitted galaxy or a measured Milky Way velocity field.

Source: the publicly available [FIRE-2 releases](https://flathub.flatironinstitute.org/fire), [Wetzel et al. DR1, especially the snapshot units](https://arxiv.org/abs/2202.06969), and [Wetzel et al. DR2](https://arxiv.org/abs/2508.06608). The simulation is m12i_res7100 from the core suite. Aperture coordinates are proper distances from the corresponding catalog centre. The comparison uses the same *fixed terminal disk axis* for all epochs, not a rotating frame. Peculiar velocities are raw velocities times sqrt(a); subtract the catalog peculiar centre velocity and add H times proper displacement for the proper-frame drift. The separate centre-trajectory control uses the nonuniform three-epoch derivative of the stored comoving centre. The factor 977.7922216807892 converts kpc/Myr to km/s. Cosmological a,h,Omega_m,Omega_Lambda come from the actual simulation, not an MTS cosmological fit.

## Reverse the response to bound an unknown field

The tangent is **real** linear. Use the real mass inner product \((u,v)=\Re u^\dagger v\). The quadrature-weighted reciprocity of \(\mathcal P\) gives \(S_z^\top v=\mathcal P[\Re(m^*v)]z\). For any real extra lapse on the space-time quadrature grid the fractional response pairs the source \(-ihQ m\) with \(d_j\); explicitly the dimensional kernel is
\[
 G_{jr\mu}=A_* h\,w_r w_\mu\Im[d_j(r,\mu)^*m(r,\mu)].
\]
For both arms use the same ground-state reference quadrature probability \(\pi\) to remove spatially constant forcing before integration: \(Q^\circ=Q-\sum\pi Q\), equivalent to \(G^\circ=G-\pi\sum G\) per time slice. This fixes the phase convention and avoids interpreting midpoint phase discretization as a response to a uniform clock offset. The finite archive's chemical rotation, ordinary potential zero and \(V^2/2\) term are unchanged. Independent smooth forward tests check the factors, sign and normalization of \(G\); this is not just differentiating an output table.

For \(Q_c=Q_{\rm mean}+\Delta Q/2,\ Q_r=Q_{\rm mean}-\Delta Q/2\), the *matched* wave response is \( (G_c-G_r)Q_{\rm mean}+(G_c+G_r)\Delta Q/2\). For arbitrary shared values of half-range at most \(q\) on each time slice the sharp grid gain is \(q\sum|G_c-G_r|\): choose a sign pattern and then subtract the common constant. Sum over time and/or angles **before** taking absolute values if the unknown field is static and/or radial. With independent unit half-ranges in both arms the gain is \(\sum|G_c|+\sum|G_r|\). These are conditional worst cases on the finite grid, not evidence that a galaxy can generate such alternating profiles. A change to an unknown metric can also have a *direct* effect on an observable; the differential-lapse bounds here concern only its **induced wave-state contribution**.

A more physical variant bounds a radial gradient rather than the value on each node. Let \(g_i\) be the angularly summed kernel, \(B_i=\sum_{k\le i}g_k\). Since \(\sum g_i=0\),
\[

 |\delta A|\le \|\partial_y Q\|_\infty\sum_i|B_i|(y_{i+1}-y_i).

Whether such a lapse solves the parent field equations is a separate question. The static bound sums over time first; the time-varying radial bound permits independent slopes at each step.

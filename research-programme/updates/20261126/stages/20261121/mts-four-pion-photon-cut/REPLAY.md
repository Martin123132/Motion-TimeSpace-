# Local reproduction

1. This directory sits beside the sealed four-pion stress and elastic pion directories. Importing sources.py rechecks their pinned manifests and all files those manifests cover. Nothing writes to them.
2. Windows x64: the included project.dll is the single-threaded angular sum built from project.cpp. To rebuild, run build.cmd with the Visual Studio 2022 C++ tools. Python 3.13 with NumPy/SciPy. Set OPENBLAS_NUM_THREADS=1 and OMP_NUM_THREADS=1. No worker, service or scheduler is needed after the foreground program exits.
3. Run `python -B calculate.py` from this folder. Generates checks.json, four-pion.csv, window-nodes.csv and window.csv. Quadratures vary pair masses, two decay angles, relative azimuth and beam direction; at 0.8 GeV the latter and the internal event grids are also changed separately. For the energy integral compare 5 and 8 nodes at fixed underlying grid, then refine that grid at 8 nodes. All probes share F=0.0924 and m=0.1395704 GeV. The ARGUS input is the saved, digest-checked table; no network is used.
4. Run `python -B external_check.py` using the included figure-marker extract for the independent theoretical cross-check. To repeat extraction rather than trusting the extract, obtain the [original TUM thesis](https://users.ph.nat.tum.de/T39/T39_files/T39_people_files/duell_files/Dipl-MultiPion.pdf), SHA-256 in external-points.json, then supply its path with `--pdf` (additional dependency: PyMuPDF). Printed p. 67, Fig. 5.9: calibrate tick positions on both axes, take the midpoint of the lower-series vertical errorbar at each selected energy; do not substitute the upper four-charged curve. These are plotted theory outputs, not experimental points. The code prints fractional differences instead of treating their quoted integration errors as digitization or model uncertainties.
5. For integrity run `python -B verify.py`. Toolchain versions may produce tiny floating-point differences; a digest mismatch is not a measured discrepancy. Current checks and prior manifests refer to this computer's saved artifacts. Rebuilding the DLL can change binary metadata even when the numerical results agree.

# Freeze: reverse the flow, not the mass
Run only on the two archived neutral wave preparations at snapshot 590, without adjusting the host, gauge, occupation, sampling, light path labels, or ordinary source. These are conditional states in a simulated environment, not two observed galaxies. Test the one-slice outputs, not reversal of the subsequent cosmological history.

In a real spatial basis with no imposed gauge vector, conjugation leaves density and integrated number invariant and negates Im(psi* grad psi), where * means complex conjugation. With the original isolated boundary prescription the Newtonian potential and force are even. The initial potential rate from continuity and the transverse shift from momentum are odd. Predict the same Newton term and minus each saved current term in each of three links and their 2:2:-1 combination. The absolute clock rate including all sources does NOT have to reverse. An arbitrary uniform phase (0.71 radians) must do nothing; a real standing state must have zero current despite nonzero density, and the empty state must contribute neither. The standing state is an algebraic control, not an alternative fit or an equal-mass preparation.

Freeze numerical predictions from the original order-12 file before transforming either state. For parity use max absolute error divided by the corresponding nonzero reference field/term scale (per column and arm across links), with threshold 1e-9; for the almost cancelling three-link Newton term use the component-link scale. Use that same forward scale for vanishing current controls. Check both native-evolution and flux methods. For physical occupation and density test the input states as well as the resulting potentials. Record nonzero wave-on and current controls; no passing score from an all-zero pipeline.

Independent test: use freely falling clocks and integrate the null and timelike Hamiltonians, without using the analytic echo summation. Isolate the term linear in current in a metric with phi=psi=u Vdot/c^3, g0i=B_i/c^3 (u=ct measured in kpc). At launch the induced spatial metric is flat in this isolated coefficient test. Shoot both signs of the metric perturbation at artificial factors 2e7 and 1e7, extract its derivative at zero by centered differences. These factors improve numerical resolution; they are not physical parameters. Predict agreement within 0.5% for EACH of the three nonzero link coefficients and the combined coefficient in both preparations, at both factors. Record any failure before reinterpretation. GR with identical sources is a matched control, not a competing prediction. No fitting or observation has been used to choose flow direction.

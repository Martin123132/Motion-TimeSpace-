# Reading and reproducing this checkpoint
With the project's Python 3.13, use python -B verify.py to re-read the frozen predictions, source hashes, verdicts and both manifests. That is read-only and needs only the standard library. The previous stage is mts-fire-geodesic-echo-20261121 (sibling); its 76-file receipt checks the earlier clocks, the baryonic-only controls and GR comparisons. The freeze included all 71 existing source-stage files before that stage's documents/manifest were added.

The numerical sequence was freeze.py, parity.py, current_rays.py, then the separately declared PHASE-CONTROL.md and phase_control.py. Use -B and one thread. parity.py intentionally exits nonzero because the original uniform-phase control failed; it saves the numerical receipt before that check. It does not modify the inputs. The verifier returning success means the recorded passes AND failures are reproduced, not that all numerical controls passed. Run numerical replays into a private copy with the same sibling tree; do not overwrite retained results. The runs use NumPy, SciPy and, for the high-precision phase follow-up, mpmath. The unit-gain ray answer is obtained from differences between opposite amplified coefficients, for resolution only. No external data, account, uploads, remote agents or open workers are required.

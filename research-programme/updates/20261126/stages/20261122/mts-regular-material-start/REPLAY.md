# Replaying the private regular start

Use the original Windows Python 3.13 environment, modified CAMB library and pinned parent workspaces. Each numerical script sets one BLAS/OpenMP thread, checks inherited holds, and writes only identical or new results. Do not run Python with assertions disabled. Capture helpers create a temporary private build directory, verify/remove their own temporary compiler drive, then exit. The linear readouts are already saved.

1. Inputs (already present): run `py -3.13 -B capture_early.py`, followed by `early_polar.py`, `output_control.py` and `material_control.py` in the same way. For each of cold and heavy run `early_source.py MODEL`, `incident_early.py MODEL`, and `radiation_terms.py MODEL`. There are 38 mode batches per model, not 38 model fits.
2. Run `origin.py` for corrected initial packets, then `clock_check.py`. Retained unversioned origins/flight files are rejected diagnostic records. To reconstruct their sign error for a forensic replay, reverse **only** the signs on the ordered ql,qr Hessian weights in the two phi products of Q in a separate scratch copy. Never use rejected packets as default inputs.
3. Evolve `py -3.13 -B regular_flow.py MODEL STEP NU_LIMIT TRACE PH_LIMIT [SCHEME] [THERMAL]`. Adopted: `MODEL 1 18 0 6 radau 1`. Controls: same with step 2, trace 1 or thermal 0 changed one at a time. The saved SDIRK checks use step 1,2,4 at 18/6 and step 1 at 12/4, thermal 0. Each call includes all three starts and both primordial amplitudes. Physical matter variables are in the restart; numerical log-time scaling is not part of the stored physics.
4. Run `spectral_start.py MODEL` (ray projection and spectral-source integration), then `spectral_gravity.py`, `compare.py` and `seal_stage.py --verify`. None require network, fits, or public actions. Endpoints, full time comparisons, failures and thermal closure tests are separate. The seal checks files for corruption; it is not what proves the equations.

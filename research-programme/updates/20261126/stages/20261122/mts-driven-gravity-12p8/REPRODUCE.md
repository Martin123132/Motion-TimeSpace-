# Reproducing this private continuation

All calculation scripts use the retained Python 3.13 environment and numerical libraries of the preceding checkpoint. Start in this directory. Each numerical worker is one-threaded. No network fetches or public repository actions are required; the pre-existing local Boltzmann engine, scalar backgrounds and sealed parent packets must be present. The native reader temporarily loads the original private compiler. The inherited owner holds and this directory's STOP-REQUESTED file are checked at batch boundaries. Do not start a second copy of an already running batch.

1. Run native12.py, sources12.py, angular12.py and common12.py in that order. This includes all 782 exact incident wave numbers, independent output wave numbers and both free-curvature choices. The common prediction is saved before constructing finite-momentum answers. Run contrast12.py freeze to lock the early-only nuisance coefficients.
2. For each MODEL (cold or heavy), run exact12.py MODEL -52 25 4, then joint12.py MODEL 4 for the coarse raw check. Run exact12.py MODEL -50 25 4, then joint12.py MODEL 2, cross12.py MODEL 2 and quality12.py MODEL 2. These are the deliberately retained mixed-incoming-grid results. Run contrast12.py frozen and contrast12.py 39 once for both backgrounds.
3. Run carrier12.py. For each MODEL run refined12.py MODEL pack -52 25 2, refined12.py MODEL gravity 2, refined12.py MODEL verify 2. These use a direct finer-time replay of first-order incident states, while continuing the original accumulated quadratic state. Run native_precision12.py and native_flight12.py. Run artifact12.py MODEL to predict the original transfer-grid artifact rather than subtract a fitted residual.
4. For each MODEL run odd12.py MODEL to fill the interlaced fine nodes, then refined12.py MODEL gravity 1 and refined12.py MODEL verify 1. The even-node and odd-node outputs use the same source, new grid and original quadratic histories. A per-node lagStart keeps the unchanged old low moments and the earlier-sourced upper moments; the common wave and spectral shape are stored separately.
5. Run finish12.py, reflection12.py MODEL (both models), contrast_quality12.py and acoustic12.py. The last script only reads a homogeneous optical-opacity history outside the new window, not the old long-window potential to be predicted. Matched-microscopic-join files independently reconstruct the actual seam for *every* momentum from the old and new drivers; quality12's matched-even packet field source_join retains the corresponding raw replay diagnostic, not a substitute for this comparison.
6. Run verify12.py --seal after the frozen documentation is present. verify12.py enforces the primary thermal, gravity, source, time, angle and characteristic comparisons, while exposing the negative controls and native pointwise/endpoint exceptions as separate rows. Existing products must be byte-identical; never overwrite a divergent earlier run. A clean repeat of an expensive solver on a different compiler/library build may differ in the last bits: use a separate private comparison directory rather than replacing archived files.

Example: invoke each script with `py -3.13 -B` followed by its name and arguments. The two matched-state-*77.npz files are the complete main endpoint packets; the matched-*-q*.npz files hold the continuing incident distributions and logarithmic slopes. Boundary-response-* files are a diagnostic shadow, not interchangeable with the main all-momentum restart.

# Private local replay
Python 3.13, -B, one numerical thread per process; no compiled code added. Use the retained sibling research directories and their verified originals; this is not a stand-alone public distribution. The stored reference files use write-once writers. Do not delete them to bypass a replay mismatch. For exploratory numerical changes make a separate stage copy.

1. hierarchy.py: native heavy and paired cold perturbations, historical chunk maxima and code/background hashes, explicit late radiation. Builds a time grid containing the original dates plus a 65-point log-a panel and a short final derivative stencil. No large redshift extrapolation or interpolation between z99 and z10.
2. fetch_controls.py: acquire only missing IDs, positions and velocities at snapshot 001. Checks earlier range identity including ETag/time/length, source URL and epoch for each shard, imposes a 100 MB cap per shard, saves local receipts. Existing complete, hash-matched packets need no network. The 34,436 gas particles come from four fixed native chunk regions per shard, every eighth particle in each. Do not treat these as an unbiased whole-host census or infer gas occupation from them.
3. evolve.py then project.py: integrated reduced equations, source/launch switches; prepare and evaluate the common random modes from the verified original seed. project.py's phase-band packet extends the source to 5/Mpc only for native screened modes. No modes beyond that are assigned parent support by this test. The previous broad result through 2.4/Mpc is reproduced at launch for the original realization.
4. particle_test.py: all 5.51 million coarse IDs, the original native lattice forward prediction on the unrefined mask, two masks and the independent out-of-band leakage control. The mean gas/dark same-cell residual is descriptive only (three coincident pairs). Raw and foreground-controlled band errors are different comparisons. Actual sample positions and velocities are kept; there is no fitted factor to align amplitudes.
5. relative_transport.py and nonlinear_sources.py: source-isolated relative equations and comparison to final evolved state; two-grid instantaneous product checks. The latter are not a second-order time integration.
6. verify_stage.py: reports source accounting, independent checks and the file manifest, without starting another worker.

No other chat, repository, scheduler or user application was changed. No public update. All stage-owned fetches and numerical workers terminate on completion; no background service is needed. Dataset and code provenance: adjacent stages' seals, the four local retrieval receipts, [FIRE-2 DR2](https://arxiv.org/abs/2508.06608), and [MUSIC](https://arxiv.org/abs/1103.6031).

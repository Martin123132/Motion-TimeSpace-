# Reproduce from private pinned inputs

Use the original Python 3.13, NumPy and SciPy environment. Each numerical command is a single threaded local calculation with bytecode disabled. There is no external data download. Model names are cold and heavy; run each where MODEL appears. Do not replace older saved files.

1. Reconstruct the material forward state on both original gravity routes with `py -3.13 -B material_overlap.py`. Every sixteenth output is checked against the pinned previous Radau calculation. The phase-space transport reads that forward solution; no endpoint potential is integrated backwards as input.
2. For each model and stride 1 and 2 run `packets.py MODEL STRIDE base`. Node ID n means q=2^(n/4). Use `packets.py MODEL 2 -52 25 1` for the primary and finer grids; extra lower/upper tail controls are -64:-52:2 and 26:29:2 (Python exclusive end). Stride 1 uses -52:25:4. Each packet contains the direct geodesic source difference, incident low moments/slopes and the full first-order angular endpoint. Already-computed packets are checked and skipped by the packet job.
3. `transport.py cold 2 0.00625 1` is the archived initial standalone diagnostic. Use `coupled.py MODEL 0` and `coupled.py MODEL 1` for the two coupled routes; `balance.py MODEL 2` for the independent integrated divergences; `ward.py MODEL` and `ward.py MODEL --dense` for the predicted gravity subtraction.
4. `accuracy.py MODEL derivative` and `accuracy.py MODEL integration` test microscopic derivatives, the zero-mass limit, cadence, initial lag, momentum resolution and tails. `native_overlap.py` compares the integrated first-order densities and fluxes with the independently captured native outputs. `leading.py MODEL` uses the algebraic tangent (no true-q inputs); `score.py MODEL` then compares its frozen file with the resolved solution. `fine_grid.py MODEL` provides the 77-node restart and comparison. No observer or hidden fit parameter sets a coefficient.
5. `retarded.py` checks the physical driven overlap and the deliberately unforced long-distance reflection control. `contrast.py`, `contrast_controls.py` and `contrast_refine.py` evaluate primordial-amplitude degeneracies and separately controlled numerical variants. The certificates and failure tables remain machine-readable.
6. `audit.py --verify` rechecks the release gates, outputs and SHA-256 hashes. Primary restart is `fine-MODEL.npz`: physical common material state, integrated massless angular moments, 77 true-momentum normal distributions at the endpoint, and both forced and nonzero primordial-control columns. The associated first-order full input-leg endpoints live in `kin-MODEL-s2-qNODE.npz` for each node. Thermal range is finite, and no missing higher angular modes have been assumed to remain zero throughout the gap.

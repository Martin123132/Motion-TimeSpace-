# Evolving the wave and both gravitational potentials, on the same phases

The retained wave's second-order response is not identical to the fixed-curvature response. The surrounding source matters more than integration step size in this experiment. We did not use a galaxy or a stream to choose that source. This is a radiation-era calculation, separate from the Pal 5 lifetime and release-time result (not bundled here).

Evolved both original backgrounds, 513 native times over eight carrier cycles, five preselected output wavevectors, all signed long/short pairs reaching each. All percentages below are norms of *differences*, divided by the reference norm over complex probes and saved times (not a cosmological RMS or a componentwise percentage). Per-probe values (not bundled here) · [absolute reference scales and comparisons](evidence-001.zip) (archive member: `all-comparisons.csv`) · [derivation and physical assumptions](DERIVATION.md).

- Heavy wave: holding the spatial curvature fixed changes the canonical second-order field by **0.840%** relative to the conditional responsive calculation; fixing the whole metric changes it by **0.979%**. A scalar-only normal-density/current constraint changes it by **75.2%**, but imposes a different exterior and metric launch. These are changes in a perturbation, not in the background field or a local force measurement.
- Calculating curvature two ways — gravitational trace propagation versus evolving total energy and current — gives **0.0478%** disagreement on the heavy bank, but **1.153%** on the cold bank. The cold branch fails the same 0.5% test. Reconstructing first-order total sources consistently from the interpolated metric closes the same comparison to **0.000038% heavy / 0.001003% cold**. That control enforces linear identities, not second-order agreement. It changes the actual predicted lapse by **0.220% heavy / 2.64% cold** relative to the original trace solution; do not call this a precision fix.
- An independent held-out-wavenumber diagnostic explains the caution: on half grids direct cold first-order trace interpolation misses held-out values by 0.44–0.47%; deriving it from the interpolated potentials misses by 18–19%. Those numbers measure deliberate thinning, not known errors on the full grid. Curvature consistency by itself does not establish accurate matter inputs. All original native outputs and sourcing retained.
- With original forcing, halving the evolution step changes the heavy field norm by 0.00149%; coarsening the saved time sources changes it by 0.0070% (worst probe 0.126%). The lapse is much less sensitive to the angular and thermal hierarchy refinement than to the source representation. The independent four-metric Ricci trace agrees at all twelve points; zero drive stays zero on all five control branches.
- Sensitivities, not predictions of the missing terms: adding a shear with the shape and amplitude of the saved photon-bulk contribution changes the lapse by **18.9% heavy / 145% cold**. Varying the initial total coordinate density by the size of its own quadratic coordinate correction changes it by **11.8% / 143%**. Both opposite-sign sensitivity pairs superpose. The relative cold response is large in part because the conditional reference lapse is small. These are not upper bounds, priors, or evidence that either source is realized.

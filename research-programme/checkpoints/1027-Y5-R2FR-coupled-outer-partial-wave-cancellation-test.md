# 5011 — coupled outer partial-wave cancellation test

## Purpose

Checkpoint 5008 left a concrete question, not a vague missing-input list: do the `hhh` and `phi phi h` three-particle cuts remove the `J>=4` nonlocal tower of the completed `hh` outer cut?

Checkpoint 5010 gives

```text
D3_plus/kappa^6 = -E[H]/(16384 pi^4).
```

Using `kappa^2=32 pi G`, this becomes the directly comparable normalization

```text
D3_plus/G^3 = -(2/pi) E[H].
```

For `D(z)=sum_J (2J+1)d_J P_J(z)`, the code evaluates

```text
d_J^(3) = -(2/pi) E_[z,phase space][P_J(z) H(z,phase space)].
```

The `phi phi h` kernel is independently reimplemented with Numba and agrees pointwise with checkpoint 5010 to a maximum relative residual of `8.450e-15`. This permits high-statistics randomized Sobol tests without changing the amplitude.

## Result

The pointwise soft-plus estimator does not establish any `J>=4` cancellation. Its multi-seed errors remain uncontrolled, and the large tails are generated by a soft expansion that is non-uniform in the forward region. These mode values are diagnostics, not physical partial-wave estimates.

## 1. Exact CTP projector theorem

Work in one finite, regulated `(k,-k)` pair cell. The corresponding Fock
space contains the joint vacuum `|0_k,0_-k>`. Define

```text
P0=|0,0><0,0|,
P1=I-P0.
```

Then

```text
P0^2=P0=P0^dagger,
P1^2=P1=P1^dagger,
P0P1=P1P0=0,
P0+P1=I.
```

For every positive trace-one density operator `rho`,

```text
W0=Tr(rho P0)>=0,
W1=Tr(rho P1)>=0,
W0+W1=1.
```

The executable verifies these identities directly and repeats the positivity
test on 128 deterministic random positive density matrices. This is not a
Monte Carlo proof; the random trials guard the implementation while the
operator identities provide the proof.

The finite-cell qualification matters. An infinite product of vacuum
probabilities can vanish in the continuum or thermodynamic limit. A local
occupation field must therefore be defined per regulated/coarse-grained cell,
not by silently using a global Fock-vacuum probability.

## 2. Exact squeezed-pair projective map

For `0<=r<1`, the normalized two-mode squeezed state has geometric number
probabilities

```text
p_m=(1-r)r^m.
```

The probability of the vacuum block is `p_0=1-r`; the probability of the
orthogonal occupied block is

```text
sum_(m>=1) p_m=r.
```

Because the mean occupation of either mode is

```text
Nbar=sum_m m p_m=r/(1-r),
```

the exact binary probabilities are

```text
W0=1/(1+Nbar),
W1=Nbar/(1+Nbar).
```

Equivalently, the unnormalised projective weights are `1` and `Nbar`. If
their odds scale as

```text
ln(W1/W0)=q(u-u0),
```

the logistic equation follows identically. No Landau cubic or quartic
potential is needed.

This construction is kinematic. Checkpoints 4949, 5156 and 5178 show that a
Gaussian CTP action permits occupation/squeezing data but does not select
them. Selection would have to come from a derived preparation history or an
initial-boundary functional `Gamma_rho0`.

The pure squeezed state also retains coherence between number sectors. A
binary classical state is obtained only when the theory restricts to the
algebra generated by `P0,P1`, performs the corresponding measurement, or
derives physical dephasing. This is why the metric test is not optional.

## 3. Three inequivalent metrics

For fixed orthogonal density matrices `rho0,rho1`, let

```text
rho(n)=(1-n)rho0+n rho1.
```

The relative-entropy/Bogoliubov metric on the two block weights is

```text

 =d^2/dn^2[n ln n+(1-n)ln(1-n)]
 =1/[n(1-n)].
```

This is the checkpoint-5199 Fisher metric.

The full squeezed geometric distribution `p_m=(1-n)n^m` contains more
number-resolution information:

```text

 =sum_m p_m (d ln p_m/dn)^2
 =1/[n(1-n)^2].
```

Coarse-graining all `m>=1` outcomes into `P1` reduces it to the binary metric,
as required by information monotonicity.

The known bulk Gaussian 2PI term has a different origin. Split a fixed total
positive covariance into

```text

```

The Euclidean log-determinant shape is


```text

```

The equality equation `g_bulk=g_boundary` reduces to

```text

```

The match at the single symmetric point `n=1/2` therefore cannot establish a
global metric identity.

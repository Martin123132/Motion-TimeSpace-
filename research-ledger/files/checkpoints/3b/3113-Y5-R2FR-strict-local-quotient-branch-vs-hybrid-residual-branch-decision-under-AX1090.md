## Martin Fork Heuristic

These are not axioms and they do not override data. They are private navigation rules for forks where a familiar GR slogan appears to reject a branch too quickly.

1. Do not reject a branch merely because a parent-time or flow-time variable behaves opposite to public GR time dilation. First ask which time is operational clock time, which is internal evolution time, and which is an affine/null limiting parameter.
2. Keep tested SR/GR public clock predictions fixed inside the local quotient. If the parent interpretation changes public clock rates, it must face clock, muon, GPS, Ives-Stilwell, and PPN constraints immediately.
3. Treat "space and time are not two things" as a warning against separating spatial traversal from temporal readout too early. The quotient map may be where paradoxes are resolved.
4. Treat the photon/no-proper-time issue as a possible quotient-degeneracy/null-limit theorem target, not as a slogan.
5. A branch that reverses an intuition but preserves all public observables is worth investigating. A branch that reverses public observables without a compensating readout map is not.
6. Gravity-as-climbing-gear is a useful metaphor for local frame/readout mapping: the question is how the public clock and ruler are attached to the parent flow, not whether local GR tests can be ignored.

This means future derivations should check frame/readout/quotient mismatch before declaring "wrong because GR says the sign goes the other way." It also means no local clock claim is allowed unless the public observable agrees with existing tests.

## Newton Constant Note

GR does not derive the numerical value of Newton's constant; it uses `G` as an empirically measured coupling. Newtonian mechanics also treats the gravitational constant as measured, not derived from first principles.

For MTS, deriving the numerical value of `G` would be a major bonus, but it is not required for the first local-GR reduction. The required first target is weaker and sharper:

```text
same parent quotient coefficient -> EH coefficient 1/(16*pi*G_eff)
same parent quotient coefficient -> matter source coupling
same G_eff -> Cavendish/Newton/orbital/PPN local readouts
```

If that coefficient lock is proved, MTS reduces to calibrated GR locally. If a deeper derivation later fixes `G_eff` from parent microstructure, that becomes an upgrade rather than a blocker for the GR-limit proof.

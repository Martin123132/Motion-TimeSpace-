## Theorem

Let the physical metric boundary datum be:

```text
z_metric := [g_pub, e_pub, mu_obs]|S / (Diff(S) x SO(1,3)_S).
```

If the exterior public geometry is invariant under an `SO(3)` action and `S` is an orbit sphere, then every tangent direction on `S` is generated by a rotational Killing field `K`.

The condition is:

```text
Lie_K z_metric = 0
```

for all `K in so(3)` tangent to `S`.

Therefore:

```text
P_phys d_S z_metric = 0
```

and hence:

```text
B_metric_multipole_tidal = 0.
```

This is the precise version of “spherical monopole has no tangential physical boundary drift.”

## What Does Not Follow

The theorem requires exact symmetry. It does not follow from the word “vacuum.”

Vacuum exterior geometry can still carry:

- quadrupole and higher mass multipoles;
- external tidal fields;
- spin/frame-dragging current multipoles;
- non-spherical binding or shape corrections;
- residual public-metric boundary terms.

So the false shortcut:

```text
vacuum exterior => B_metric = 0
```

is rejected.

The true route is:

```text
exact SO(3) monopole symmetry => B_metric = 0
```

or:

```text
B_metric <= B_mass_multipoles
          + B_external_tide
          + B_spin_frame_drag
          + B_shape_binding
          + B_res_metric.
```

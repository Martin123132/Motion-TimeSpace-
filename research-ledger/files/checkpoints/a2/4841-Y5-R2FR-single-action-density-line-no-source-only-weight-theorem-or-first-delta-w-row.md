```text
w_A = w_common (1 + epsilon_A)
delta_w_species = P_perp_common_mode epsilon_A
```

```text
JH_DqZ_injection = (P_source_delta_w + P_DqZ_delta_w) delta_w_species
density_qbasic_feed = P_density delta_w_species + JH_DqZ_injection
```

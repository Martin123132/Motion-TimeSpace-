# 3520 - Quotient Action Principle Derives q Normal Form Or Finite Source Bounds

## Summary
- **Derivation win:** the 3519 q normal form is derivable from a quotient action principle.
- **Coupling lock:** a direct term like `Integral mu C_qT q_private T` is not invariant under representative changes, so `C_qT=0` follows if `q_private` is truly representative-only and the source stress is q-basic.
- **Weyl lock:** `q_private` dependence is killed by quotient invariance; a one-Weyl scalar also needs a forbidden spurion/readout object unless it is a separate physical operator.
- **Honest limit:** QAP does not by itself prove full local GR, because q-basic hidden sectors can still induce `R2`, `f(R)`, `Weyl2`, or nonlocal operators after elimination.
- **Current status:** exact conditional theorem built; parent ownership of the equivalence relation/qmap/action descent is not signed, so finite bounds remain active.

## Core Proof
Let `pi: Conf_parent -> Conf_phys` quotient representative changes generated by `v_q`. The quotient action principle is

`S_parent = pi^* S_phys + dB_basic + S_constraint`,

with the constraint and boundary pieces first-class/proper on the local branch. For a vertical `v_q`, `Dpi[v_q]=0`, so every pulled-back physical bulk term has zero vertical variation.

For any direct source operator

`S_direct = Integral mu f(q_private) O_basic`,

where `mu` and `O_basic` are quotient-basic,

`L_vq S_direct = Integral mu f'(q_private) L_vq(q_private) O_basic`.

For arbitrary local `O_basic` and nonzero representative motion `L_vq(q_private)`, quotient invariance forces `f'=0`. For `f=C q_private`, this gives `C=0`. The only escape is to promote `q_private` to a physical scalar, which immediately removes the vertical theorem route and requires finite bounds.

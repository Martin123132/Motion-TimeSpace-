# 2301 - Y5/R2FR q First-Class Removal Or Ricci/Weyl Source-Vector Split

## Verdict

2301 tries the clean route first: remove q as a first-class/constraint variable. That would kill the source vector without fitting. Current result: not signed. The canonical package still lacks parent Omega, momentum map, bracket closure, degree count, matter descent, and boundary/source neutrality.

The fallback derivation step is now sharp: `B_qR curvature` splits into `B_qRic` and `B_qWeyl`. Ricci/Einstein-sector mixing might become LHS-owned after positivity/diagonalization. Weyl/tidal mixing is dangerous because it survives in local vacuum. There is a possible exact kill: if q is scalar/quotient or first-class absent with no Weyl spurion, linear Weyl mixing is forbidden. That certificate is the next target.
